End-to-end FPGA Agent

Plain-English spec in. Verified RTL and a bitstream out.

Built and measured on a Digilent Nexys A7-100T (Artix-7). Next: AMD Kria KR260 and ZedBoard (Zynq-7000).

An open-source agent that designs hardware for AMD FPGAs. Describe a block in plain English and it asks about what you left out, writes the design and its tests, and builds it with Vivado. Only checks it did not write can pass its work.

What it does

The agent follows the stages of AMD's UltraFast methodology: an interview to settle what the spec leaves open, a plan, the RTL and its tests, then Vivado {{board.vivado}} through synthesis and place and route to a bitstream. The runs shown here used Anthropic's Claude Sonnet ({{dev.model.0}}) through Claude Code.

How it is checked

A model that writes a design and its tests can make the same mistake in both. So the agent's own tests never decide. Each task has hidden tests, written in advance against an independent model of the spec and themselves checked by mutation testing. Timing must be met after routing, and the board has the last word.

What has been shown so far

On {{dev.tasks}} development tasks the agent passed every hidden test in {{dev.hidden_pass}} of {{dev.runs}} runs. In {{dev.escapes}} more its own checks passed and the hidden tests failed, each time because it read the spec differently from the test author. The fixes made since are not yet measured.

Development tasks are the ones used to find faults, so these figures are a record of the work, not a score. The score will come from held-out tasks; the first attempt was stopped before any result was analysed. A hand-built reference design passes all its tests on the board, but no agent-built design has been on one yet.
