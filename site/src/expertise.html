Areas of expertise

FPGA design draws on many specialisms, from clock crossings to memory controllers. This page takes them one at a time and says, for each, what the agent knows, what its flow checks on every run, what has been measured and what is not yet shown.

Each area is a drawer. It opens with a few plain sentences, then the measurements with a link to the file each comes from, then the gaps. The lists behind it (the skills the agent can load, the checks in the flow, and where AMD's advice differs between device families) sit in a Details section inside the drawer, closed until you want them.

How far the evidence goes

Each area carries one of four levels, the highest that its committed results support. An area is "shown in agent runs" only when the agent's own development runs exercised it, and development runs are never the held-out score.
