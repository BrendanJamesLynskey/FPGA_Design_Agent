There is no held-out score yet. What this page has is every development run: the runs used to find and fix the agent's faults. They show how it works and fails, not how it will do on tasks it has never seen.

Held-out evaluation

The agent at tag eval-1 was to run {{eval.runs_per_task}} times on each of {{eval.tasks}} tasks it had never seen. That evaluation was stopped before any result was analysed. It could not finish in time, and the owner chose to grow the benchmark (more tasks, boards and application areas) and improve the agent first. An automatic update of Claude Code partway through had also blocked nine runs, since the agent refuses to run on an untested version. Nothing from it is reported; the stop is recorded in the pre-registration. A baseline evaluation on the larger benchmark comes next, with a new tag and pre-registration, by the same method.
