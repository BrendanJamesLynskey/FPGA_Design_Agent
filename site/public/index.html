Open agent, measured

Plain English spec in. Verified RTL and a bitstream out, for a Nexys A7-100T.

The FPGA Design Agent interviews you about a spec, plans the design, writes the RTL and its checks, builds it with Vivado 2025.2, and stops at independent gates. Only checks it did not write count as a pass: a blind golden model, mutation testing, the post-route reports, and the board.

13 of 21

development runs passed every hidden test (11 development tasks, claude-sonnet-5-5). Development, not the held-out score

6 of 21

runs were escapes: every check the agent ran passed, and the hidden tests still failed. The run records class all 6 as spec interpretation, not logic errors. The changes made in response have not been measured yet; eval-1 measures them.

8 of 8

UART tests and 4 of 4 logic-analyser captures passed on the board, in all 3 bring-up runs, for the hand-built reference design. No agent-built design from the development runs has been on a board yet.
