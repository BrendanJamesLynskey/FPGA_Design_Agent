The agent at tag eval-1 on 19 tasks it never saw during development, 3 runs each. The method is on the evaluation page.

Development tasks

Development tasks, not the held-out score 21 runs on 11 development tasks, claude-sonnet-5-5, 2026-11-06 to 2026-11-09. The agent was changed between runs to fix what these runs exposed, so this is a record of the work, not a measure of how it will do on new tasks.

What happened in each run

Escapes by the check that should have caught them

Each escape was a spec the agent read differently from the hidden tests (a pin named differently, an unasked register layout). The changes made in response went to the interview, the agent's own checks and, where a task's text was found to leave a behaviour unstated, to that task (dated, before eval-1 was frozen). Whether they help is measured by eval-1, not claimed here.
