Problems / D. Cryptography and security

NTT engine behind the test shell

c16_ntt_engine Course tier course part 16 D Cryptography and security Nexys A7-100T

The problem

An engine for the number-theoretic transform used in the post-quantum key-exchange standard ML-KEM. It holds a polynomial of many coefficients, and transforms it forwards or backwards in place, with all arithmetic modulo a small prime. It avoids divide and remainder operators, stays within a clock limit and reports how long each transform took.

Where it is used. The transform makes polynomial multiplication fast in lattice-based cryptography, and is the heaviest step in post-quantum key exchange and signature schemes. Hardware engines speed it up for servers and embedded devices.

Adapted from a project in the owner's FPGA design course (the course itself is private).

The spec the agent is given

NTT engine behind the test shell

I want a block for the Nexys A7-100T's FPGA that computes the "number-theoretic transform" used in the post-quantum key-exchange standard FIPS 203 (ML-KEM), forwards and backwards, on a polynomial of 256 coefficients, and I want to exercise it entirely from the test shell.

  • Every coefficient is a whole number from 0 to 3328 (arithmetic is modulo q = 3329). The transform is exactly the one in FIPS 203: "NTT" is algorithm 9 and "NTT inverse" is algorithm 10, including the final multiplication by 3303 at the end of the inverse.
  • The block holds the 256 coefficients itself. I load them over the shell while the block is idle, two coefficients to a shell write, ask for a forward or an inverse transform with a start command, and read the 256 results back over the shell, two to a read, once the block says it is done. The transform replaces the coefficients (in place).
  • The block must raise a "busy" signal while it works and a "done" flag at the end. A new request will not come while it is busy.
  • Time limit: from the clock that takes the start request to the clock before the "done" pulse it must take no more than 1,200 clocks for either direction, and I can read back how many clocks the last transform took. Use no divide operators and no remainder operators (they do not belong in a design for this part), and no floating-point blocks.
  • CPU_RESETN clears busy and done. I will check several transforms exactly: forward ones (a single one, all coefficients 3328, a random one) and an inverse (on a random polynomial). LED0 shows done and LED1 shows busy. The shell runs at 115200 baud on the USB-UART. The design ID is "NTTE".

Test hooks: top module c16_ntt_engine_top, ports named as in the board's master XDC, and the test shell's CLKS_PER_BIT, TIMEOUT_CYCLES and BUILD_STAMP parameters as top-level parameters. There are no other time constants.

Exactly spec.md. Anything it leaves open, the agent has to ask about.

What the hidden tests check

The requirements in the hidden spec, and how each is shown to hold:

  • REQ-01 the forward transform of each tested polynomial equals FIPS 203 algorithm 9 (shown by simulation)
  • REQ-02 the inverse transform of a random polynomial equals FIPS 203 algorithm 10 including the multiplication by 3303 (shown by simulation)
  • REQ-03 a transform takes at most 1200 busy clocks in either direction (shown by simulation)
  • REQ-04 The design closes timing at 100 MHz with no unconstrained path (shown by report analysis)
The full behaviour rules from hidden/spec.yaml

transform

  • q = 3329, zetas = 17^bitrev7(i) mod q. The forward transform is FIPS 203 algorithm 9; the inverse is algorithm 10 including the final multiplication of every coefficient by 3303. The transform replaces the 256 coefficients in place (natural order in and out as in the algorithms).
  • Coefficients are 0..3328; results are 0..3328.

timing

  • BUSY is high for at most 1200 clocks per transform (reference 896 forward, 1152 inverse); CYCLES reports the count. No divide or remainder operators.

access

  • Loads are accepted only while idle. The coefficient pair p is words {c[2p+1], c[2p]}; LD_PTR and RD_PTR count pairs 0..127.

leds

  • LED[0] = DONE, LED[1] = BUSY, the other LEDs are 0.

module c16_ntt_engine_regs (
    input  logic        clk,
    input  logic        rst,
    output logic [15:0] led,
    input  logic [6:0]  win_addr,
    input  logic        win_wr,
    input  logic        win_rd,
    input  logic [31:0] win_wdata,
    output logic [31:0] win_rdata
);
    logic [7:0]  rd_ptr;
    logic [11:0] ld_lo, ld_hi, ld_d, rd_d, plo, phi;
    logic [7:0]  ld_a;
    logic [1:0]  ld_ph;
    logic        ld_en, start, inv, busy, done, dn, rd_ph;
    logic [11:0] cyc;

    assign led = {14'd0, busy, dn};
    logic [6:0] ld_ptr_q;
    assign ld_a = {ld_ptr_q, ld_ph[1]};

    ntt_engine u_core (.clk(clk), .rst_n(!rst), .ld_en(ld_en), .ld_addr(ld_a), .ld_data(ld_d), .start(start), .inverse(inv),
                       .busy(busy), .done(done), .rd_addr({rd_ptr[6:0], rd_ph}), .rd_data(rd_d));

    always_ff @(posedge clk) begin
        start <= 1'b0;
        rd_ph <= ~rd_ph;
        if (rd_ph) phi <= rd_d; else plo <= rd_d;
        if (ld_ph != 2'd0) begin
            ld_ph <= ld_ph + 2'd1;
            if (ld_ph == 2'd1) begin ld_d <= ld_hi; ld_en <= 1'b1; end
            if (ld_ph == 2'd2) begin ld_en <= 1'b0; ld_ph <= 2'd0; ld_ptr_q <= ld_ptr_q + 7'd1; end
        end
        if (busy) cyc <= cyc + 12'd1;
        if (done) dn <= 1'b1;
        if (win_wr) begin
            case (win_addr)
                7'd0: ld_ptr_q <= win_wdata[6:0];
                7'd1: rd_ptr <= win_wdata[7:0];
                7'd2: begin ld_lo <= win_wdata[11:0]; ld_hi <= win_wdata[27:16]; ld_d <= win_wdata[11:0]; ld_en <= 1'b1; ld_ph <= 2'd1; end
                7'd3: begin start <= 1'b1; inv <= 1'b0; dn <= 1'b0; cyc <= 12'd0; end
                7'd4: begin start <= 1'b1; inv <= 1'b1; dn <= 1'b0; cyc <= 12'd0; end
                default: ;
            endcase
        end
        win_rdata <= 32'd0;
        if (win_rd) begin
            case (win_addr)
                7'd0: win_rdata <= {25'd0, ld_ptr_q};
                7'd1: win_rdata <= {24'd0, rd_ptr};
                7'd5: win_rdata <= {30'd0, dn, busy};
                7'd6: begin win_rdata <= {4'd0, phi, 4'd0, plo}; rd_ptr <= rd_ptr + 8'd1; end
                7'd7: win_rdata <= {20'd0, cyc};

        end
    end

// source: solutions/p16l07_ntt/ntt_engine.sv (course file, unchanged below this line)
// Part 16 lesson 7 exercise: an NTT engine for ML-KEM (FIPS 203): 256 coefficients modulo q = 3329, one butterfly per clock, in place. Given: ntt_zetas_pkg.sv (function zeta(k): the table of FIPS 203 appendix A).
//   ld_en with ld_addr / ld_data writes coefficient ld_addr (any time the engine is idle). rd_addr / rd_data is an asynchronous read of coefficient rd_addr (rd_data follows rd_addr within the same clock).
//   start (one clock, only while !busy) with inverse = 0 runs the forward transform (algorithm 9), with inverse = 1 the inverse (algorithm 10, including the final multiplication of every coefficient by 128^-1 = 3303).
//   Forward: 7 layers (len = 128, 64, ..., 2) of 128 butterflies, one per clock = 896 clocks. For layer l (l = 0..6) with len = 128 >> l and G = 1 << l groups of 2*len coefficients: group g = c / len, offset j = c % len
//   (c = the butterfly counter 0..127 of the layer), the pair is (g*2*len + j, g*2*len + j + len) and the twiddle is zeta(G + g)  [k runs 1, 2, 3, ... through the layers].
//   Inverse: 7 layers (len = 2, 4, ..., 128) of 128 butterflies with G = 128 / len groups and twiddle zeta(2*G - 1 - g) [k runs 127, 126, ... down to 1], then 256 clocks multiplying coefficient i by 3303: 896 + 256 = 1152 clocks.
//   Butterfly, forward: t = zeta * f[hi] mod q; f[hi] = f[lo] - t; f[lo] = f[lo] + t.  Inverse: t = f[lo]; f[lo] = t + f[hi]; f[hi] = zeta * (f[hi] - t).  All mod q, with Barrett reduction (no % operator).
//   busy is high from the clock after start for exactly 896 (forward) or 1152 (inverse) clocks; done is high for exactly one clock after the last. rst_n is synchronous, active low, clears busy and done only.
module ntt_engine (
    input  logic        clk,
    input  logic        rst_n,
    input  logic        ld_en,
    input  logic [7:0]  ld_addr,
    input  logic [11:0] ld_data,
    input  logic        start,
    input  logic        inverse,
    output logic        busy,
    output logic        done,
    input  logic [7:0]  rd_addr,
    output logic [11:0] rd_data
);
    import ntt_zetas_pkg::*;
    localparam int Q = 3329;
    logic [11:0] mem [0:255];
    logic        inv_r, scaling;
    logic [2:0]  layer;                    // 0..6
    logic [6:0]  c;                        // butterfly counter in the layer
    logic [7:0]  sc;                       // scaling counter
    assign rd_data = mem[rd_addr];

    function automatic logic [11:0] barrett(input logic [23:0] p);
        logic [36:0] m;
        logic [11:0] t;
        logic [23:0] r;
        m = p * 13'd5039;
        t = m[35:24];
        r = p - t * 12'd3329;
        barrett = (r >= Q) ? 12'(r - Q) : r[11:0];
    endfunction
    function automatic logic [11:0] addq(input logic [11:0] u, input logic [11:0] v);
        logic [12:0] s;
        s = u + v;
        addq = (s >= Q) ? 12'(s - Q) : s[11:0];
    endfunction
    function automatic logic [11:0] subq(input logic [11:0] u, input logic [11:0] v);
        subq = (u >= v) ? (u - v) : 12'(u + Q - v);
    endfunction

    // address generation for the current butterfly
    logic [7:0]  len, lo, hi;
    logic [7:0]  g, j;
    logic [7:0]  gcount;
    logic [6:0]  kidx;
    logic [11:0] z, vlo, vhi, tt, nlo, nhi;
    always_comb begin
        len = inv_r ? (8'd2 << layer) : (8'd128 >> layer);
        gcount = 8'd128 / len;
        g = {1'b0, c} / len;
        j = {1'b0, c} % len;
        lo = g * 2 * len + j;
        hi = lo + len;
        kidx = inv_r ? 7'(2 * gcount - 1 - g) : 7'(gcount + g);
        z = zeta(kidx);
        vlo = mem[lo];
        vhi = mem[hi];
        tt = barrett(z * vhi);
        if (!inv_r) begin nlo = addq(vlo, tt); nhi = subq(vlo, tt); end
        else begin nlo = addq(vlo, vhi); nhi = barrett(z * subq(vhi, vlo)); end
    end
    always_ff @(posedge clk) begin
        done <= 1'b0;
        if (ld_en && !busy) mem[ld_addr] <= ld_data;
        if (!rst_n) busy <= 1'b0;
        else if (!busy) begin
            if (start) begin busy <= 1'b1; inv_r <= inverse; layer <= 3'd0; c <= 7'd0; scaling <= 1'b0; sc <= 8'd0; end
        end else if (!scaling) begin
            mem[lo] <= nlo;
            mem[hi] <= nhi;
            if (c == 7'd127) begin
                c <= 7'd0;
                if (layer == 3'd6) begin
                    if (inv_r) scaling <= 1'b1;
                    else begin busy <= 1'b0; done <= 1'b1; end
                end else layer <= layer + 1'b1;
            end else c <= c + 1'b1;
        end else begin
            mem[sc] <= barrett(mem[sc] * 12'd3303);
            sc <= sc + 1'b1;
            if (sc == 8'd255) begin busy <= 1'b0; done <= 1'b1; end
        end
    end
endmodule

"""Acceptance tests of c16_ntt_engine against model.py (hidden from the agent)."""

from __future__ import annotations

import cocotb
from benchmark.lib.bench import Board, peek
from model import (CYCLES, DESIGN_ID, LD_DATA, LD_PTR, RD_DATA, RD_PTR, START_FWD, START_INV, STATUS, bench_cases,
                   intt, ntt)


async def transform(b: Board, name: str, op: str, poly: list[int]) -> None:
    await b.write(LD_PTR, 0)
    for p in range(128):
        await b.write(LD_DATA, poly[2 * p] | poly[2 * p + 1] << 16)
    await b.write(START_INV if op == "inverse" else START_FWD, 1)
    await b.cycles(1250)
    await b.expect(STATUS, 2, f"{name}: DONE and not BUSY")
    cyc = await b.read(CYCLES)
    assert 100 <= cyc <= 1200, f"{name}: BUSY for {cyc} clocks (must be at most 1200)"
    want = (intt if op == "inverse" else ntt)(poly)
    await b.write(RD_PTR, 0)
    for p in range(128):
        got = await b.read(RD_DATA)
        w = want[2 * p] | want[2 * p + 1] << 16
        assert got == w, f"{name}: {op} coefficients {2 * p},{2 * p + 1}: RTL 0x{got:08X}, model 0x{w:08X}"

"""P16-3 model: the number-theoretic transform of ML-KEM (FIPS 203 algorithms 9 and 10, q = 3329, 256 coefficients) and the transforms the block is asked for (standalone: python only)."""
import hashlib
import math
import random
import struct


Q = 3329


def bitrev7(i: int) -> int:
    return int(format(i, "07b")[::-1], 2)


ZETAS = [pow(17, bitrev7(i), Q) for i in range(128)]     # FIPS 203 Appendix A: 1, 1729, 2580, 3289, ...


def ntt(f: list[int]) -> list[int]:
    """FIPS 203 algorithm 9."""
    f = list(f)
    k, ln = 1, 128
    while ln >= 2:
        for start in range(0, 256, 2 * ln):
            z = ZETAS[k]
            k += 1
            for j in range(start, start + ln):
                t = z * f[j + ln] % Q
                f[j + ln] = (f[j] - t) % Q
                f[j] = (f[j] + t) % Q
        ln >>= 1
    return f


def intt(f: list[int]) -> list[int]:
    """FIPS 203 algorithm 10."""
    f = list(f)
    k, ln = 127, 2
    while ln <= 128:
        for start in range(0, 256, 2 * ln):
            z = ZETAS[k]
            k -= 1
            for j in range(start, start + ln):
                t = f[j]
                f[j] = (t + f[j + ln]) % Q
                f[j + ln] = z * (f[j + ln] - t) % Q
        ln <<= 1
    return [x * 3303 % Q for x in f]


def poly_mul_negacyclic(a: list[int], b: list[int]) -> list[int]:
    """Schoolbook product modulo x^256 + 1 (the ring of ML-KEM), the reference for the NTT's purpose."""
    r = [0] * 256
    for i, x in enumerate(a):
        for j, y in enumerate(b):
            k = i + j
            if k < 256:
                r[k] = (r[k] + x * y) % Q
            else:
                r[k - 256] = (r[k - 256] - x * y) % Q
    return r


def basecase_mul(a_hat: list[int], b_hat: list[int]) -> list[int]:
    """FIPS 203 algorithm 11 (MultiplyNTTs): 128 degree-1 products modulo x^2 - zeta^(2 bitrev7(i) + 1)."""
    h = [0] * 256
    for i in range(128):
        g = pow(17, 2 * bitrev7(i) + 1, Q)
        a0, a1, b0, b1 = a_hat[2 * i], a_hat[2 * i + 1], b_hat[2 * i], b_hat[2 * i + 1]
        h[2 * i] = (a0 * b0 + a1 * b1 % Q * g) % Q
        h[2 * i + 1] = (a0 * b1 + a1 * b0) % Q
    return h


def polys():
    rng = random.Random(18)
    return [[0] * 256, [1] + [0] * 255, [Q - 1] * 256, [rng.randrange(Q) for _ in range(256)], [rng.randrange(Q) for _ in range(256)]]


def reference_output():
    cases = []
    for p in polys():
        cases.append({"op": "forward", "input": p, "output": ntt(p), "clocks": 896})
    for p in polys()[3:]:
        cases.append({"op": "inverse", "input": p, "output": intt(p), "clocks": 1152})
    return {"cases": cases}
