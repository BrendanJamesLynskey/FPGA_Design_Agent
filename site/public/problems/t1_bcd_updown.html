Problems / A. Basic digital design drills

Decimal up/down counter with selectable step

t1_bcd_updown Benchmark v1 T1 A Basic digital design drills Nexys A7-100T

The problem

A four-digit decimal counter driven by two push buttons. One button counts up and the other counts down, and each press changes the count by a step that two switches choose. The count wraps round at both ends and the design keeps a tally of how many times it has wrapped. The buttons are debounced so a bounce cannot count twice, and the value shows on the seven-segment display in decimal, on the LEDs in binary, and over the test shell.

Where it is used. Up/down counters with a selectable step turn up in panel meters, production-line tallies, ticket and people counters, and setpoint dials. The debounced button input is needed in almost any product with a mechanical switch.

The spec the agent is given

Decimal up/down counter with selectable step

I want a four-digit decimal counter on the Nexys A7-100T.

  • BTNU counts up and BTND counts down. Each press moves the count by the step chosen on the two right-hand switches: SW[1:0] = 00 gives 1, 01 gives 2, 10 gives 5 and 11 gives 10. The buttons bounce, so one press must move it exactly once.
  • The count runs from 0000 to 9999 and wraps round at both ends (going up past 9999 carries on from the bottom, going down past 0 carries on from the top). I'd like to know how many times it has wrapped.
  • The right-hand four digits of the 7-segment display show the count in decimal, without leading zeros: 7 shows as a single 7, and zero shows as a single 0. The other digits stay dark.
  • LED[13:0] show the count in binary.
  • CPU_RESETN resets everything to zero.
  • Over the test shell (USB-UART, 115200 baud) I can read the count (binary and as BCD digits), set it, read the wrap count, and read the step the switches select. The design ID is "BCDU".

Test hooks: top module t1_bcd_updown_top, ports named as in the board's master XDC, the test shell's CLKS_PER_BIT, TIMEOUT_CYCLES and BUILD_STAMP parameters, plus DEBOUNCE_CYCLES (debounce time in clocks) and REFRESH_BITS (each display digit is lit for 2^REFRESH_BITS clocks) as top-level parameters.

Exactly spec.md. Anything it leaves open, the agent has to ask about.

Interface

Top module t1_bcd_updown_top on the Nexys A7-100T (xc7a100tcsg324-1). Clock: CLK100MHZ at 100 MHz (board oscillator). Reset: CPU_RESETN, active low: COUNT, WRAPS and every other register return to 0; debounced levels return to 0. Resources expected: a few hundred LUTs and FFs; no BRAM, no DSP.

What the hidden tests check

The requirements in the hidden spec, and how each is shown to hold:

  • REQ-01 Up/down presses move COUNT by the selected step modulo 10000 and count wraps (shown by simulation)
  • REQ-02 A button change shorter than the debounce time never counts; holding does not repeat (shown by simulation)
  • REQ-03 The display shows COUNT in decimal with leading zeros blanked, one digit at a time (shown by simulation)
  • REQ-04 The register window has the listed map, reset values and the out-of-range write rule (shown by simulation)
  • REQ-05 The design closes timing at 100 MHz with no unconstrained path (shown by report analysis)
  • REQ-06 On the board the register window answers as the model predicts (shown by on the board)
The full behaviour rules from hidden/spec.yaml

step

  • STEP is 1, 2, 5 or 10 for SW[1:0] = 00, 01, 10, 11 (switches synchronised by two flops, not debounced).

counter

  • COUNT is an integer 0..9999.
  • A press of BTNU sets COUNT to (COUNT + STEP) mod 10000; a press of BTND sets COUNT to (COUNT - STEP) mod 10000.
  • Each time an up or down press wraps (the sum is >= 10000 or the difference is < 0), WRAPS increments by one (8 bits, wraps at 256).
  • If an up press and a down press land on the same clock, neither acts and WRAPS is unchanged.
  • A shell write to COUNT on the same clock as a press wins (the press is lost).

debounce

  • Each button is synchronised (two flops), then debounced. The debounced level changes only after the synchronised input has differed from it for DEBOUNCE_CYCLES consecutive clocks; a shorter difference restarts the count.
  • A press is a 0 -> 1 change of the debounced level; releases do nothing; holding a button does not repeat.

leds

  • LED[13:0] = COUNT in binary; LED[15:14] = 0. No PWM.

display

  • Digits are numbered 0 (rightmost, AN[0]) to 7. They are lit one at a time in order 0..7, each for 2^REFRESH_BITS clocks; while digit k is lit AN[k] = 0 and the other AN = 1.
  • Digits 0..3 show the units, tens, hundreds and thousands of COUNT in decimal.
  • Leading zeros are blank - digit k (k = 1..3) is dark (all AN stay 1 in its slot) when COUNT < 10^k. Digit 0 is always lit (zero shows as 0).
  • Digits 4..7 are always dark. DP is always 1 (off).
  • Glyphs (segments lit): 0 abcdef, 1 bc, 2 abdeg, 3 abcdg, 4 bcfg, 5 acdfg, 6 acdefg, 7 abc, 8 abcdefg, 9 abcdfg; CA..CG active low.

Settled assumptions

  • steps wrap modulo 10000 rather than clamping at the ends. the user asks for wrapping at both ends; modulo keeps each press a fixed step.
  • simultaneous up and down presses cancel. neither direction is preferred in the request.

// bcd_updown.sv: the counter, wrap count, binary-to-BCD converter, LEDs and
// display contents of t1_bcd_updown, behind the shell's register window.
module bcd_updown #(
    parameter int DEBOUNCE_CYCLES = 1_000_000
) (
    input  logic        clk,
    input  logic        rst,
    input  logic        btn_up,
    input  logic        btn_down,
    input  logic [1:0]  sw_async,
    output logic [15:0] led,
    output logic [7:0][6:0] seg_lit,
    output logic [7:0]  blank,
    input  logic [6:0]  win_addr,
    input  logic        win_wr,
    input  logic        win_rd,
    input  logic [31:0] win_wdata,
    output logic [31:0] win_rdata
);
    localparam logic [6:0] R_COUNT = 7'h00, R_BCD = 7'h01, R_WRAPS = 7'h02, R_STEP = 7'h03;

    logic       up_lvl, dn_lvl, p_up, p_dn;
    logic [1:0] sw;
    logic [13:0] count, step;
    logic [7:0]  wraps;
    logic [14:0] sum;
    logic signed [14:0] diff;

    bm_debounce #(.CYCLES(DEBOUNCE_CYCLES)) u_up (.clk(clk), .rst(rst), .d_async(btn_up),   .level(up_lvl), .rise(p_up));
    bm_debounce #(.CYCLES(DEBOUNCE_CYCLES)) u_dn (.clk(clk), .rst(rst), .d_async(btn_down), .level(dn_lvl), .rise(p_dn));
    sync2 #(.WIDTH(2)) u_sw (.clk(clk), .rst(rst), .d(sw_async), .q(sw));

    always_comb begin
        case (sw)
            2'd0: step = 14'd1;
            2'd1: step = 14'd2;
            2'd2: step = 14'd5;
            default: step = 14'd10;
        endcase
    end

    assign sum  = {1'b0, count} + {1'b0, step};
    assign diff = $signed({1'b0, count}) - $signed({1'b0, step});

    wire wr_count = win_wr && win_addr == R_COUNT && win_wdata < 32'd10000;

    always_ff @(posedge clk) begin
        if (rst) begin
            count <= '0;
            wraps <= '0;
        end else begin
            if (wr_count) begin
                count <= win_wdata[13:0];
            end else if (p_up && !p_dn) begin
                if (sum >= 15'd10000) begin
                    count <= 14'(sum - 15'd10000);
                    wraps <= wraps + 1'b1;
                end else begin
                    count <= sum[13:0];
                end
            end else if (p_dn && !p_up) begin
                if (diff < 0) begin
                    count <= 14'(diff + 15'sd10000);
                    wraps <= wraps + 1'b1;
                end else begin
                    count <= diff[13:0];
                end
            end
            if (win_wr && win_addr == R_WRAPS) wraps <= '0;
        end
    end

    // Iterative binary-to-BCD (shift and add 3): one conversion every 15 clocks.
    logic [13:0] sh_bin;
    logic [15:0] sh_bcd, bcd;
    logic [3:0]  sh_n;
    function automatic logic [15:0] add3(input logic [15:0] b);
        for (int i = 0; i < 4; i++)
            if (b[4*i +: 4] >= 4'd5) b[4*i +: 4] = b[4*i +: 4] + 4'd3;
        return b;
    endfunction
    always_ff @(posedge clk) begin
        if (rst) begin
            sh_n <= '0; sh_bin <= '0; sh_bcd <= '0; bcd <= '0;
        end else if (sh_n == 4'd0) begin
            sh_bin <= count; sh_bcd <= '0; sh_n <= 4'd1;
        end else begin
            {sh_bcd, sh_bin} <= {add3(sh_bcd), sh_bin} << 1;
            if (sh_n == 4'd14) begin
                bcd  <= add3(sh_bcd) << 1 | 16'(sh_bin[13]);
                sh_n <= 4'd0;
            end else begin
                sh_n <= sh_n + 1'b1;
            end
        end
    end

    function automatic logic [6:0] glyph(input logic [3:0] d);
        case (d)                       // bit 0 = a ... bit 6 = g, 1 = lit
            4'd0: glyph = 7'b0111111;  4'd1: glyph = 7'b0000110;
            4'd2: glyph = 7'b1011011;  4'd3: glyph = 7'b1001111;
            4'd4: glyph = 7'b1100110;  4'd5: glyph = 7'b1101101;
            4'd6: glyph = 7'b1111101;  4'd7: glyph = 7'b0000111;
            4'd8: glyph = 7'b1111111;  4'd9: glyph = 7'b1101111;
            default: glyph = 7'b0000000;
        endcase
    endfunction

    always_comb begin
        for (int k = 0; k < 8; k++) seg_lit[k] = (k < 4) ? glyph(bcd[4*k +: 4]) : 7'b0;
        blank[0] = 1'b0;
        blank[1] = bcd[15:4] == 12'd0;
        blank[2] = bcd[15:8] == 8'd0;
        blank[3] = bcd[15:12] == 4'd0;
        blank[7:4] = 4'hF;
    end

    assign led = {2'b00, count};

    always_ff @(posedge clk) begin
        if (rst) win_rdata <= '0;
        else if (win_rd) begin
            case (win_addr)
                R_COUNT: win_rdata <= {18'd0, count};
                R_BCD:   win_rdata <= {16'd0, bcd};
                R_WRAPS: win_rdata <= {24'd0, wraps};
                R_STEP:  win_rdata <= {28'd0, step[3:0]};
                default: win_rdata <= '0;
            endcase
        end
    end
endmodule

// bm_debounce.sv: two-flop synchroniser, then a counting debounce. The level
// changes only after the synchronised input has differed from it for CYCLES
// consecutive clocks; a shorter difference restarts the count. rise is a
// one-clock pulse on each 0 -> 1 change of the level.
module bm_debounce #(
    parameter int CYCLES = 1_000_000
) (
    input  logic clk,
    input  logic rst,
    input  logic d_async,
    output logic level,
    output logic rise
);
    localparam int CW = $clog2(CYCLES + 1);
    logic        d;
    logic [CW-1:0] run;

    sync2 u_sync (.clk(clk), .rst(rst), .d(d_async), .q(d));

    always_ff @(posedge clk) begin
        rise <= 1'b0;
        if (rst) begin
            level <= 1'b0;
            run   <= '0;
        end else if (d == level) begin
            run <= '0;
        end else if (run == CW'(CYCLES - 1)) begin
            level <= d;
            run   <= '0;
            rise  <= d;
        end else begin
            run <= run + 1'b1;
        end
    end
endmodule

// bm_scan8.sv: eight-digit multiplexed display. Digit k (0 = rightmost, AN[0])
// is lit for 2^REFRESH_BITS clocks, in order 0..7. While digit k is lit its
// anode is low unless blank[k] is set (then every anode stays high for that
// slot). seg is active-low {g,f,e,d,c,b,a}; dp_n is active low.
module bm_scan8 #(
    parameter int REFRESH_BITS = 17
) (
    input  logic        clk,
    input  logic        rst,
    input  logic        enable,
    input  logic [7:0][6:0] seg_lit,    // per digit k: seg_lit[k]: 1 = segment lit, bit 0 = a
    input  logic [7:0]  blank,
    input  logic [7:0]  dp_lit,
    output logic [7:0]  an,
    output logic [6:0]  seg_n,
    output logic        dp_n
);
    logic [REFRESH_BITS+2:0] t;
    logic [2:0] k;
    assign k = t[REFRESH_BITS+2:REFRESH_BITS];

    always_ff @(posedge clk) begin
        if (rst) begin
            t     <= '0;
            an    <= 8'hFF;
            seg_n <= 7'h7F;
            dp_n  <= 1'b1;
        end else begin
            t     <= t + 1'b1;
            an    <= (enable && !blank[k]) ? ~(8'b1 << k) : 8'hFF;
            seg_n <= ~seg_lit[k];
            dp_n  <= ~dp_lit[k];
        end
    end
endmodule

module t1_bcd_updown_top #(
    parameter int          CLKS_PER_BIT    = 868,
    parameter int          TIMEOUT_CYCLES  = 100_000,
    parameter int          DEBOUNCE_CYCLES = 1_000_000,
    parameter int          REFRESH_BITS    = 17,
    parameter logic [31:0] BUILD_STAMP     = 32'h0
) (
    input  logic        CLK100MHZ,
    input  logic        CPU_RESETN,
    input  logic        BTNU,
    input  logic        BTND,
    input  logic [15:0] SW,
    output logic [15:0] LED,
    output logic        CA, CB, CC, CD, CE, CF, CG, DP,
    output logic [7:0]  AN,
    input  logic        UART_TXD_IN,
    output logic        UART_RXD_OUT
);
    logic        clk, rst, win_wr, win_rd;
    logic [6:0]  win_addr, seg_n;
    logic [31:0] win_wdata, win_rdata;
    logic [7:0][6:0] seg_lit;
    logic [7:0]  blank;

    assign clk = CLK100MHZ;
    reset_sync u_rst (.clk(clk), .rst_n_async(CPU_RESETN), .rst(rst));

    fpga_shell #(.CLKS_PER_BIT(CLKS_PER_BIT), .TIMEOUT_CYCLES(TIMEOUT_CYCLES),
                 .DESIGN_ID(32'h4243_4455), .BUILD_STAMP(BUILD_STAMP)) u_shell (
        .clk(clk), .rst(rst), .uart_rx(UART_TXD_IN), .uart_tx(UART_RXD_OUT),
        .win_addr(win_addr), .win_wr(win_wr), .win_rd(win_rd), .win_wdata(win_wdata), .win_rdata(win_rdata));

    bcd_updown #(.DEBOUNCE_CYCLES(DEBOUNCE_CYCLES)) u_ctr (
        .clk(clk), .rst(rst), .btn_up(BTNU), .btn_down(BTND), .sw_async(SW[1:0]),
        .led(LED), .seg_lit(seg_lit), .blank(blank),
        .win_addr(win_addr), .win_wr(win_wr), .win_rd(win_rd), .win_wdata(win_wdata), .win_rdata(win_rdata));

    bm_scan8 #(.REFRESH_BITS(REFRESH_BITS)) u_scan (
        .clk(clk), .rst(rst), .enable(1'b1), .seg_lit(seg_lit), .blank(blank), .dp_lit(8'h00),
        .an(AN), .seg_n(seg_n), .dp_n(DP));
    assign {CG, CF, CE, CD, CC, CB, CA} = seg_n;
endmodule

"""Acceptance tests of t1_bcd_updown against model.py (hidden from the agent)."""

from __future__ import annotations

import random

import cocotb
from benchmark.lib.bench import Board, peek, scan_display
from model import BCD, COUNT, DESIGN_ID, STEP, WRAPS, Model

IDLE = {"BTNU": 0, "BTND": 0, "SW": 0}


class Env:
    def __init__(self, dut) -> None:
        self.b = Board(dut, IDLE)
        self.dut, self.m = dut, Model()
        self.n = self.b.param("DEBOUNCE_CYCLES")
        self.slot = 1 << self.b.param("REFRESH_BITS")

    async def start(self) -> None:
        await self.b.start()

    async def press(self, btn: str) -> None:
        pin = getattr(self.dut, btn)
        pin.value = 1
        await self.b.cycles(self.n + 6)
        pin.value = 0
        await self.b.cycles(self.n + 6)
        self.m.press(up=btn == "BTNU", down=btn == "BTND")

    async def switches(self, v: int) -> None:
        self.dut.SW.value = v
        await self.b.cycles(4)
        self.m.sw = v

    async def check_regs(self) -> None:
        for off in (COUNT, BCD, WRAPS, STEP):
            await self.b.expect(off, self.m.read(off), ("COUNT", "BCD", "WRAPS", "STEP")[off])

    async def check_display(self) -> None:
        seen = await scan_display(self.dut, self.b.clk, self.slot)
        want = self.m.display()
        assert {k: v[0] for k, v in seen.items()} == want, f"display {seen} != model {want}"
        assert all(v[1] == 1 for v in seen.values()), "DP lit"

    async def check_leds(self) -> None:
        led = await peek(self.b.clk, self.dut.LED)
        assert led == self.m.leds(), f"LED {led:04X} != model {self.m.leds():04X}"

@cocotb.test()
async def test_debounce_rejects_bounce(dut):
    e = Env(dut)
    await e.start()
    pin = dut.BTNU
    for width in (1, 3, e.n // 2, e.n - 3):      # every pulse shorter than the debounce time
        pin.value = 1
        await e.b.cycles(width)
        pin.value = 0
        await e.b.cycles(e.n + 4)
    await e.check_regs()                         # no press yet
    # a bouncy press: chatter then a long steady level counts once
    for w in (2, 5, 3, 7):
        pin.value = 1
        await e.b.cycles(w)
        pin.value = 0
        await e.b.cycles(w)
    pin.value = 1
    await e.b.cycles(4 * e.n)                    # held: no repeat
    pin.value = 0
    await e.b.cycles(e.n + 6)
    e.m.press(up=True)
    await e.check_regs()

async def test_simultaneous_presses_cancel(dut):
    e = Env(dut)
    await e.start()
    await e.b.write(COUNT, 50)
    e.m.write(COUNT, 50)

"""Golden model of t1_bcd_updown, written from spec.yaml alone (never from any RTL)."""

from __future__ import annotations

STEPS = (1, 2, 5, 10)
COUNT, BCD, WRAPS, STEP = 0, 1, 2, 3
DESIGN_ID = 0x42434455
GLYPHS = ("abcdef", "bc", "abdeg", "abcdg", "bcfg", "acdfg", "acdefg", "abc", "abcdefg", "abcdfg")


def seg_pins(lit: str) -> int:
    """Active-low CA..CG, bit 0 = CA."""
    return sum(0 if s in lit else 1 << i for i, s in enumerate("abcdefg"))


class Model:
    def __init__(self) -> None:
        self.count = 0
        self.wraps = 0
        self.sw = 0

    @property
    def step(self) -> int:
        return STEPS[self.sw & 3]

    def press(self, up: bool = False, down: bool = False) -> None:
        if up and down:
            return
        if up:
            n = self.count + self.step
        elif down:
            n = self.count - self.step
        else:
            return
        if n >= 10000 or n < 0:
            self.wraps = (self.wraps + 1) & 0xFF
        self.count = n % 10000

    def read(self, off: int) -> int:
        if off == COUNT:
            return self.count
        if off == BCD:
            return sum(((self.count // 10 ** k) % 10) << (4 * k) for k in range(4))
        if off == WRAPS:
            return self.wraps
        if off == STEP:
            return self.step
        return 0

    def write(self, off: int, v: int) -> None:
        if off == COUNT and v < 10000:
            self.count = v
        elif off == WRAPS:
            self.wraps = 0

    def leds(self) -> int:
        return self.count & 0x3FFF

    def display(self) -> dict[int, int]:
        """{digit: active-low segments} for the digits that are lit; absent digits are dark."""
        out = {0: seg_pins(GLYPHS[self.count % 10])}
        for k in range(1, 4):
            if self.count >= 10 ** k:
                out[k] = seg_pins(GLYPHS[(self.count // 10 ** k) % 10])
        return out
