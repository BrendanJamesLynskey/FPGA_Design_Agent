Problems / D. Cryptography and security

AES-128 encryption over the USB-UART

c16_nexys_aes_uart Course tier course part 16 D Cryptography and security Nexys A7-100T

The problem

An AES encryption engine on the Nexys A7 that reaches the outside world over the serial port. It takes a key and a block of data from a PC over the USB serial port, runs the standard AES rounds in hardware and sends the encrypted block back. Its output can be checked against published test vectors.

Where it is used. AES protects disk encryption, network links, wireless standards and secure storage, and hardware cores are built into processors and system-on-chip designs for speed and low power.

Adapted from a project in the owner's FPGA design course (the course itself is private).

The spec the agent is given

AES-128 encryption over the USB-UART

I want the Nexys A7-100T to encrypt one block of data with the AES-128 cipher when my PC sends it a key and a block over the USB serial port, and to send the encrypted block back.

  • The cipher is AES with a 128-bit key, exactly as published in FIPS 197 (encryption only, one 16-byte block at a time, no chaining). Bytes are in the order the standard writes them: byte 0 first.
  • The serial link: 115200 baud, 8 data bits, no parity, 1 stop bit, on the board's USB-serial port.
  • The request is 32 bytes: the 16 key bytes, byte 0 first, and then the 16 plaintext bytes, byte 0 first. As soon as the 32nd byte has arrived the board encrypts and then sends back exactly 16 bytes, the ciphertext, byte 0 first. Nothing is remembered from one request to the next: every request carries its own key. (This is a bench demonstration; I know a key sent over a serial cable is not secret.) While it is working, further input bytes can be ignored. The PC always waits for the reply before the next request.
  • The active-low reset button (CPU_RESETN) returns the board to waiting for the first byte of a request. Show on LED0 that the board is busy (from the 32nd byte until the reply is sent).
  • The subject of this design is the USB-UART itself, so it does not embed the test shell; I will test it with a serial driver at the real protocol and a faster baud rate.

Test hooks: top module c16_nexys_aes_uart_top, ports named as in the board's master XDC, and a CLKS_PER_BIT parameter as a top-level parameter (868 on the board; the bench shrinks it). There are no other time constants.

Exactly spec.md. Anything it leaves open, the agent has to ask about.

What the hidden tests check

The requirements in the hidden spec, and how each is shown to hold:

  • REQ-01 the reply equals AES-128 of the request for the two FIPS 197 examples and six more requests (shown by simulation)
  • REQ-02 every request carries its own key: consecutive requests with different keys are all answered correctly (shown by simulation)
  • REQ-03 CPU_RESETN drops a part-received request, and LED0 is high only while busy (shown by simulation)
  • REQ-04 The design closes timing at 100 MHz with no unconstrained path (shown by report analysis)
The full behaviour rules from hidden/spec.yaml

cipher

  • reply = AES-128 encryption (FIPS 197) of the 16 plaintext bytes under the 16 key bytes of the same request; byte 0 first in the request and in the reply.

protocol

  • request: 32 bytes, key then plaintext; reply: 16 ciphertext bytes sent after the 32nd byte; nothing is remembered between requests. Input bytes during work may be ignored.
  • CPU_RESETN returns the board to waiting for the first byte of a request, dropping a partly received request.

leds

  • LED[0] = busy, from the 32nd byte until the reply has been sent.

// source: solutions/p16l02_aes128/aes128.sv (course file, unchanged below this line)
// Part 16 lesson 2 exercise: an iterative AES-128 encryptor, one round per clock, round keys expanded on the fly (FIPS 197). The S-box is given (aes_sbox_tab.sv, a look-up table).
//
// Blocks are 128-bit vectors in FIPS 197 byte order: byte 0 (state row 0, column 0) is bits [127:120], byte 1 is [119:112], ... byte 15 is [7:0]; byte i is row i%4, column i/4. A key is the same.
// start (one clock, while !busy) samples key and pt: round 0 (AddRoundKey) is done in that clock. Rounds 1..10 take one clock each (round 10 has no MixColumns). busy is high from the clock after start until the
// result is ready. done is high for exactly one clock when ct is valid; ct then keeps its value until the next start. The latency is constant: done is high 10 rising edges after the edge that sampled start,
// whatever the key and data. rst_n is synchronous, active low, and clears busy and done.
module aes128 (
    input  logic         clk,
    input  logic         rst_n,
    input  logic         start,
    input  logic [127:0] key,
    input  logic [127:0] pt,
    output logic         busy,
    output logic         done,
    output logic [127:0] ct
);
    logic [127:0] st, rk;
    logic [3:0]   rnd;
    logic [7:0]   rcon;
    logic [7:0]   sb [0:15];
    logic [7:0]   kb [0:3];
    for (genvar i = 0; i < 16; i++) begin : g_sb
        aes_sbox_tab u (.x(st[127 - 8*i -: 8]), .y(sb[i]));
    end
    for (genvar i = 0; i < 4; i++) begin : g_kb
        aes_sbox_tab u (.x(rk[(3 - ((i + 1) % 4)) * 8 +: 8]), .y(kb[i]));      // SubWord(RotWord(w3)): w3 = rk[31:0], byte 0 of w3 is rk[31:24]
    end
    function automatic logic [7:0] xt(input logic [7:0] a);
        xt = {a[6:0], 1'b0} ^ (a[7] ? 8'h1B : 8'h00);
    endfunction
    // next round key
    logic [31:0] w0, w1, w2, w3, t, n0, n1, n2, n3;
    logic [127:0] rk_n;
    always_comb begin
        {w0, w1, w2, w3} = rk;
        t = {kb[0] ^ rcon, kb[1], kb[2], kb[3]};
        n0 = w0 ^ t; n1 = w1 ^ n0; n2 = w2 ^ n1; n3 = w3 ^ n2;
        rk_n = {n0, n1, n2, n3};
    end
    // round function
    logic [7:0] sr [0:15];
    logic [7:0] mc [0:15];
    logic [127:0] st_n;
    always_comb begin
        for (int c = 0; c < 4; c++)
            for (int r = 0; r < 4; r++) sr[4*c + r] = sb[4*((c + r) % 4) + r];
        for (int c = 0; c < 4; c++) begin
            mc[4*c + 0] = xt(sr[4*c]) ^ (xt(sr[4*c + 1]) ^ sr[4*c + 1]) ^ sr[4*c + 2] ^ sr[4*c + 3];
            mc[4*c + 1] = sr[4*c] ^ xt(sr[4*c + 1]) ^ (xt(sr[4*c + 2]) ^ sr[4*c + 2]) ^ sr[4*c + 3];
            mc[4*c + 2] = sr[4*c] ^ sr[4*c + 1] ^ xt(sr[4*c + 2]) ^ (xt(sr[4*c + 3]) ^ sr[4*c + 3]);
            mc[4*c + 3] = (xt(sr[4*c]) ^ sr[4*c]) ^ sr[4*c + 1] ^ sr[4*c + 2] ^ xt(sr[4*c + 3]);
        end
        for (int i = 0; i < 16; i++) st_n[127 - 8*i -: 8] = (rnd == 4'd10) ? sr[i] : mc[i];
        st_n = st_n ^ rk_n;
    end
    always_comb begin
        case (rnd)
            4'd1: rcon = 8'h01; 4'd2: rcon = 8'h02; 4'd3: rcon = 8'h04; 4'd4: rcon = 8'h08; 4'd5: rcon = 8'h10;
            4'd6: rcon = 8'h20; 4'd7: rcon = 8'h40; 4'd8: rcon = 8'h80; 4'd9: rcon = 8'h1B; default: rcon = 8'h36;
        endcase
    end
    always_ff @(posedge clk) begin
        done <= 1'b0;
        if (!rst_n) busy <= 1'b0;
        else if (!busy) begin
            if (start) begin st <= pt ^ key; rk <= key; rnd <= 4'd1; busy <= 1'b1; end
        end else begin
            st <= st_n; rk <= rk_n; rnd <= rnd + 1'b1;
            if (rnd == 4'd10) begin busy <= 1'b0; done <= 1'b1; ct <= st_n; end
        end
    end
endmodule

// source: labs/p16_crypto/aes_uart_system.sv (course file, unchanged below this line)
// Part 16 lab 1 and agent project p16_nexys_aes_uart, the working core (checked in Icarus by test_lab_uart.py): AES-128 encryption over a UART. Protocol (8N1): the host sends 32 bytes, the key (16 bytes, byte 0
// first) and then the plaintext block (16 bytes, byte 0 first); about 270 clocks of UART-independent latency later the board answers with the 16 ciphertext bytes (byte 0 first). Nothing is stored between blocks.
// Uses the course's iterative AES-128 (solutions/p16l02_aes128 with its S-box table). THE KEY ARRIVES OVER THE UART: this is a bench demonstration of the datapath, not a way to protect a key.
module aes_uart_system #(
    parameter int CLKS_PER_BIT = 868
) (
    input  logic clk,
    input  logic rst_n,
    input  logic rxd,
    output logic txd,
    output logic busy
);
    logic        rx_vld, tx_busy, tx_go;
    logic [7:0]  rx_data, tx_data;
    uart_rx #(.CLKS_PER_BIT(CLKS_PER_BIT)) u_rx (.clk, .rst_n, .rxd, .vld(rx_vld), .data(rx_data));
    uart_tx #(.CLKS_PER_BIT(CLKS_PER_BIT)) u_tx (.clk, .rst_n, .go(tx_go), .data(tx_data), .busy(tx_busy), .txd);
    logic [255:0] sh;
    logic [5:0]   nrx;
    logic         a_start, a_busy, a_done;
    logic [127:0] ct;
    aes128 u_aes (.clk, .rst_n, .start(a_start), .key(sh[255:128]), .pt(sh[127:0]), .busy(a_busy), .done(a_done), .ct);
    typedef enum logic [1:0] {S_RX, S_RUN, S_TX} st_t;
    st_t st;
    logic [4:0] k;
    logic [1:0] ph;
    assign busy = (st != S_RX);
    assign a_start = (st == S_RUN) && (ph == 2'd0);
    assign tx_go = (st == S_TX) && (ph == 2'd0) && !tx_busy;
    assign tx_data = ct[127 - 8*k -: 8];
    always_ff @(posedge clk) begin
        if (!rst_n) begin st <= S_RX; nrx <= '0; ph <= '0; k <= '0; end
        else case (st)
            S_RX: if (rx_vld) begin
                sh <= {sh[247:0], rx_data};
                if (nrx == 6'd31) begin nrx <= '0; st <= S_RUN; ph <= 2'd0; end else nrx <= nrx + 1'b1;
            end
            S_RUN: case (ph)
                2'd0: ph <= 2'd1;                                   // start pulse is high in this clock
                default: if (a_done) begin st <= S_TX; ph <= 2'd0; k <= '0; end
            endcase
            S_TX: case (ph)
                2'd0: if (tx_go) ph <= 2'd1;
                2'd1: if (tx_busy) ph <= 2'd2;
                default: if (!tx_busy) begin
                    ph <= 2'd0;
                    k <= k + 1'b1;
                    if (k == 5'd15) st <= S_RX;
                end
            endcase
            default: st <= S_RX;
        endcase
    end
endmodule

module uart_rx #(
    parameter int CLKS_PER_BIT = 868
) (
    input  logic       clk,
    input  logic       rst_n,
    input  logic       rxd,
    output logic       vld,
    output logic [7:0] data
);
    logic        s1, s2, run;
    logic [15:0] cnt;
    logic [3:0]  bitn;
    always_ff @(posedge clk) begin
        s1 <= rxd;
        s2 <= s1;
        vld <= 1'b0;
        if (!rst_n) run <= 1'b0;
        else if (!run) begin
            if (!s2) begin run <= 1'b1; cnt <= CLKS_PER_BIT / 2; bitn <= 4'd0; end
        end else if (cnt != 0) cnt <= cnt - 1'b1;
        else begin
            cnt <= CLKS_PER_BIT - 1;
            bitn <= bitn + 1'b1;
            if (bitn == 4'd0) begin if (s2) run <= 1'b0; end
            else if (bitn <= 4'd8) data <= {s2, data[7:1]};
            else begin run <= 1'b0; vld <= s2; end
        end
    end
endmodule

"""P16-1 model: AES-128 requests (key then plaintext, 32 bytes) and the replies the board must send (standalone: python only)."""
import hashlib
import math
import random
import struct


def xtime(a: int) -> int:
    a <<= 1
    return (a ^ 0x11B) & 0xFF if a & 0x100 else a


def gmul(a: int, b: int) -> int:
    """Multiplication in GF(2^8) modulo x^8 + x^4 + x^3 + x + 1."""
    r = 0
    while b:
        if b & 1:
            r ^= a
        a = xtime(a)
        b >>= 1
    return r


def _build_sbox():
    inv = [0] * 256
    for a in range(1, 256):
        for b in range(1, 256):
            if gmul(a, b) == 1:
                inv[a] = b
                break
    sb = []
    for a in range(256):
        x = inv[a]
        y = x
        for s in (1, 2, 3, 4):
            y ^= ((x << s) | (x >> (8 - s))) & 0xFF
        sb.append(y ^ 0x63)
    return sb


SBOX = _build_sbox()


RCON = [0x01, 0x02, 0x04, 0x08, 0x10, 0x20, 0x40, 0x80, 0x1B, 0x36]


def expand_key(key: bytes) -> list[bytes]:
    """The 11 round keys of AES-128 (16 bytes each)."""
    w = [list(key[4 * i:4 * i + 4]) for i in range(4)]
    for i in range(4, 44):
        t = list(w[i - 1])
        if i % 4 == 0:
            t = t[1:] + t[:1]
            t = [SBOX[b] for b in t]
            t[0] ^= RCON[i // 4 - 1]
        w.append([a ^ b for a, b in zip(w[i - 4], t)])
    return [bytes(sum(w[4 * r:4 * r + 4], [])) for r in range(11)]


def _shift_rows(s):
    return [s[4 * ((c + r) % 4) + r] for c in range(4) for r in range(4)]


def _mix_columns(s):
    out = []
    for c in range(4):
        a = s[4 * c:4 * c + 4]
        out += [gmul(a[0], 2) ^ gmul(a[1], 3) ^ a[2] ^ a[3], a[0] ^ gmul(a[1], 2) ^ gmul(a[2], 3) ^ a[3],
                a[0] ^ a[1] ^ gmul(a[2], 2) ^ gmul(a[3], 3), gmul(a[0], 3) ^ a[1] ^ a[2] ^ gmul(a[3], 2)]
    return out


def aes128_encrypt(key: bytes, block: bytes, trace: list | None = None) -> bytes:
    """AES-128 encryption of one block. `trace`, if given, receives the state after every round."""
    rk = expand_key(key)
    s = [a ^ b for a, b in zip(block, rk[0])]
    if trace is not None:
        trace.append(bytes(s))
    for r in range(1, 11):
        s = [SBOX[b] for b in s]
        s = _shift_rows(s)
        if r != 10:
            s = _mix_columns(s)
        s = [a ^ b for a, b in zip(s, rk[r])]
        if trace is not None:
            trace.append(bytes(s))
    return bytes(s)


def requests():
    kats = [("2b7e151628aed2a6abf7158809cf4f3c" + "3243f6a8885a308d313198a2e0370734"), ("000102030405060708090a0b0c0d0e0f" + "00112233445566778899aabbccddeeff")]   # FIPS 197 appendix B and C.1
    rng = random.Random(16)
    return kats + [rng.randbytes(32).hex() for _ in range(6)]


def reply_for(req_hex):
    b = bytes.fromhex(req_hex)
    return aes128_encrypt(b[:16], b[16:]).hex()


def reference_output():
    return {"cases": [{"request": r, "reply": reply_for(r)} for r in requests()]}

DESIGN_ID = None

    return [(r, reply_for(r)) for r in requests()]
