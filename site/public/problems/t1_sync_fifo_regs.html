Problems / A. Basic digital design drills

Byte FIFO behind the test shell

t1_sync_fifo_regs Benchmark v1 T1 A Basic digital design drills Nexys A7-100T

The problem

A small first-in first-out buffer of sixteen bytes that is driven entirely through the test shell. Writing a byte pushes it on, reading a register removes the oldest byte, and another register lets the user look at the oldest byte without removing it. The design reports empty, full and an almost-full flag with a settable threshold, and keeps sticky error flags for pushing into a full buffer and popping an empty one. The LEDs show the fill level as a bar.

Where it is used. FIFOs sit between nearly any two parts of a digital system that run at different rates, such as a UART and a processor, a sensor and a DMA engine, or network packet stages. Almost-full flags are what let a sender slow down in time.

The spec the agent is given

Byte FIFO behind the test shell

I want a small FIFO on the Nexys A7-100T that I can exercise entirely from the test shell: 16 entries of 8 bits.

  • Writing a byte to a push register adds it at the tail. Reading a pop register returns the byte at the head and removes it. I also want to look at the head byte without removing it, and to read how many bytes are stored.
  • Flags: empty, full, and an almost-full flag whose threshold I can set over the shell.
  • Pushing into a full FIFO loses the byte; popping an empty FIFO returns 0. Both mistakes must be remembered in sticky error flags until I clear them, each on its own.
  • The LEDs show the fill level as a bar graph growing from LED[0].
  • CPU_RESETN empties the FIFO and clears every flag.
  • The shell runs at 115200 baud on the USB-UART. The design ID is "FIFO".

Test hooks: top module t1_sync_fifo_regs_top, ports named as in the board's master XDC, and the test shell's CLKS_PER_BIT, TIMEOUT_CYCLES and BUILD_STAMP parameters as top-level parameters. There are no other time constants.

Exactly spec.md. Anything it leaves open, the agent has to ask about.

Interface

Top module t1_sync_fifo_regs_top on the Nexys A7-100T (xc7a100tcsg324-1). Clock: CLK100MHZ at 100 MHz (board oscillator). Reset: CPU_RESETN, active low: the FIFO empties (LEVEL = 0), OVERFLOW = UNDERFLOW = 0, AF_THRESH = 12; stored bytes need not be cleared. Resources expected: about 100 LUTs (16x8 distributed RAM) and 50 FFs; no BRAM, no DSP.

Top-level parameters (board values): CLKS_PER_BIT = 868, TIMEOUT_CYCLES = 100000. The hidden bench shrinks them to CLKS_PER_BIT = 8, TIMEOUT_CYCLES = 400.

What the hidden tests check

The requirements in the hidden spec, and how each is shown to hold:

  • REQ-01 HEAD and POP are first-word-fall-through - the first read after a push returns that byte, never a lagged one (shown by simulation)
  • REQ-02 Bytes leave in arrival order across pointer wraps; LEVEL and the flags follow the model (shown by simulation)
  • REQ-03 Push when full is dropped and sets OVERFLOW; pop when empty returns 0 and sets UNDERFLOW; both are W1C sticky (shown by simulation)
  • REQ-04 ALMOST_FULL compares LEVEL >= AF_THRESH for every threshold (shown by simulation)
  • REQ-05 LED[15:0] are the LEVEL thermometer (shown by simulation)
  • REQ-06 The design closes timing at 100 MHz with no unconstrained path (shown by report analysis)
  • REQ-07 On the board a push/pop sequence over the shell answers as the model predicts (shown by on the board)
The full behaviour rules from hidden/spec.yaml

fifo

  • Depth 16, width 8. LEVEL is the number of bytes stored, 0..16.
  • A write to PUSH stores wdata[7:0] at the tail when LEVEL < 16; when LEVEL = 16 the byte is dropped, nothing changes and OVERFLOW is set.
  • Reads are first-word-fall-through: HEAD and POP return the byte at the head now, with no extra read. A read of POP returns the head byte and removes it (LEVEL - 1). A read of HEAD returns the same byte and removes nothing.
  • A read of POP or HEAD when empty returns 0; a POP read when empty also sets UNDERFLOW. A HEAD read when empty does not.
  • Bytes leave in the order they arrived, across any number of pointer wraps.

flags

  • EMPTY = (LEVEL = 0), FULL = (LEVEL = 16), ALMOST_FULL = (LEVEL >= AF_THRESH).
  • OVERFLOW and UNDERFLOW are sticky: once set they stay set until a write to FLAGS with that bit 1 (write-1-to-clear); a 0 bit leaves its flag alone.

leds

  • Thermometer - LED[k] = 1 for k < LEVEL, so LEVEL = 16 lights all sixteen and LEVEL = 0 none. No PWM.

Settled assumptions

  • the FIFO is built in fabric, not with the FIFO Generator IP. first-word-fall-through over a register read is simplest in plain RTL.
  • a HEAD read of an empty FIFO is not an error. peeking does not consume anything.

// sync_fifo_regs.sv: 16 x 8 first-word-fall-through FIFO driven from the
// shell's register window, with sticky W1C error flags, for t1_sync_fifo_regs.
module sync_fifo_regs (
    input  logic        clk,
    input  logic        rst,
    output logic [15:0] led,
    input  logic [6:0]  win_addr,
    input  logic        win_wr,
    input  logic        win_rd,
    input  logic [31:0] win_wdata,
    output logic [31:0] win_rdata
);
    localparam logic [6:0] R_PUSH = 7'h00, R_POP = 7'h01, R_HEAD = 7'h02, R_LEVEL = 7'h03,
                           R_FLAGS = 7'h04, R_AF = 7'h05;

    logic [7:0]  mem [16];
    logic [3:0]  wp, rp;
    logic [4:0]  level, af_th;
    logic        ovf, unf;
    logic [7:0]  head;

    wire empty = level == 5'd0;
    wire full  = level == 5'd16;
    wire afull = level >= af_th;
    wire push  = win_wr && win_addr == R_PUSH;
    wire pop   = win_rd && win_addr == R_POP;

    assign head = empty ? 8'd0 : mem[rp];

    always_ff @(posedge clk)
        if (push && !full) mem[wp] <= win_wdata[7:0];

    always_ff @(posedge clk) begin
        if (rst) begin
            wp <= '0; rp <= '0; level <= '0; ovf <= 1'b0; unf <= 1'b0; af_th <= 5'd12;
        end else begin
            if (push) begin
                if (full) ovf <= 1'b1;
                else begin
                    wp    <= wp + 4'd1;
                    level <= level + 5'd1;
                end
            end
            if (pop) begin
                if (empty) unf <= 1'b1;
                else begin
                    rp    <= rp + 4'd1;
                    level <= level - 5'd1;
                end
            end
            if (win_wr && win_addr == R_FLAGS) begin
                if (win_wdata[8]) ovf <= 1'b0;
                if (win_wdata[9]) unf <= 1'b0;
            end
            if (win_wr && win_addr == R_AF) af_th <= win_wdata[4:0];
        end
    end

    always_ff @(posedge clk) begin
        if (rst) led <= '0;
        else     for (int k = 0; k < 16; k++) led[k] <= 5'(k) < level;
    end

    always_ff @(posedge clk) begin
        if (rst) win_rdata <= '0;
        else if (win_rd) begin
            case (win_addr)
                R_POP:   win_rdata <= {24'd0, head};
                R_HEAD:  win_rdata <= {24'd0, head};
                R_LEVEL: win_rdata <= {27'd0, level};
                R_FLAGS: win_rdata <= {22'd0, unf, ovf, 5'd0, afull, full, empty};
                R_AF:    win_rdata <= {27'd0, af_th};
                default: win_rdata <= '0;
            endcase
        end
    end
endmodule

// t1_sync_fifo_regs_top.sv: board top (Nexys A7-100T, master-XDC port names).
// Reference design for benchmark task t1_sync_fifo_regs; DESIGN_ID "FIFO".
module t1_sync_fifo_regs_top #(
    parameter int          CLKS_PER_BIT   = 868,
    parameter int          TIMEOUT_CYCLES = 100_000,
    parameter logic [31:0] BUILD_STAMP    = 32'h0
) (
    input  logic        CLK100MHZ,
    input  logic        CPU_RESETN,
    output logic [15:0] LED,
    input  logic        UART_TXD_IN,
    output logic        UART_RXD_OUT
);
    logic        clk, rst, win_wr, win_rd;
    logic [6:0]  win_addr;
    logic [31:0] win_wdata, win_rdata;

    assign clk = CLK100MHZ;
    reset_sync u_rst (.clk(clk), .rst_n_async(CPU_RESETN), .rst(rst));

    fpga_shell #(.CLKS_PER_BIT(CLKS_PER_BIT), .TIMEOUT_CYCLES(TIMEOUT_CYCLES),
                 .DESIGN_ID(32'h4649_464F), .BUILD_STAMP(BUILD_STAMP)) u_shell (
        .clk(clk), .rst(rst), .uart_rx(UART_TXD_IN), .uart_tx(UART_RXD_OUT),
        .win_addr(win_addr), .win_wr(win_wr), .win_rd(win_rd), .win_wdata(win_wdata), .win_rdata(win_rdata));

    sync_fifo_regs u_fifo (
        .clk(clk), .rst(rst), .led(LED),
        .win_addr(win_addr), .win_wr(win_wr), .win_rd(win_rd), .win_wdata(win_wdata), .win_rdata(win_rdata));
endmodule

"""Acceptance tests of t1_sync_fifo_regs against model.py (hidden from the agent)."""

from __future__ import annotations

import random

import cocotb
from benchmark.lib.bench import Board, peek
from model import AF_THRESH, DESIGN_ID, FLAGS, HEAD, LEVEL, POP, PUSH, Model


class Env:
    def __init__(self, dut) -> None:
        self.b = Board(dut, {})
        self.dut, self.m = dut, Model()

    async def start(self) -> None:
        await self.b.start()

    async def push(self, v: int) -> None:
        await self.b.write(PUSH, v)
        self.m.push(v)

    async def pop(self) -> None:
        want = self.m.pop()
        await self.b.expect(POP, want, "POP")

    async def wr(self, off: int, v: int) -> None:
        await self.b.write(off, v)
        self.m.write(off, v)

    async def check_regs(self) -> None:
        for off, name in ((HEAD, "HEAD"), (LEVEL, "LEVEL"), (FLAGS, "FLAGS"), (AF_THRESH, "AF_THRESH"),
                          (PUSH, "PUSH")):
            await self.b.expect(off, self.m.read(off), name)

    async def check_leds(self) -> None:
        led = await peek(self.b.clk, self.dut.LED)
        assert led == self.m.leds(), f"LED {led:04X} != model {self.m.leds():04X}"


@cocotb.test()
async def test_identity_and_reset(dut):
    e = Env(dut)
    await e.start()
    assert await e.b.shell_id() == DESIGN_ID
    await e.check_regs()
    await e.check_leds()


@cocotb.test()
async def test_fwft_head_and_pop(dut):
    """Trap: a FIFO Generator in standard (non-FWFT) read mode shows a byte one read late; HEAD and POP here must
    return the head byte at once."""
    e = Env(dut)
    await e.start()
    await e.push(0xA1)
    await e.b.expect(HEAD, 0xA1, "HEAD right after the first push")
    await e.push(0xB2)
    await e.push(0xC3)
    await e.b.expect(HEAD, 0xA1, "HEAD")
    await e.pop()                               # A1
    await e.b.expect(HEAD, 0xB2, "HEAD after one pop")
    await e.b.expect(HEAD, 0xB2, "HEAD read twice removes nothing")
    await e.pop()                               # B2
    await e.pop()                               # C3
    await e.pop()                               # empty: 0, UNDERFLOW
    await e.check_regs()


@cocotb.test()
async def test_fill_and_overflow(dut):
    e = Env(dut)
    await e.start()
    for i in range(16):
        await e.push(0x40 + i)
        if i in (0, 7, 11, 15):
            await e.check_regs()
            await e.check_leds()
    await e.push(0xEE)                          # dropped: OVERFLOW
    await e.push(0xEF)
    await e.check_regs()
    await e.check_leds()
    for _ in range(16):
        await e.pop()
    await e.check_regs()
    await e.check_leds()


@cocotb.test()
async def test_underflow_and_w1c(dut):
    e = Env(dut)
    await e.start()
    await e.b.expect(HEAD, 0, "HEAD when empty")
    await e.check_regs()                        # a HEAD read when empty is not an underflow
    await e.pop()                               # UNDERFLOW
    for _ in range(17):
        await e.push(7)                         # OVERFLOW too
    await e.check_regs()
    await e.wr(FLAGS, 0)                        # 0 bits clear nothing
    await e.check_regs()
    await e.wr(FLAGS, 1 << 8)                   # clears only OVERFLOW
    await e.check_regs()
    await e.wr(FLAGS, 0x07)                     # read-only bits: ignored
    await e.check_regs()
    await e.wr(FLAGS, 1 << 9)
    await e.check_regs()
    await e.pop()
    await e.wr(FLAGS, 0x300)
    await e.check_regs()


@cocotb.test()
async def test_almost_full_threshold(dut):
    e = Env(dut)
    await e.start()
    for th in (0, 1, 5, 16, 17, 31, 12):
        await e.wr(AF_THRESH, th)
        await e.check_regs()
    for i in range(16):                         # walk the level with the threshold at 12, then 4
        await e.push(i)
        await e.b.expect(FLAGS, e.m.read(FLAGS), "FLAGS")
    await e.wr(AF_THRESH, 4)
    for _ in range(14):
        await e.pop()
        await e.b.expect(FLAGS, e.m.read(FLAGS), "FLAGS")


@cocotb.test()
async def test_pointer_wrap_order(dut):
    e = Env(dut)
    await e.start()
    n = 0
    for _ in range(7):                          # level hovers 3..8 while the pointers wrap several times
        for _ in range(8):
            await e.push(n & 0xFF)
            n += 5
        for _ in range(5):
            await e.pop()
        await e.b.expect(LEVEL, e.m.read(LEVEL), "LEVEL")
        await e.b.expect(HEAD, e.m.read(HEAD), "HEAD")
        if len(e.m.q) > 8:
            for _ in range(len(e.m.q) - 3):
                await e.pop()
    await e.check_regs()
    await e.check_leds()


@cocotb.test()
async def test_leds_thermometer(dut):
    e = Env(dut)
    await e.start()
    for i in range(16):
        await e.push(i)
        await e.check_leds()
    for _ in range(16):
        await e.pop()
        await e.check_leds()


@cocotb.test()
async def test_register_rules(dut):
    e = Env(dut)
    await e.start()
    await e.push(0x1_2345_6789)                 # only [7:0] stored
    await e.b.write(POP, 0x55)                  # writes to RO registers are ignored (no pop, no push)
    await e.b.write(HEAD, 0x66)
    await e.b.write(LEVEL, 3)
    await e.wr(AF_THRESH, 0xFFFF_FFE3)          # [4:0] only
    await e.check_regs()
    for off in (0x06, 0x41, 0x7F):
        await e.b.expect(off, 0, "unmapped")
    await e.pop()
    await e.check_regs()


@cocotb.test()
async def test_random_traffic(dut):
    e = Env(dut)
    await e.start()
    rng = random.Random(int(cocotb.RANDOM_SEED))
    for _ in range(70):
        r = rng.random()
        bias = 0.6 if len(e.m.q) < 8 else 0.4
        if r < 0.05:
            await e.wr(AF_THRESH, rng.randrange(32))
        elif r < 0.1:
            await e.wr(FLAGS, rng.choice((0x100, 0x200, 0x300)))
        elif r < 0.1 + bias:
            await e.push(rng.getrandbits(8))
        else:
            await e.pop()
        if rng.random() < 0.15:
            await e.b.expect(FLAGS, e.m.read(FLAGS), "FLAGS")
    await e.check_regs()
    await e.check_leds()

"""Golden model of t1_sync_fifo_regs, written from spec.yaml alone (never from any RTL)."""

from __future__ import annotations

PUSH, POP, HEAD, LEVEL, FLAGS, AF_THRESH = range(6)
DESIGN_ID = 0x4649464F          # "FIFO"


class Model:
    def __init__(self) -> None:
        self.q: list[int] = []
        self.ovf = self.unf = 0
        self.af = 12

    def push(self, v: int) -> None:
        if len(self.q) == 16:
            self.ovf = 1
        else:
            self.q.append(v & 0xFF)

    def pop(self) -> int:
        if not self.q:
            self.unf = 1
            return 0
        return self.q.pop(0)

    def flags(self) -> int:
        n = len(self.q)
        return int(n == 0) | int(n == 16) << 1 | int(n >= self.af) << 2 | self.ovf << 8 | self.unf << 9

    def read(self, off: int) -> int:
        """A side-effect-free read (POP is handled by pop())."""
        if off == HEAD:
            return self.q[0] if self.q else 0
        if off == LEVEL:
            return len(self.q)
        if off == FLAGS:
            return self.flags()
        if off == AF_THRESH:
            return self.af
        return 0

    def write(self, off: int, v: int) -> None:
        if off == PUSH:
            self.push(v)
        elif off == FLAGS:
            if v >> 8 & 1:
                self.ovf = 0
            if v >> 9 & 1:
                self.unf = 0
        elif off == AF_THRESH:
            self.af = v & 0x1F

    def leds(self) -> int:
        return (1 << len(self.q)) - 1
