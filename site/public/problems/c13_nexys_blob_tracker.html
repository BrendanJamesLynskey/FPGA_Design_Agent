Problems / S. Computer vision

Blob finder behind the test shell

c13_nexys_blob_tracker Course tier course part 13 S Computer vision Nexys A7-100T

The problem

A blob finder for a small black-and-white picture. Pixels arrive one at a time, and the block groups bright pixels that touch along their sides into objects, then reports the size of the biggest object and its middle point. Objects that touch only at a corner count as separate, and ties are settled by position. A new picture can follow without any leftovers from the last.

Where it is used. Finding and following bright objects is used in robot vision, light-spot trackers, inspection cameras and laser-pointer or marker tracking. Doing the labelling in a single pass over the pixel stream suits FPGAs.

Adapted from a project in the owner's FPGA design course (the course itself is private).

The spec the agent is given

Blob finder behind the test shell

I want a block for the Nexys A7-100T's FPGA that finds the biggest bright object in a small picture and says where its middle point is, and I want to exercise it entirely from the test shell.

  • The picture is 40 pixels wide and 30 high, one bit per pixel (1 = bright), and arrives as a stream of pixels, one per clock when available, with a start-of-picture mark and an end-of-line mark. The pictures contain a few bright rectangles on a dark background and a stray pixel or two; sometimes two touch only at a corner, and one object is U-shaped.
  • An object is a group of bright pixels that touch along their sides (up, down, left or right). Two groups that touch only at a corner are two objects; a U-shaped object is one object.
  • When a picture has gone by, tell me the area (the number of pixels) of the biggest object and its middle point: the average of its pixel coordinates in whole pixels, rounded down, x counted from 0 at the left and y from 0 at the top. If two objects have the same area, the one that starts higher (the smaller top row), and if that is also equal, the one further left, is the biggest.
  • A new picture can follow a finished one, and nothing is left over from the earlier picture.

The shell is slow, so the stream is driven for me: I park a whole picture over the shell (32 pixels per write, row by row, the first pixel of a word in its lowest bit) and give a "go" command, and the block then presents the pixels to the stream, one per clock. A status flag says busy from "go" until the report for that picture is final, and another says that a report is available. I read the area and the x and y of the middle point over the shell. CPU_RESETN returns the block to idle and forgets the report. LED0 shows busy. The shell runs at 115200 baud on the USB-UART. The design ID is "BLOB".

Test hooks: top module c13_nexys_blob_tracker_top, ports named as in the board's master XDC, and the test shell's CLKS_PER_BIT, TIMEOUT_CYCLES and BUILD_STAMP parameters as top-level parameters. There are no other time constants.

Exactly spec.md. Anything it leaves open, the agent has to ask about.

What the hidden tests check

The requirements in the hidden spec, and how each is shown to hold:

  • REQ-01 for every picture the reported area, x and y equal the reference (shown by simulation)
  • REQ-02 two objects that touch only diagonally are reported separately (shown by simulation)
  • REQ-03 the U-shaped object is one object (shown by simulation)
The full behaviour rules from hidden/spec.yaml

stream

  • AXI4-Stream video slave (tdata[0] = pixel, tvalid, tready, tuser = start of picture, tlast = end of line), 40 x 30; the wrapper drives one pixel per clock and holds a pixel until tready.

objects

  • 4-connected groups of bright pixels (neighbours up, down, left, right); a diagonal contact does not join two objects; a U-shaped object is one object. Up to 64 provisional labels of a single-pass labeller are available.

biggest

  • Largest area; on a tie the object with the smaller top row, then the smaller left edge.

centroid

  • (sum x // area, sum y // area), integer division (floor), pixel coordinates from 0.

empty picture

  • Not exercised by the bench (a picture with no bright pixel has no object).

leds

  • LED[0] = BUSY, the other LEDs are 0.

Settled assumptions

  • the picture buffer and the stream generator are part of the test wrapper, not of the block under test the shell cannot present a stream; any design must provide the register map above

// P13-2 reference glue (v1.1 scope): the labeller (ccl.sv, the course's single-pass union-find labeller) plus the choice of the biggest object and its centroid.
// A picture goes in as a stream of 1-bit pixels (s_tdata[0], tuser on the first pixel); when the labeller has listed every object the report is final and `done` pulses for one clock.
// Biggest = largest area; on a tie the smaller top row, then the smaller left edge. Centroid = (sum x // area, sum y // area).
module blob_report #(
    parameter int W = 40,
    parameter int H = 30
) (
    input  logic        clk,
    input  logic        rst_n,
    input  logic [7:0]  s_tdata,
    input  logic        s_tvalid,
    output logic        s_tready,
    input  logic        s_tuser,
    input  logic        s_tlast,
    output logic        done,
    output logic [15:0] area,
    output logic [7:0]  cx,
    output logic [7:0]  cy
);
    logic        ov, ovf, ccl_done, ccl_busy;
    logic [15:0] o_area;
    logic [19:0] o_sx, o_sy;
    logic [7:0]  o_xmin, o_xmax, o_ymin, o_ymax;
    logic [15:0] b_area;
    logic [19:0] b_sx, b_sy;
    logic [7:0]  b_xmin, b_ymin;
    logic        have;
    logic        dbusy;
    logic [4:0]  dcnt;
    logic [19:0] qx, qy;                    // numerator shifting out, quotient shifting in
    logic [20:0] rx, ry;
    wire  [20:0] nrx = {rx[19:0], qx[19]}, nry = {ry[19:0], qy[19]};

    ccl #(.W(W), .H(H), .MAXL(64)) u_ccl (.clk(clk), .rst_n(rst_n), .s_tdata(s_tdata), .s_tvalid(s_tvalid), .s_tready(s_tready), .s_tuser(s_tuser), .s_tlast(s_tlast),
        .busy(ccl_busy), .out_valid(ov), .out_area(o_area), .out_sx(o_sx), .out_sy(o_sy), .out_xmin(o_xmin), .out_xmax(o_xmax), .out_ymin(o_ymin), .out_ymax(o_ymax),
        .done(ccl_done), .overflow(ovf));

    wire better = !have || (o_area > b_area) || (o_area == b_area && (o_ymin < b_ymin || (o_ymin == b_ymin && o_xmin < b_xmin)));

    always_ff @(posedge clk) begin
        done <= 1'b0;
        if (!rst_n) begin
            have <= 1'b0; dbusy <= 1'b0; area <= 16'd0; cx <= 8'd0; cy <= 8'd0; b_area <= 16'd0;
        end else begin
            if (s_tvalid && s_tready && s_tuser) begin have <= 1'b0; b_area <= 16'd0; end   // a new picture: forget the previous choice
            if (ov && better) begin
                have <= 1'b1;
                b_area <= o_area; b_sx <= o_sx; b_sy <= o_sy; b_xmin <= o_xmin; b_ymin <= o_ymin;
            end
            if (ccl_done) begin
                area <= b_area;
                if (b_area == 0) begin cx <= 8'd0; cy <= 8'd0; done <= 1'b1; end
                else begin                                          // the centroid: two restoring divisions, one bit per clock
                    dbusy <= 1'b1; dcnt <= 5'd19; qx <= b_sx; qy <= b_sy; rx <= '0; ry <= '0;
                end
            end
            if (dbusy) begin
                qx <= {qx[18:0], (nrx >= {5'd0, b_area})};
                qy <= {qy[18:0], (nry >= {5'd0, b_area})};
                rx <= (nrx >= {5'd0, b_area}) ? nrx - {5'd0, b_area} : nrx;
                ry <= (nry >= {5'd0, b_area}) ? nry - {5'd0, b_area} : nry;
                dcnt <= dcnt - 5'd1;
                if (dcnt == 5'd0) begin
                    dbusy <= 1'b0; done <= 1'b1;
                    cx <= {qx[6:0], (nrx >= {5'd0, b_area})};
                    cy <= {qy[6:0], (nry >= {5'd0, b_area})};
                end
            end
        end
    end
endmodule

// c13_nexys_blob_tracker_regs.sv: the shell window of course task c13_nexys_blob_tracker: a parked picture, a stream generator and the report registers.
module c13_nexys_blob_tracker_regs (
    input  logic        clk,
    input  logic        rst,
    output logic [15:0] led,
    input  logic [6:0]  win_addr,
    input  logic        win_wr,
    input  logic        win_rd,
    input  logic [31:0] win_wdata,
    output logic [31:0] win_rdata
);
    localparam int NPIX = 1200;
    logic [31:0] ram [0:37];
    logic [5:0]  ptr;
    logic        streaming, have_report, rep_done;
    logic [10:0] tx_i;
    logic [7:0]  s_tdata, cx, cy;
    logic        s_tvalid, s_tready, s_tuser, s_tlast;
    logic [15:0] area;
    logic [5:0]  tx_x;
    logic [31:0] nxt_w;
    wire busy = streaming;
    assign led = {15'd0, busy};

    blob_report #(.W(40), .H(30)) u_core (.clk(clk), .rst_n(!rst), .s_tdata(s_tdata), .s_tvalid(s_tvalid), .s_tready(s_tready), .s_tuser(s_tuser), .s_tlast(s_tlast),
                                            .done(rep_done), .area(area), .cx(cx), .cy(cy));

    assign nxt_w = ram[tx_i[10:5]];
    wire slot_free = !s_tvalid || s_tready;

    always_ff @(posedge clk) begin
        if (win_wr) begin
            case (win_addr)
                7'd0: ptr <= win_wdata[5:0];
                7'd1: begin ram[ptr] <= win_wdata; ptr <= ptr + 6'd1; end
                7'd2: begin streaming <= 1'b1; have_report <= 1'b0; tx_i <= 11'd0; tx_x <= 6'd0; s_tvalid <= 1'b0; end
                default: ;
            endcase
        end
        if (streaming && slot_free) begin
            if (tx_i < NPIX) begin
                s_tvalid <= 1'b1;
                s_tdata  <= {7'd0, nxt_w[tx_i[4:0]]};
                s_tuser  <= (tx_i == 11'd0);
                s_tlast  <= (tx_x == 6'd39);
                tx_i     <= tx_i + 11'd1;
                tx_x     <= (tx_x == 6'd39) ? 6'd0 : tx_x + 6'd1;
            end else s_tvalid <= 1'b0;
        end
        if (rep_done) begin streaming <= 1'b0; have_report <= 1'b1; end
        win_rdata <= 32'd0;
        if (win_rd) begin
            case (win_addr)
                7'd0: win_rdata <= {26'd0, ptr};
                7'd3: win_rdata <= {30'd0, have_report, busy};
                7'd4: win_rdata <= {16'd0, area};
                7'd5: win_rdata <= {24'd0, cx};
                7'd6: win_rdata <= {24'd0, cy};
                default: ;
            endcase
        end
        if (rst) begin
            ptr <= '0; streaming <= 1'b0; have_report <= 1'b0; tx_i <= '0; tx_x <= '0; s_tvalid <= 1'b0; win_rdata <= 32'd0; s_tdata <= '0; s_tuser <= 1'b0; s_tlast <= 1'b0;
        end
    end
endmodule

ccl.sv reference RTL, 179 lines
DownloadOn GitHubMIT licence
// Part 13 project reference (07a1c form): single-pass connected-component labelling with a union-find parent table and per-root statistics.
// The first form of this reference was behavioural (32-bit integer arrays, two union-find searches unrolled to 64 steps in one clock, one clock per pixel); Vivado could not
// finish it. This form takes a few clocks per pixel, follows the parent chain one step per clock, and uses sized registers. The labels, areas and sums are the same.
// Per object (label 1 .. MAXL-1): area, sum of x, sum of y, bounding box. Pixels with s_tdata[0] = 1 are object pixels; s_tuser marks the first pixel of a picture.
module ccl #(
    parameter int W = 20,
    parameter int H = 14,
    parameter int MAXL = 64
) (
    input  logic        clk,
    input  logic        rst_n,
    input  logic [7:0]  s_tdata,
    input  logic        s_tvalid,
    output logic        s_tready,
    input  logic        s_tuser,
    input  logic        s_tlast,
    output logic        busy,
    output logic        out_valid,
    output logic [15:0] out_area,
    output logic [19:0] out_sx,
    output logic [19:0] out_sy,
    output logic [7:0]  out_xmin,
    output logic [7:0]  out_xmax,
    output logic [7:0]  out_ymin,
    output logic [7:0]  out_ymax,
    output logic        done,
    output logic        overflow
);
    localparam int LW = $clog2(MAXL);                 // label width
    localparam int XW = $clog2(W);
    localparam int YW = $clog2(H);
    typedef enum logic [2:0] {S_IDLE, S_FIND_U, S_FIND_L, S_READ, S_APPLY, S_ADV, S_SCAN} state_t;
    state_t st;

    logic [LW-1:0] parent [0:MAXL-1];
    logic [15:0]   area   [0:MAXL-1];
    logic [19:0]   sx     [0:MAXL-1];
    logic [19:0]   sy     [0:MAXL-1];
    logic [7:0]    xmin   [0:MAXL-1];
    logic [7:0]    xmax   [0:MAXL-1];
    logic [7:0]    ymin   [0:MAXL-1];
    logic [7:0]    ymax   [0:MAXL-1];
    logic [LW-1:0] line_q [0:W-1];                    // labels of the previous row
    logic [XW-1:0] x, xi;                             // position of the next pixel, and of the pixel being processed
    logic [YW-1:0] y, yi;
    logic [LW-1:0] left, cur, ru, rl, rootp;
    logic [LW:0]   nxt_ext;                           // next free label, with a spare top bit so that MAXL is representable
    logic [LW:0]   scan;
    logic [LW:0]   it;                                // find steps taken
    logic          pix;

    assign busy     = (st == S_SCAN);
    assign s_tready = (st == S_IDLE);

    // statistics of the pixel being applied: the chosen root, optionally merged with the other root, plus this pixel
    wire           both   = (ru != 0) && (rl != 0) && (ru != rl);
    wire [LW-1:0]  r_lo   = (ru < rl) ? ru : rl;
    wire [LW-1:0]  r_hi   = (ru < rl) ? rl : ru;
    wire           is_new = (ru == 0) && (rl == 0);
    wire  [LW-1:0] sel    = both ? r_lo : ((ru != 0) ? ru : rl);
    wire  [15:0]   a_base_w = area[sel] + (both ? area[r_hi] : 16'd0);
    wire  [19:0]   sx_base_w = sx[sel] + (both ? sx[r_hi] : 20'd0);
    wire  [19:0]   sy_base_w = sy[sel] + (both ? sy[r_hi] : 20'd0);
    wire  [7:0]    xmin_b_w = (both && xmin[r_hi] < xmin[sel]) ? xmin[r_hi] : xmin[sel];
    wire  [7:0]    xmax_b_w = (both && xmax[r_hi] > xmax[sel]) ? xmax[r_hi] : xmax[sel];
    wire  [7:0]    ymin_b_w = (both && ymin[r_hi] < ymin[sel]) ? ymin[r_hi] : ymin[sel];
    wire  [7:0]    ymax_b_w = (both && ymax[r_hi] > ymax[sel]) ? ymax[r_hi] : ymax[sel];
    logic [15:0] a_base;
    logic [19:0] sx_base, sy_base;
    logic [7:0]  xmin_b, xmax_b, ymin_b, ymax_b;
    wire  [7:0]    xi8 = 8'(xi), yi8 = 8'(yi);

    integer i;
    always_ff @(posedge clk) begin
        out_valid <= 1'b0;
        done <= 1'b0;
        if (!rst_n) begin
            st <= S_IDLE; x <= '0; y <= '0; left <= '0; nxt_ext <= (LW+1)'(1); overflow <= 1'b0;
        end else begin
            case (st)
                S_IDLE: if (s_tvalid) begin
                    xi  <= s_tuser ? '0 : x;
                    yi  <= s_tuser ? '0 : y;
                    pix <= s_tdata[0];
                    if (s_tuser) begin
                        left <= '0; nxt_ext <= (LW+1)'(1); overflow <= 1'b0;
                        for (i = 0; i < MAXL; i = i + 1) begin parent[i] <= LW'(i); area[i] <= 16'd0; end
                    end
                    if (s_tdata[0]) begin
                        // up = previous row's label at this x (0 on the first row); the left label is 0 on the first column
                        cur <= (s_tuser || y == 0) ? '0 : line_q[x];
                        it  <= '0;
                        st  <= S_FIND_U;
                    end else begin
                        rootp <= '0;                                  // a dark pixel has no label
                        st <= S_ADV;
                    end
                end
                S_FIND_U: begin
                    if (cur != 0 && parent[cur] != cur && it < MAXL) begin cur <= parent[cur]; it <= it + 1'b1; end
                    else begin
                        ru  <= cur;
                        cur <= (xi == 0) ? '0 : left;
                        it  <= '0;
                        st  <= S_FIND_L;
                    end
                end
                S_FIND_L: begin
                    if (cur != 0 && parent[cur] != cur && it < MAXL) begin cur <= parent[cur]; it <= it + 1'b1; end
                    else begin
                        rl <= cur;
                        st <= S_READ;
                    end
                end
                S_READ: begin                                      // read the chosen root (and the one merged into it) into registers
                    a_base <= a_base_w; sx_base <= sx_base_w; sy_base <= sy_base_w;
                    xmin_b <= xmin_b_w; xmax_b <= xmax_b_w; ymin_b <= ymin_b_w; ymax_b <= ymax_b_w;
                    st <= S_APPLY;
                end
                S_APPLY: begin
                    if (is_new) begin
                        if (nxt_ext < MAXL) begin
                            // a new object: label nxt_ext, statistics start from this pixel
                            parent[nxt_ext[LW-1:0]] <= nxt_ext[LW-1:0];
                            area[nxt_ext[LW-1:0]] <= 16'd1;
                            sx[nxt_ext[LW-1:0]] <= 20'(xi); sy[nxt_ext[LW-1:0]] <= 20'(yi);
                            xmin[nxt_ext[LW-1:0]] <= xi8; xmax[nxt_ext[LW-1:0]] <= xi8;
                            ymin[nxt_ext[LW-1:0]] <= yi8; ymax[nxt_ext[LW-1:0]] <= yi8;
                            rootp <= nxt_ext[LW-1:0];
                            nxt_ext <= nxt_ext + 1'b1;
                        end else begin
                            rootp <= '0; overflow <= 1'b1;
                        end
                    end else begin
                        if (both) begin
                            parent[r_hi] <= r_lo;
                            area[r_hi] <= 16'd0;
                        end
                        area[sel] <= a_base + 16'd1;
                        sx[sel]   <= sx_base + 20'(xi);
                        sy[sel]   <= sy_base + 20'(yi);
                        xmin[sel] <= (xi8 < xmin_b) ? xi8 : xmin_b;

                        y <= yi + 1'b1;
                    end else begin
                        left <= rootp; x <= xi + 1'b1;

                    else st <= S_IDLE;

                        st <= S_IDLE;
                        done <= 1'b1;

async def report(b: Board, name: str, pic) -> None:
    await b.write(PTR, 0)
    for w in pack_words(pic):
        await b.write(DATA, w)
    await b.write(GO, 1)
    await b.cycles(1300)
    for _ in range(300):
        if not (await b.read(STATUS)) & 1:
            break
    else:
        raise AssertionError(f"{name}: still busy long after the picture")

    await b.expect(CX, exp["cx"], f"{name}: x of the middle point")
    await b.expect(CY, exp["cy"], f"{name}: y of the middle point")

"""P13-2 reference model: the biggest-blob list (numpy, flood fill; equal to the course exercise on every frame) and the bench pictures. Standalone copy of the course model."""
import numpy as np

W, H, N = 40, 30, 8
NPIX = W * H


def label_ref(m):
    """Golden 4-connected blob list by flood fill: (area, sum_x, sum_y, xmin, xmax, ymin, ymax), sorted."""
    h, w = m.shape
    seen = np.zeros_like(m, bool)
    out = []
    for y0 in range(h):
        for x0 in range(w):
            if m[y0, x0] and not seen[y0, x0]:
                st, pts = [(x0, y0)], []
                seen[y0, x0] = True
                while st:
                    x, y = st.pop()
                    pts.append((x, y))
                    for dx, dy in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                        a, b = x + dx, y + dy
                        if 0 <= a < w and 0 <= b < h and m[b, a] and not seen[b, a]:
                            seen[b, a] = True
                            st.append((a, b))
                xs, ys = [p[0] for p in pts], [p[1] for p in pts]
                out.append((len(pts), sum(xs), sum(ys), min(xs), max(xs), min(ys), max(ys)))
    return sorted(out)


def frames():
    out = []
    for t in range(N):
        m = np.zeros((H, W), np.uint8)
        m[4:7 + t, 3 + 2 * t:11 + 2 * t] = 1                    # a rectangle, 8 wide, that grows downward and moves right (area 24, 32, 40, ... 80)
        m[18:24, 22:24] = 1; m[18:24, 28:30] = 1; m[24:26, 22:30] = 1    # a U of area 40: two arms that join only at the bottom
        m[8 + t:11 + t, 24:27] = 1                              # a 3 x 3 block moving down toward the U
        m[14 + t // 2, 33 + t // 4] = 1                         # a stray pixel
        m[7 + t:9 + t, 11 + 2 * t:13 + 2 * t] = 1               # touches the rectangle's bottom right corner diagonally only (not 4-connected)
        out.append(m)
    return out


def biggest(m):
    blobs = label_ref(m)
    best = max(blobs, key=lambda b: (b[0], -b[5], -b[3]))        # area; ties: the blob with the smaller top row, then the smaller left edge
    area, sx, sy = best[0], best[1], best[2]
    return {"area": area, "cx": sx // area, "cy": sy // area}


def extra_pictures():
    """Pictures the bench adds to the eight of the course: a single pixel in the last corner, a comb and a ring that need several merges, and three equal blobs (the top-left one wins)."""
    empty = np.zeros((H, W), np.uint8)
    empty[29, 39] = 1
    merge = np.zeros((H, W), np.uint8)
    merge[2:12, 2] = 1; merge[2:12, 6] = 1; merge[2:12, 10] = 1; merge[11, 2:11] = 1      # a comb: three teeth joined at the bottom (several equivalences)
    merge[16:28, 20] = 1; merge[16, 20:36] = 1; merge[16:28, 35] = 1; merge[27, 20:36] = 1  # a ring (a closed loop)
    tie = np.zeros((H, W), np.uint8)
    tie[5:8, 5:11] = 1; tie[5:8, 25:31] = 1; tie[20:23, 15:21] = 1                          # three blobs of 18 pixels: the top-left one (smaller top row, smaller left edge) wins
    return [empty, merge, tie]


def bench_pictures():
    return [(f"animation picture {i}", f) for i, f in enumerate(frames())] + [(n, p) for n, p in zip(("single pixel in the corner", "comb and ring", "three-way tie"), extra_pictures())]


def pack_words(m):
    flat = [int(v) for v in m.flatten()] + [0] * 16
    return [sum(flat[32 * i + k] << k for k in range(32)) for i in range(38)]
