Problems / A. Basic digital design drills

LED pattern sequencer

t1_pattern_sequencer Benchmark v1 T1 A Basic digital design drills Nexys A7-100T

The problem

A programmable light show for the sixteen LEDs. The user writes up to sixteen steps, each with an LED pattern and a time to show it, then starts the show over the shell. It can loop for ever or play once and stop. A button pauses and resumes it, and changing the pattern of the step that is playing shows on the LEDs straight away.

Where it is used. The same table-driven idea sits behind status-light sequences, indicator and display animations, stage and sign lighting, and small waveform or stimulus generators that replay a stored list of values with timing.

The spec the agent is given

LED pattern sequencer

I want the Nexys A7-100T's sixteen LEDs to play back a little light show that I program over the test shell.

  • The show is up to sixteen steps. Each step is a 16-bit LED pattern and how long to show it, in milliseconds, up to a couple of hundred. I choose how many steps are in use.
  • It can loop for ever or play once and stop on the last step. I start and stop it over the shell; starting always begins at the first step.
  • BTNC pauses and resumes the show (it bounces, so debounce it).
  • When I change a step's pattern while the show runs, I want to see the change straight away.
  • CPU_RESETN resets everything.
  • Over the test shell (USB-UART, 115200 baud) I can write the steps, set the length and the mode, start and stop, and read which step is playing, whether it is running, paused or finished, and how many times it has gone round. The design ID is "PSEQ".

Test hooks: top module t1_pattern_sequencer_top, ports named as in the board's master XDC, the test shell's CLKS_PER_BIT, TIMEOUT_CYCLES and BUILD_STAMP parameters, plus DEBOUNCE_CYCLES (debounce time in clocks) and TICK_CYCLES (clocks per millisecond, the unit of step durations) as top-level parameters.

Exactly spec.md. Anything it leaves open, the agent has to ask about.

Interface

Top module t1_pattern_sequencer_top on the Nexys A7-100T (xc7a100tcsg324-1). Clock: CLK100MHZ at 100 MHz (board oscillator). Reset: CPU_RESETN, active low: stopped (RUN = 0, PAUSED = 0, DONE = 0), ONESHOT = 0, LENGTH = 4, INDEX = 0, LOOPS = 0, LED = 0; the entries are not changed by reset (they power up 0). Resources expected: about 150 LUTs (16 x 24 distributed RAM) and 60 FFs; no BRAM, no DSP.

Top-level parameters (board values): CLKS_PER_BIT = 868, DEBOUNCE_CYCLES = 1000000, TICK_CYCLES = 100000, TIMEOUT_CYCLES = 100000. The hidden bench shrinks them to CLKS_PER_BIT = 8, DEBOUNCE_CYCLES = 16, TICK_CYCLES = 16, TIMEOUT_CYCLES = 400.

What the hidden tests check

The requirements in the hidden spec, and how each is shown to hold:

  • REQ-01 Each entry is shown for exactly DUR * TICK_CYCLES running clocks (DUR 0 = 256 ticks) in index order (shown by simulation)
  • REQ-02 Loop mode wraps after LENGTH entries; one-shot stops on the last entry with DONE and the pattern held (shown by simulation)
  • REQ-03 BTNC pauses and resumes; paused time does not count (shown by simulation)
  • REQ-04 A pattern write to the playing entry shows at once; start always begins at entry 0 (shown by simulation)
  • REQ-05 The register window has the listed map and rules (shown by simulation)
  • REQ-06 The design closes timing at 100 MHz with no unconstrained path (shown by report analysis)
  • REQ-07 On the board a programmed one-shot show ends DONE on the last entry after the expected time (shown by on the board)
The full behaviour rules from hidden/spec.yaml

entries

  • Sixteen entries, each PATTERN (16 bits) and DUR (8 bits, ticks of TICK_CYCLES clocks; DUR = 0 means 256 ticks).
  • LENGTH (1..16) entries are played - indices 0..LENGTH-1.

playback

  • Start - a CTRL write with RUN = 1 while stopped begins at entry 0 (PAUSED = 0, DONE = 0). A write with RUN = 1 while running only updates ONESHOT. A write with RUN = 0 stops (RUN = PAUSED = DONE = 0) and the LEDs go dark.
  • Entry i is shown for exactly DUR_i * TICK_CYCLES clocks of running, unpaused time; DUR_i is latched when the entry starts, the pattern is read live, so a write to the playing entry's PATTERN shows on the LEDs at once.
  • At the end of entry i - if i + 1 < LENGTH the next entry starts on the next clock; otherwise LOOPS += 1 (16 bits, wrapping) and either entry 0 starts (loop) or, with ONESHOT = 1, playback stops with DONE = 1 and the LEDs keep showing the last entry's pattern.
  • LENGTH is read at each entry end, so changing it while running takes effect at the next entry end.

pause

  • BTNC is synchronised (two flops), then debounced. The debounced level changes only after the synchronised input has differed from it for DEBOUNCE_CYCLES consecutive clocks; a shorter difference restarts the count. A press is a 0 -> 1 change of the debounced level.
  • A press while RUN = 1 toggles PAUSED. While paused the entry's tick counter and prescaler stand still and the LEDs keep the pattern; the clock of the pausing press still counts and the clock of the resuming press does not, so a pause adds exactly the clocks between the two presses. A press while stopped does nothing.

leds

  • LED[15:0] = PATTERN of the current entry while running (paused or not) or DONE; 0 when stopped and not DONE.

Settled assumptions

  • a duration of 0 means 256 ticks. an 8-bit field with no useless zero-length step.
  • the LEDs go dark when stopped but hold the last step after a one-shot finishes. the request says a one-shot stops on the last step.
  • reset keeps the sixteen pattern entries (they power up 0) and stops playback; everything else returns to its reset value. the entries are configuration the user loaded; the request does not say that a reset erases them.
  • LENGTH is read at the end of each entry, so a change while running takes effect at the next entry end. the request does not say when a changed length applies; the end of an entry never cuts one short.

// bm_debounce.sv: two-flop synchroniser, then a counting debounce. The level
// changes only after the synchronised input has differed from it for CYCLES
// consecutive clocks; a shorter difference restarts the count. rise is a
// one-clock pulse on each 0 -> 1 change of the level.
module bm_debounce #(
    parameter int CYCLES = 1_000_000
) (
    input  logic clk,
    input  logic rst,
    input  logic d_async,
    output logic level,
    output logic rise
);
    localparam int CW = $clog2(CYCLES + 1);
    logic        d;
    logic [CW-1:0] run;

    sync2 u_sync (.clk(clk), .rst(rst), .d(d_async), .q(d));

    always_ff @(posedge clk) begin
        rise <= 1'b0;
        if (rst) begin
            level <= 1'b0;
            run   <= '0;
        end else if (d == level) begin
            run <= '0;
        end else if (run == CW'(CYCLES - 1)) begin
            level <= d;
            run   <= '0;
            rise  <= d;
        end else begin
            run <= run + 1'b1;
        end
    end
endmodule

// pattern_sequencer.sv: 16-entry LED pattern/duration memory played in loop or
// one-shot mode, paused by BTNC, for t1_pattern_sequencer.
module pattern_sequencer #(
    parameter int DEBOUNCE_CYCLES = 1_000_000,
    parameter int TICK_CYCLES     = 100_000
) (
    input  logic        clk,
    input  logic        rst,
    input  logic        btn,
    output logic [15:0] led,
    input  logic [6:0]  win_addr,
    input  logic        win_wr,
    input  logic        win_rd,
    input  logic [31:0] win_wdata,
    output logic [31:0] win_rdata
);
    localparam logic [6:0] R_CTRL = 7'h00, R_LEN = 7'h01, R_INDEX = 7'h02, R_STATUS = 7'h03, R_LOOPS = 7'h04;
    localparam int PW = $clog2(TICK_CYCLES + 1);

    logic [15:0]   pat [16];
    logic [7:0]    dur [16];
    logic          lvl, press, run, oneshot, paused, done;
    logic [4:0]    len;
    logic [3:0]    idx;
    logic [8:0]    left;            // ticks left in this entry, 1..256
    logic [15:0]   loops;
    logic [PW-1:0] pre;

    bm_debounce #(.CYCLES(DEBOUNCE_CYCLES)) u_db (.clk(clk), .rst(rst), .d_async(btn), .level(lvl), .rise(press));

    wire wr_entry = win_wr && win_addr[6:4] == 3'b001;
    wire wr_ctrl  = win_wr && win_addr == R_CTRL;
    wire tick     = pre == PW'(TICK_CYCLES - 1);

    function automatic logic [8:0] ticks(input logic [7:0] d);
        return (d == 8'd0) ? 9'd256 : {1'b0, d};
    endfunction

    initial for (int i = 0; i < 16; i++) begin pat[i] = '0; dur[i] = '0; end

    always_ff @(posedge clk)
        if (wr_entry) begin
            pat[win_addr[3:0]] <= win_wdata[15:0];
            dur[win_addr[3:0]] <= win_wdata[23:16];
        end

    always_ff @(posedge clk) begin
        if (rst) begin
            run <= 1'b0; oneshot <= 1'b0; paused <= 1'b0; done <= 1'b0; len <= 5'd4; idx <= '0;
            left <= '0; loops <= '0; pre <= '0;
        end else begin
            if (win_wr && win_addr == R_LEN && win_wdata[4:0] != 5'd0 && win_wdata[4:0] <= 5'd16)
                len <= win_wdata[4:0];
            if (wr_ctrl) oneshot <= win_wdata[1];
            if (wr_ctrl && !win_wdata[0]) begin
                run <= 1'b0; paused <= 1'b0; done <= 1'b0;
            end else if (wr_ctrl && !run) begin
                run <= 1'b1; paused <= 1'b0; done <= 1'b0; idx <= '0; pre <= '0;
                left <= ticks(dur[0]);
            end else if (run) begin
                if (press) paused <= !paused;
                if (!paused) begin
                    pre <= tick ? '0 : pre + 1'b1;
                    if (tick) begin
                        if (left != 9'd1) left <= left - 9'd1;
                        else if (5'(idx) + 5'd1 < len) begin
                            idx  <= idx + 4'd1;
                            left <= ticks(dur[idx + 4'd1]);
                        end else begin
                            loops <= loops + 1'b1;
                            if (oneshot) begin
                                run  <= 1'b0;
                                done <= 1'b1;
                            end else begin
                                idx  <= '0;
                                left <= ticks(dur[0]);
                            end
                        end
                    end
                end
            end
        end
    end

    always_ff @(posedge clk) begin
        if (rst) led <= '0;
        else     led <= (run || done) ? pat[idx] : 16'd0;
    end

    always_ff @(posedge clk) begin
        if (rst) win_rdata <= '0;
        else if (win_rd) begin
            if (win_addr[6:4] == 3'b001) win_rdata <= {8'd0, dur[win_addr[3:0]], pat[win_addr[3:0]]};
            else case (win_addr)
                R_CTRL:   win_rdata <= {30'd0, oneshot, run};
                R_LEN:    win_rdata <= {27'd0, len};
                R_INDEX:  win_rdata <= {28'd0, idx};
                R_STATUS: win_rdata <= {29'd0, done, paused, run};
                R_LOOPS:  win_rdata <= {16'd0, loops};
                default:  win_rdata <= '0;
            endcase
        end
    end
endmodule

// t1_pattern_sequencer_top.sv: board top (Nexys A7-100T, master-XDC port names).
// Reference design for benchmark task t1_pattern_sequencer; DESIGN_ID "PSEQ".
module t1_pattern_sequencer_top #(
    parameter int          CLKS_PER_BIT    = 868,
    parameter int          TIMEOUT_CYCLES  = 100_000,
    parameter int          DEBOUNCE_CYCLES = 1_000_000,
    parameter int          TICK_CYCLES     = 100_000,
    parameter logic [31:0] BUILD_STAMP     = 32'h0
) (
    input  logic        CLK100MHZ,
    input  logic        CPU_RESETN,
    input  logic        BTNC,
    output logic [15:0] LED,
    input  logic        UART_TXD_IN,
    output logic        UART_RXD_OUT
);
    logic        clk, rst, win_wr, win_rd;
    logic [6:0]  win_addr;
    logic [31:0] win_wdata, win_rdata;

    assign clk = CLK100MHZ;
    reset_sync u_rst (.clk(clk), .rst_n_async(CPU_RESETN), .rst(rst));

    fpga_shell #(.CLKS_PER_BIT(CLKS_PER_BIT), .TIMEOUT_CYCLES(TIMEOUT_CYCLES),
                 .DESIGN_ID(32'h5053_4551), .BUILD_STAMP(BUILD_STAMP)) u_shell (
        .clk(clk), .rst(rst), .uart_rx(UART_TXD_IN), .uart_tx(UART_RXD_OUT),
        .win_addr(win_addr), .win_wr(win_wr), .win_rd(win_rd), .win_wdata(win_wdata), .win_rdata(win_rdata));

    pattern_sequencer #(.DEBOUNCE_CYCLES(DEBOUNCE_CYCLES), .TICK_CYCLES(TICK_CYCLES)) u_seq (
        .clk(clk), .rst(rst), .btn(BTNC), .led(LED),
        .win_addr(win_addr), .win_wr(win_wr), .win_rd(win_rd), .win_wdata(win_wdata), .win_rdata(win_rdata));
endmodule

"""Acceptance tests of t1_pattern_sequencer against model.py (hidden from the agent).

A watcher logs every LED change with its clock; a playback is checked as the sequence of patterns shown and the
exact number of clocks each was shown (the first change is the start, so no absolute timing is needed)."""

from __future__ import annotations

import random

import cocotb
from benchmark.lib.bench import Board, peek
from cocotb.triggers import ReadOnly, RisingEdge
from cocotb.utils import get_sim_time
from model import CTRL, DESIGN_ID, ENTRY0, INDEX, LENGTH, LOOPS, STATUS, Model


class Watch:
    def __init__(self, dut, clk) -> None:
        self.ev: list[tuple[int, int]] = []
        cocotb.start_soon(self.run(dut, clk))

    async def run(self, dut, clk) -> None:
        prev = None
        while True:
            await RisingEdge(clk)
            await ReadOnly()
            v = int(dut.LED.value)
            if v != prev:
                self.ev.append((int(get_sim_time("ns")) // 10, v))
            prev = v

    def take(self) -> list[tuple[int, int]]:
        ev, self.ev = self.ev, []
        return ev


def shown(ev: list[tuple[int, int]]) -> list[tuple[int, int]]:
    """(pattern, clocks) for every change except the last (whose length is not yet known)."""
    return [(v, ev[i + 1][0] - t) for i, (t, v) in enumerate(ev[:-1])]


class Env:
    def __init__(self, dut) -> None:
        self.b = Board(dut, {"BTNC": 0})
        self.dut = dut
        self.n = self.b.param("DEBOUNCE_CYCLES")
        self.tick = self.b.param("TICK_CYCLES")
        self.m = Model(self.tick)
        self.w: Watch | None = None

    def now(self) -> int:
        return int(get_sim_time("ns")) // 10

    async def start(self) -> None:
        await self.b.start()
        self.w = Watch(self.dut, self.b.clk)
        await self.b.cycles(2)
        self.w.take()

    async def wr(self, off: int, v: int) -> None:
        await self.b.write(off, v)
        self.m.write(off, v)

    async def program(self, entries: list[tuple[int, int]], length: int | None = None) -> None:
        for i, (pat, dur) in enumerate(entries):
            await self.wr(ENTRY0 + i, pat | dur << 16)
        if length is not None:
            await self.wr(LENGTH, length)

    async def play(self, ctrl: int, clocks: int) -> list[tuple[int, int]]:
        """Start (from stopped) and watch for ``clocks``; returns the LED changes from the start on."""
        self.w.take()
        await self.wr(CTRL, ctrl)
        await self.b.cycles(clocks)
        return self.w.take()

    async def press(self) -> int:
        self.dut.BTNC.value = 1
        t = self.now()
        await self.b.cycles(self.n + 6)
        self.dut.BTNC.value = 0
        await self.b.cycles(self.n + 6)
        return t

    async def wait_for(self, pattern: int, limit: int = 20000) -> int:
        for _ in range(limit):
            await RisingEdge(self.b.clk)
            if self.w.ev and self.w.ev[-1][1] == pattern:
                return self.w.ev[-1][0]
        raise AssertionError(f"pattern {pattern:04X} never shown")


PATS = [0x0001, 0x8000, 0x00F0, 0x0F0F, 0xAAAA, 0x5555, 0xFF00, 0x1234, 0x0420, 0xC003, 0x7E7E, 0x0101, 0x8421,
        0x3C3C, 0x6006, 0x0FF0]


@cocotb.test()
async def test_identity_and_reset(dut):
    e = Env(dut)
    await e.start()
    assert await e.b.shell_id() == DESIGN_ID
    for off, want in ((CTRL, 0), (LENGTH, 4), (INDEX, 0), (STATUS, 0), (LOOPS, 0), (ENTRY0, 0), (ENTRY0 + 15, 0)):
        await e.b.expect(off, want)
    assert await peek(e.b.clk, dut.LED) == 0


@cocotb.test()
async def test_loop_playback(dut):
    e = Env(dut)
    await e.start()
    durs = [3, 1, 5, 2, 4]
    await e.program([(PATS[i], d) for i, d in enumerate(durs)], length=5)
    total = sum(durs) * e.tick
    ev = await e.play(1, 2 * total + total // 2)
    want = e.m.show(len(ev) - 1)
    assert shown(ev) == want, f"shown {shown(ev)} != model {want}"
    await e.b.expect(STATUS, 1, "STATUS running")
    await e.wr(CTRL, 0)                         # stop: LEDs dark
    await e.b.expect(STATUS, 0, "STATUS stopped")
    assert await peek(e.b.clk, dut.LED) == 0
    loops = await e.b.read(LOOPS)
    assert loops >= 2, f"LOOPS {loops} after more than two passes"


@cocotb.test()
async def test_one_shot_holds_last(dut):
    e = Env(dut)
    await e.start()
    await e.program([(PATS[i], 2 + i) for i in range(6)], length=3)
    ev = await e.play(0b11, 20 * e.tick + 2000)
    assert [v for _, v in ev] == PATS[:3], f"one-shot showed {[hex(v) for _, v in ev]}"
    assert shown(ev) == e.m.show(2)
    await e.b.expect(STATUS, 0b100, "STATUS DONE")
    await e.b.expect(INDEX, 2, "INDEX of the last entry")
    await e.b.expect(LOOPS, 1, "LOOPS")
    await e.b.expect(CTRL, 0b10, "CTRL after one-shot")
    assert await peek(e.b.clk, dut.LED) == PATS[2], "LEDs must hold the last pattern"
    ev = await e.play(0b11, 20 * e.tick)        # starts again from entry 0
    assert ev and ev[0][1] == PATS[0]
    await e.wr(CTRL, 0)                         # stop clears DONE and darkens
    await e.b.expect(STATUS, 0, "STATUS")
    assert await peek(e.b.clk, dut.LED) == 0


@cocotb.test()
async def test_pause_button(dut):
    e = Env(dut)
    await e.start()
    await e.program([(PATS[i], 100) for i in range(3)], length=3)
    e.w.take()
    await e.wr(CTRL, 1)
    t_on = await e.wait_for(PATS[0])
    await e.b.cycles(3 * e.tick)
    r1 = await e.press()                        # pause
    await e.b.expect(STATUS, 0b011, "STATUS paused")
    assert await peek(e.b.clk, dut.LED) == PATS[0]
    await e.b.cycles(2000)
    r2 = await e.press()                        # resume
    t_next = await e.wait_for(PATS[1])
    assert t_next - t_on == 100 * e.tick + (r2 - r1), \
        f"entry 0 lasted {t_next - t_on} clocks, want {100 * e.tick} + paused {r2 - r1}"
    await e.b.expect(STATUS, 0b001, "STATUS resumed")
    await e.wr(CTRL, 0)
    await e.press()                             # stopped: a press does nothing
    await e.b.expect(STATUS, 0, "STATUS")

@cocotb.test()
async def test_length_rules(dut):
    e = Env(dut)
    await e.start()
    await e.program([(PATS[i], 4) for i in range(4)] + [(PATS[4], 120)], length=5)
    await e.wr(LENGTH, 0)                       # ignored
    await e.wr(LENGTH, 17)                      # ignored
    await e.b.expect(LENGTH, 5, "LENGTH")
    e.w.take()
    await e.wr(CTRL, 1)
    await e.wait_for(PATS[4])                   # entry 4 is long: change LENGTH while it plays
    await e.wr(LENGTH, 2)
    await e.b.cycles(120 * e.tick + 20 * e.tick)
    ev = e.w.take()
    vals = [v for _, v in ev]
    assert vals[:5] == PATS[:5] and vals[5:9] == [PATS[0], PATS[1], PATS[0], PATS[1]], \
        f"after LENGTH = 2 the show must wrap after entry 1: {[hex(v) for v in vals]}"


@cocotb.test()
async def test_live_pattern_edit(dut):
    e = Env(dut)
    await e.start()
    await e.program([(PATS[0], 3), (PATS[1], 150), (PATS[2], 3)], length=3)
    e.w.take()
    await e.wr(CTRL, 1)
    t1 = await e.wait_for(PATS[1])
    await e.wr(ENTRY0 + 1, 0x0BAD | 150 << 16)  # shows at once; the entry's timing is unchanged
    assert await peek(e.b.clk, dut.LED) == 0x0BAD

"""Golden model of t1_pattern_sequencer, written from spec.yaml alone (never from any RTL)."""

from __future__ import annotations

CTRL, LENGTH, INDEX, STATUS, LOOPS = range(5)
ENTRY0 = 0x10
DESIGN_ID = 0x50534551          # "PSEQ"


class Model:
    def __init__(self, tick: int) -> None:
        self.tick = tick
        self.pat = [0] * 16
        self.dur = [0] * 16
        self.length = 4
        self.oneshot = 0

    def write(self, off: int, v: int) -> None:
        if ENTRY0 <= off < ENTRY0 + 16:
            self.pat[off - ENTRY0] = v & 0xFFFF
            self.dur[off - ENTRY0] = (v >> 16) & 0xFF
        elif off == LENGTH and 1 <= (v & 0x1F) <= 16:
            self.length = v & 0x1F
        elif off == CTRL:
            self.oneshot = (v >> 1) & 1

    def read_entry(self, i: int) -> int:
        return self.pat[i] | self.dur[i] << 16

    def clocks(self, i: int) -> int:
        return (self.dur[i] or 256) * self.tick

    def show(self, n: int) -> list[tuple[int, int]]:
        """The first n (pattern, clocks shown) of a playback started now, with no pause and no writes."""
        out, i = [], 0
        while len(out) < n:
            out.append((self.pat[i], self.clocks(i)))
            i += 1
            if i >= self.length:
                if self.oneshot:
                    break
                i = 0
        return out
