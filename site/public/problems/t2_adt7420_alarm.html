Problems / F. Interfaces and protocols

Temperature alarm with the on-board ADT7420

t2_adt7420_alarm Benchmark v1 T2 F Interfaces and protocols Nexys A7-100T

The problem

A temperature monitor that talks over I2C to the sensor chip on the board. On a configure command it sets the sensor to its high-resolution mode and loads the high and low limits the user wrote beforehand. After that it reads the temperature at regular intervals and keeps the latest, highest and lowest readings and a count. The alarm is the sensor's own interrupt pin, shown in a status bit and on an LED, and any missing acknowledgement from the sensor is reported.

Where it is used. Digital temperature sensors with a limit pin are used in computers, servers, power supplies and battery packs to raise an over-temperature alert without the processor polling. Thermal protection in an FPGA board or a data-centre server follows the same pattern.

The spec the agent is given

Temperature alarm with the on-board ADT7420

Using the Nexys A7-100T's ADT7420 temperature sensor (I2C on TMP_SCL / TMP_SDA, address 0x4B), I want a temperature monitor with a hardware alarm.

  • On a configure command, set the sensor to its high-resolution 16-bit mode with the interrupt pin in comparator mode, active low, and load its high and low limits from two registers I write beforehand (raw sensor format).
  • After that, read the temperature regularly (a parameter gives the period in clocks) and keep the raw 16-bit reading, the highest and lowest readings since configuring, and a count of readings.
  • The alarm is the sensor's own TMP_INT pin: show it in a status bit and on LED0.
  • Report I2C failures (no acknowledge) in the status.
  • The usual open-drain care on the bus; the sensor may stretch the clock. SCL speed from a parameter giving a quarter of the SCL period in clocks (100 kHz on the board).
  • Through the test shell; design ID "TALM".

Test hooks: top module t2_adt7420_alarm_top, ports named as in the board's master XDC (TMP_SCL, TMP_SDA, TMP_INT, LED, the USB-UART pins, CLK100MHZ, CPU_RESETN), the test shell's CLKS_PER_BIT, TIMEOUT_CYCLES and BUILD_STAMP parameters, plus QUARTER (a quarter of the SCL period, in clocks) and PERIOD_CYCLES (clocks between temperature readings) as top-level parameters.

Exactly spec.md. Anything it leaves open, the agent has to ask about.

Interface

Top module t2_adt7420_alarm_top on the Nexys A7-100T (xc7a100tcsg324-1). Clock: CLK100MHZ at 100 MHz (board oscillator). Reset: CPU_RESETN, active low: registers to reset values; no I2C traffic until a configure command; both lines released. Resources expected: a few hundred LUTs and FFs; no BRAM, no DSP.

Top-level parameters (board values): CLKS_PER_BIT = 868, PERIOD_CYCLES = 25000000, QUARTER = 250, TIMEOUT_CYCLES = 100000. The hidden bench shrinks them to CLKS_PER_BIT = 8, PERIOD_CYCLES = 8000, QUARTER = 3, TIMEOUT_CYCLES = 400.

What the hidden tests check

The requirements in the hidden spec, and how each is shown to hold:

  • REQ-01 Configure writes CONFIG 0x90, T_HIGH and T_LOW in that order (shown by simulation)
  • REQ-02 Readings use a repeated START and keep the full 16-bit value (shown by simulation)
  • REQ-03 MAX, MIN, SAMPLES and VALID follow the readings; NACKs are reported and discard the reading (shown by simulation)
  • REQ-04 ALARM and LED0 follow TMP_INT, active low (shown by simulation, on the board)
  • REQ-05 On the board the reading is a plausible room temperature with odd low bits seen over time (shown by on the board)
  • REQ-06 The design closes timing at 100 MHz with no unconstrained path (shown by report analysis)
The full behaviour rules from hidden/spec.yaml

bus

  • I2C waveforms as an open-drain master with Q = QUARTER clocks - START SDA low, wait 2Q, SCL low, wait Q; each of the 9 bits of a byte - set SDA, wait Q, release SCL and wait until it is seen high (stretching), wait 2Q, sample, SCL low, wait Q; repeated START - release SDA, wait Q, release SCL and wait high, wait 2Q, SDA low, wait 2Q, SCL low, wait Q; STOP - SDA low, wait Q, release SCL and wait high, wait 2Q, release SDA, wait 2Q.
  • The lines are only pulled low or released.

configure

  • A write to CTRL with bit 0 = 1 while BUSY = 0 configures - TEMP, MAX, MIN, SAMPLES and VALID are cleared, NACK cleared, then three write transactions to address 0x4B in this order - [START, 0x96, 0x03, 0x90, STOP] (CONFIG - 16-bit resolution, comparator mode, INT active low, fault queue 1); [START, 0x96, 0x04, THIGH[15:8], THIGH[7:0], STOP]; [START, 0x96, 0x06, TLOW[15:8], TLOW[7:0], STOP].
  • After the third transaction CONFIGURED is set (even if a NACK occurred) and polling begins. Writes to CTRL while BUSY are ignored; a later configure repeats the sequence and restarts the statistics.

polling

  • While CONFIGURED, a reading starts PERIOD_CYCLES clocks after the previous one started (the first PERIOD_CYCLES clocks after the configure sequence ends) - [START, 0x96, 0x00, repeated START, 0x97, read MSB with ACK, read LSB with NACK, STOP]. Never a STOP between the pointer write and the read (the sensor would lose its pointer).
  • A reading with no NACK sets TEMP = {MSB, LSB}, SAMPLES += 1, and MAX / MIN (compared as signed 16-bit) - the first reading after a configure sets both; VALID is set.
  • If any byte of a transaction is NACKed, the master sends STOP after that byte, NACK is set (sticky until the next configure), and a reading is discarded.
  • BUSY is 1 during the configure sequence and during each reading.

alarm

  • ALARM = NOT TMP_INT (synchronised by two flops) - the pin is active low. LED[0] = ALARM; LED[15:1] = 0.

Settled assumptions

  • the fault queue is left at 1 (CONFIG[1:0] = 00). the request does not ask for filtering of the alarm.
  • T_HYST stays at its power-on value (5 C). no hysteresis setting was requested.

// t2_adt7420_alarm_top.sv: board top (Nexys A7-100T, master-XDC port names).
// Reference design for benchmark task t2_adt7420_alarm; DESIGN_ID "TALM".
// ADT7420 in 16-bit mode, comparator-mode alarm on TMP_INT (active low), readings over the shell.
module t2_adt7420_alarm_top #(
    parameter int          CLKS_PER_BIT   = 868,
    parameter int          TIMEOUT_CYCLES = 100_000,
    parameter int          QUARTER        = 250,
    parameter int          PERIOD_CYCLES  = 25_000_000,
    parameter logic [31:0] BUILD_STAMP    = 32'h0
) (
    input  logic        CLK100MHZ,
    input  logic        CPU_RESETN,
    inout  wire         TMP_SCL,
    inout  wire         TMP_SDA,
    input  logic        TMP_INT,
    output logic [15:0] LED,
    input  logic        UART_TXD_IN,
    output logic        UART_RXD_OUT
);
    logic        clk, rst, win_wr, win_rd, scl_oe, sda_oe, int_n;
    logic [1:0]  lines;
    logic [6:0]  win_addr;
    logic [31:0] win_wdata, win_rdata;

    assign clk = CLK100MHZ;
    reset_sync u_rst (.clk(clk), .rst_n_async(CPU_RESETN), .rst(rst));

    fpga_shell #(.CLKS_PER_BIT(CLKS_PER_BIT), .TIMEOUT_CYCLES(TIMEOUT_CYCLES),
                 .DESIGN_ID(32'h5441_4C4D), .BUILD_STAMP(BUILD_STAMP)) u_shell (
        .clk(clk), .rst(rst), .uart_rx(UART_TXD_IN), .uart_tx(UART_RXD_OUT),
        .win_addr(win_addr), .win_wr(win_wr), .win_rd(win_rd), .win_wdata(win_wdata), .win_rdata(win_rdata));

    assign TMP_SCL = scl_oe ? 1'b0 : 1'bz;
    assign TMP_SDA = sda_oe ? 1'b0 : 1'bz;
    sync2 #(.WIDTH(2), .RESET_VALUE(2'b11)) u_sync (.clk(clk), .rst(rst), .d({TMP_SCL, TMP_SDA}), .q(lines));
    sync2 #(.WIDTH(1), .RESET_VALUE(1'b1)) u_int (.clk(clk), .rst(rst), .d(TMP_INT), .q(int_n));

    talm_ctl #(.QUARTER(QUARTER), .PERIOD_CYCLES(PERIOD_CYCLES)) u_ctl (
        .clk(clk), .rst(rst), .scl_in(lines[1]), .sda_in(lines[0]), .scl_oe(scl_oe), .sda_oe(sda_oe),
        .alarm(!int_n),
        .win_addr(win_addr), .win_wr(win_wr), .win_rd(win_rd), .win_wdata(win_wdata), .win_rdata(win_rdata));

    always_ff @(posedge clk) begin
        if (rst) LED <= '0;
        else     LED <= {15'd0, !int_n};
    end
endmodule

// talm_ctl.sv: ADT7420 alarm monitor. Configure: CONFIG = 0x90 (16-bit,
// comparator, INT active low), T_HIGH, T_LOW. Then a reading every
// PERIOD_CYCLES: pointer 0x00, repeated START, two bytes. MAX/MIN/SAMPLES.
module talm_ctl #(
    parameter int QUARTER       = 250,
    parameter int PERIOD_CYCLES = 25_000_000
) (
    input  logic        clk,
    input  logic        rst,
    input  logic        scl_in,
    input  logic        sda_in,
    output logic        scl_oe,
    output logic        sda_oe,
    input  logic        alarm,          // synchronised, active high
    input  logic [6:0]  win_addr,
    input  logic        win_wr,
    input  logic        win_rd,
    input  logic [31:0] win_wdata,
    output logic [31:0] win_rdata
);
    localparam logic [2:0] S = 3'd1, W = 3'd2, R = 3'd3, P = 3'd4;
    localparam logic [7:0] AW = 8'h96, AR = 8'h97, CONFIG_VAL = 8'h90;
    localparam int PW = $clog2(PERIOD_CYCLES + 1);

    typedef enum logic [2:0] {IDLE, ISSUE, WAIT1, WAIT, ABORT, ABORT_W} st_t;
    st_t st;

    logic        go, cbusy, cnack, configured, valid, nack, busy, reading;
    logic [2:0]  op;
    logic [7:0]  wd, rx, msb;
    logic        rn, last;
    logic [4:0]  step;
    logic [15:0] thigh, tlow, temp, tmax, tmin;
    logic [31:0] samples;
    logic [PW-1:0] pc;
    logic        pend;

    tm_i2c_core #(.QUARTER(QUARTER)) u_i2c (
        .clk(clk), .rst(rst), .go(go), .op(op), .wdata(wd), .rnack(rn), .scl_in(scl_in), .sda_in(sda_in),
        .scl_oe(scl_oe), .sda_oe(sda_oe), .busy(cbusy), .owned(), .nack(cnack), .rxdata(rx));

    // the two programs: configure (17 steps) and reading (8 steps)
    always_comb begin
        op = P; wd = 8'h00; rn = 1'b0; last = 1'b0;
        if (!reading) begin
            case (step)
                5'd0:  op = S;
                5'd1:  begin op = W; wd = AW; end
                5'd2:  begin op = W; wd = 8'h03; end
                5'd3:  begin op = W; wd = CONFIG_VAL; end
                5'd4:  op = P;
                5'd5:  op = S;
                5'd6:  begin op = W; wd = AW; end
                5'd7:  begin op = W; wd = 8'h04; end
                5'd8:  begin op = W; wd = thigh[15:8]; end
                5'd9:  begin op = W; wd = thigh[7:0]; end
                5'd10: op = P;
                5'd11: op = S;
                5'd12: begin op = W; wd = AW; end
                5'd13: begin op = W; wd = 8'h06; end
                5'd14: begin op = W; wd = tlow[15:8]; end
                5'd15: begin op = W; wd = tlow[7:0]; end
                default: begin op = P; last = 1'b1; end
            endcase
        end else begin
            case (step)
                5'd0: op = S;
                5'd1: begin op = W; wd = AW; end
                5'd2: begin op = W; wd = 8'h00; end
                5'd3: op = S;                                 // repeated START (the bus is owned)
                5'd4: begin op = W; wd = AR; end
                5'd5: begin op = R; rn = 1'b0; end
                5'd6: begin op = R; rn = 1'b1; end
                default: begin op = P; last = 1'b1; end
            endcase
        end
    end

    wire start_cfg = win_wr && win_addr == 7'h00 && win_wdata[0] && !busy;

    // reading timer: from the start of the previous reading
    always_ff @(posedge clk) begin
        if (rst || !configured) begin
            pc <= '0; pend <= 1'b0;
        end else if (st == IDLE && pend && !start_cfg) begin
            pc <= '0; pend <= 1'b0;
        end else if (pc == PW'(PERIOD_CYCLES - 1)) begin
            pc <= '0; pend <= 1'b1;
        end else begin
            pc <= pc + 1'b1;
        end
    end

    always_ff @(posedge clk) begin
        go <= 1'b0;
        if (rst) begin
            st <= IDLE; step <= '0; reading <= 1'b0; busy <= 1'b0; configured <= 1'b0; valid <= 1'b0;
            nack <= 1'b0; thigh <= 16'h2000; tlow <= 16'h0500; temp <= '0; tmax <= '0; tmin <= '0;
            samples <= '0; msb <= '0;
        end else begin
            if (win_wr && win_addr == 7'h02) thigh <= win_wdata[15:0];
            if (win_wr && win_addr == 7'h03) tlow  <= win_wdata[15:0];
            case (st)
                IDLE: if (start_cfg) begin
                    busy <= 1'b1; reading <= 1'b0; step <= '0; configured <= 1'b0;
                    valid <= 1'b0; nack <= 1'b0; temp <= '0; tmax <= '0; tmin <= '0; samples <= '0;
                    st <= ISSUE;
                end else if (configured && pend) begin
                    busy <= 1'b1; reading <= 1'b1; step <= '0; st <= ISSUE;
                end
                ISSUE: begin go <= 1'b1; st <= WAIT1; end
                WAIT1: st <= WAIT;
                WAIT: if (!cbusy) begin
                    if (op == W && cnack) begin
                        nack <= 1'b1;
                        st <= ABORT;
                    end else if (last) begin
                        st <= IDLE; busy <= 1'b0;
                        if (!reading) configured <= 1'b1;
                    end else begin
                        if (reading && step == 5'd5) msb <= rx;
                        if (reading && step == 5'd6) begin
                            temp <= {msb, rx};
                            samples <= samples + 1'b1;
                            valid <= 1'b1;
                            if (!valid || $signed({msb, rx}) > $signed(tmax)) tmax <= {msb, rx};
                            if (!valid || $signed({msb, rx}) < $signed(tmin)) tmin <= {msb, rx};
                        end
                        step <= step + 1'b1;
                        st <= ISSUE;
                    end
                end
                // a NACK: STOP, then end this program (a configure still completes its remaining transactions)
                ABORT: begin
                    if (!reading && step < 5'd11) begin
                        step <= (step < 5'd5) ? 5'd4 : 5'd10;     // the STOP of this transaction, then go on
                        st <= ISSUE;
                    end else begin
                        step <= 5'd16;                           // the final STOP
                        if (reading) step <= 5'd7;
                        st <= ISSUE;
                    end
                end
                default: st <= IDLE;
            endcase
        end
    end

    always_ff @(posedge clk) begin
        if (rst) win_rdata <= '0;
        else if (win_rd) begin
            case (win_addr)
                7'h01:   win_rdata <= {27'd0, alarm, nack, valid, configured, busy};
                7'h02:   win_rdata <= {16'd0, thigh};
                7'h03:   win_rdata <= {16'd0, tlow};
                7'h04:   win_rdata <= {16'd0, temp};
                7'h05:   win_rdata <= {16'd0, tmax};
                7'h06:   win_rdata <= {16'd0, tmin};
                7'h07:   win_rdata <= samples;
                default: win_rdata <= '0;
            endcase
        end
    end
endmodule

// tm_i2c_core.sv: byte-command I2C master (open drain). One command at a time:
// START (repeated START when the bus is owned), WRITE byte, READ byte, STOP.
// Q = QUARTER clocks. Every SCL high time counts from SCL seen high, so a
// slave that stretches the clock is waited for.
module tm_i2c_core #(
    parameter int QUARTER = 250
) (
    input  logic       clk,
    input  logic       rst,
    input  logic       go,          // one clock; ignored while busy
    input  logic [2:0] op,
    input  logic [7:0] wdata,
    input  logic       rnack,
    input  logic       scl_in,      // synchronised bus levels
    input  logic       sda_in,
    output logic       scl_oe,      // 1 = pull low
    output logic       sda_oe,
    output logic       busy,
    output logic       owned,
    output logic       nack,
    output logic [7:0] rxdata
);
    localparam logic [2:0] OP_START = 3'd1, OP_WRITE = 3'd2, OP_READ = 3'd3, OP_STOP = 3'd4;
    localparam int CW = $clog2(2 * QUARTER + 1);

    typedef enum logic [3:0] {
        IDLE, S1, S2, R1, R2, R3, R4, B1, B2, B3, P1, P2, P3
    } st_t;
    st_t st;

    logic [CW-1:0] cnt;
    logic [3:0]    k;               // bit 0..8 of a byte command
    logic          rd, ack_n;
    logic [7:0]    sh;

    localparam logic [CW-1:0] Q1 = CW'(QUARTER - 1), Q2 = CW'(2 * QUARTER - 1);

    always_ff @(posedge clk) begin
        if (rst) begin
            st <= IDLE; cnt <= '0; k <= '0; rd <= 1'b0; ack_n <= 1'b0; sh <= '0;
            scl_oe <= 1'b0; sda_oe <= 1'b0; busy <= 1'b0; owned <= 1'b0; nack <= 1'b0; rxdata <= '0;
        end else begin
            case (st)
                IDLE: if (go) begin
                    case (op)
                        OP_START: begin
                            busy <= 1'b1;
                            if (owned) begin st <= R1; sda_oe <= 1'b0; cnt <= Q1; end
                            else       begin st <= S1; sda_oe <= 1'b1; cnt <= Q2; end
                        end
                        OP_WRITE, OP_READ: if (owned) begin
                            busy <= 1'b1;
                            st <= B1; k <= '0; rd <= op == OP_READ; ack_n <= rnack; sh <= wdata;
                            sda_oe <= (op == OP_WRITE) ? !wdata[7] : 1'b0;
                            cnt <= Q1;
                        end
                        OP_STOP: if (owned) begin
                            busy <= 1'b1;
                            st <= P1; sda_oe <= 1'b1; cnt <= Q1;
                        end
                        default: ;
                    endcase
                end
                // START on a free bus: SDA low (2Q), SCL low (Q)
                S1: if (cnt == '0) begin st <= S2; scl_oe <= 1'b1; cnt <= Q1; end else cnt <= cnt - 1'b1;
                S2: if (cnt == '0) begin st <= IDLE; busy <= 1'b0; owned <= 1'b1; end else cnt <= cnt - 1'b1;
                // repeated START
                R1: if (cnt == '0) begin st <= R2; scl_oe <= 1'b0; cnt <= Q2; end else cnt <= cnt - 1'b1;
                R2: if (!scl_in) cnt <= Q2;
                    else if (cnt == '0) begin st <= R3; sda_oe <= 1'b1; cnt <= Q2; end
                    else cnt <= cnt - 1'b1;
                R3: if (cnt == '0) begin st <= R4; scl_oe <= 1'b1; cnt <= Q1; end else cnt <= cnt - 1'b1;
                R4: if (cnt == '0) begin st <= IDLE; busy <= 1'b0; end else cnt <= cnt - 1'b1;
                // one bit of WRITE / READ: SDA set (Q), SCL high (2Q, sample), SCL low (Q)
                B1: if (cnt == '0) begin st <= B2; scl_oe <= 1'b0; cnt <= Q2; end else cnt <= cnt - 1'b1;
                B2: if (!scl_in) cnt <= Q2;
                    else if (cnt == '0) begin
                        st <= B3; scl_oe <= 1'b1; cnt <= Q1;
                        if (k == 4'd8) begin
                            if (!rd) nack <= sda_in;
                        end else begin
                            sh <= {sh[6:0], sda_in};
                        end
                    end else cnt <= cnt - 1'b1;
                B3: if (cnt == '0) begin
                        if (k == 4'd8) begin
                            st <= IDLE; busy <= 1'b0;
                            if (rd) rxdata <= sh;
                        end else begin
                            st <= B1; k <= k + 1'b1; cnt <= Q1;
                            if (k == 4'd7) sda_oe <= rd ? !ack_n : 1'b0;          // the ACK bit
                            else           sda_oe <= rd ? 1'b0 : !sh[7];           // sh already shifted
                        end
                    end else cnt <= cnt - 1'b1;
                // STOP: SDA low (Q), SCL high (2Q), SDA released (2Q)
                P1: if (cnt == '0) begin st <= P2; scl_oe <= 1'b0; cnt <= Q2; end else cnt <= cnt - 1'b1;
                P2: if (!scl_in) cnt <= Q2;
                    else if (cnt == '0) begin st <= P3; sda_oe <= 1'b0; cnt <= Q2; end
                    else cnt <= cnt - 1'b1;
                P3: if (cnt == '0) begin st <= IDLE; busy <= 1'b0; owned <= 1'b0; end else cnt <= cnt - 1'b1;
                default: st <= IDLE;
            endcase
        end
    end
endmodule

from benchmark.lib.i2c_devices import Adt7420, I2cBus
from model import ALARM, BUSY, CTRL, DESIGN_ID, MAX, MIN, SAMPLES, STATUS, TEMP, THIGH, TLOW, Model

READING_LEN = 8                                   # log entries of one reading


# v1.2: SCL high time is 2Q to 2Q + SYNC_SLACK clocks. The spec says wait until SCL is seen high through a two-flop
# synchroniser, then 2Q: 2-3 clocks of synchroniser plus 1-3 of state and registered-output latency; 8 allows for that.
SYNC_SLACK = 8


class Env:
    def __init__(self, dut) -> None:
        self.b = Board(dut, {"dev_scl_pull": 0, "dev_sda_pull": 0, "TMP_INT": 1})
        self.dut, self.m = dut, Model()
        self.q = self.b.param("QUARTER")
        self.period = self.b.param("PERIOD_CYCLES")

    async def start(self, temp_q7: int = 0x0D87, present: bool = True) -> None:
        await self.b.start()
        self.dev = Adt7420(temp_q7, int_pin=self.dut.TMP_INT)
        self.bus = I2cBus(self.dut, [self.dev] if present else [])
        self.present = present
        self.pos = 0                               # log entries already checked
        self.done_at: list[int] = []               # clock at which each reading was seen complete

    def take(self, n: int) -> list[tuple]:
        seg = self.bus.log[self.pos:self.pos + n]
        self.pos += n
        return seg

    async def configure(self) -> None:
        await self.b.write(CTRL, 1)
        want = self.m.configure(self.present)
        await self.b.cycles(40 * 9 * (4 * self.q + 4))
        got = self.take(len(want))
        assert got == want, f"configure: bus {got} != model {want}"
        assert not self.bus.errors, self.bus.errors[:3]

    async def readings(self, n: int) -> None:
        """Wait for ``n`` more readings (each checked against the model as it ends)."""
        per = READING_LEN if self.present else 3
        for _ in range(n):
            while len(self.bus.log) < self.pos + per:
                await self.b.cycles(50)
            code = (self.dev.temp_q7 & 0xFFFF) if self.present else None
            want = self.m.reading(code)
            got = self.take(per)
            assert got == want, f"reading: bus {got} != model {want}"
            self.done_at.append(int(get_sim_time("ns")) // 10)
        assert not self.bus.errors, self.bus.errors[:3]

    async def regs(self, offs=(STATUS, TEMP, MAX, MIN, SAMPLES)) -> None:
        """Right after a reading: the registers (read before the next reading is due)."""
        for off in offs:
            got = await self.b.read(off)
            want = self.m.read(off)
            if off == STATUS:
                got &= ~BUSY
            assert got == want, f"window 0x{off:02X}: RTL 0x{got:08X}, model 0x{want:08X}"

@cocotb.test(timeout_time=1746300, timeout_unit="ns")
async def test_alarm_follows_int(dut):
    e = Env(dut)
    await e.start(temp_q7=25 * 128)
    await e.b.write(THIGH, 30 * 128)
    e.m.write(THIGH, 30 * 128)
    await e.configure()
    await e.readings(1)
    await e.regs((STATUS,))
    assert await peek(e.b.clk, dut.LED) == 0
    e.dev.set_temp(31 * 128)                      # above T_HIGH: the sensor pulls INT low
    e.m.alarm = True
    await e.b.cycles(10)
    assert int(dut.TMP_INT.value) == 0, "device model: INT should be active (low)"
    assert await peek(e.b.clk, dut.LED) == 1, "LED0 does not show the alarm"
    await e.readings(1)
    await e.regs((STATUS,))
    e.dev.set_temp(27 * 128)                      # still above T_HIGH - T_HYST (5 C): INT stays active
    await e.readings(1)
    await e.regs((STATUS,))
    e.dev.set_temp(24 * 128)                      # below T_HIGH - T_HYST: INT released
    e.m.alarm = False
    await e.b.cycles(10)
    assert await peek(e.b.clk, dut.LED) == 0
    await e.readings(1)
    await e.regs((STATUS,))

"""Golden model of t2_adt7420_alarm, written from spec.yaml alone (never from any RTL).

Register effects, and the bus transactions (benchmark/lib/i2c_devices.I2cBus log entries) of the configure
sequence and of each reading."""

from __future__ import annotations

DESIGN_ID = 0x54414C4D
CTRL, STATUS, THIGH, TLOW, TEMP, MAX, MIN, SAMPLES = range(8)
BUSY, CONFIGURED, VALID, NACK, ALARM = 1, 2, 4, 8, 16
ADDR = 0x4B


def s16(v: int) -> int:
    return v - 0x10000 if v & 0x8000 else v


class Model:
    def __init__(self) -> None:
        self.thigh, self.tlow = 0x2000, 0x0500
        self.temp = self.max = self.min = 0
        self.samples = 0
        self.configured = self.valid = self.nack = False
        self.alarm = False

    def write(self, off: int, v: int) -> None:
        if off == THIGH:
            self.thigh = v & 0xFFFF
        elif off == TLOW:
            self.tlow = v & 0xFFFF

    def configure(self, present: bool = True) -> list[tuple]:
        self.temp = self.max = self.min = self.samples = 0
        self.valid = self.nack = False
        self.configured = True
        txs = [[0x03, 0x90], [0x04, self.thigh >> 8, self.thigh & 0xFF], [0x06, self.tlow >> 8, self.tlow & 0xFF]]
        log: list[tuple] = []
        for t in txs:
            if present:
                log += [("S",), ("A", ADDR, 0, True)] + [("W", b, True) for b in t] + [("P",)]
            else:
                log += [("S",), ("A", ADDR, 0, False), ("P",)]
        if not present:
            self.nack = True
        return log

    def reading(self, code: int | None) -> list[tuple]:
        """One reading; ``code`` is the 16-bit value the sensor returns (None: no device, the address NACKs)."""
        if code is None:
            self.nack = True
            return [("S",), ("A", ADDR, 0, False), ("P",)]
        self.temp = code
        if not self.valid or s16(code) > s16(self.max):
            self.max = code
        if not self.valid or s16(code) < s16(self.min):
            self.min = code
        self.valid = True
        self.samples += 1
        return [("S",), ("A", ADDR, 0, True), ("W", 0x00, True), ("Sr",), ("A", ADDR, 1, True),
                ("R", code >> 8, True), ("R", code & 0xFF, False), ("P",)]

    def status(self) -> int:
        return (CONFIGURED if self.configured else 0) | (VALID if self.valid else 0) | \
            (NACK if self.nack else 0) | (ALARM if self.alarm else 0)

    def read(self, off: int) -> int:
        return {STATUS: self.status(), THIGH: self.thigh, TLOW: self.tlow, TEMP: self.temp, MAX: self.max,
                MIN: self.min, SAMPLES: self.samples}.get(off, 0)
