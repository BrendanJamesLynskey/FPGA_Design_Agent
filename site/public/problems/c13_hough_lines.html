Problems / S. Computer vision

Hough line accumulator behind the test shell

c13_hough_lines Course tier course part 13 S Computer vision Nexys A7-100T

The problem

A line detector for a small edge picture. Each edge point votes for every straight line that could pass through it, in a set of evenly spaced directions, and the votes are counted in a table of direction against distance from the origin. Where many points lie on one line their votes pile up in one cell. The table can be cleared and read back cell by cell.

Where it is used. The Hough transform finds lane markings, edges of objects and straight features in machine vision, robotics and document scanning. Hardware versions run it on video streams in real time.

Adapted from a project in the owner's FPGA design course (the course itself is private).

The spec the agent is given

Hough line accumulator behind the test shell

I want a block that is told where the edge points of a small picture are and then tells me which straight lines they form, and I want to exercise it entirely from the test shell.

  • The picture is 32 by 32. I give the block the edge points one at a time over the shell: x and y (0 to 31) in one write, which presents the point to the block for one clock; the block takes a new point only when it is not busy, and it says so in a status register.
  • The block looks for lines at 16 directions spaced evenly over 180 degrees (0, 11.25, 22.5 ... degrees, the angle of the line's normal) and records, for each direction, how many points would lie on each possible distance from the origin (whole numbers, from -48 to +47). I want to be able to read any of these counts back: I select a direction and a distance and then read the count.
  • A "clear" command starts a new picture by zeroing all counts.
  • I will test it with pictures of single straight lines at known angles, and with several lines at once. CPU_RESETN returns the block to idle. LED0 shows that the block is busy. The shell runs at 115200 baud on the USB-UART. The design ID is "HOUG".

Test hooks: top module c13_hough_lines_top, ports named as in the board's master XDC, and the test shell's CLKS_PER_BIT, TIMEOUT_CYCLES and BUILD_STAMP parameters as top-level parameters. There are no other time constants.

Exactly spec.md. Anything it leaves open, the agent has to ask about.

What the hidden tests check

The requirements in the hidden spec, and how each is shown to hold:

  • REQ-01 the counts read back equal the model's accumulator for pictures of single lines (diagonal, vertical) and for several lines at once (shown by simulation)
  • REQ-02 CLEAR zeroes all counts and a new picture starts from zero (shown by simulation)
  • REQ-03 the 96-entry distance table (-48 to +47) covers every vote of a 32 x 32 picture, and votes outside it would be dropped (shown by simulation)
  • REQ-04 The design closes timing at 100 MHz with no unconstrained path (shown by report analysis)
The full behaviour rules from hidden/spec.yaml

voting

  • For each presented point (x, y) and each direction index k in 0..15: rho = ((x*CT[k] + y*ST[k] + 64) >>> 7) + 48 with CT[k] = round(128 cos(k*pi/16)) and ST[k] = round(128 sin(k*pi/16)) (arithmetic shift, round-half-up); if 0 <= rho < 96 the count of (k, rho) increases by one.
  • CT = [128, 126, 118, 106, 91, 71, 49, 25, 0, -25, -49, -71, -91, -106, -118, -126]; ST = [0, 25, 49, 71, 91, 106, 118, 126, 128, 126, 118, 106, 91, 71, 49, 25].

handshake

  • A point written while BUSY is ignored; BUSY is high for about 17 clocks per point (the reference). The shell is slower than a point, so the bench never overlaps points.

leds

  • LED[0] = BUSY, the other LEDs are 0.

Settled assumptions

  • the table is not cleared by CPU_RESETN. only the clear command zeroes the counts; the bench always clears first.

// c13_hough_lines_regs.sv: the shell window of course task c13_hough_lines.
module c13_hough_lines_regs (
    input  logic        clk,
    input  logic        rst,
    output logic [15:0] led,
    input  logic [6:0]  win_addr,
    input  logic        win_wr,
    input  logic        win_rd,
    input  logic [31:0] win_wdata,
    output logic [31:0] win_rdata
);
    logic        pt_v, clr, busy;
    logic [7:0]  pt_x, pt_y;
    logic [3:0]  rd_theta;
    logic [6:0]  rd_rho;
    logic [15:0] rd_cnt;

    assign led = {15'd0, busy};

    hough #(.NT(16), .NR(96), .ROFF(48)) u_core (.clk(clk), .rst_n(!rst), .pt_valid(pt_v), .pt_x(pt_x), .pt_y(pt_y), .busy(busy),
                                                  .clear(clr), .rd_theta(rd_theta), .rd_rho(rd_rho), .rd_cnt(rd_cnt));

    always_ff @(posedge clk) begin
        pt_v <= 1'b0; clr <= 1'b0;
        if (win_wr) begin
            case (win_addr)
                7'd0: begin pt_x <= win_wdata[7:0]; pt_y <= win_wdata[15:8]; pt_v <= 1'b1; end
                7'd1: clr <= 1'b1;
                7'd2: begin rd_theta <= win_wdata[3:0]; rd_rho <= win_wdata[14:8]; end
                default: ;
            endcase
        end
        win_rdata <= 32'd0;
        if (win_rd) begin
            case (win_addr)
                7'd2: win_rdata <= {17'd0, rd_rho, 4'd0, rd_theta};
                7'd3: win_rdata <= {16'd0, rd_cnt};
                7'd4: win_rdata <= {31'd0, busy};
                default: ;
            endcase
        end
        if (rst) begin pt_v <= 1'b0; clr <= 1'b0; rd_theta <= '0; rd_rho <= '0; win_rdata <= 32'd0; end
    end
endmodule

hough.sv reference RTL, 143 lines
DownloadOn GitHubMIT licence
// Part 13 lesson 8 reference solution: a Hough transform accumulator for straight lines, 16 angles, one angle per clock.
//
// A line is the set of points (x, y) with x*cos(t) + y*sin(t) = rho. For each edge point and each of the NT = 16 angles t_k = k * pi / 16 (k = 0 .. 15, in steps of
// 11.25 degrees) the block computes   rho_k = ((x * ctab(k) + y * stab(k) + 64) >>> 7) + ROFF   (cos and sin are in Q7: ctab(k) = round(128 cos t_k), given below;
// >>> is the arithmetic shift, floor) and adds one to the accumulator cell acc[k][rho_k]. ROFF = 48 makes the index non-negative for x, y in 0 .. 63 (rho runs from
// about -64 to +64, of which cells 0 .. NR-1 = 0 .. 95 are kept; a point whose index falls outside is not counted).
// Handshake: pt_valid with busy low presents a point (pt_x, pt_y 8 bits each); the block then sets busy for the NT clocks it takes (one angle per clock, k = 0 first)
// and clears it at the end; a point presented while busy is ignored. clear (a one-clock pulse, only when not busy) zeroes every cell in ONE clock.
// Read port: rd_theta (k), rd_rho (cell) select a cell and rd_cnt shows its 16-bit count one clock later. rst_n is synchronous, active low (it does not clear the cells).
// The tables are computed by a CORDIC or a small ROM; lesson 8 discusses which and the cost.
//
// Block-RAM form (07a1c): the 1536 counts live in two block RAMs written together (one read port each: the read-modify-write of a vote, and the read port), and one
// valid bit per cell in flip-flops. A cell whose valid bit is 0 reads as 0, so `clear` still zeroes every cell in ONE clock (it clears the valid bits, not the RAMs).
// A vote takes four clocks after its angle clock (distance register, index register, read, write), so busy stays high four clocks longer than before; a read sees the same value one clock after the select.
module hough_cell_ram #(
    parameter int N = 1536
) (
    input  logic        clk,
    input  logic        we,
    input  logic [10:0] waddr,
    input  logic [15:0] wdata,
    input  logic [10:0] raddr,
    output logic [15:0] rdata
);
    (* ram_style = "block" *) logic [15:0] mem [0:N-1];
    always_ff @(posedge clk) begin
        if (we) mem[waddr] <= wdata;
        rdata <= mem[raddr];
    end
endmodule

module hough #(
    parameter int NT = 16,
    parameter int NR = 96,
    parameter int ROFF = 48
) (
    input  logic        clk,
    input  logic        rst_n,
    input  logic        pt_valid,
    input  logic [7:0]  pt_x,
    input  logic [7:0]  pt_y,
    output logic        busy,
    input  logic        clear,
    input  logic [3:0]  rd_theta,
    input  logic [6:0]  rd_rho,
    output logic [15:0] rd_cnt
);
    function automatic signed [8:0] ctab(input [3:0] k);
        case (k)
            4'd0: ctab = 128;
            4'd1: ctab = 126;
            4'd2: ctab = 118;
            4'd3: ctab = 106;
            4'd4: ctab = 91;
            4'd5: ctab = 71;
            4'd6: ctab = 49;
            4'd7: ctab = 25;
            4'd8: ctab = 0;
            4'd9: ctab = -25;
            4'd10: ctab = -49;
            4'd11: ctab = -71;
            4'd12: ctab = -91;
            4'd13: ctab = -106;
            4'd14: ctab = -118;
            4'd15: ctab = -126;
            default: ctab = 0;
        endcase
    endfunction
    function automatic signed [8:0] stab(input [3:0] k);
        case (k)
            4'd0: stab = 0;
            4'd1: stab = 25;
            4'd2: stab = 49;
            4'd3: stab = 71;
            4'd4: stab = 91;
            4'd5: stab = 106;
            4'd6: stab = 118;
            4'd7: stab = 126;
            4'd8: stab = 128;
            4'd9: stab = 126;
            4'd10: stab = 118;
            4'd11: stab = 106;
            4'd12: stab = 91;
            4'd13: stab = 71;
            4'd14: stab = 49;
            4'd15: stab = 25;
            default: stab = 0;
        endcase
    endfunction
    localparam int NC = NT * NR;
    logic [NC-1:0] vld;       // a cell that was never voted since the last clear reads as 0
    initial vld = '0;
    logic [7:0]  x, y;
    logic [4:0]  k;          // 0 .. NT-1 while busy
    integer rho;
    logic start_q;
    logic signed [15:0] rho_r;  logic [3:0] k_r;  logic p_en;   // stage P: the distance, registered
    logic        s0_en, s0_vote, s1_en, s1_vote, vld_a, vld_b;   // stage 0: index registered; stage 1: the vote's RAM read is on q_a
    logic [10:0] s0_idx, s1_idx;
    logic [15:0] q_a, q_b;
    assign busy = (k != 0) || start_q || p_en || s0_en || s1_en;

    // stage 0 (the angle clock): the cell index of this angle's vote
    always_comb rho = (($signed({1'b0, x}) * ctab(k[3:0]) + $signed({1'b0, y}) * stab(k[3:0]) + 64) >>> 7) + ROFF;
    wire         vote0 = p_en && rho_r >= 0 && rho_r < NR;
    wire  [10:0] idx0  = 11'(k_r * NR + rho_r);
    wire  [10:0] ridx  = 11'(rd_theta * NR + rd_rho);
    wire  [15:0] newc  = (vld_a ? q_a : 16'd0) + 16'd1;

    hough_cell_ram #(.N(NC)) u_a (.clk(clk), .we(s1_vote), .waddr(s1_idx), .wdata(newc), .raddr(s0_idx), .rdata(q_a));
    hough_cell_ram #(.N(NC)) u_b (.clk(clk), .we(s1_vote), .waddr(s1_idx), .wdata(newc), .raddr(ridx), .rdata(q_b));
    assign rd_cnt = vld_b ? q_b : 16'd0;

    always_ff @(posedge clk) begin
        vld_b <= vld[ridx];
        vld_a <= vld[s0_idx];
        p_en <= start_q || k != 0;
        rho_r <= 16'(rho);
        k_r <= k[3:0];
        s0_en <= p_en;
        s0_vote <= vote0;
        s0_idx <= idx0;
        s1_en <= s0_en;
        s1_vote <= s0_vote;
        s1_idx <= s0_idx;
        if (!rst_n) begin
            k <= 5'd0; start_q <= 1'b0; p_en <= 1'b0; s0_en <= 1'b0; s0_vote <= 1'b0; s1_en <= 1'b0; s1_vote <= 1'b0;
        end else begin
            start_q <= 1'b0;
            if (clear && !busy) begin
                vld <= '0;
            end
            if (s1_vote) vld[s1_idx] <= 1'b1;
            if (pt_valid && !busy) begin
                x <= pt_x; y <= pt_y;
                start_q <= 1'b1;
            end
            if (start_q || k != 0) begin
                k <= (k == NT - 1) ? 5'd0 : k + 5'd1;
            end
        end
    end
endmodule

"""Acceptance tests of c13_hough_lines against model.py (hidden from the agent)."""

from __future__ import annotations

import cocotb
from benchmark.lib.bench import Board, peek
from model import CLEAR, DESIGN_ID, PT, RD_CNT, RD_SEL, STATUS, accumulate, bench_pictures, read_bins


async def picture(b: Board, name: str, pts) -> None:
    await b.write(CLEAR, 1)
    for x, y in pts:
        await b.write(PT, x | y << 8)
    await b.expect(STATUS, 0, f"{name}: not busy after the last point")
    acc = accumulate(pts)
    for k, r in read_bins(acc):
        await b.write(RD_SEL, k | r << 8)
        await b.expect(RD_CNT, int(acc[k][r]), f"{name}: count of direction {k}, distance index {r}")


@cocotb.test()
async def test_identity_and_reset(dut):
    b = Board(dut, {})
    await b.start()
    assert await b.shell_id() == DESIGN_ID
    for off in (RD_SEL, STATUS):
        await b.expect(off, 0, f"reset value of {off}")


@cocotb.test()
async def test_diagonal_line(dut):
    b = Board(dut, {})
    await b.start()
    n, p = bench_pictures()[0]
    await picture(b, n, p)


@cocotb.test()
async def test_vertical_line(dut):
    b = Board(dut, {})
    await b.start()
    n, p = bench_pictures()[1]
    await picture(b, n, p)


@cocotb.test()
async def test_four_lines_then_clear(dut):
    """Several lines at once, then CLEAR and a different picture: nothing is left over."""
    b = Board(dut, {})
    await b.start()
    n, p = bench_pictures()[2]
    await picture(b, n, p)
    n2, p2 = bench_pictures()[0]
    await picture(b, n2 + " after clear", p2)


@cocotb.test()
async def test_corners_and_registers(dut):
    """Points at the picture corners reach the table edges (rho = -48 and +47 are inside), RD_SEL is a plain register."""
    b = Board(dut, {})
    await b.start()
    pts = [(0, 0), (31, 31), (31, 0), (0, 31), (16, 16)]
    await b.write(CLEAR, 1)
    for x, y in pts:
        await b.write(PT, x | y << 8)
    acc = accumulate(pts)
    for k in range(16):
        for r in (0, 1, 47, 48, 94, 95):
            await b.write(RD_SEL, k | r << 8)
            await b.expect(RD_CNT, int(acc[k][r]), f"corners: direction {k}, distance index {r}")
    await b.write(RD_SEL, 0xFFFF_FFFF)
    await b.expect(RD_SEL, 0x7F0F, "RD_SEL keeps k and r")
    led = await peek(b.clk, dut.LED)
    assert led == 0, f"LED {led:04X}: idle"
    for off in (0x05, 0x41, 0x7F):
        await b.expect(off, 0, "unmapped")

"""P13-5 reference model: the Hough accumulator of the reference picture (numpy; bit-exact with the course exercise p13l08_hough)."""
import numpy as np


def line_image(w, h, lines):
    """Edge pixels (0/1) of lines given as (theta_deg, rho): points with x cos t + y sin t = rho, drawn by rounding along the longer axis."""
    img = np.zeros((h, w), np.uint8)
    for th, rho in lines:
        c, s = np.cos(np.radians(th)), np.sin(np.radians(th))
        if abs(s) >= abs(c):
            for x in range(w):
                y = int(round((rho - x * c) / s))
                if 0 <= y < h:
                    img[y, x] = 1
        else:
            for y in range(h):
                x = int(round((rho - y * s) / c))
                if 0 <= x < w:
                    img[y, x] = 1
    return img

NT, NR, ROFF = 16, 96, 48
CT = [int(round(128 * np.cos(k * np.pi / NT))) for k in range(NT)]
ST = [int(round(128 * np.sin(k * np.pi / NT))) for k in range(NT)]
LINES = [(0, 10), (90, 20), (45, 28), (135, 4)]


def points():
    img = line_image(32, 32, LINES)
    return [(int(x), int(y)) for y, x in np.argwhere(img)]


def accumulate(pts):
    acc = np.zeros((NT, NR), np.int64)
    for x, y in pts:
        for k in range(NT):
            rho = ((x * CT[k] + y * ST[k] + 64) >> 7) + ROFF
            if 0 <= rho < NR:
                acc[k, rho] += 1
    return acc


def reference_output():
    return {"acc": accumulate(points()).tolist()}


if __name__ == "__main__":
    print("cos", CT, "sin", ST)


# ---- benchmark wrapper: the shell register map (from spec.yaml) ----
DESIGN_ID = 0x484F5547          # "HOUG"
PT, CLEAR, RD_SEL, RD_CNT, STATUS = 0x00, 0x01, 0x02, 0x03, 0x04


def pts_of(lines):
    img = line_image(32, 32, lines)
    return [(int(x), int(y)) for y, x in np.argwhere(img)]


def bench_pictures():
    """(name, points): one diagonal line, one vertical line, and the four-line picture of the course."""
    return [("diagonal", pts_of([(45, 28)])), ("vertical", pts_of([(0, 20)])), ("four_lines", points())]


def read_bins(acc):
    """The bins the bench reads back: every bin with a count of at least 5 (the peaks), and a fixed sample of 40 other bins."""
    peaks = [(k, r) for k in range(NT) for r in range(NR) if acc[k][r] >= 5]
    other = [(k, r) for k in range(NT) for r in range(NR) if acc[k][r] < 5][::37][:40]
    return peaks + other
