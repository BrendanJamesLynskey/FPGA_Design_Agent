Problems / A. Basic digital design drills

Scrolling message on the eight 7-segment digits

t2_sevenseg_marquee Benchmark v1 T2 A Basic digital design drills Nexys A7-100T

The problem

A scrolling message on the eight seven-segment digits. Each character of the message is a raw pattern of segments that the user writes, so odd symbols are possible, and the digits show an eight-character window onto the message that wraps round. When scrolling is on, the window moves one character at a time in either direction, and a brightness setting dims the display by shortening how long each digit is lit.

Where it is used. Segment displays with time-shared digits appear in clocks, appliances, test equipment and price displays, and scrolling text is how a short message is fitted onto a display that is too narrow for it.

The spec the agent is given

Scrolling message on the eight 7-segment digits

I want to scroll a short message across the Nexys A7-100T's eight 7-segment digits, with full control of every segment (it is for odd symbols and letters, not numbers).

  • The message is up to 16 characters, and each character is a raw segment pattern I write myself: one byte per character, bit 0 = segment a through bit 6 = segment g, bit 7 = the decimal point, 1 = lit. No character decoding of any kind in the FPGA. The message buffer sits at window offsets 0x10 to 0x1F of the test shell.
  • A length register (1 to 16) says how much of the buffer is the message. The digits show an 8-character window onto the message, which wraps round continuously (a message shorter than 8 just repeats).
  • When scrolling is on, the window moves by one character every so often (a parameter, in clocks); a direction bit chooses which way. I also want to read and set the current scroll position.
  • A brightness setting from 0 to 7 that dims the whole display by shortening how long each digit is lit.
  • Design ID "MARQ".

Test hooks: top module t2_sevenseg_marquee_top, ports named as in the board's master XDC (CA..CG, DP, AN, the USB-UART pins, CLK100MHZ, CPU_RESETN), the test shell's CLKS_PER_BIT, TIMEOUT_CYCLES and BUILD_STAMP parameters, plus SCROLL_CYCLES (clocks between scroll steps) and REFRESH_BITS (each digit's time slot is 2^REFRESH_BITS clocks) as top-level parameters.

Exactly spec.md. Anything it leaves open, the agent has to ask about.

Interface

Top module t2_sevenseg_marquee_top on the Nexys A7-100T (xc7a100tcsg324-1). Clock: CLK100MHZ at 100 MHz (board oscillator). Reset: CPU_RESETN, active low: registers to reset values (message all 0 = blank), scroll counter 0, display scan restarts at digit 0. Resources expected: about two hundred LUTs and FFs (the 16-byte buffer in flops or LUT RAM); no BRAM, no DSP.

Top-level parameters (board values): CLKS_PER_BIT = 868, REFRESH_BITS = 17, SCROLL_CYCLES = 25000000, TIMEOUT_CYCLES = 100000. The hidden bench shrinks them to CLKS_PER_BIT = 8, REFRESH_BITS = 4, SCROLL_CYCLES = 6000, TIMEOUT_CYCLES = 400.

What the hidden tests check

The requirements in the hidden spec, and how each is shown to hold:

  • REQ-01 Every digit shows its window byte's raw segments with no decoding (shown by simulation)
  • REQ-02 The window wraps modulo LENGTH; POS steps every SCROLL_CYCLES in the chosen direction (shown by simulation)
  • REQ-03 Each digit is lit for exactly (DIM + 1)/8 of its slot, one digit at a time (shown by simulation)
  • REQ-04 LENGTH and POS write rules hold (shown by simulation)
  • REQ-05 On the board the message scrolls visibly and DIM dims it (shown by on the board)
  • REQ-06 The design closes timing at 100 MHz with no unconstrained path (shown by report analysis)
The full behaviour rules from hidden/spec.yaml

window

  • Digits are numbered 0 (rightmost, AN[0]) to 7 (leftmost). Digit k shows message byte MSG[(POS + 7 - k) mod LENGTH] - the leftmost digit shows MSG[POS], the rightmost MSG[(POS + 7) mod LENGTH].
  • A byte drives the segments directly - bit 0 a (CA), 1 b, 2 c, 3 d, 4 e, 5 f, 6 g (CG), 7 the decimal point (DP); 1 = lit. The pins are active low (CA = NOT bit 0, ..., DP = NOT bit 7). No decoding.

scan

  • Digits are scanned in order 0..7, one slot of 2^REFRESH_BITS clocks each, starting with digit 0 after reset.
  • In digit k's slot, AN[k] = 0 for the first (DIM + 1) * 2^(REFRESH_BITS - 3) clocks of the slot and 1 for the rest; every other AN bit is 1 throughout. DIM = 7 lights the whole slot. Segment pins carry digit k's pattern for the whole slot.

scrolling

  • A scroll counter counts clocks while CTRL.SCROLL = 1. When it reaches SCROLL_CYCLES - 1 it restarts at 0 and POS steps - POS = (POS + 1) mod LENGTH if CTRL.DIR = 0 (text moves left), (POS + LENGTH - 1) mod LENGTH if DIR = 1.
  • While CTRL.SCROLL = 0 the counter is held at 0. Any write to CTRL or POS restarts the counter at 0.

registers rules

  • LENGTH accepts 1..16; writes of 0 or above 16 are ignored. If a new LENGTH is <= POS, POS becomes 0.
  • A write to POS of a value >= LENGTH is ignored.

Settled assumptions

  • the leftmost digit shows the message byte at POS. a message reads left to right, so POS is where reading starts.
  • dimming keeps the slot length and shortens the lit part from the start of the slot. a fixed scan rate avoids flicker changes when the brightness changes.
  • any write to POS restarts the scroll counter at 0, as a write to CTRL does, whether or not SCROLL is set. a new start position then always shows for a full scroll period.

// marquee.sv: 16-byte raw-segment message, an 8-digit window that wraps
// modulo LENGTH, scrolling every SCROLL_CYCLES, and a dimmed digit scan.
module marquee #(
    parameter int SCROLL_CYCLES = 25_000_000,
    parameter int REFRESH_BITS  = 17
) (
    input  logic        clk,
    input  logic        rst,
    output logic [7:0]  an,
    output logic [7:0]  seg_n,        // {DP, G, F, E, D, C, B, A}, active low
    input  logic [6:0]  win_addr,
    input  logic        win_wr,
    input  logic        win_rd,
    input  logic [31:0] win_wdata,
    output logic [31:0] win_rdata
);
    localparam int SW = $clog2(SCROLL_CYCLES + 1);

    logic [7:0]  msg [16];
    logic [1:0]  ctrl;
    logic [4:0]  len;
    logic [3:0]  pos;
    logic [2:0]  dim;
    logic [SW-1:0] sc;

    wire wr_ctrl = win_wr && win_addr == 7'h00;
    wire wr_len  = win_wr && win_addr == 7'h01 && win_wdata[4:0] != 5'd0 && win_wdata[31:0] <= 32'd16;
    wire wr_pos  = win_wr && win_addr == 7'h02 && win_wdata[31:0] < {27'd0, len};
    wire step    = ctrl[0] && sc == SW'(SCROLL_CYCLES - 1);

    always_ff @(posedge clk) begin
        if (rst) begin
            for (int i = 0; i < 16; i++) msg[i] <= 8'h00;
            ctrl <= '0; len <= 5'd8; pos <= '0; dim <= 3'd7; sc <= '0;
        end else begin
            if (win_wr && win_addr[6:4] == 3'b001) msg[win_addr[3:0]] <= win_wdata[7:0];
            if (wr_ctrl) ctrl <= win_wdata[1:0];
            if (win_wr && win_addr == 7'h03) dim <= win_wdata[2:0];
            // scroll counter
            if (wr_ctrl || wr_pos || !ctrl[0] || step) sc <= '0;
            else                                     sc <= sc + 1'b1;
            // position
            if (wr_len) begin
                len <= win_wdata[4:0];
                if (win_wdata[4:0] <= {1'b0, pos}) pos <= '0;
            end else if (wr_pos) begin
                pos <= win_wdata[3:0];
            end else if (step) begin
                if (!ctrl[1]) pos <= ({1'b0, pos} + 5'd1 >= len) ? 4'd0 : pos + 1'b1;
                else          pos <= (pos == 4'd0) ? 4'(len - 5'd1) : pos - 1'b1;
            end
        end
    end

    // display scan. The message index of each digit comes from a short pipeline instead of a modulo:
    // dix[7] = POS (the leftmost digit), dix[k-1] = dix[k] + 1 wrapped at LENGTH. Each stage is one
    // increment and compare, so a change of POS or LENGTH settles within 8 clocks (far inside a digit slot).
    logic [REFRESH_BITS+2:0] t;
    logic [2:0] k;
    logic       lit;
    logic [3:0] dix [8];
    logic [7:0] cur;

    assign k   = t[REFRESH_BITS+2:REFRESH_BITS];
    assign lit = t[REFRESH_BITS-1:REFRESH_BITS-3] <= dim;
    assign cur = msg[dix[k]];

    always_ff @(posedge clk) begin
        if (rst) begin
            for (int i = 0; i < 8; i++) dix[i] <= '0;
        end else begin
            dix[7] <= pos;
            for (int i = 0; i < 7; i++)
                dix[i] <= ({1'b0, dix[i + 1]} + 5'd1 >= len) ? 4'd0 : dix[i + 1] + 4'd1;
        end
    end

    always_ff @(posedge clk) begin
        if (rst) begin
            t <= '0; an <= 8'hFF; seg_n <= 8'hFF;
        end else begin
            t     <= t + 1'b1;
            an    <= lit ? ~(8'b1 << k) : 8'hFF;
            seg_n <= ~cur;
        end
    end

    always_ff @(posedge clk) begin
        if (rst) win_rdata <= '0;
        else if (win_rd) begin
            if (win_addr[6:4] == 3'b001) win_rdata <= {24'd0, msg[win_addr[3:0]]};
            else case (win_addr)
                7'h00:   win_rdata <= {30'd0, ctrl};
                7'h01:   win_rdata <= {27'd0, len};
                7'h02:   win_rdata <= {28'd0, pos};
                7'h03:   win_rdata <= {29'd0, dim};
                default: win_rdata <= '0;
            endcase
        end
    end
endmodule

// t2_sevenseg_marquee_top.sv: board top (Nexys A7-100T, master-XDC port names).
// Reference design for benchmark task t2_sevenseg_marquee; DESIGN_ID "MARQ".
// A scrolling message of raw segment bytes on the eight digits.
module t2_sevenseg_marquee_top #(
    parameter int          CLKS_PER_BIT   = 868,
    parameter int          TIMEOUT_CYCLES = 100_000,
    parameter int          SCROLL_CYCLES  = 25_000_000,
    parameter int          REFRESH_BITS   = 17,
    parameter logic [31:0] BUILD_STAMP    = 32'h0
) (
    input  logic       CLK100MHZ,
    input  logic       CPU_RESETN,
    output logic       CA, CB, CC, CD, CE, CF, CG, DP,
    output logic [7:0] AN,
    input  logic       UART_TXD_IN,
    output logic       UART_RXD_OUT
);
    logic        clk, rst, win_wr, win_rd;
    logic [6:0]  win_addr;
    logic [31:0] win_wdata, win_rdata;
    logic [7:0]  seg_n;

    assign clk = CLK100MHZ;
    reset_sync u_rst (.clk(clk), .rst_n_async(CPU_RESETN), .rst(rst));

    fpga_shell #(.CLKS_PER_BIT(CLKS_PER_BIT), .TIMEOUT_CYCLES(TIMEOUT_CYCLES),
                 .DESIGN_ID(32'h4D41_5251), .BUILD_STAMP(BUILD_STAMP)) u_shell (
        .clk(clk), .rst(rst), .uart_rx(UART_TXD_IN), .uart_tx(UART_RXD_OUT),
        .win_addr(win_addr), .win_wr(win_wr), .win_rd(win_rd), .win_wdata(win_wdata), .win_rdata(win_rdata));

    marquee #(.SCROLL_CYCLES(SCROLL_CYCLES), .REFRESH_BITS(REFRESH_BITS)) u_mq (
        .clk(clk), .rst(rst), .an(AN), .seg_n(seg_n),
        .win_addr(win_addr), .win_wr(win_wr), .win_rd(win_rd), .win_wdata(win_wdata), .win_rdata(win_rdata));

    assign {DP, CG, CF, CE, CD, CC, CB, CA} = seg_n;
endmodule

"""Acceptance tests of t2_sevenseg_marquee against model.py (hidden from the agent)."""

from __future__ import annotations

import random

import cocotb
from cocotb.utils import get_sim_time
from benchmark.lib.bench import Board
from cocotb.triggers import FallingEdge, ReadOnly, RisingEdge
from model import CTRL, DESIGN_ID, DIM, DIR, LENGTH, MSG0, POS, SCROLL, Model

PINS = ("CA", "CB", "CC", "CD", "CE", "CF", "CG", "DP")
ODD = [0x49, 0x80, 0x36, 0x01, 0x7F, 0x63, 0x5C, 0xC9, 0x14, 0x22, 0x08, 0x41, 0x2A, 0x55, 0x9C, 0xF0]


class Env:
    def __init__(self, dut) -> None:
        self.b = Board(dut)
        self.dut, self.m = dut, Model()
        self.rb = self.b.param("REFRESH_BITS")
        self.slot = 1 << self.rb
        self.scroll = self.b.param("SCROLL_CYCLES")

    async def start(self) -> None:
        await self.b.start()

    async def wr(self, off: int, v: int) -> None:
        await self.b.write(off, v)
        self.m.write(off, v)

    async def regs(self) -> None:
        for off in (CTRL, LENGTH, POS, DIM):
            await self.b.expect(off, self.m.read(off), f"window 0x{off:02X}")

    async def scan(self) -> tuple[dict[int, set[int]], list[tuple[int | None, int]]]:
        """Watch 9 slots: per digit, the set of segment patterns while lit, and the runs (digit or None, clocks)."""
        pats: dict[int, set[int]] = {}
        runs: list[tuple[int | None, int]] = []
        cur, n = -1, 0
        for _ in range(9 * self.slot):
            await RisingEdge(self.b.clk)
            await ReadOnly()
            an = int(self.dut.AN.value)
            low = [k for k in range(8) if not (an >> k) & 1]
            assert len(low) <= 1, f"more than one digit lit: AN=0b{an:08b}"
            k = low[0] if low else None
            if k is not None:
                pats.setdefault(k, set()).add(sum(int(getattr(self.dut, p).value) << i for i, p in enumerate(PINS)))
            if k != cur:
                runs.append((cur, n))
                cur, n = k, 0
            n += 1
        await FallingEdge(self.b.clk)
        return pats, runs[2:]                    # drop the start-up entry and the first (partial) run

    async def check_display(self, check_dim: bool = True) -> None:
        pats, runs = await self.scan()
        want = self.m.display()
        got = {k: next(iter(v)) if len(v) == 1 else sorted(v) for k, v in pats.items()}
        assert got == want, f"digits (active-low DP..A) RTL {got} != model {want}"
        if check_dim:
            lit = self.m.lit_clocks(self.rb)
            lit_runs = [n for k, n in runs if k is not None]
            assert len(lit_runs) >= 6 and all(n == lit for n in lit_runs), \
                f"lit runs {lit_runs} clocks, model {lit} (DIM {self.m.dim})"
            order = [k for k, _ in runs if k is not None]
            assert all((b - a) % 8 == 1 for a, b in zip(order, order[1:])), f"scan order {order}"

@cocotb.test(timeout_time=2839520, timeout_unit="ns")
async def test_scroll_steps(dut):
    e = Env(dut)
    await e.start()
    for i, v in enumerate(ODD):
        await e.wr(MSG0 + i, v)
    await e.wr(LENGTH, 10)
    await e.wr(POS, 8)
    await e.wr(CTRL, SCROLL)                      # the counter restarts at this write (~560 clocks before it returns)
    # POS read (its win_rd comes ~640 clocks into the access) at 2.5 steps after the write: between steps 2 and 3
    await e.b.cycles(int(2.5 * e.scroll) - 560 - 640)
    e.m.step(2)
    await e.b.expect(POS, e.m.pos, "POS after 2.5 scroll periods")   # 8 -> 9 -> 0 (wraps at LENGTH 10)
    # exact step period: watch POS change on the display (digit 7 shows MSG[POS])
    times = []
    last = None
    while len(times) < 3:
        await RisingEdge(e.b.clk)
        await ReadOnly()
        if not int(dut.AN.value) >> 7 & 1:
            v = sum(int(getattr(dut, p).value) << i for i, p in enumerate(PINS))
            if last is not None and v != last:
                times.append(int(get_sim_time("ns")) // 10)
            last = v
    await FallingEdge(e.b.clk)
    gaps = [b - a for a, b in zip(times, times[1:])]
    assert all(abs(g - e.scroll) <= 8 * e.slot for g in gaps), f"scroll steps {gaps} clocks apart, model {e.scroll}"
    await e.wr(CTRL, SCROLL | DIR)                # now right: POS decreases; the counter restarts
    pos_now = await e.b.read(POS)                 # ~1200 clocks after the write took effect
    e.m.pos = pos_now
    await e.b.cycles(int(1.5 * e.scroll) - 1760 - 640)
    e.m.step(1)
    await e.b.expect(POS, e.m.pos, "POS 1.5 periods after DIR = 1")
    await e.wr(CTRL, 0)
    await e.b.cycles(2 * e.scroll)
    await e.regs()                                 # stopped
    await e.check_display()
    # a POS write restarts the scroll counter: write it 0.6 period after enabling, read it 0.8 period later
    await e.wr(CTRL, SCROLL)
    await e.b.cycles(int(0.6 * e.scroll) - 1200)
    await e.wr(POS, 5)
    await e.b.cycles(int(0.8 * e.scroll) - 1200)
    await e.b.expect(POS, 5, "POS 0.8 period after a POS write (the counter restarts)")
    await e.wr(CTRL, 0)

"""Golden model of t2_sevenseg_marquee, written from spec.yaml alone (never from any RTL)."""

from __future__ import annotations

DESIGN_ID = 0x4D415251
CTRL, LENGTH, POS, DIM, MSG0 = 0x00, 0x01, 0x02, 0x03, 0x10
SCROLL, DIR = 1, 2


class Model:
    def __init__(self) -> None:
        self.msg = [0] * 16
        self.ctrl, self.length, self.pos, self.dim = 0, 8, 0, 7

    def write(self, off: int, v: int) -> None:
        v &= 0xFFFF_FFFF
        if MSG0 <= off < MSG0 + 16:
            self.msg[off - MSG0] = v & 0xFF
        elif off == CTRL:
            self.ctrl = v & 3
        elif off == LENGTH:
            if 1 <= v <= 16:
                self.length = v
                if v <= self.pos:
                    self.pos = 0
        elif off == POS:
            if v < self.length:
                self.pos = v
        elif off == DIM:
            self.dim = v & 7

    def read(self, off: int) -> int:
        if MSG0 <= off < MSG0 + 16:
            return self.msg[off - MSG0]
        return {CTRL: self.ctrl, LENGTH: self.length, POS: self.pos, DIM: self.dim}.get(off, 0)

    def step(self, n: int = 1) -> None:
        for _ in range(n):
            if self.ctrl & DIR:
                self.pos = (self.pos + self.length - 1) % self.length
            else:
                self.pos = (self.pos + 1) % self.length

    def digit_byte(self, k: int) -> int:
        return self.msg[(self.pos + 7 - k) % self.length]

    def display(self) -> dict[int, int]:
        """{digit: (DP..A pin levels, active low: 8 bits, bit 0 = CA, bit 7 = DP)}."""
        return {k: ~self.digit_byte(k) & 0xFF for k in range(8)}

    def lit_clocks(self, refresh_bits: int) -> int:
        return (self.dim + 1) << (refresh_bits - 3)
