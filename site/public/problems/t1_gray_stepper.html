Problems / A. Basic digital design drills

Gray-code stepper on the LEDs

t1_gray_stepper Benchmark v1 T1 A Basic digital design drills Nexys A7-100T

The problem

A ten-bit Gray-code counter shown on the LEDs. Each button press steps it once, and a switch picks the direction. An automatic mode steps at a rate set over the shell, in milliseconds a step. In a Gray code only one bit changes on each step, including when the count wraps round, and the task asks for that to be proved rather than just tested.

Where it is used. Gray codes are used in rotary and linear position encoders, where several bits changing at once could be misread, and in the pointers of asynchronous FIFOs that cross between clock domains.

The spec the agent is given

Gray-code stepper on the LEDs

I want a 10-bit Gray-code counter shown on LED[9:0] of the Nexys A7-100T.

  • Each press of BTNU steps the counter once. SW[15] picks the direction: down when it is up (1), up when it is down (0). The button bounces, so one press must give exactly one step.
  • There is also an automatic mode that steps on its own at a rate I set over the shell, in milliseconds per step; a rate of zero means it stands still. Buttons still work in automatic mode.
  • The whole point is that exactly one LED changes on every step, including when the count wraps round at either end. I want that proved, not just tested.
  • LED[15] is lit while automatic mode is on. The other LEDs stay off.
  • CPU_RESETN resets everything.
  • Over the test shell (USB-UART, 115200 baud) I can read the Gray code, read and set the count in plain binary, turn automatic mode on and off, set the rate, and read how many steps have been taken. The design ID is "GRAY".

Test hooks: top module t1_gray_stepper_top, ports named as in the board's master XDC, the test shell's CLKS_PER_BIT, TIMEOUT_CYCLES and BUILD_STAMP parameters, plus DEBOUNCE_CYCLES (debounce time in clocks) and TICK_CYCLES (clocks per unit of the rate, one millisecond on the board) as top-level parameters.

Exactly spec.md. Anything it leaves open, the agent has to ask about.

What the hidden tests check

The requirements in the hidden spec, and how each is shown to hold:

  • REQ-01 Every step (press or automatic, either direction, wrap included) changes exactly one bit of LED[9:0] and of GRAY (shown by simulation, formal)
  • REQ-02 GRAY = BIN xor (BIN >> 1) at all times and a step moves BIN by one modulo 1024 in the SW[15] direction (shown by simulation, formal)
  • REQ-03 Automatic steps are exactly RATE * TICK_CYCLES clocks apart; RATE = 0 stops them (shown by simulation)
  • REQ-04 One debounced press gives one step; bounces shorter than the debounce time do nothing (shown by simulation)
  • REQ-05 The register window has the listed map and reset values (shown by simulation)
  • REQ-06 The design closes timing at 100 MHz with no unconstrained path (shown by report analysis)
  • REQ-07 On the board the register window answers as the model predicts and automatic mode steps (shown by on the board)
The full behaviour rules from hidden/spec.yaml

counter

  • BIN is a 10-bit binary count 0..1023; GRAY = BIN xor (BIN >> 1) (reflected binary Gray code).
  • A step sets BIN to (BIN + 1) mod 1024 when DIR = 0, (BIN - 1) mod 1024 when DIR = 1, so GRAY changes in exactly one bit, the wrap included.
  • DIR is SW[15], synchronised by two flops (not debounced); 1 = down.
  • Each step adds 1 to STEPS (16 bits, wrapping). Shell writes to BIN are not steps.
  • If a press and an automatic step fall on the same clock, the counter moves one step only (STEPS += 1).
  • A shell write to BIN on the same clock as a step wins (the step is lost and not counted).

button

  • BTNU is synchronised (two flops), then debounced. The debounced level changes only after the synchronised input has differed from it for DEBOUNCE_CYCLES consecutive clocks; a shorter difference restarts the count.
  • A press is a 0 -> 1 change of the debounced level and makes one step, in either mode; holding does not repeat.

auto

  • While AUTO = 1 and RATE != 0, a tick occurs every TICK_CYCLES clocks and a step every RATE ticks, so steps are exactly RATE * TICK_CYCLES clocks apart.
  • The tick prescaler and the tick count are held at 0 while AUTO = 0 or RATE = 0, and restart from 0 on every write to CTRL or RATE; the first automatic step is RATE * TICK_CYCLES clocks after the write that enables it.
  • RATE = 0 stops automatic stepping (AUTO stays set).

leds

  • LED[9:0] = GRAY, registered from the same register as BIN so the pins change together on each step; LED[15] = AUTO; LED[14:10] = 0. No PWM.

Settled assumptions

  • the rate is in whole milliseconds (TICK_CYCLES clocks) per step, 16 bits. the request gives milliseconds per step.
  • RATE resets to 250 (four steps a second) with AUTO off. a visible default once automatic mode is turned on.

// bm_debounce.sv: two-flop synchroniser, then a counting debounce. The level
// changes only after the synchronised input has differed from it for CYCLES
// consecutive clocks; a shorter difference restarts the count. rise is a
// one-clock pulse on each 0 -> 1 change of the level.
module bm_debounce #(
    parameter int CYCLES = 1_000_000
) (
    input  logic clk,
    input  logic rst,
    input  logic d_async,
    output logic level,
    output logic rise
);
    localparam int CW = $clog2(CYCLES + 1);
    logic        d;
    logic [CW-1:0] run;

    sync2 u_sync (.clk(clk), .rst(rst), .d(d_async), .q(d));

    always_ff @(posedge clk) begin
        rise <= 1'b0;
        if (rst) begin
            level <= 1'b0;
            run   <= '0;
        end else if (d == level) begin
            run <= '0;
        end else if (run == CW'(CYCLES - 1)) begin
            level <= d;
            run   <= '0;
            rise  <= d;
        end else begin
            run <= run + 1'b1;
        end
    end
endmodule

// gray_stepper.sv: 10-bit binary count shown as reflected Gray code, stepped by
// debounced BTNU presses and by an automatic rate, for t1_gray_stepper.
module gray_stepper #(
    parameter int DEBOUNCE_CYCLES = 1_000_000,
    parameter int TICK_CYCLES     = 100_000
) (
    input  logic        clk,
    input  logic        rst,
    input  logic        btn,
    input  logic        dir_async,
    output logic [15:0] led,
    input  logic [6:0]  win_addr,
    input  logic        win_wr,
    input  logic        win_rd,
    input  logic [31:0] win_wdata,
    output logic [31:0] win_rdata
);
    localparam logic [6:0] R_GRAY = 7'h00, R_BIN = 7'h01, R_CTRL = 7'h02, R_RATE = 7'h03, R_STEPS = 7'h04;
    localparam int PW = $clog2(TICK_CYCLES + 1);

    logic          lvl, press, dir, auto_on, run, astep, step;
    logic [9:0]    bin, gray, bin_nx;
    logic [15:0]   rate, tk, steps;
    logic [PW-1:0] pre;

    bm_debounce #(.CYCLES(DEBOUNCE_CYCLES)) u_db (.clk(clk), .rst(rst), .d_async(btn), .level(lvl), .rise(press));
    sync2 u_dir (.clk(clk), .rst(rst), .d(dir_async), .q(dir));

    wire wr_bin  = win_wr && win_addr == R_BIN;
    wire wr_ctrl = win_wr && win_addr == R_CTRL;
    wire wr_rate = win_wr && win_addr == R_RATE;

    assign run    = auto_on && rate != 16'd0;
    assign astep  = run && !wr_ctrl && !wr_rate && pre == PW'(TICK_CYCLES - 1) && tk == rate - 16'd1;
    assign step   = press || astep;
    assign bin_nx = dir ? bin - 10'd1 : bin + 10'd1;

    always_ff @(posedge clk) begin
        if (rst) begin
            pre <= '0; tk <= '0; auto_on <= 1'b0; rate <= 16'd250;
        end else begin
            if (wr_ctrl) auto_on <= win_wdata[0];
            if (wr_rate) rate <= win_wdata[15:0];
            if (wr_ctrl || wr_rate || !run) begin
                pre <= '0;
                tk  <= '0;
            end else if (pre == PW'(TICK_CYCLES - 1)) begin
                pre <= '0;
                tk  <= (tk == rate - 16'd1) ? 16'd0 : tk + 16'd1;
            end else begin
                pre <= pre + 1'b1;
            end
        end
    end

    always_ff @(posedge clk) begin
        if (rst) begin
            bin <= '0; gray <= '0; steps <= '0;
        end else if (wr_bin) begin
            bin  <= win_wdata[9:0];
            gray <= win_wdata[9:0] ^ (win_wdata[9:0] >> 1);
        end else if (step) begin
            bin   <= bin_nx;
            gray  <= bin_nx ^ (bin_nx >> 1);
            steps <= steps + 1'b1;
        end
    end

`ifdef FORMAL
    // REQ-01: a step (no BIN write) changes exactly one bit of the Gray register.
    logic past_valid = 1'b0;
    always_ff @(posedge clk) past_valid <= 1'b1;
    always_ff @(posedge clk)
        if (past_valid && !$past(rst) && !rst && $past(step) && !$past(wr_bin))
            assert ($countones(gray ^ $past(gray)) == 1);
    always_comb assert (rst || gray == (bin ^ (bin >> 1)));
`endif

    assign led = {auto_on, 5'd0, gray};

    always_ff @(posedge clk) begin
        if (rst) win_rdata <= '0;
        else if (win_rd) begin
            case (win_addr)
                R_GRAY:  win_rdata <= {22'd0, gray};
                R_BIN:   win_rdata <= {22'd0, bin};
                R_CTRL:  win_rdata <= {23'd0, dir, 7'd0, auto_on};
                R_RATE:  win_rdata <= {16'd0, rate};
                R_STEPS: win_rdata <= {16'd0, steps};
                default: win_rdata <= '0;
            endcase
        end
    end
endmodule

"""Acceptance tests of t1_gray_stepper against model.py (hidden from the agent)."""

from __future__ import annotations

import random

import cocotb
from benchmark.lib.bench import Board, peek
from cocotb.triggers import ReadOnly, RisingEdge
from model import BIN, CTRL, DESIGN_ID, GRAY, RATE, STEPS, Model, gray

IDLE = {"BTNU": 0, "SW": 0}
NAMES = ("GRAY", "BIN", "CTRL", "RATE", "STEPS")


class Watch:
    """Records every change of LED[9:0] as (clock index, old, new)."""

    def __init__(self, clk, led) -> None:
        self.clk, self.led, self.events, self.t = clk, led, [], 0
        self.task = cocotb.start_soon(self.run())

    async def run(self) -> None:
        prev = None
        while True:
            await RisingEdge(self.clk)
            await ReadOnly()
            self.t += 1
            v = int(self.led.value) & 0x3FF
            if prev is not None and v != prev:
                self.events.append((self.t, prev, v))
            prev = v

    def take(self) -> list[tuple[int, int, int]]:
        ev, self.events = self.events, []
        return ev


class Env:
    def __init__(self, dut) -> None:
        self.b = Board(dut, IDLE)
        self.dut, self.m = dut, Model()
        self.n = self.b.param("DEBOUNCE_CYCLES")
        self.tick = self.b.param("TICK_CYCLES")
        self.w: Watch | None = None

    async def start(self) -> None:
        await self.b.start()
        self.w = Watch(self.b.clk, self.dut.LED)

    async def wr(self, off: int, v: int) -> None:
        await self.b.write(off, v)
        self.m.write(off, v)

    async def press(self) -> None:
        self.dut.BTNU.value = 1
        await self.b.cycles(self.n + 6)
        self.dut.BTNU.value = 0
        await self.b.cycles(self.n + 6)
        self.m.step()

    async def direction(self, d: int) -> None:
        self.dut.SW.value = d << 15
        await self.b.cycles(4)
        self.m.dir = d

    def check_steps(self, ev, period: int | None = None) -> None:
        """Each event is one step of the model: one bit, the right next code; optionally evenly spaced."""
        for i, (t, old, new) in enumerate(ev):
            assert bin(old ^ new).count("1") == 1, f"step {old:010b} -> {new:010b} changes more than one LED"
            assert new == self.m.next_gray(old), f"step {old:010b} -> {new:010b}, model says {self.m.next_gray(old):010b}"
            if period and i:
                assert t - ev[i - 1][0] == period, f"automatic steps {t - ev[i - 1][0]} clocks apart, want {period}"

    async def check_regs(self) -> None:
        for off in range(5):
            await self.b.expect(off, self.m.read(off), NAMES[off])

    async def check_leds(self) -> None:
        led = await peek(self.b.clk, self.dut.LED)
        assert led == self.m.leds(), f"LED {led:04X} != model {self.m.leds():04X}"

    await e.check_regs()

@cocotb.test()
async def test_press_during_auto(dut):
    """v1.2: a press while AUTO = 1 makes one extra step and does not move the automatic grid (the prescaler restarts
    only on a CTRL or RATE write): the automatic steps stay exactly RATE * TICK_CYCLES clocks apart across the press."""
    e = Env(dut)
    await e.start()
    await e.wr(RATE, 100)
    period = 100 * e.tick
    e.w.take()
    await e.wr(CTRL, 1)
    for _ in range(2 * period):
        if e.w.events:
            break
        await e.b.cycles(1)
    assert e.w.events, "no automatic step"
    await e.b.cycles(period // 4)
    t_press = e.w.t
    await e.press()                              # about 2 * (DEBOUNCE_CYCLES + 6) clocks, inside one period
    await e.b.cycles(3 * period)
    await e.wr(CTRL, 0)
    ev = e.w.take()
    e.check_steps(ev)
    window = (t_press, t_press + e.n + 12)
    auto = [x for x in ev if not window[0] <= x[0] <= window[1]]
    assert len(ev) - len(auto) == 1, f"the press gave {len(ev) - len(auto)} LED changes"
    assert len(auto) >= 4, f"only {len(auto)} automatic steps"
    for a, b in zip(auto, auto[1:]):
        assert b[0] - a[0] == period, f"automatic steps {b[0] - a[0]} clocks apart across a press, want {period}"
    e.m.step(len(ev) - 1)                        # the press was counted by press()
    await e.check_regs()
    await e.check_leds()

"""Golden model of t1_gray_stepper, written from spec.yaml alone (never from any RTL)."""

from __future__ import annotations

GRAY, BIN, CTRL, RATE, STEPS = 0, 1, 2, 3, 4
DESIGN_ID = 0x47524159          # "GRAY"


def gray(b: int) -> int:
    return b ^ (b >> 1)


def ungray(g: int) -> int:
    b = 0
    while g:
        b ^= g
        g >>= 1
    return b


class Model:
    def __init__(self) -> None:
        self.bin = 0
        self.auto = 0
        self.rate = 250
        self.steps = 0
        self.dir = 0

    def step(self, n: int = 1) -> None:
        for _ in range(n):
            self.bin = (self.bin + (-1 if self.dir else 1)) % 1024
            self.steps = (self.steps + 1) & 0xFFFF

    def next_gray(self, g: int) -> int:
        """The Gray code one step on from ``g`` in the current direction."""
        return gray((ungray(g) + (-1 if self.dir else 1)) % 1024)

    def read(self, off: int) -> int:
        return {GRAY: gray(self.bin), BIN: self.bin, CTRL: self.auto | self.dir << 8, RATE: self.rate,
                STEPS: self.steps}.get(off, 0)

    def write(self, off: int, v: int) -> None:
        if off == BIN:
            self.bin = v & 0x3FF
        elif off == CTRL:
            self.auto = v & 1
        elif off == RATE:
            self.rate = v & 0xFFFF

    def leds(self) -> int:
        return self.auto << 15 | gray(self.bin)
