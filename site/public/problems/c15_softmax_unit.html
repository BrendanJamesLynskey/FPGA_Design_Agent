Problems / I. Machine learning inference

Softmax unit behind the test shell

c15_softmax_unit Course tier course part 15 I Machine learning inference Nexys A7-100T

The problem

A unit that turns eight scores into eight probabilities that add up to one, with bigger scores getting bigger shares. It must cope with very large or very different scores, so it works relative to the largest score, and it uses small tables and multipliers instead of floating-point or divider blocks. The result is checked to within a stated error.

Where it is used. Softmax ends classifiers and sits inside the attention step of transformer language models. Accelerators implement it in fixed-point hardware because it is a bottleneck when done naively.

Adapted from a project in the owner's FPGA design course (the course itself is private).

The spec the agent is given

Softmax unit behind the test shell

I want a block for the Nexys A7-100T's FPGA that turns eight scores into eight probabilities the way a neural network does ("softmax"): each probability is e raised to the power of its score, divided by the sum of those numbers over all eight, so the eight probabilities add up to one and a bigger score gets a bigger probability. I want to exercise it entirely from the test shell.

  • The input is eight scores loaded over the shell, each a signed 16-bit number that is the real score times 256 (so 256 means a score of 1.0, -128 means -0.5), followed by a "go" command.
  • The output is the eight probabilities that I read back over the shell, each an unsigned 16-bit number that is the probability times 32768 (so 32768 means 1.0), with a flag that says they are ready.
  • The scores can be anywhere in the 16-bit range, including all eight equal, one score far above the rest, and large values that would overflow a naive calculation (adding the same amount to every score must not change the answer). Use no floating-point blocks and no division blocks; a few small tables and multipliers are fine.
  • Accuracy I need: every probability within 1/128 of the true value, and the eight probabilities adding up to 1 within 1/128. Anything inside that is acceptable; I do not need a particular design.
  • I will check the outputs for a few dozen score sets against my own calculation with real numbers. CPU_RESETN clears the loaded scores and the ready flag. LED0 shows the ready flag. The shell runs at 115200 baud on the USB-UART. The design ID is "SMAX".

Test hooks: top module c15_softmax_unit_top, ports named as in the board's master XDC, and the test shell's CLKS_PER_BIT, TIMEOUT_CYCLES and BUILD_STAMP parameters as top-level parameters. There are no other time constants.

Exactly spec.md. Anything it leaves open, the agent has to ask about.

What the hidden tests check

The requirements in the hidden spec, and how each is shown to hold:

  • REQ-01 every probability is within 1/128 of the true value and the eight sum to 1 within 1/128, for each tested score set (shown by simulation)
  • REQ-02 large scores and all-equal scores do not overflow, and a common offset on all scores does not change the answer (shown by simulation)
  • REQ-03 READY is 0 after GO is written and 1 when OUT is valid (shown by simulation)
  • REQ-04 The design closes timing at 100 MHz with no unconstrained path (shown by report analysis)
The full behaviour rules from hidden/spec.yaml

function

  • p_i = exp(x_i/256 - max) / sum_j exp(x_j/256 - max) for the eight scores x_i (signed 16-bit, real value times 256); output lane i is round(p_i * 32768) as an unsigned 16-bit number.
  • Accuracy: |p_i/32768 - true_i| <= 1/128 for every lane and |sum(p)/32768 - 1| <= 1/128; adding one constant to all scores gives the same probabilities (to within the same budget).

handshake

  • A write to GO clears READY and presents the loaded scores for one clock; READY is 1 within 8 clocks and stays 1 until the next GO; OUT reads 0 while READY is 0.

leds

  • LED[0] = READY, the other LEDs are 0.

// c15_softmax_unit_regs.sv: the shell window of course task c15_softmax_unit.
module c15_softmax_unit_regs (
    input  logic        clk,
    input  logic        rst,
    output logic [15:0] led,
    input  logic [6:0]  win_addr,
    input  logic        win_wr,
    input  logic        win_rd,
    input  logic [31:0] win_wdata,
    output logic [31:0] win_rdata
);
    logic [127:0] x_r;
    logic [127:0] o_w;
    logic go, ov, vld;
    
    assign led = {15'd0, vld};

    softmax_unit #(.N(8)) u_core (.clk(clk), .rst_n(!rst), .in_valid(go), .x(x_r[127:0]), .out_valid(ov), .p(o_w[127:0]));
    
    always_ff @(posedge clk) begin
        go <= 1'b0;
        if (ov) vld <= 1'b1;
        if (win_wr) begin
            if (win_addr < 7'd4) x_r[win_addr*32 +: 32] <= win_wdata;
            else if (win_addr == 7'h10) begin go <= 1'b1; vld <= 1'b0; end
        end
        win_rdata <= 32'd0;
        if (win_rd) begin
            if (win_addr < 7'd4) win_rdata <= x_r[win_addr*32 +: 32];
            else if (win_addr == 7'h11) win_rdata <= {31'd0, vld};
            else if (win_addr >= 7'h20 && win_addr < 7'd36) win_rdata <= vld ? o_w[(win_addr - 7'h20)*32 +: 32] : 32'd0;
        end
        if (rst) begin x_r <= '0; go <= 1'b0; vld <= 1'b0; win_rdata <= 32'd0; end
    end
endmodule

// Part 15 lesson 6 exercise: a softmax unit for N = 8 scores, within a stated error budget, using only integer arithmetic, a 64-entry exp table and a 128-entry reciprocal table.
//
// Input: N signed 16-bit scores in Q8.8 (x_i / 256 is the real score), packed x[i*16 +: 16]. Output: N unsigned 16-bit probabilities in Q0.15 (32768 = 1.0), packed p[i*16 +: 16].
// With in_valid high, one clock later (out_valid high; rst_n synchronous, active low, clears out_valid only), p holds:
//   1. m = max(x_i)                                         (the max subtraction: every exponent argument is then <= 0, so the exp never overflows)
//   2. e_i = exp2neg(m - x_i), a 17-bit Q0.16 value:  d = m - x_i (0 .. 65535, Q8.8);  d = 0 gives exactly 65536;
//        otherwise t = (d * 23637 + 8192) >> 14 (d * log2(e) in Q8.8), n = t >> 8, f = t & 255;  e = 0 if n >= 17, else EXP_LUT[f >> 2] >> n,
//        with EXP_LUT[k] = round(65536 * 2^(-(k + 0.5) / 64)), k = 0..63.
//   3. S = sum e_i (at least 65536);  p = index of the highest set bit of S (16 .. 19);  ms = S >> (p - 15) (16 bits, 32768 .. 65535);
//        L = RECIP_LUT[(ms - 32768) >> 8] with RECIP_LUT[k] = round(2^31 / (32768 + 256 k + 128)), k = 0..127  (so 1/S is about L / 2^(p+16)).
//   4. P_i = (e_i * L + 2^p) >> (p + 1)                      (the probability times 32768, rounded)
// Golden model: tools/ai_models.softmax_int (bit-exact). Error budget against the float softmax of the same scores: every probability within 1/128 (0.0078) absolute; the probabilities

"""Acceptance tests of c15_softmax_unit against model.py (hidden from the agent)."""

from __future__ import annotations

import cocotb
from benchmark.lib.bench import Board, peek
from model import BUDGET, DESIGN_ID, GO, OUT0, STATUS, X0, bench_inputs, lanes_to_regs, softmax_float


async def run_x(b: Board, x: list[int], what: str) -> list[int]:
    for k, w in enumerate(lanes_to_regs(x)):
        await b.write(X0 + k, w)
    await b.write(GO, 1)
    await b.expect(STATUS, 1, f"READY {what}")
    p = []
    for k in range(4):
        w = await b.read(OUT0 + k)
        p += [w & 0xFFFF, w >> 16]
    ref = softmax_float(x)
    err = max(abs(v / 32768 - r) for v, r in zip(p, ref))
    assert err <= BUDGET, f"{what} scores {x}: worst error {err:.5f} above {BUDGET:.5f}; got {p}"
    assert abs(sum(p) / 32768 - 1) <= BUDGET, f"{what} scores {x}: probabilities sum to {sum(p) / 32768:.5f}"
    return p


@cocotb.test()
async def test_identity_and_reset(dut):
    b = Board(dut, {})

    assert await b.shell_id() == DESIGN_ID

"""P15-2 model: the score sets and the float reference with the error budget (standalone: numpy only)."""
import numpy as np

N = 8
BUDGET = 1 / 128


def inputs():
    """330 deterministic sets of eight signed 16-bit Q8.8 scores."""
    rng = np.random.default_rng(15)
    cases = [[0] * N, [32767] + [-32768] * (N - 1), [-32768] * N, [1000] + [0] * (N - 1), list(range(0, N * 256, 256))]
    for scale in (0.5, 2.0, 6.0, 30.0):
        for _ in range(80):
            cases.append([int(v) for v in np.clip(np.round(rng.normal(0, scale, N) * 256), -32768, 32767)])
    base = cases[10]
    for off in (-20000, 20000, -777, 5000, 12000):                     # the same differences, shifted: the answer must not move
        cases.append([int(np.clip(v + off, -32768, 32767)) for v in base])
    return cases


def softmax_float(x):
    z = np.asarray(x, dtype=float) / 256.0
    e = np.exp(z - z.max())
    return e / e.sum()


def reference_output():
    """A perfect answer (the float result rounded to Q0.15)."""
    return {"p": [[int(round(v * 32768)) for v in softmax_float(x)] for x in inputs()]}

def lanes_to_regs(v, bits=16):
    m = (1 << bits) - 1
    return [sum((v[i + k] & m) << (bits * k) for k in range(32 // bits) if i + k < len(v)) for i in range(0, len(v), 32 // bits)]
