Problems / O. Audio

Sound-level meter from the PDM microphone

t2_pdm_vu Benchmark v1 T2 O Audio Nexys A7-100T

The problem

A sound-level meter using the board's digital microphone. The microphone sends a fast stream of single bits where the density of ones follows the sound. The design counts the ones in each block of bits, and since silence gives about half ones, the level is how far the count is from half. A peak value holds for a while after a loud block and then falls slowly, and a bar of LEDs shows the level.

Where it is used. Pulse-density microphones are standard in phones, laptops and smart speakers, and level meters and voice-activity detectors are built on exactly this kind of ones counting before any heavier audio processing.

The spec the agent is given

Sound-level meter from the PDM microphone

I'd like a simple sound-level meter on the Nexys A7-100T using its PDM microphone, shown as a bar graph on the 16 LEDs, with the numbers readable over the test shell.

  • Clock the microphone from the 100 MHz board clock divided down (a parameter sets the half period of M_CLK in clocks; about 2.5 MHz on the board). Use the microphone channel that has M_LRSEL driven high, and take the data on the correct clock edge for that channel.
  • Count the ones in each block of a fixed number of bits (a parameter). Silence gives about half ones, so the level of a block is how far the count is from half the block size.
  • Keep a peak value that holds for a while after a loud block and then falls back slowly; how long it holds and how fast it falls should be settable.
  • LEDs: a bar graph of the level, all 16 lit at full scale.
  • Registers for the level, the peak (which I can reset), the settings, and how many blocks have gone by.
  • Design ID "PDMV".

Test hooks: top module t2_pdm_vu_top, ports named as in the board's master XDC (M_CLK, M_DATA, M_LRSEL, LED, the USB-UART pins, CLK100MHZ, CPU_RESETN), the test shell's CLKS_PER_BIT, TIMEOUT_CYCLES and BUILD_STAMP parameters, plus CLK_HALF (M_CLK half period in clocks) and WINDOW (bits per block, a multiple of 32) as top-level parameters.

Exactly spec.md. Anything it leaves open, the agent has to ask about.

Interface

Top module t2_pdm_vu_top on the Nexys A7-100T (xc7a100tcsg324-1). Clock: CLK100MHZ at 100 MHz (board oscillator). Reset: CPU_RESETN, active low: registers to reset values; M_CLK low; the first block starts with the first sample after reset. Resources expected: under a hundred LUTs and FFs; no BRAM, no DSP.

Top-level parameters (board values): CLKS_PER_BIT = 868, CLK_HALF = 20, TIMEOUT_CYCLES = 100000, WINDOW = 4096. The hidden bench shrinks them to CLKS_PER_BIT = 8, CLK_HALF = 4, TIMEOUT_CYCLES = 400, WINDOW = 256.

What the hidden tests check

The requirements in the hidden spec, and how each is shown to hold:

  • REQ-01 M_CLK has period 2 * CLK_HALF clocks with 50 % duty; M_LRSEL is always 1 (shown by simulation)
  • REQ-02 Data is taken at M_CLK falling edges (the channel M_LRSEL = 1 selects) (shown by simulation)
  • REQ-03 ONES, LEVEL and BLOCKS follow every block (shown by simulation)
  • REQ-04 PEAK holds for HOLD blocks and then decays by DECAY per block; a write clears it (shown by simulation)
  • REQ-05 The LED bar shows LEVEL against the listed thresholds (shown by simulation, on the board)
  • REQ-06 On the board a quiet room gives a low level with bit activity, and a clap raises the peak (shown by on the board)
  • REQ-07 The design closes timing at 100 MHz with no unconstrained path (shown by report analysis)
The full behaviour rules from hidden/spec.yaml

microphone

  • M_CLK is a registered output - low for CLK_HALF clocks, then high for CLK_HALF clocks, repeating; after reset it is low and first rises CLK_HALF clocks after reset ends.
  • M_LRSEL is driven 1 at all times. With M_LRSEL = 1 the microphone drives M_DATA after each M_CLK rising edge and releases it after the falling edge (SPK0833 data sheet), so data is valid during the high half.
  • M_DATA is synchronised by two flops; the sample of each M_CLK cycle is the synchronised value on the clock at which the design drives M_CLK from 1 to 0 (the falling edge). (For CLK_HALF >= 4 this is the pin as of 2 clocks before the fall, inside the valid window.)

level

  • Samples are taken in blocks of WINDOW consecutive samples, the first block starting with the first sample after reset. At each block end - ONES = number of 1 samples in the block, LEVEL = |ONES - WINDOW/2|, BLOCKS += 1, then the peak update.
  • Peak update, in order - if LEVEL > PEAK then PEAK = LEVEL and the hold counter = HOLD; else if the hold counter > 0 it decreases by 1; else PEAK = PEAK - DECAY, or 0 if PEAK < DECAY.
  • A write to PEAK sets PEAK and the hold counter to 0.

leds

  • LED[i] = 1 when LEVEL >= (i + 1) * WINDOW / 32, for i = 0..15 (a bar from LED0 up; all 16 at LEVEL = WINDOW/2). Updated at each block end.

Settled assumptions

  • the hold and decay are counted in blocks. the level only changes at block ends, so blocks are the natural unit.
  • the bar shows the level, not the peak. the request asks for a bar graph of the level.

// pdm_vu.sv: PDM microphone clock (registered, period 2 * CLK_HALF), samples at
// the M_CLK falling edge (M_LRSEL = 1 channel), ones per WINDOW-sample block,
// LEVEL = |ones - WINDOW/2|, PEAK with hold and decay, LED bar.
module pdm_vu #(
    parameter int CLK_HALF = 20,
    parameter int WINDOW   = 4096
) (
    input  logic        clk,
    input  logic        rst,
    input  logic        mdata,       // synchronised
    output logic        mclk,
    output logic [15:0] led,
    input  logic [6:0]  win_addr,
    input  logic        win_wr,
    input  logic        win_rd,
    input  logic [31:0] win_wdata,
    output logic [31:0] win_rdata
);
    localparam int HW = $clog2(CLK_HALF + 1);
    localparam int NW = $clog2(WINDOW + 1);
    localparam int STEP = WINDOW / 32;

    logic [HW-1:0] hc;
    logic [NW-1:0] n, ones, ones_last;
    logic [15:0]   level, peak;
    logic [7:0]    hold_set, hold;
    logic [3:0]    decay;
    logic [31:0]   blocks;

    wire fall = mclk && hc == HW'(CLK_HALF - 1);
    wire last = fall && n == NW'(WINDOW - 1);
    wire [NW-1:0] ones_n = ones + {{(NW-1){1'b0}}, mdata};
    wire [15:0] lvl_n = (ones_n >= NW'(WINDOW / 2)) ? 16'(ones_n - NW'(WINDOW / 2)) : 16'(NW'(WINDOW / 2) - ones_n);

    always_ff @(posedge clk) begin
        if (rst) begin
            hc <= '0; mclk <= 1'b0; n <= '0; ones <= '0; ones_last <= '0; level <= '0; peak <= '0;
            hold_set <= 8'd8; decay <= 4'd1; hold <= '0; blocks <= '0; led <= '0;
        end else begin
            if (win_wr && win_addr == 7'h00) {decay, hold_set} <= win_wdata[11:0];
            if (hc == HW'(CLK_HALF - 1)) begin
                hc <= '0;
                mclk <= ~mclk;
            end else begin
                hc <= hc + 1'b1;
            end
            if (fall) begin
                if (last) begin
                    n <= '0; ones <= '0; ones_last <= ones_n; level <= lvl_n; blocks <= blocks + 1'b1;
                    for (int i = 0; i < 16; i++) led[i] <= lvl_n >= 16'((i + 1) * STEP);
                    if (lvl_n > peak)      begin peak <= lvl_n; hold <= hold_set; end
                    else if (hold != '0)   hold <= hold - 1'b1;
                    else                   peak <= (peak < {12'd0, decay}) ? 16'd0 : peak - {12'd0, decay};
                end else begin
                    n <= n + 1'b1; ones <= ones_n;
                end
            end
            if (win_wr && win_addr == 7'h02) begin peak <= '0; hold <= '0; end
        end
    end

    always_ff @(posedge clk) begin
        if (rst) win_rdata <= '0;
        else if (win_rd) begin
            case (win_addr)
                7'h00:   win_rdata <= {20'd0, decay, hold_set};
                7'h01:   win_rdata <= {16'd0, level};
                7'h02:   win_rdata <= {16'd0, peak};
                7'h03:   win_rdata <= 32'(ones_last);
                7'h04:   win_rdata <= blocks;
                default: win_rdata <= '0;
            endcase
        end
    end
endmodule

// t2_pdm_vu_top.sv: board top (Nexys A7-100T, master-XDC port names).
// Reference design for benchmark task t2_pdm_vu; DESIGN_ID "PDMV".
// PDM microphone level meter (M_LRSEL high, data at M_CLK falling edges), LED bar.
module t2_pdm_vu_top #(
    parameter int          CLKS_PER_BIT   = 868,
    parameter int          TIMEOUT_CYCLES = 100_000,
    parameter int          CLK_HALF       = 20,
    parameter int          WINDOW         = 4096,
    parameter logic [31:0] BUILD_STAMP    = 32'h0
) (
    input  logic        CLK100MHZ,
    input  logic        CPU_RESETN,
    output logic        M_CLK,
    input  logic        M_DATA,
    output logic        M_LRSEL,
    output logic [15:0] LED,
    input  logic        UART_TXD_IN,
    output logic        UART_RXD_OUT
);
    logic        clk, rst, win_wr, win_rd, mdata;
    logic [6:0]  win_addr;
    logic [31:0] win_wdata, win_rdata;

    assign clk = CLK100MHZ;
    reset_sync u_rst (.clk(clk), .rst_n_async(CPU_RESETN), .rst(rst));

    fpga_shell #(.CLKS_PER_BIT(CLKS_PER_BIT), .TIMEOUT_CYCLES(TIMEOUT_CYCLES),
                 .DESIGN_ID(32'h5044_4D56), .BUILD_STAMP(BUILD_STAMP)) u_shell (
        .clk(clk), .rst(rst), .uart_rx(UART_TXD_IN), .uart_tx(UART_RXD_OUT),
        .win_addr(win_addr), .win_wr(win_wr), .win_rd(win_rd), .win_wdata(win_wdata), .win_rdata(win_rdata));

    sync2 u_sync (.clk(clk), .rst(rst), .d(M_DATA), .q(mdata));

    always_ff @(posedge clk) begin
        if (rst) M_LRSEL <= 1'b1;
        else     M_LRSEL <= 1'b1;
    end

    pdm_vu #(.CLK_HALF(CLK_HALF), .WINDOW(WINDOW)) u_vu (
        .clk(clk), .rst(rst), .mdata(mdata), .mclk(M_CLK), .led(LED),
        .win_addr(win_addr), .win_wr(win_wr), .win_rd(win_rd), .win_wdata(win_wdata), .win_rdata(win_rdata));
endmodule

"""Acceptance tests of t2_pdm_vu against model.py (hidden from the agent)."""

from __future__ import annotations

import random

import cocotb
from benchmark.lib.bench import Board, peek
from mic_model import Mic
from model import BLOCKS, CTRL, DESIGN_ID, LEVEL, ONES, PEAK, Model


def periodic(pattern: list[int]):
    return lambda j: pattern[j % len(pattern)]


class Env:
    def __init__(self, dut) -> None:
        self.b = Board(dut, {"M_DATA": 0})
        self.dut = dut
        self.half = self.b.param("CLK_HALF")
        self.w = self.b.param("WINDOW")
        self.m = Model(self.w)
        self.block_clocks = self.w * 2 * self.half

    async def start(self, bit=None) -> None:
        self.bits = bit or periodic([0, 1])
        self.mic = Mic(self.dut, lambda j: self.bits(j))      # before reset ends: it must see the first M_CLK rise
        await self.b.start()

    def advance_model(self, upto: int) -> None:
        while len(self.m.history) - 1 < upto:
            k = len(self.m.history) - 1
            self.m.block(sum(self.bits(j) for j in range(k * self.w, (k + 1) * self.w)))

    async def check_reg(self, off: int, name: str) -> None:
        """BLOCKS, the register, BLOCKS: the register must match the model at one block count in between."""
        k0 = await self.b.read(BLOCKS)
        v = await self.b.read(off)
        k1 = await self.b.read(BLOCKS)
        assert k0 <= k1 <= k0 + 3, f"BLOCKS went from {k0} to {k1}"
        self.advance_model(k1)
        ok = [k for k in range(k0, k1 + 1) if self.m.regs(k)[off] == v]
        assert ok, f"{name} = {v}, model {[self.m.regs(k)[off] for k in range(k0, k1 + 1)]} for blocks {k0}..{k1}"

    async def wait_blocks(self, n: int) -> None:
        await self.b.cycles(n * self.block_clocks)


@cocotb.test(timeout_time=1097890, timeout_unit="ns")
async def test_identity_and_reset(dut):
    e = Env(dut)
    await e.start()
    assert await e.b.shell_id() == DESIGN_ID
    await e.b.expect(CTRL, e.m.ctrl(), "CTRL")
    for off in (0x05, 0x7F):
        await e.b.expect(off, 0, "unmapped")
    assert await peek(e.b.clk, dut.M_LRSEL) == 1


@cocotb.test(timeout_time=1003500, timeout_unit="ns")
async def test_mclk_timing(dut):
    e = Env(dut)
    await e.start()
    await e.b.cycles(40 * e.half)
    highs, lows = e.mic.highs[1:], e.mic.lows[1:]          # the first phase starts at reset
    assert highs and set(highs) == {e.half} and set(lows) == {e.half}, \
        f"M_CLK high {sorted(set(highs))} low {sorted(set(lows))}, model {e.half} each"


@cocotb.test(timeout_time=1228640, timeout_unit="ns")
async def test_lrsel_high_falling_edge(dut):
    """Trap: the textbook drives M_LRSEL low and samples at the rising edge; this spec uses the M_LRSEL = 1 channel,
    whose data is valid in the high half and taken at the falling edge (the other half carries garbage here)."""
    pat = [1, 1, 1, 0] * 4                                  # 75 % ones: ONES = 3/4 WINDOW, LEVEL = WINDOW/4
    e = Env(dut)
    await e.start(periodic(pat))
    await e.wait_blocks(2)
    assert not e.mic.lrsel_low_seen, "M_LRSEL was driven low"
    await e.check_reg(ONES, "ONES")
    await e.check_reg(LEVEL, "LEVEL")


@cocotb.test(timeout_time=2795630, timeout_unit="ns")
async def test_levels_and_leds(dut):
    e = Env(dut)
    await e.start()
    for ones_per_32 in (16, 0, 32, 20, 9):                  # density in 32-bit patterns
        pat = [1] * ones_per_32 + [0] * (32 - ones_per_32)
        start = (await e.b.read(BLOCKS) + 2) * e.w          # from a block boundary well ahead
        old = e.bits
        e.bits = (lambda p, s, o: (lambda j: p[j % 32] if j >= s else o(j)))(pat, start, old)
        await e.wait_blocks(4)
        await e.check_reg(LEVEL, "LEVEL")
        await e.check_reg(ONES, "ONES")
        e.advance_model(await e.b.read(BLOCKS))
        led = await peek(e.b.clk, dut.LED)
        assert led == e.m.history[-1]["led"], f"LED {led:016b}, model {e.m.history[-1]['led']:016b}"


@cocotb.test(timeout_time=2795630, timeout_unit="ns")
async def test_peak_hold_and_decay(dut):
    e = Env(dut)
    await e.start()
    await e.b.write(CTRL, 0x302)                            # HOLD 2 blocks, DECAY 3
    e.m.write_ctrl(0x302)
    await e.b.expect(CTRL, 0x302, "CTRL")
    k = await e.b.read(BLOCKS) + 2
    loud = [1] * 18 + [0] * 14                              # LEVEL = WINDOW/16 (two LEDs), blocks k and k+1 only
    quiet = periodic([0, 1])
    e.bits = (lambda j: loud[j % 32] if k * e.w <= j < (k + 2) * e.w else quiet(j))
    await e.b.cycles((k + 2 - await e.b.read(BLOCKS)) * e.block_clocks)
    for _ in range(10):                                     # hold, then decay to 0
        await e.check_reg(PEAK, "PEAK")
    # a write clears PEAK: with a long hold the peak would otherwise stay
    e.advance_model(await e.b.read(BLOCKS) + 1)             # blocks so far use the old settings
    await e.b.write(CTRL, 0x1C8)                            # HOLD 200 blocks, DECAY 1
    e.m.write_ctrl(0x1C8)
    k = await e.b.read(BLOCKS) + 2
    e.bits = (lambda j: loud[j % 32] if k * e.w - 8 <= j < (k + 1) * e.w + 8 else quiet(j))   # 8 spare samples
    await e.b.cycles((k + 2 - await e.b.read(BLOCKS)) * e.block_clocks)
    await e.check_reg(PEAK, "PEAK held")
    await e.b.write(PEAK, 1)
    await e.b.expect(PEAK, 0, "PEAK after a write")
    await e.b.cycles(2 * e.block_clocks)
    await e.b.expect(PEAK, 0, "PEAK two blocks after the clear (quiet input)")


@cocotb.test(timeout_time=1481320, timeout_unit="ns")
async def test_random_stream(dut):
    rng = random.Random(int(cocotb.RANDOM_SEED))
    dens = [rng.random() for _ in range(64)]
    cache: dict[int, int] = {}

    def bit(j: int) -> int:
        if j not in cache:
            cache[j] = int(random.Random(j * 7919 + 13).random() < dens[(j // 97) % 64])
        return cache[j]

    e = Env(dut)
    await e.start(bit)
    v = rng.randrange(1 << 12)
    e.advance_model(await e.b.read(BLOCKS) + 1)
    await e.b.write(CTRL, v)
    e.m.write_ctrl(v)
    for _ in range(4):
        await e.wait_blocks(1)
        await e.check_reg(rng.choice((LEVEL, ONES, PEAK)), "register")

"""Golden model of t2_pdm_vu, written from spec.yaml alone (never from any RTL)."""

from __future__ import annotations

DESIGN_ID = 0x50444D56
CTRL, LEVEL, PEAK, ONES, BLOCKS = range(5)


class Model:
    """Per-block history from the microphone bit stream; registers as of any block count."""

    def __init__(self, window: int) -> None:
        self.w = window
        self.hold_set, self.decay = 8, 1
        self.history: list[dict] = [{"level": 0, "peak": 0, "ones": 0, "hold": 0, "led": 0}]

    def ctrl(self) -> int:
        return self.decay << 8 | self.hold_set

    def write_ctrl(self, v: int) -> None:
        self.hold_set, self.decay = v & 0xFF, (v >> 8) & 0xF

    def clear_peak(self) -> None:
        self.history[-1] = dict(self.history[-1], peak=0, hold=0)

    def block(self, ones: int) -> None:
        prev = self.history[-1]
        level = abs(ones - self.w // 2)
        peak, hold = prev["peak"], prev["hold"]
        if level > peak:
            peak, hold = level, self.hold_set
        elif hold > 0:
            hold -= 1
        else:
            peak = max(0, peak - self.decay)
        led = sum(1 << i for i in range(16) if level >= (i + 1) * self.w // 32)
        self.history.append({"level": level, "peak": peak, "ones": ones, "hold": hold, "led": led})

    def regs(self, k: int) -> dict[int, int]:
        h = self.history[k]
        return {LEVEL: h["level"], PEAK: h["peak"], ONES: h["ones"], BLOCKS: k}
