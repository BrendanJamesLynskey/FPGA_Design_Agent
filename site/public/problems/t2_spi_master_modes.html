Problems / F. Interfaces and protocols

General-purpose SPI master on Pmod JB

t2_spi_master_modes Benchmark v1 T2 F Interfaces and protocols Nexys A7-100T

The problem

A general-purpose SPI master for whatever chip is plugged in later. It supports all four clock polarity and phase modes, most-significant or least-significant bit first, and eight-bit or sixteen-bit frames, with a settable clock speed. Writing the transmit register starts a frame, and chip select can be held low across several frames. An internal loopback feeds the data output back to the input, so it can be tested with nothing connected.

Where it is used. SPI is the usual fast link to flash memory, ADCs and DACs, displays, sensors and radio chips, and the four modes exist because different chips expect the clock and data to line up differently. A flexible master like this is a standard part of any microcontroller or FPGA toolkit.

The spec the agent is given

General-purpose SPI master on Pmod JB

I want an SPI master on Pmod JB of the Nexys A7-100T that I can point at whatever SPI part I plug in later, so it must not assume one device.

  • Pins: JB1 is chip select (active low), JB2 MOSI, JB3 MISO, JB4 SCLK.
  • All four SPI modes (clock polarity and phase both selectable), MSB-first by default with an LSB-first option, and 8-bit or 16-bit frames.
  • SCLK speed from a divisor register that gives the SCLK half period in 100 MHz clocks; 2 is the smallest that makes sense, so anything smaller is not accepted. After reset I'd like 1 MHz.
  • Normally chip select goes low for one frame and back high after it, but I need a "hold" setting that keeps it low across several frames (for parts that want a command and then data in one select), and releases it when I clear the setting.
  • Writing the transmit register starts a frame. The received frame is readable afterwards. Status: busy, and a done flag I clear by writing 1 to it.
  • With nothing plugged in I still want to test it on the board, so add an internal loopback (MISO fed from our own MOSI).
  • Everything through the test shell; design ID "SPIM".

Test hooks: top module t2_spi_master_modes_top, ports named as in the board's master XDC (JB1, JB2, JB3, JB4, the USB-UART pins, CLK100MHZ, CPU_RESETN), the test shell's CLKS_PER_BIT, TIMEOUT_CYCLES and BUILD_STAMP parameters as top-level parameters. The SCLK rate comes only from the divisor register.

Exactly spec.md. Anything it leaves open, the agent has to ask about.

Interface

Top module t2_spi_master_modes_top on the Nexys A7-100T (xc7a100tcsg324-1). Clock: CLK100MHZ at 100 MHz (board oscillator). Reset: CPU_RESETN, active low: every register returns to its reset value; no frame in progress; CS_N high, SCLK low, MOSI low. Resources expected: about a hundred LUTs and FFs; no BRAM, no DSP.

What the hidden tests check

The requirements in the hidden spec, and how each is shown to hold:

  • REQ-01 All four CPOL/CPHA modes put out and sample data on the edges listed, with SCLK idle at CPOL (shown by simulation)
  • REQ-02 8- and 16-bit frames, MSB or LSB first, with RXDATA filled in the same order (shown by simulation)
  • REQ-03 SCLK edges are exactly DIV clocks apart; DIV writes below 2 are ignored (shown by simulation)
  • REQ-04 CS_HOLD keeps CS_N low across frames and clearing it releases CS_N (shown by simulation)
  • REQ-05 Loopback returns each frame's data in RXDATA (shown by simulation, on the board)
  • REQ-06 The design closes timing at 100 MHz with no unconstrained path (shown by report analysis)
The full behaviour rules from hidden/spec.yaml

frame

  • A write to TXDATA while BUSY = 0 starts a frame of N bits (N = 16 if CTRL.W16 = 1, else 8) with TXDATA's bits [N-1:0]. A write to TXDATA while BUSY = 1 is ignored (TXDATA keeps its value).
  • CTRL (except CS_HOLD) and DIV are taken when a frame starts; changing them during a frame does not affect it.
  • Bit order - MSB first (bit N-1 first) unless CTRL.LSB = 1 (bit 0 first). Received bits fill RXDATA in the same order (the first bit received lands in bit N-1, or in bit 0 with LSB = 1).

timing

  • Let t = 0 be the clock on which CS_N goes low for the frame (or, with CS_N already held low, the clock on which the frame starts). SCLK has 2N edges, at t = k*DIV for k = 1..2N (exactly DIV clocks apart); before the first edge and after the last SCLK is at its idle level CPOL.
  • Edges k odd are leading edges, k even trailing edges. CPHA = 0 - MOSI carries the first bit from t = 0, the slave samples on leading edges, MOSI changes to the next bit on each trailing edge (except the last). CPHA = 1 - MOSI changes to bit i on leading edge 2i+1 and the slave samples on trailing edges.
  • The master samples MISO at the same edges the slave samples MOSI (MISO is synchronised by two flops, so DIV of 5 or more is needed for a slave that changes MISO on the opposite edge).
  • The frame ends at t = (2N+1)*DIV - BUSY falls, DONE is set, RXDATA is updated, and CS_N goes high on that clock unless CTRL.CS_HOLD = 1.
  • MOSI is 0 while no frame is in progress.

chip select

  • CS_N goes low when a frame starts (if it is not already low).
  • While no frame is in progress, CS_N is high whenever CTRL.CS_HOLD = 0 - clearing CS_HOLD after held frames releases CS_N within 2 clocks of the CTRL write. Setting CS_HOLD alone never drives CS_N low.

loopback

  • With CTRL.LOOP = 1 the master's MISO input is its own MOSI output (JB3 ignored); the pins still carry the frame.

divisor

  • DIV is 16 bits; a write whose bits [15:0] are below 2 is ignored entirely. Reset 50 (SCLK 1 MHz).

status

  • DONE is set at every frame end and stays set until a write to STATUS with bit 1 = 1. Reads never clear it.

Settled assumptions

  • a TXDATA write while busy is ignored rather than queued. the request has no queue; ignoring is the simplest safe rule.
  • the first SCLK edge comes one half period after CS_N falls, and CS_N rises one half period after the last edge. gives the slave one half period of setup and hold around chip select.

// spim_core.sv: SPI master frame engine. Edges at t = k*div (k = 1..2N) after
// the frame starts; frame end at t = (2N+1)*div. Modes by cpol/cpha; 8 or 16
// bits; MSB or LSB first. All outputs registered.
module spim_core (
    input  logic        clk,
    input  logic        rst,
    input  logic        start,      // one clock, ignored while busy
    input  logic [15:0] txd,
    input  logic [15:0] div,
    input  logic        cpol,       // live value: idle level and frame setting
    input  logic        cpha,
    input  logic        lsb,
    input  logic        w16,
    input  logic        cs_hold,    // live value
    input  logic        miso,       // synchronous
    output logic        busy,
    output logic        done,       // one-clock pulse at frame end
    output logic [15:0] rxd,
    output logic        cs_n,
    output logic        sclk,
    output logic        mosi
);
    logic        c_pol, c_pha, c_lsb, c_w16;
    logic [15:0] dv, cnt, tx, rx;
    logic [5:0]  k;                 // edges done so far
    logic [4:0]  nb;

    // bit i of the frame in transmit order
    function automatic logic bit_at(input logic [15:0] d, input logic [4:0] n, input logic l, input logic [4:0] i);
        bit_at = l ? d[i[3:0]] : d[4'(n - 5'd1 - i)];
    endfunction

    logic [5:0] e;                  // the edge about to happen
    assign e = k + 6'd1;

    always_ff @(posedge clk) begin
        done <= 1'b0;
        if (rst) begin
            busy <= 1'b0; cs_n <= 1'b1; sclk <= 1'b0; mosi <= 1'b0; rxd <= '0;
            c_pol <= 1'b0; c_pha <= 1'b0; c_lsb <= 1'b0; c_w16 <= 1'b0;
            dv <= '0; cnt <= '0; tx <= '0; rx <= '0; k <= '0; nb <= '0;
        end else if (!busy) begin
            sclk <= cpol;
            mosi <= 1'b0;
            if (!cs_hold) cs_n <= 1'b1;
            if (start) begin
                busy  <= 1'b1;
                cs_n  <= 1'b0;
                c_pol <= cpol; c_pha <= cpha; c_lsb <= lsb; c_w16 <= w16;
                dv    <= div;
                cnt   <= div - 1'b1;
                tx    <= txd;
                rx    <= '0;
                k     <= '0;
                nb    <= w16 ? 5'd16 : 5'd8;
                mosi  <= cpha ? 1'b0 : bit_at(txd, w16 ? 5'd16 : 5'd8, lsb, 5'd0);
            end
        end else if (cnt != '0) begin
            cnt <= cnt - 1'b1;
        end else begin
            cnt <= dv - 1'b1;
            k   <= e;
            if (k == {nb, 1'b0}) begin                       // end slot: no edge
                busy <= 1'b0;
                done <= 1'b1;
                rxd  <= rx;
                mosi <= 1'b0;
                if (!cs_hold) cs_n <= 1'b1;
            end else begin
                sclk <= ~sclk;
                if (e[0] != c_pha) begin                       // sample edge
                    // index of the bit sampled: CPHA 0 -> (e-1)/2, CPHA 1 -> e/2 - 1; both = (e-1) >> 1
                    if (c_lsb) rx[4'((e - 6'd1) >> 1)] <= miso;
                    else       rx[4'(nb - 5'd1 - 5'((e - 6'd1) >> 1))] <= miso;
                end else if (c_pha) begin                      // CPHA 1: leading edge 2i+1 puts out bit i
                    mosi <= bit_at(tx, nb, c_lsb, 5'((e - 6'd1) >> 1));
                end else if (e != {nb, 1'b0}) begin            // CPHA 0: trailing edge 2i puts out bit i
                    mosi <= bit_at(tx, nb, c_lsb, 5'(e >> 1));
                end
            end
        end
    end
endmodule

// spim_regs.sv: registers of the Pmod JB SPI master in the shell window.
module spim_regs (
    input  logic        clk,
    input  logic        rst,
    input  logic        miso_pin,     // JB3, synchronised
    output logic        cs_n,
    output logic        sclk,
    output logic        mosi,
    input  logic [6:0]  win_addr,
    input  logic        win_wr,
    input  logic        win_rd,
    input  logic [31:0] win_wdata,
    output logic [31:0] win_rdata
);
    localparam logic [6:0] R_CTRL = 7'h00, R_DIV = 7'h01, R_TXDATA = 7'h02, R_RXDATA = 7'h03, R_STATUS = 7'h04;

    logic [5:0]  ctrl;
    logic [15:0] div, txd, rxd;
    logic        busy, done_p, done_f;

    wire start = win_wr && win_addr == R_TXDATA && !busy;

    always_ff @(posedge clk) begin
        if (rst) begin
            ctrl <= '0; div <= 16'd50; txd <= '0; done_f <= 1'b0;
        end else begin
            if (win_wr && win_addr == R_CTRL) ctrl <= win_wdata[5:0];
            if (win_wr && win_addr == R_DIV && win_wdata[15:0] >= 16'd2) div <= win_wdata[15:0];
            if (start) txd <= win_wdata[15:0];
            done_f <= (done_f && !(win_wr && win_addr == R_STATUS && win_wdata[1])) || done_p;
        end
    end

    spim_core u_core (
        .clk(clk), .rst(rst), .start(start), .txd(win_wdata[15:0]), .div(div),
        .cpol(ctrl[0]), .cpha(ctrl[1]), .lsb(ctrl[2]), .w16(ctrl[3]), .cs_hold(ctrl[4]),
        .miso(ctrl[5] ? mosi : miso_pin),
        .busy(busy), .done(done_p), .rxd(rxd), .cs_n(cs_n), .sclk(sclk), .mosi(mosi));

    always_ff @(posedge clk) begin
        if (rst) win_rdata <= '0;
        else if (win_rd) begin
            case (win_addr)
                R_CTRL:   win_rdata <= {26'd0, ctrl};
                R_DIV:    win_rdata <= {16'd0, div};
                R_TXDATA: win_rdata <= {16'd0, txd};
                R_RXDATA: win_rdata <= {16'd0, rxd};
                R_STATUS: win_rdata <= {29'd0, !cs_n, done_f, busy};
                default:  win_rdata <= '0;
            endcase
        end
    end
endmodule

"""Acceptance tests of t2_spi_master_modes against model.py (hidden from the agent)."""

from __future__ import annotations

import random

import cocotb
from benchmark.lib.bench import Board, peek
from model import (BUSY, CPHA, CPOL, CS_ACTIVE, CS_HOLD, CTRL, DESIGN_ID, DIV, DONE, LOOP, LSB, RXDATA, STATUS,
                   TXDATA, W16, Model, nbits, tx_bits)
from spi_slave import SpiSlave


class Env:
    def __init__(self, dut) -> None:
        self.b = Board(dut, {"JB3": 0})
        self.dut, self.m = dut, Model()

    async def start(self) -> None:
        await self.b.start()
        self.s = SpiSlave(self.dut)

    async def wr(self, off: int, v: int) -> None:
        await self.b.write(off, v)
        self.m.write(off, v)

    async def regs(self) -> None:
        for off, name in ((CTRL, "CTRL"), (DIV, "DIV"), (TXDATA, "TXDATA"), (RXDATA, "RXDATA"), (STATUS, "STATUS")):
            await self.b.expect(off, self.m.read(off), name)

    async def setup(self, ctrl: int, div: int) -> None:
        await self.wr(CTRL, ctrl)
        await self.wr(DIV, div)

    async def frames(self, values: list[int], miso: list[int] | None = None) -> None:
        """Send frames back to back (CS held between them if CS_HOLD) and check every pin against the model."""
        c, d = self.m.ctrl, self.m.div
        miso = miso or [0] * len(values)
        q: list[int] = []
        for v in miso:
            q += tx_bits(v, c)
        cs_was_low = self.m.cs_low
        self.s.mode(c & CPOL, (c & CPHA) >> 1, q)
        want_mosi: list[int] = []
        for v, r in zip(values, miso):
            await self.b.write(TXDATA, v)
            self.m.write(TXDATA, v)
            await self.b.cycles((2 * nbits(c) + 1) * d + 8)
            want_mosi.append(self.m.finish(tx_bits(r, c)))
        self.check_pins(want_mosi, cs_was_low)
        await self.regs()

    def check_pins(self, want_mosi: list[list[int]], cs_was_low: bool) -> None:
        c, d, s = self.m.ctrl, self.m.div, self.s
        n = nbits(c)
        cpol, cpha = c & CPOL, (c & CPHA) >> 1
        assert not s.idle_bad, s.idle_bad
        edges = s.edges
        assert len(edges) == 2 * n * len(want_mosi), f"{len(edges)} SCLK edges, model {2 * n * len(want_mosi)}"
        falls = [t for t, v in s.cs_events if v == 0]
        rises = [t for t, v in s.cs_events if v == 1]
        nf = len(want_mosi)
        if c & CS_HOLD:
            assert len(falls) == (0 if cs_was_low else 1), f"CS_N fell {len(falls)} times with CS_HOLD"
            assert not rises, "CS_N rose although CS_HOLD is set"
            if falls:
                assert d <= edges[0][0] - falls[0] <= 2 * d, f"first edge {edges[0][0] - falls[0]} clocks after CS_N fell"
        else:
            n_fall = nf - (1 if cs_was_low else 0)
            assert len(falls) == n_fall and len(rises) == nf, f"CS_N fell {len(falls)} / rose {len(rises)} times"
            for f in range(nf):
                first, last = edges[2 * n * f][0], edges[2 * n * f + 2 * n - 1][0]
                if f < len(falls) or not cs_was_low:
                    t_fall = falls[f - (1 if cs_was_low else 0)] if (f > 0 or not cs_was_low) else None
                    if t_fall is not None:
                        assert d <= first - t_fall <= 2 * d, f"frame {f}: first edge {first - t_fall} after CS_N fell"
                assert d <= rises[f] - last <= 2 * d, f"frame {f}: CS_N rose {rises[f] - last} clocks after the last edge"
        for f, want in enumerate(want_mosi):
            fe = edges[2 * n * f:2 * n * (f + 1)]
            gaps = [b[0] - a[0] for a, b in zip(fe, fe[1:])]
            assert set(gaps) == {d}, f"frame {f}: SCLK edge spacing {sorted(set(gaps))}, DIV {d}"
            levels = [lv for _, lv, _ in fe]
            assert levels == [1 - cpol, cpol] * n, f"frame {f}: SCLK levels {levels} (CPOL {cpol})"
            sampled = [mo for k, (_, _, mo) in enumerate(fe) if (k % 2) == cpha]
            assert sampled == want, f"frame {f}: MOSI at the sample edges {sampled}, model {want}"
        for a, b in zip(range(len(want_mosi) - 1), range(1, len(want_mosi))):
            gap = edges[2 * n * b][0] - edges[2 * n * a + 2 * n - 1][0]
            assert gap >= 2 * d, f"frames {a},{b}: only {gap} clocks between them"

@cocotb.test(timeout_time=1793040, timeout_unit="ns")
async def test_modes_1_and_2(dut):

"""Golden model of t2_spi_master_modes, written from spec.yaml alone (never from any RTL)."""

from __future__ import annotations

DESIGN_ID = 0x5350494D
CTRL, DIV, TXDATA, RXDATA, STATUS = 0, 1, 2, 3, 4
CPOL, CPHA, LSB, W16, CS_HOLD, LOOP = 1, 2, 4, 8, 16, 32
BUSY, DONE, CS_ACTIVE = 1, 2, 4


def nbits(ctrl: int) -> int:
    return 16 if ctrl & W16 else 8


def tx_bits(value: int, ctrl: int) -> list[int]:
    """The data bits in the order they go out on MOSI."""
    n = nbits(ctrl)
    order = range(n) if ctrl & LSB else range(n - 1, -1, -1)
    return [(value >> i) & 1 for i in order]


def assemble(bits: list[int], ctrl: int) -> int:
    """RXDATA from the bits received in order."""
    n = nbits(ctrl)
    order = list(range(n)) if ctrl & LSB else list(range(n - 1, -1, -1))
    return sum(b << i for b, i in zip(bits, order))


class Model:
    def __init__(self) -> None:
        self.ctrl = 0
        self.div = 50
        self.txdata = 0
        self.rxdata = 0
        self.done = False
        self.cs_low = False

    def write(self, off: int, v: int) -> bool:
        """Returns True if the write starts a frame (the caller then calls finish())."""
        v &= 0xFFFF_FFFF
        if off == CTRL:
            self.ctrl = v & 0x3F
            if not self.ctrl & CS_HOLD:
                self.cs_low = False
        elif off == DIV:
            if v & 0xFFFF >= 2:
                self.div = v & 0xFFFF
        elif off == TXDATA:
            self.txdata = v & 0xFFFF
            self.cs_low = True
            return True
        elif off == STATUS and v & DONE:
            self.done = False
        return False

    def finish(self, miso_bits: list[int] | None = None) -> list[int]:
        """The frame ends: returns the MOSI bits; RXDATA from ``miso_bits`` (or MOSI itself in loopback)."""
        out = tx_bits(self.txdata, self.ctrl)
        got = out if self.ctrl & LOOP else (miso_bits or [0] * len(out))
        self.rxdata = assemble(got, self.ctrl)
        self.done = True
        if not self.ctrl & CS_HOLD:
            self.cs_low = False
        return out

    def read(self, off: int) -> int:
        if off == CTRL:
            return self.ctrl
        if off == DIV:
            return self.div
        if off == TXDATA:
            return self.txdata
        if off == RXDATA:
            return self.rxdata
        if off == STATUS:
            return (DONE if self.done else 0) | (CS_ACTIVE if self.cs_low else 0)
        return 0
