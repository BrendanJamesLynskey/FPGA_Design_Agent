Problems / S. Computer vision

Corner finder behind the test shell

c13_nexys_harris_vga Course tier course part 13 S Computer vision Nexys A7-100T

The problem

A corner detector for a small grey-scale picture. It measures how brightness changes around each pixel in two directions, combines the measurements into a corner score, and keeps only scores that are high and are the largest nearby, so that each corner is reported once. The result is a list of corner positions, and the LEDs show how many were found.

Where it is used. Harris corner detection is a classic first step in feature tracking, image stitching, camera calibration and visual odometry. FPGAs run it on streaming video where a processor would be too slow.

Adapted from a project in the owner's FPGA design course (the course itself is private).

The spec the agent is given

Corner finder behind the test shell

I want a block for the Nexys A7-100T's FPGA that finds the corners of the bright rectangles in a small picture, and I want to exercise it entirely from the test shell.

  • The picture is 80 pixels wide and 60 high, 8-bit grey, and arrives as a stream of pixels, one per clock when available, row by row, with a start-of-picture mark and an end-of-line mark. It shows a few bright rectangles on a dark background; a different picture can follow.
  • Find the corners of the rectangles. A corner is reported once, at the corner pixel: not along the edges, and not as a cluster of neighbouring pixels. Rectangles that are only faintly brighter than the background have no corners worth reporting. A rectangle that touches the edge of the picture has only the corners that are inside the picture; the edge of the picture itself is not a corner.
  • When the picture has been processed, tell me how many corners were found and where each one is (x and y in whole pixels, x counted from 0 at the left and y from 0 at the top), as a list I can read.
  • The 16 LEDs show, in binary, how many corners were found in the picture.
  • The red CPU reset button returns the block to idle and forgets the list.

The shell is slow, so the stream is driven for me: I park a whole picture over the shell (four pixels per write, row by row, the first pixel of a word in its lowest byte) and give a "go" command, and the block then presents the pixels to the stream, one per clock. A status flag says busy from "go" until the list is final, and another says that a list is available. I read the number of corners, and then the corners one at a time (I select a place in the list and read it). The shell runs at 115200 baud on the USB-UART. The design ID is "HARR".

Test hooks: top module c13_nexys_harris_vga_top, ports named as in the board's master XDC, and the test shell's CLKS_PER_BIT, TIMEOUT_CYCLES and BUILD_STAMP parameters as top-level parameters. There are no other time constants.

Exactly spec.md. Anything it leaves open, the agent has to ask about.

What the hidden tests check

The requirements in the hidden spec, and how each is shown to hold:

  • REQ-01 the detected corner set equals the reference set (within 1 pixel; no extra detections) (shown by simulation)
  • REQ-02 the LEDs (the count) equal the number of corners reported (shown by simulation)
The full behaviour rules from hidden/spec.yaml

stream

  • AXI4-Stream video slave (tdata[7:0], tvalid, tready, tuser = start of picture, tlast = end of line), 80 x 60; the wrapper drives one pixel per clock and holds a pixel until tready.

detector

  • Harris corner response with non-maximum suppression, as the course exercise: Sobel gradients scaled down by 4 (arithmetic shift), structure tensor summed over 3 x 3, k = 1/16, R = det - (trace*trace >> 4), signed 48-bit; threshold 50 000 000 (signed compare); the pixel is a corner if R is strictly greater than NW, N, NE, W and greater-or-equal than E, SW, S, SE; replicated borders (edge pixels extend the picture).

expected result

  • The corner pixels of the rectangles that are visible inside the picture, exactly (the bench accepts a detection within one pixel of each true corner, and no extra detections).

weak rectangles

  • A rectangle only about 45 grey levels brighter than its surroundings gives a response below the threshold: no corners.

leds

  • LED[15:0] = COUNT.

Settled assumptions

  • the picture buffer and the stream generator are part of the test wrapper, not of the block under test the shell cannot present a stream; any design must provide the register map above

// c13_nexys_harris_vga_regs.sv: the shell window of course task c13_nexys_harris_vga: a parked picture, a stream generator and the corner-list readback.
module c13_nexys_harris_vga_regs (
    input  logic        clk,
    input  logic        rst,
    output logic [15:0] led,
    input  logic [6:0]  win_addr,
    input  logic        win_wr,
    input  logic        win_rd,
    input  logic [31:0] win_wdata,
    output logic [31:0] win_rdata
);
    localparam int NPIX = 4800;
    logic [31:0] ram [0:1199];
    logic [10:0] ptr;
    logic        streaming, have_report;
    logic [12:0] tx_i;
    logic [6:0]  tx_x;
    logic [7:0]  s_tdata;
    logic        s_tvalid, s_tready, s_tuser, s_tlast, core_done;
    logic [15:0] count;
    logic [5:0]  sel;
    logic [6:0]  rd_x, rd_y;
    wire busy = streaming;
    assign led = count;

    harris_detect #(.W(80), .H(60)) u_core (.clk(clk), .rst_n(!rst), .s_tdata(s_tdata), .s_tvalid(s_tvalid), .s_tready(s_tready), .s_tuser(s_tuser), .s_tlast(s_tlast),
                                              .done(core_done), .count(count), .rd_idx(sel), .rd_x(rd_x), .rd_y(rd_y));

    wire [31:0] nxt_w = ram[tx_i[12:2]];
    wire slot_free = !s_tvalid || s_tready;

    always_ff @(posedge clk) begin
        if (win_wr) begin
            case (win_addr)
                7'd0: ptr <= win_wdata[10:0];
                7'd1: begin ram[ptr] <= win_wdata; ptr <= ptr + 11'd1; end
                7'd2: begin streaming <= 1'b1; have_report <= 1'b0; tx_i <= 13'd0; tx_x <= 7'd0; s_tvalid <= 1'b0; end
                7'd5: sel <= win_wdata[5:0];
                default: ;
            endcase
        end
        if (streaming && slot_free) begin
            if (tx_i < NPIX) begin
                s_tvalid <= 1'b1;
                s_tdata  <= nxt_w[8*tx_i[1:0] +: 8];
                s_tuser  <= (tx_i == 13'd0);
                s_tlast  <= (tx_x == 7'd79);
                tx_i     <= tx_i + 13'd1;
                tx_x     <= (tx_x == 7'd79) ? 7'd0 : tx_x + 7'd1;
            end else s_tvalid <= 1'b0;
        end
        if (streaming && tx_i == NPIX && !s_tvalid && core_done) begin streaming <= 1'b0; have_report <= 1'b1; end
        win_rdata <= 32'd0;
        if (win_rd) begin
            case (win_addr)
                7'd0: win_rdata <= {21'd0, ptr};
                7'd3: win_rdata <= {30'd0, have_report, busy};
                7'd4: win_rdata <= {16'd0, count};
                7'd5: win_rdata <= {26'd0, sel};
                7'd6: win_rdata <= (16'(sel) < count) ? {17'd0, rd_y, 1'b0, rd_x} : 32'd0;
                default: ;
            endcase
        end
        if (rst) begin
            ptr <= '0; sel <= '0; streaming <= 1'b0; have_report <= 1'b0; tx_i <= '0; tx_x <= '0; s_tvalid <= 1'b0; win_rdata <= 32'd0; s_tdata <= '0; s_tuser <= 1'b0; s_tlast <= 1'b0;
        end
    end
endmodule

harris.sv reference RTL, 99 lines
DownloadOn GitHubMIT licence
// Part 13 project reference (07a1c form): Harris response and non-maximum suppression on a 7 x 7 window, pipelined and with one shared response unit.
// The first form of this reference computed the nine responses of the 3 x 3 neighbourhood in parallel (243 multipliers, about 100,000 LUTs): it did not fit the device.
// This form computes the same numbers in a different order:
//   cycle 1: the Sobel gradients ix, iy of the 25 pixels of the central 5 x 5 (each >>> 2, as the model does);
//   cycle 2: their products ix*ix, iy*iy, ix*iy;
//   cycle 3: the sums of three neighbouring products along each row;
//   cycle 4: the 3 x 3 box sums sxx, syy, sxy for each of the nine response positions (the three row sums added);
//   cycles 5 .. 15: one position per clock through one det - trace^2/16 unit (three multipliers, pipelined);
//   cycle 16: the non-maximum suppression and the threshold; out_valid is high in cycle 17.
// Cycle 0 is the clock in which in_valid is high; the window must hold still from then until out_valid (harris_detect does that).
module harris (
    input  logic                clk,
    input  logic                rst_n,
    input  logic                in_valid,
    input  logic [391:0]        win,
    input  logic signed [47:0]  thresh,
    output logic                out_valid,
    output logic signed [47:0]  resp,
    output logic                corner
);
    function automatic integer px(input [391:0] w, input integer r, input integer c);
        px = w[(7*r + c)*8 +: 8];
    endfunction
    function automatic integer gx(input [391:0] w, input integer r, input integer c);
        gx = (px(w, r-1, c+1) + 2*px(w, r, c+1) + px(w, r+1, c+1)) - (px(w, r-1, c-1) + 2*px(w, r, c-1) + px(w, r+1, c-1));
    endfunction
    function automatic integer gy(input [391:0] w, input integer r, input integer c);
        gy = (px(w, r+1, c-1) + 2*px(w, r+1, c) + px(w, r+1, c+1)) - (px(w, r-1, c-1) + 2*px(w, r-1, c) + px(w, r-1, c+1));
    endfunction

    // stage 1: gradients of window rows / columns 1 .. 5 (index 0 .. 4)
    logic signed [8:0]  ix  [0:4][0:4], iy  [0:4][0:4];
    // stage 2: products
    logic signed [17:0] ixx [0:4][0:4], iyy [0:4][0:4], ixy [0:4][0:4];
    // stage 3: sums of three products along a row (index: row 0 .. 4, first column 0 .. 2)
    logic signed [20:0] hxx [0:4][0:2], hyy [0:4][0:2], hxy [0:4][0:2];
    // stage 4: box sums for the nine response positions (row-major: nw n ne w c e sw s se)
    logic signed [23:0] sxx [0:8], syy [0:8], sxy [0:8];
    // the shared response unit: operands, products, response
    logic [4:0]         t;                          // the cycle number once a window has been presented (cycle 0 = in_valid)
    logic               run;
    logic signed [23:0] o_xx, o_yy, o_xy, o_tr;
    logic signed [47:0] p_det_a, p_det_b, p_tr2, rsp;
    logic signed [47:0] rr [0:8];

    integer a, b;
    always_ff @(posedge clk) begin
        for (a = 0; a < 5; a = a + 1)
            for (b = 0; b < 5; b = b + 1) begin
                ix[a][b]  <= 9'(gx(win, a + 1, b + 1) >>> 2);
                iy[a][b]  <= 9'(gy(win, a + 1, b + 1) >>> 2);
                ixx[a][b] <= ix[a][b] * ix[a][b];
                iyy[a][b] <= iy[a][b] * iy[a][b];
                ixy[a][b] <= ix[a][b] * iy[a][b];
            end
        for (a = 0; a < 5; a = a + 1)
            for (b = 0; b < 3; b = b + 1) begin
                hxx[a][b] <= 21'(ixx[a][b]) + 21'(ixx[a][b + 1]) + 21'(ixx[a][b + 2]);
                hyy[a][b] <= 21'(iyy[a][b]) + 21'(iyy[a][b + 1]) + 21'(iyy[a][b + 2]);
                hxy[a][b] <= 21'(ixy[a][b]) + 21'(ixy[a][b + 1]) + 21'(ixy[a][b + 2]);
            end
        for (a = 0; a < 3; a = a + 1)
            for (b = 0; b < 3; b = b + 1) begin
                sxx[3*a + b] <= 24'(hxx[a][b]) + 24'(hxx[a + 1][b]) + 24'(hxx[a + 2][b]);
                syy[3*a + b] <= 24'(hyy[a][b]) + 24'(hyy[a + 1][b]) + 24'(hyy[a + 2][b]);
                sxy[3*a + b] <= 24'(hxy[a][b]) + 24'(hxy[a + 1][b]) + 24'(hxy[a + 2][b]);
            end
        // one position per clock: position p is selected in cycle 4 + p, its response is stored in cycle 7 + p
        o_xx <= sxx[(t >= 4 && t <= 12) ? t - 4 : 0];
        o_yy <= syy[(t >= 4 && t <= 12) ? t - 4 : 0];
        o_xy <= sxy[(t >= 4 && t <= 12) ? t - 4 : 0];
        o_tr <= sxx[(t >= 4 && t <= 12) ? t - 4 : 0] + syy[(t >= 4 && t <= 12) ? t - 4 : 0];
        p_det_a <= o_xx * o_yy;
        p_det_b <= o_xy * o_xy;
        p_tr2   <= o_tr * o_tr;
        rsp     <= (p_det_a - p_det_b) - (p_tr2 >>> 4);
        if (t >= 7 && t <= 15) rr[t - 7] <= rsp;
    end

    wire signed [47:0] rc = rr[4];
    wire is_max = (rc > rr[0]) && (rc > rr[1]) && (rc > rr[2]) && (rc > rr[3]) && (rc >= rr[5]) && (rc >= rr[6]) && (rc >= rr[7]) && (rc >= rr[8]);

    always_ff @(posedge clk) begin
        if (t == 5'd16) begin
            resp   <= rc;
            corner <= (rc > thresh) && is_max;
        end
        if (!rst_n) begin
            out_valid <= 1'b0; run <= 1'b0; t <= 5'd0;
        end else begin
            out_valid <= 1'b0;
            if (in_valid) begin run <= 1'b1; t <= 5'd1; end
            else if (run) begin
                t <= t + 5'd1;
                if (t == 5'd16) begin run <= 1'b0; t <= 5'd0; out_valid <= 1'b1; end
            end
        end
    end
endmodule

// P13-1 reference glue (v1.1 scope): a picture goes in as a stream of 8-bit pixels (80 x 60) into a picture store; when the last pixel is in, a scan engine builds the
// 7 x 7 window of every pixel (edge pixels replicated), one column per clock, and hands it to the course's Harris response and non-maximum suppression (harris.sv).
// The picture is held in seven block-RAM copies (one per window row, each written together and read through a registered port), so Vivado infers block RAM
// instead of 38,400 flip-flops with seven read multiplexers each; the address is registered before the RAM, so a column arrives two clocks after its address (the drain states 5 and 6).
// Each corner is appended to a list (x, y); `count` counts all corners found (the list holds the first 64); `done` is high from the end of the scan until the next picture starts.
module harris_pic_ram #(
    parameter int N = 4800
) (
    input  logic        clk,
    input  logic        we,
    input  logic [12:0] waddr,
    input  logic [7:0]  wdata,
    input  logic [12:0] raddr,
    output logic [7:0]  rdata
);
    (* ram_style = "block" *) logic [7:0] mem [0:N-1];
    always_ff @(posedge clk) begin
        if (we) mem[waddr] <= wdata;
        rdata <= mem[raddr];
    end
endmodule

module harris_detect #(
    parameter int W = 80,
    parameter int H = 60
) (
    input  logic        clk,
    input  logic        rst_n,
    input  logic [7:0]  s_tdata,
    input  logic        s_tvalid,
    output logic        s_tready,
    input  logic        s_tuser,
    input  logic        s_tlast,
    output logic        done,
    output logic [15:0] count,
    input  logic [5:0]  rd_idx,
    output logic [6:0]  rd_x,
    output logic [6:0]  rd_y
);
    localparam int N = W * H;
    logic [12:0] wn;                        // pixels stored
    logic [6:0]  px, py;                    // pixel being examined
    logic [2:0]  k;                         // window column being loaded
    logic [2:0]  st;                        // 0 idle/store, 1 fill, 2 fire, 3 wait, 4 collect
    logic [7:0]  wreg [0:6][0:6];
    logic [391:0] win;
    logic        in_valid, h_valid, h_corner;
    logic signed [47:0] h_resp;
    logic [6:0]  lx [0:63], ly [0:63];
    logic        cap_en, cap_en1;           // a column was addressed two clocks ago: its pixels are on q now
    logic [2:0]  kd, kd1;                   // the window column those pixels belong to
    logic [7:0]  q [0:6];                   // registered read of the seven picture copies
    logic [12:0] raddr [0:6], raddr_q [0:6];
    wire         pic_we = (st == 3'd0) && s_tvalid && s_tready;
    wire  [12:0] pic_wa = s_tuser ? 13'd0 : wn;

    harris u_h (.clk(clk), .rst_n(rst_n), .in_valid(in_valid), .win(win), .thresh(48'sd50000000), .out_valid(h_valid), .resp(h_resp), .corner(h_corner));

    assign s_tready = (st == 3'd0) && !(wn == N);
    wire acc = s_tvalid && s_tready;
    assign rd_x = lx[rd_idx];
    assign rd_y = ly[rd_idx];

    function automatic integer clamp(input integer v, input integer hi);
        clamp = (v < 0) ? 0 : (v > hi) ? hi : v;
    endfunction

    integer r, c;
    always_comb begin
        for (int i = 0; i < 7; i++)
            raddr[i] = 13'(clamp(int'(py) - 3 + i, H - 1) * W + clamp(int'(px) - 3 + int'(k), W - 1));
    end
    for (genvar g = 0; g < 7; g++) begin : g_pic
        harris_pic_ram #(.N(N)) u_ram (.clk(clk), .we(pic_we), .waddr(pic_wa), .wdata(s_tdata), .raddr(raddr_q[g]), .rdata(q[g]));
    end

    always_ff @(posedge clk) begin
        in_valid <= 1'b0;
        for (r = 0; r < 7; r = r + 1) raddr_q[r] <= raddr[r];
        cap_en1 <= (st == 3'd1);
        kd1 <= k;
        cap_en <= cap_en1;
        kd <= kd1;
        if (cap_en) for (r = 0; r < 7; r = r + 1) wreg[r][kd] <= q[r];
        if (!rst_n) begin
            st <= 3'd0; wn <= 13'd0; done <= 1'b0; count <= 16'd0;
        end else begin
            case (st)
                3'd0: if (acc) begin
                    if (s_tuser) begin
                        wn <= 13'd1; done <= 1'b0; count <= 16'd0;
                    end else begin
                        wn <= wn + 13'd1;
                        if (wn == N - 1) begin st <= 3'd1; px <= 7'd0; py <= 7'd0; k <= 3'd0; end
                    end
                end
                3'd1: begin                                        // address one column of the window per clock (the pixels follow one clock later)
                    k <= k + 3'd1;
                    if (k == 3'd6) st <= 3'd5;
                end
                3'd5: st <= 3'd6;                                  // drain: the last two columns are still on their way
                3'd6: st <= 3'd2;                                  // the last column is captured into wreg at the end of this clock
                3'd2: begin
                    for (r = 0; r < 7; r = r + 1)
                        for (c = 0; c < 7; c = c + 1)
                            win[(7*r + c)*8 +: 8] <= wreg[r][c];
                    in_valid <= 1'b1;
                    st <= 3'd3;
                end
                3'd3: st <= 3'd4;                                  // harris.sv registers the answer one clock after in_valid
                3'd4: begin
                    if (h_valid) begin
                        if (h_corner) begin
                            if (count < 64) begin lx[count[5:0]] <= px; ly[count[5:0]] <= py; end
                            count <= count + 16'd1;
                        end
                        k <= 3'd0;
                        if (px == W - 1) begin
                            px <= 7'd0;
                            if (py == H - 1) begin st <= 3'd0; done <= 1'b1; wn <= 13'd0; end
                            else begin py <= py + 7'd1; st <= 3'd1; end
                        end else begin px <= px + 7'd1; st <= 3'd1; end
                    end
                end
                default: st <= 3'd0;
            endcase
        end

"""Acceptance tests of c13_nexys_harris_vga against model.py (hidden from the agent)."""

from __future__ import annotations

import cocotb
from benchmark.lib.bench import Board, peek
from model import COUNT, CORNER, DATA, DESIGN_ID, GO, PTR, SEL, STATUS, bench_pictures, check_corners, corners, pack_words


async def run_picture(b: Board, dut, name: str, img) -> None:
    exp = corners(img)
    await b.write(PTR, 0)
    for w in pack_words(img):
        await b.write(DATA, w)
    await b.write(GO, 1)
    await b.cycles(4800)
    for _ in range(600):
        if not (await b.read(STATUS)) & 1:
            break
    else:
        raise AssertionError(f"{name}: still busy long after the picture")
    st = await b.read(STATUS)
    assert st & 2, f"{name}: no list available after the picture (STATUS 0x{st:X})"
    n = await b.read(COUNT)
    got = []
    for i in range(min(n, 64)):
        await b.write(SEL, i)
        v = await b.read(CORNER)
        got.append((v & 0x7F, (v >> 8) & 0x7F))
    why = check_corners(got, exp)
    assert not why, f"{name}: " + "; ".join(why) + f" (reported {got}, true {[tuple(c) for c in exp]})"
    assert n == len(got), f"{name}: the count is {n} but {len(got)} corners were readable"
    led = await peek(b.clk, dut.LED)
    assert led == n, f"{name}: LEDs show {led}, the count is {n}"

"""P13-1 reference model: the Harris corner list (numpy, bit-exact with the course exercise) and the bench pictures. Standalone copy of the course model."""
import numpy as np

W, H, THRESH = 80, 60, 50_000_000
BOXES = ((12, 10, 30, 26), (50, 32, 68, 50))


def squares(w, h, boxes):
    """Bright rectangles (x0, y0, x1, y1 inclusive, value 220) on a dark background (30)."""
    img = np.full((h, w), 30, np.uint8)
    for x0, y0, x1, y1 in boxes:
        img[y0:y1 + 1, x0:x1 + 1] = 220
    return img


def scene():
    return squares(W, H, BOXES)


def _grad(p, r, c):
    gx = (p[r - 1, c + 1] + 2 * p[r, c + 1] + p[r + 1, c + 1]) - (p[r - 1, c - 1] + 2 * p[r, c - 1] + p[r + 1, c - 1])
    gy = (p[r + 1, c - 1] + 2 * p[r + 1, c] + p[r + 1, c + 1]) - (p[r - 1, c - 1] + 2 * p[r - 1, c] + p[r - 1, c + 1])
    return gx >> 2, gy >> 2


def response_map(img):
    p = np.pad(img.astype(np.int64), 3, mode="edge")
    ix = np.zeros(p.shape, np.int64)
    iy = np.zeros(p.shape, np.int64)
    for r in range(1, p.shape[0] - 1):
        for c in range(1, p.shape[1] - 1):
            ix[r, c], iy[r, c] = _grad(p, r, c)
    R = np.zeros(p.shape, np.int64)
    for r in range(2, p.shape[0] - 2):
        for c in range(2, p.shape[1] - 2):
            a, b = ix[r - 1:r + 2, c - 1:c + 2], iy[r - 1:r + 2, c - 1:c + 2]
            sxx, syy, sxy = int((a * a).sum()), int((b * b).sum()), int((a * b).sum())
            R[r, c] = sxx * syy - sxy * sxy - (((sxx + syy) ** 2) >> 4)
    return R


def corners(img=None):
    img = scene() if img is None else img
    R = response_map(img)
    out = []
    for y in range(H):
        for x in range(W):
            r, c = y + 3, x + 3
            rc = R[r, c]
            strict = all(rc > R[r + dy, c + dx] for dy, dx in ((-1, -1), (-1, 0), (-1, 1), (0, -1)))
            loose = all(rc >= R[r + dy, c + dx] for dy, dx in ((0, 1), (1, -1), (1, 0), (1, 1)))
            if rc > THRESH and strict and loose:
                out.append([x, y])
    return out


def mixed_picture():
    """Strong, weak and border-touching rectangles: a strong box inside, a weak one (contrast 45, below the threshold: no corners), a medium one on the right and bottom edges
    and a strong one on the left and bottom edges (their corners at the picture edge are replicated, not mirrored or zero-padded)."""
    img = np.full((H, W), 30, np.uint8)
    img[4:19, 4:21] = 220
    img[6:23, 30:56] = 75
    img[30:60, 60:80] = 100
    img[36:60, 0:15] = 220
    return img


def bench_pictures():
    return [("the course picture", scene()), ("strong, weak and border rectangles", mixed_picture())]


def pack_words(img):
    flat = [int(v) for v in img.flatten()]
    return [sum(flat[4 * i + k] << (8 * k) for k in range(4)) for i in range(len(flat) // 4)]


def check_corners(got, exp):
    """The course check.py rule: every true corner has a detection within one pixel, no detection is away from every true corner, and no more detections than corners."""
    why = []
    for ex, ey in exp:
        if not any(abs(x - ex) <= 1 and abs(y - ey) <= 1 for x, y in got):
            why.append(f"corner ({ex}, {ey}) not found")
    extra = [(x, y) for x, y in got if all(abs(x - ex) > 1 or abs(y - ey) > 1 for ex, ey in exp)]
    if extra:
        why.append(f"{len(extra)} detections away from every true corner: {extra[:6]}")
    if len(got) > len(exp):
        why.append(f"{len(got)} detections for {len(exp)} corners (one cross per corner expected)")
    return why
