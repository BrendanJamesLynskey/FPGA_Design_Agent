Problems / A. Basic digital design drills

Four-floor lift controller

t1_elevator_fsm Benchmark v1 T1 A Basic digital design drills Nexys A7-100T

The problem

A controller for a lift serving four floors. Switches act as the call buttons; the lift travels a floor in a fixed time, opens its door for a fixed time at each floor that was called, and keeps going in one direction while there are calls further on before it turns round. LEDs show the floor, the outstanding calls, the door and whether it is moving, and the test shell reads the same state as registers.

Where it is used. Lift and elevator controllers, and the same pattern (serve requests in one sweep, then reverse) in disk-head scheduling and in machine controllers. It is a standard exercise in writing a finite-state machine with timers.

The spec the agent is given

Four-floor lift controller

I want a model of a lift serving four floors (0 to 3) on the Nexys A7-100T.

  • SW[3:0] are the call buttons, one per floor: flicking a switch up calls the lift to that floor. Leaving it up doesn't call again; it has to go down and up again.
  • The lift takes a fixed time to travel one floor, and when it stops at a floor that was called its door stays open for a fixed time. It should behave like a real lift: keep going in the same direction while there are calls further on, and only then turn round. It starts at floor 0 with the door shut.
  • LED[3:0] show which floor the lift is at (one LED lit) and LED[15] is lit while the door is open. Also show the outstanding calls on LED[7:4]. LED[14] is lit while the lift is moving between floors.
  • CPU_RESETN resets everything.
  • Over the test shell (USB-UART, 115200 baud) I can read the floor, the direction, the outstanding calls, what the lift is doing and how many floors it has travelled, and place calls. The design ID is "ELEV".

Test hooks: top module t1_elevator_fsm_top, ports named as in the board's master XDC, the test shell's CLKS_PER_BIT, TIMEOUT_CYCLES and BUILD_STAMP parameters, plus FLOOR_CYCLES (clocks to travel one floor) and DOOR_CYCLES (clocks the door stays open) as top-level parameters.

Exactly spec.md. Anything it leaves open, the agent has to ask about.

Interface

Top module t1_elevator_fsm_top on the Nexys A7-100T (xc7a100tcsg324-1). Clock: CLK100MHZ at 100 MHz (board oscillator). Reset: CPU_RESETN, active low: FLOOR = 0, DIR = up, PENDING = 0, STATE = IDLE, MOVES = 0; the switch edge detector's previous value is 0. Resources expected: under a hundred LUTs and FFs; no BRAM, no DSP.

Top-level parameters (board values): CLKS_PER_BIT = 868, DOOR_CYCLES = 200000000, FLOOR_CYCLES = 150000000, TIMEOUT_CYCLES = 100000. The hidden bench shrinks them to CLKS_PER_BIT = 8, DOOR_CYCLES = 300, FLOOR_CYCLES = 400, TIMEOUT_CYCLES = 400.

What the hidden tests check

The requirements in the hidden spec, and how each is shown to hold:

  • REQ-01 The car serves calls in SCAN order - it keeps its direction while calls remain ahead, then turns (shown by simulation)
  • REQ-02 Travel takes exactly FLOOR_CYCLES a floor and each stop opens the door for exactly DOOR_CYCLES (shown by simulation)
  • REQ-03 Calls are switch 0 -> 1 edges or shell W1S writes; a call for the open-door floor is ignored (shown by simulation)
  • REQ-04 FLOOR, DIR, PENDING, STATE, MOVES and the LEDs follow the model (shown by simulation)
  • REQ-05 The car never leaves floors 0..3 and the door is never open while moving (shown by simulation, formal)
  • REQ-06 The design closes timing at 100 MHz with no unconstrained path (shown by report analysis)
  • REQ-07 On the board a shell call is served and MOVES and FLOOR change as the model predicts (shown by on the board)
The full behaviour rules from hidden/spec.yaml

calls

  • SW[3:0] are synchronised by two flops (not debounced). A call for floor k is a 0 -> 1 change of synchronised SW[k]; a switch already up after reset calls once.
  • A shell write to PENDING with bit k = 1 is a call for floor k (write-1-to-set; 0 bits do nothing).
  • A call sets PENDING[k], except a call for the floor where the door is open now, which is ignored.

motion

  • States - IDLE (0), MOVING (1), DOOR (2). DIR is 0 for up, 1 for down. ahead(d) = some PENDING bit beyond FLOOR in direction d.
  • Decision (taken every clock in IDLE, and on the clock the door closes) - if PENDING[FLOOR] then clear it and open the door (DOOR); else if ahead(DIR) then start MOVING in DIR; else if ahead(not DIR) then flip DIR and start MOVING; else IDLE.
  • MOVING - after exactly FLOOR_CYCLES clocks FLOOR changes by one in DIR and MOVES += 1 (16 bits, wrapping). If PENDING[FLOOR] is then set, it is cleared and the door opens; otherwise the next floor's travel starts on the same clock (calls remain ahead, so DIR never flips while moving).
  • DOOR - the door is open for exactly DOOR_CYCLES clocks, then closes and the decision is taken on that clock.
  • So travel from floor a to floor b without stops takes |a - b| * FLOOR_CYCLES clocks, and LED[15] is high for exactly DOOR_CYCLES clocks a stop.

leds

  • LED[3:0] one-hot FLOOR (LED[FLOOR] = 1); LED[7:4] = PENDING; LED[14] = MOVING; LED[15] = door open; LED[13:8] = 0. Registered, no PWM.

Settled assumptions

  • a call for the floor the car is idle at opens the door there without moving. a real lift opens for a call at its own floor.
  • the car starts upwards after reset. it starts at the bottom floor.

// elevator_fsm.sv: four-floor SCAN lift controller with travel and door timers,
// for t1_elevator_fsm, behind the shell's register window.
module elevator_fsm #(
    parameter int FLOOR_CYCLES = 150_000_000,
    parameter int DOOR_CYCLES  = 200_000_000
) (
    input  logic        clk,
    input  logic        rst,
    input  logic [3:0]  sw_async,
    output logic [15:0] led,
    input  logic [6:0]  win_addr,
    input  logic        win_wr,
    input  logic        win_rd,
    input  logic [31:0] win_wdata,
    output logic [31:0] win_rdata
);
    localparam logic [6:0] R_FLOOR = 7'h00, R_DIR = 7'h01, R_PEND = 7'h02, R_STATE = 7'h03, R_MOVES = 7'h04;
    localparam logic [1:0] IDLE = 2'd0, MOVING = 2'd1, DOOR = 2'd2;

    logic [3:0]  sw, sw_q, pend, calls, p1, above, below;
    logic [1:0]  state, floor, nf;
    logic        dir;
    logic [15:0] moves;
    logic [31:0] timer;

    sync2 #(.WIDTH(4)) u_sw (.clk(clk), .rst(rst), .d(sw_async), .q(sw));

    // calls this clock; one for the floor with the door open is dropped
    always_comb begin
        calls = (sw & ~sw_q) | ((win_wr && win_addr == R_PEND) ? win_wdata[3:0] : 4'd0);
        if (state == DOOR) calls[floor] = 1'b0;
        p1 = pend | calls;
        for (int k = 0; k < 4; k++) begin
            above[k] = 2'(k) > floor;
            below[k] = 2'(k) < floor;
        end
    end

    wire ahead_up = (p1 & above) != 4'd0;
    wire ahead_dn = (p1 & below) != 4'd0;
    assign nf = dir ? floor - 2'd1 : floor + 2'd1;

    always_ff @(posedge clk) begin
        if (rst) begin
            sw_q <= '0; pend <= '0; state <= IDLE; floor <= '0; dir <= 1'b0; moves <= '0; timer <= '0;
        end else begin
            sw_q <= sw;
            pend <= p1;
            timer <= timer + 1'b1;
            if (state == MOVING && timer == 32'(FLOOR_CYCLES - 1)) begin
                floor <= nf;
                moves <= moves + 1'b1;
                timer <= '0;
                if (p1[nf]) begin
                    pend[nf] <= 1'b0;
                    state    <= DOOR;
                end
            end else if (state == IDLE || (state == DOOR && timer == 32'(DOOR_CYCLES - 1))) begin
                timer <= '0;
                if (p1[floor]) begin
                    pend[floor] <= 1'b0;
                    state       <= DOOR;
                end else if (dir ? ahead_dn : ahead_up) begin
                    state <= MOVING;
                end else if (dir ? ahead_up : ahead_dn) begin
                    dir   <= !dir;
                    state <= MOVING;
                end else begin
                    state <= IDLE;
                end
            end
        end
    end

`ifdef FORMAL
    always_comb assert (state != 2'd3);
`endif

    always_ff @(posedge clk) begin
        if (rst) led <= '0;
        else     led <= {state == DOOR, state == MOVING, 6'd0, pend, 4'b0001 << floor};
    end

    always_ff @(posedge clk) begin
        if (rst) win_rdata <= '0;
        else if (win_rd) begin
            case (win_addr)
                R_FLOOR: win_rdata <= {30'd0, floor};
                R_DIR:   win_rdata <= {31'd0, dir};
                R_PEND:  win_rdata <= {28'd0, pend};
                R_STATE: win_rdata <= {30'd0, state};
                R_MOVES: win_rdata <= {16'd0, moves};
                default: win_rdata <= '0;
            endcase
        end
    end
endmodule

"""Acceptance tests of t1_elevator_fsm against model.py (hidden from the agent).

The clocked model and the RTL run side by side. Events seen on the pins (LED[14] rise = depart, LED[3:0] change =
arrive, LED[15] rise/fall = door open/close) must match the model's events in order and floor, and every interval
that does not include idle time must match exactly (FLOOR_CYCLES, DOOR_CYCLES, 0). Calls are placed well away from
the car's decision clocks, so a design whose call latency differs by a few clocks gets the same order."""

from __future__ import annotations

import random

import cocotb
from benchmark.lib.bench import Board, peek
from cocotb.triggers import ReadOnly, RisingEdge
from cocotb.utils import get_sim_time
from model import DESIGN_ID, DIR, DOOR, FLOOR, IDLE, MOVES, MOVING, PENDING, STATE, Model

NAMES = ("FLOOR", "DIR", "PENDING", "STATE", "MOVES")
SW_LAT = 2              # clocks from a switch change to the call being seen (model time base)


class Watch:
    def __init__(self, dut, clk) -> None:
        self.events: list[tuple[int, str, int]] = []
        cocotb.start_soon(self.run(dut, clk))

    async def run(self, dut, clk) -> None:
        prev = None
        while True:
            await RisingEdge(clk)
            await ReadOnly()
            v = int(dut.LED.value)
            t = int(get_sim_time("ns")) // 10
            if prev is not None and v != prev:
                fl = [k for k in range(4) if v >> k & 1]
                assert len(fl) == 1, f"LED[3:0] = {v & 15:04b} is not one-hot"
                assert not (v >> 15 & 1 and v >> 14 & 1), "door open while moving"
                f = fl[0]
                if prev >> 15 & 1 and not v >> 15 & 1:
                    self.events.append((t, "close", f))
                if v >> 14 & 1 and not prev >> 14 & 1:
                    self.events.append((t, "depart", f))
                if v & 15 != prev & 15:
                    self.events.append((t, "arrive", f))
                if v >> 15 & 1 and not prev >> 15 & 1:
                    self.events.append((t, "open", f))
            prev = v


class Env:
    def __init__(self, dut) -> None:
        self.b = Board(dut, {"SW": 0})
        self.dut = dut
        self.fc = self.b.param("FLOOR_CYCLES")
        self.dc = self.b.param("DOOR_CYCLES")
        self.cpb = self.b.param("CLKS_PER_BIT")
        self.m = Model(self.fc, self.dc)
        self.sw = 0
        self.w: Watch | None = None

    def now(self) -> int:
        return int(get_sim_time("ns")) // 10

    async def start(self) -> None:
        await self.b.start()
        self.m.t = self.now()
        self.w = Watch(self.dut, self.b.clk)

    async def switch(self, k: int, v: int) -> None:
        old = self.sw >> k & 1
        self.sw = (self.sw & ~(1 << k)) | v << k
        self.dut.SW.value = self.sw
        if v and not old:
            self.m.call(self.now() + SW_LAT, 1 << k)
        await self.b.cycles(1)

    async def flick(self, *floors: int) -> None:
        """Switches up together then down again: one call each, all seen on the same clock."""
        mask = sum(1 << k for k in floors)
        new = mask & ~self.sw
        self.sw |= mask
        self.dut.SW.value = self.sw
        if new:
            self.m.call(self.now() + SW_LAT, new)
        await self.b.cycles(6)
        self.sw &= ~mask
        self.dut.SW.value = self.sw
        await self.b.cycles(1)

    async def shell_call(self, mask: int) -> None:
        await self.b.write(PENDING, mask)
        self.m.call(self.now() - 70 * self.cpb - 3, mask & 15)   # the write acted before the 7-byte response

    async def wait(self, n: int) -> None:
        await self.b.cycles(n)

    async def settle(self, limit: int = 20000) -> None:
        """Wait until the model says the car is idle with nothing pending, then a little more."""
        self.m.run_to(self.now())
        n = 0
        while not (self.m.state == IDLE and self.m.pend == 0 and not self.m.sched):
            self.m.step()
            n += 1
            assert n < limit
        await self.b.cycles(max(0, self.m.t - self.now()) + 20)
        self.m.run_to(self.now())

    def check_events(self) -> None:
        self.m.run_to(self.now() - 4)
        got = [(k, f) for _, k, f in self.w.events]
        want = [(k, f) for _, k, f in self.m.events]
        assert got == want, f"events {got} != model {want}"
        for i in range(1, len(want)):
            dm = self.m.events[i][0] - self.m.events[i - 1][0]
            dr = self.w.events[i][0] - self.w.events[i - 1][0]
            if want[i][0] in ("depart", "open") and dm != 0:
                continue                                       # idle time before a call: not compared
            assert dr == dm, f"{want[i - 1]} -> {want[i]} took {dr} clocks, model {dm}"

    async def check_regs(self) -> None:
        self.m.run_to(self.now())
        for off in range(5):
            await self.b.expect(off, self.m.read(off), NAMES[off])

    async def check_leds(self) -> None:
        self.m.run_to(self.now())
        led = await peek(self.b.clk, self.dut.LED)
        self.m.run_to(self.now())
        assert led == self.m.leds(), f"LED {led:04X} != model {self.m.leds():04X}"

@cocotb.test()
async def test_random_calls(dut):
    e = Env(dut)
    await e.start()
    rng = random.Random(int(cocotb.RANDOM_SEED))
    for _ in range(12):
        await e.wait(rng.randrange(50, e.fc + e.dc))

"""Golden model of t1_elevator_fsm, written from spec.yaml alone (never from any RTL).

A clocked model: run_to(t) steps the spec's rules one clock at a time and logs events (time, kind, floor) with
kind in "depart", "arrive", "open", "close". Calls are scheduled at the clock they are seen."""

from __future__ import annotations

FLOOR, DIR, PENDING, STATE, MOVES = range(5)
IDLE, MOVING, DOOR = 0, 1, 2
DESIGN_ID = 0x454C4556          # "ELEV"


class Model:
    def __init__(self, floor_cycles: int, door_cycles: int) -> None:
        self.fc, self.dc = floor_cycles, door_cycles
        self.floor, self.dir, self.pend, self.state, self.moves = 0, 0, 0, IDLE, 0
        self.timer = 0
        self.t = 0
        self.sched: dict[int, int] = {}
        self.events: list[tuple[int, str, int]] = []

    def call(self, at: int, mask: int) -> None:
        assert at >= self.t, "a call scheduled in the model's past"
        self.sched[at] = self.sched.get(at, 0) | mask

    def _ahead(self, d: int, p: int) -> bool:
        return any(p >> k & 1 for k in range(4) if (k > self.floor if d == 0 else k < self.floor))

    def _decide(self, p: int) -> int:
        if p >> self.floor & 1:
            p &= ~(1 << self.floor)
            self.state, self.timer = DOOR, 0
            self.events.append((self.t, "open", self.floor))
        elif self._ahead(self.dir, p):
            self.state, self.timer = MOVING, 0
            self.events.append((self.t, "depart", self.floor))
        elif self._ahead(1 - self.dir, p):
            self.dir ^= 1
            self.state, self.timer = MOVING, 0
            self.events.append((self.t, "depart", self.floor))
        else:
            self.state = IDLE
        return p

    def step(self) -> None:
        c = self.sched.pop(self.t, 0)
        if self.state == DOOR:
            c &= ~(1 << self.floor)
        p = self.pend | c
        if self.state == MOVING:
            self.timer += 1
            if self.timer == self.fc:
                self.floor += -1 if self.dir else 1
                assert 0 <= self.floor <= 3
                self.moves = (self.moves + 1) & 0xFFFF
                self.timer = 0
                self.events.append((self.t, "arrive", self.floor))
                if p >> self.floor & 1:
                    p &= ~(1 << self.floor)
                    self.state = DOOR
                    self.events.append((self.t, "open", self.floor))
        elif self.state == DOOR:
            self.timer += 1
            if self.timer == self.dc:
                self.events.append((self.t, "close", self.floor))
                p = self._decide(p)
        else:
            p = self._decide(p)
        self.pend = p
        self.t += 1

    def run_to(self, t: int) -> None:
        while self.t < t:
            self.step()

    def read(self, off: int) -> int:
        return {FLOOR: self.floor, DIR: self.dir, PENDING: self.pend, STATE: self.state,
                MOVES: self.moves}.get(off, 0)

    def leds(self) -> int:
        return (self.state == DOOR) << 15 | (self.state == MOVING) << 14 | self.pend << 4 | 1 << self.floor
