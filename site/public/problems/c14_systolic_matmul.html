Problems / I. Machine learning inference

4 x 4 row multiplier behind the test shell

c14_systolic_matmul Course tier course part 14 I Machine learning inference Nexys A7-100T

The problem

A block that multiplies short rows of numbers by a small fixed table. The table of signed 8-bit numbers is loaded once. Rows of four numbers are then fed in one per clock with no gaps, and for each row the block gives four exact 32-bit results, one per table column, in order. The spec fixes only the results and their timing; the course builds it as a systolic array, a grid of multiply-and-add cells passing data to their neighbours, but any structure that meets the timing passes.

Where it is used. This row-by-table product is the inner step of matrix multiplication, which dominates neural-network inference. Systolic grids are the matrix engines in many AI accelerators.

Adapted from a project in the owner's FPGA design course (the course itself is private).

The spec the agent is given

4 x 4 row multiplier behind the test shell

I want a block for the Nexys A7-100T's FPGA that multiplies short rows of numbers by a fixed small table of numbers, as fast as one row per clock, and I want to exercise it entirely from the test shell.

  • The table is 4 by 4 signed 8-bit numbers. I load it once with a "load" command: all 16 numbers are loaded over the shell and applied together, and later a new table can be loaded the same way (not while rows are being processed).
  • A row is four signed 8-bit numbers presented together. Because the shell is slow, I can park up to 16 rows over the shell and then give a "burst" command with a row count; the block then presents those rows to the arithmetic on consecutive clocks, with no gaps, and keeps the results in order.
  • For each row, the block gives four signed results (each is the sum of the four row numbers times the four numbers of one column of the table, so each needs more than 8 bits; keep each as a 32-bit signed number). I read them back over the shell after the burst, and a flag tells me when all of them are in.
  • The results for a row must be ready within 8 clocks of the row being presented; every row must give its answer, in order, with no row lost even when rows come on consecutive clocks. I can read back how many clocks the first row took.
  • CPU_RESETN clears everything. Exact results only: I will compare every number with my own calculation. LED0 shows the done flag. The shell runs at 115200 baud on the USB-UART. The design ID is "MM4X".

Test hooks: top module c14_systolic_matmul_top, ports named as in the board's master XDC, and the test shell's CLKS_PER_BIT, TIMEOUT_CYCLES and BUILD_STAMP parameters as top-level parameters. There are no other time constants.

Exactly spec.md. Anything it leaves open, the agent has to ask about.

What the hidden tests check

The requirements in the hidden spec, and how each is shown to hold:

  • REQ-01 every result row equals the model, in order, for bursts of 16, 8 and 1 rows on consecutive clocks (shown by simulation)
  • REQ-02 the latency of the first row is at most 8 clocks and every row of a burst gives a result (shown by simulation)
  • REQ-03 a second table loaded after the first gives results for the new table only (shown by simulation)
  • REQ-04 The design closes timing at 100 MHz with no unconstrained path (shown by report analysis)
The full behaviour rules from hidden/spec.yaml

product

  • C[m][j] = sum over i of A[m][i] * W[i][j], exact signed arithmetic, W and A signed 8-bit, C signed 32-bit

burst

  • BURST N presents ROW0..ROW(N-1) on N consecutive clocks (one row per clock, no gaps); the results arrive in order and are stored as RES rows 0..N-1; DONE rises when the Nth is stored.
  • Latency: a row presented in clock t has its result valid in clock t+L with L at most 8 (the reference has 8); LAT reports L for ROW0.
  • A table loaded with LOAD replaces the previous one for rows presented afterwards; LOAD is not issued while a burst runs.

leds

  • LED[0] = DONE, the other LEDs are 0.

// c14_systolic_matmul_regs.sv: the shell window of course task c14_systolic_matmul.
module c14_systolic_matmul_regs (
    input  logic        clk,
    input  logic        rst,
    output logic [15:0] led,
    input  logic [6:0]  win_addr,
    input  logic        win_wr,
    input  logic        win_rd,
    input  logic [31:0] win_wdata,
    output logic [31:0] win_rdata
);
    logic [127:0] w_r, c_row;
    logic [31:0]  rowm [0:15];
    logic [127:0] resm [0:15];
    logic [4:0]   n_tot, tx_i, rx_i;
    logic [7:0]   cnt;
    logic [4:0]   lat;
    logic         txing, wl, ov, done, running, got_first;
    logic [31:0]  a_row;

    assign a_row = rowm[tx_i[3:0]];
    assign led   = {15'd0, done};

    matmul4_rows u_core (.clk(clk), .rst_n(!rst), .w_load(wl), .w_in(w_r), .row_valid(txing), .a_row(a_row),
                         .out_valid(ov), .c_row(c_row));

    always_ff @(posedge clk) begin
        wl <= 1'b0;
        if (win_wr) begin
            if (win_addr <= 7'd3) w_r[win_addr[1:0]*32 +: 32] <= win_wdata;
            else if (win_addr == 7'd4) wl <= 1'b1;
            else if (win_addr >= 7'h08 && win_addr <= 7'h17) rowm[4'(win_addr - 7'h08)] <= win_wdata;
            else if (win_addr == 7'h18) begin
                n_tot <= (win_wdata[4:0] == 5'd0) ? 5'd1 : win_wdata[4:0];
                tx_i <= 5'd0; rx_i <= 5'd0; txing <= 1'b1; done <= 1'b0; running <= 1'b0; got_first <= 1'b0; cnt <= 8'd0;
            end
        end
        if (txing) begin
            tx_i <= tx_i + 5'd1;
            if (tx_i + 5'd1 == n_tot) txing <= 1'b0;
            if (tx_i == 5'd0) begin running <= 1'b1; cnt <= 8'd1; end
        end
        if (running && !(txing && tx_i == 5'd0)) cnt <= cnt + 8'd1;
        if (ov && !done) begin
            resm[rx_i[3:0]] <= c_row;
            rx_i <= rx_i + 5'd1;
            if (!got_first) begin got_first <= 1'b1; lat <= cnt[4:0]; running <= 1'b0; end
            if (rx_i + 5'd1 == n_tot) done <= 1'b1;
        end
        win_rdata <= 32'd0;
        if (win_rd) begin
            if (win_addr <= 7'd3) win_rdata <= w_r[win_addr[1:0]*32 +: 32];
            else if (win_addr >= 7'h08 && win_addr <= 7'h17) win_rdata <= rowm[4'(win_addr - 7'h08)];
            else if (win_addr == 7'h19) win_rdata <= {31'd0, done};
            else if (win_addr == 7'h1A) win_rdata <= {27'd0, lat};
            else if (win_addr == 7'h1B) win_rdata <= {27'd0, rx_i};
            else if (win_addr >= 7'h20 && win_addr <= 7'h5F)
                win_rdata <= resm[4'(win_addr[6:2] - 5'd8)][win_addr[1:0]*32 +: 32];
        end
        if (rst) begin
            txing <= 1'b0; done <= 1'b0; running <= 1'b0; got_first <= 1'b0; wl <= 1'b0; w_r <= '0;
            tx_i <= '0; rx_i <= '0; n_tot <= '0; lat <= '0; cnt <= '0; win_rdata <= 32'd0;
            for (int i = 0; i < 16; i++) begin rowm[i] <= '0; resm[i] <= '0; end
        end
    end
endmodule

// P14-3 reference: a row-in, row-out 4 x 4 matrix multiplier. The weight-stationary array of the course (systolic4.sv) with the input rows skewed (element i delayed by i clocks) and the
// output columns de-skewed (column j delayed by 3 - j clocks), so that C[m][*] appears together, 7 clocks after the edge that sampled A[m][*]. row_valid has no gaps requirement: a new row every clock.
module matmul4_rows (
    input  logic          clk,
    input  logic          rst_n,
    input  logic          w_load,
    input  logic [127:0]  w_in,             // W[i][j] = w_in[(4*i + j)*8 +: 8], signed
    input  logic          row_valid,
    input  logic [31:0]   a_row,            // A[m][i] = a_row[i*8 +: 8], signed
    output logic          out_valid,
    output logic [127:0]  c_row             // C[m][j] = c_row[j*32 +: 32], signed
);
    logic [7:0]   dly [0:3][0:3];           // input skew: element i passes through i registers
    logic [31:0]  a_skew;
    logic [127:0] c_raw;
    logic [31:0]  odly [0:3][0:3];          // output de-skew: column j passes through 3 - j registers
    logic [7:0]   vsr;
    always_ff @(posedge clk) begin
        for (int i = 0; i < 4; i++) begin
            dly[i][0] <= row_valid ? a_row[i*8 +: 8] : 8'd0;
            for (int k = 1; k < 4; k++) dly[i][k] <= dly[i][k-1];
        end
        for (int j = 0; j < 4; j++) begin
            odly[j][0] <= c_raw[j*32 +: 32];
            for (int k = 1; k < 4; k++) odly[j][k] <= odly[j][k-1];
        end
        vsr <= rst_n ? {vsr[6:0], row_valid} : 8'd0;
    end
    // element i uses i extra registers on top of the input register (so a_skew[i] is delayed by i + 1 in all; element 0 by one)
    always_comb begin
        a_skew[7:0]   = dly[0][0];
        a_skew[15:8]  = dly[1][1];
        a_skew[23:16] = dly[2][2];
        a_skew[31:24] = dly[3][3];
        for (int j = 0; j < 4; j++) c_row[j*32 +: 32] = (j == 3) ? c_raw[j*32 +: 32] : odly[j][2 - j];
    end
    assign out_valid = vsr[7];
    systolic4 u (.clk, .rst_n, .w_load, .w_in, .a_in(a_skew), .c_out(c_raw));
endmodule
systolic4.sv reference RTL, 44 lines

// Part 14 lesson 4 exercise: a 4 x 4 weight-stationary systolic array computing C = A x W for signed 8-bit A and W (C[m][j] = sum over i of A[m][i] * W[i][j]).
//
// PE (i, j) holds the weight W[i][j]. Activations travel along a row (left to right, one register per PE); partial sums travel down a column (top to bottom, one
// register per PE). In every PE, each clock:   a_reg <= a_left;   p_reg <= p_above + a_left * W[i][j]   (row 0 has p_above = 0, column 0 has a_left = a_in[i]).
//
// Weights: with w_load = 1 for one clock, all 16 weights are taken from w_in: W[i][j] = w_in[(4*i + j)*8 +: 8]. Reset (rst_n low, synchronous) clears every a_reg and
// p_reg to zero. a_in[i*8 +: 8] is the activation entering row i; c_out[j*32 +: 32] is the signed sum leaving the bottom of column j (the p_reg of PE (3, j)).
//
// Timing: if A[m][i] is applied on a_in[i] in clock cycle m + i (sampled at the rising edge that ends that cycle; the rows are skewed by one cycle each), then
// c_out[j] holds C[m][j] after the rising edge that ends cycle m + j + 3, so it can be read during cycle m + j + 4 (a cycle starts at a rising edge).
// A zero on a_in is a bubble (it adds nothing). Only one multiply-accumulate per PE per clock: after the pipeline fills, all 16 multipliers work every clock.
module systolic4 (
    input  logic          clk,
    input  logic          rst_n,
    input  logic          w_load,
    input  logic [127:0]  w_in,
    input  logic [31:0]   a_in,
    output logic [127:0]  c_out
);
    logic signed [7:0]  wt   [0:3][0:3];
    logic signed [7:0]  a_r  [0:3][0:3];
    logic signed [31:0] p_r  [0:3][0:3];

    always_ff @(posedge clk) begin
        if (!rst_n) begin
            for (int i = 0; i < 4; i++)
                for (int j = 0; j < 4; j++) begin
                    a_r[i][j] <= '0;
                    p_r[i][j] <= '0;
                    wt[i][j]  <= '0;
                end
        end else begin
            for (int i = 0; i < 4; i++)
                for (int j = 0; j < 4; j++) begin
                    if (w_load) wt[i][j] <= w_in[(4*i + j)*8 +: 8];
                    a_r[i][j] <= (j == 0) ? $signed(a_in[i*8 +: 8]) : a_r[i][j-1];
                    p_r[i][j] <= ((i == 0) ? 32'sd0 : p_r[i-1][j])
                                 + ((j == 0) ? $signed(a_in[i*8 +: 8]) : a_r[i][j-1]) * wt[i][j];
                end
        end
    end
    always_comb
        for (int j = 0; j < 4; j++) c_out[j*32 +: 32] = p_r[3][j];
endmodule

"""Acceptance tests of c14_systolic_matmul against model.py (hidden from the agent)."""

from __future__ import annotations

import cocotb
from benchmark.lib.bench import Board, peek
from model import (BURST, COUNT, DESIGN_ID, LAT, LOAD, RES0, ROW0, STATUS, W0, matmul, pack_row, rows, rows2, s32,
                   weights, weights2)


async def load_table(b: Board, W) -> None:
    for i in range(4):
        await b.write(W0 + i, pack_row(W[i]))
    await b.write(LOAD, 1)


async def burst(b: Board, rs, W, what: str) -> None:
    want = matmul(rs, W)
    for m, r in enumerate(rs):
        await b.write(ROW0 + m, pack_row(r))
    await b.write(BURST, len(rs))
    await b.cycles(40)
    await b.expect(STATUS, 1, f"DONE {what}")
    await b.expect(COUNT, len(rs), f"COUNT {what}")
    lat = await b.read(LAT)
    assert 1 <= lat <= 8, f"{what}: first-row latency {lat} clocks (must be 1..8)"
    for m in range(len(rs)):
        for j in range(4):
            await b.expect(RES0 + 4 * m + j, s32(want[m][j]), f"{what}: C[{m}][{j}] for row {rs[m]}")


@cocotb.test()
async def test_identity_and_reset(dut):
    b = Board(dut, {})
    await b.start()
    assert await b.shell_id() == DESIGN_ID
    for off in (W0, ROW0, STATUS, LAT, COUNT, RES0):
        await b.expect(off, 0, f"reset value of {off:#x}")

"""Reference model for P14-3 (4 x 4 matrix multiplier, rows in and out). Plain Python integers."""
import random

LATENCY = 7                    # clock edges between the edge that samples a row and the edge after which its results are visible with out_valid
MAX_LATENCY = 8                # what the spec allows


def weights():
    rng = random.Random(14)
    return [[rng.randint(-128, 127) for _ in range(4)] for _ in range(4)]


def rows():
    """The fixed test set: 40 rows applied on 40 consecutive clocks, then a second batch of 12 rows after a gap with new weights (weights2())."""
    rng = random.Random(15)
    r = [[rng.randint(-128, 127) for _ in range(4)] for _ in range(34)]
    r += [[-128] * 4, [127] * 4, [-128, 127, -128, 127], [0] * 4, [1, 0, 0, 0], [0, 0, 0, 1]]
    return r


def weights2():
    rng = random.Random(16)
    return [[rng.randint(-100, 100) for _ in range(4)] for _ in range(4)]


def rows2():
    rng = random.Random(17)
    return [[rng.randint(-128, 127) for _ in range(4)] for _ in range(12)]


def matmul(rs, W):
    return [[sum(a[i] * W[i][j] for i in range(4)) for j in range(4)] for a in rs]


def reference_output():
    return {"C": matmul(rows(), weights()), "C2": matmul(rows2(), weights2()), "latency_clocks": LATENCY, "accepted_every_clock": True}


# ---- benchmark wrapper: the shell register map (from spec.yaml) ----
DESIGN_ID = 0x4D4D3458          # "MM4X"
W0, LOAD, ROW0, BURST, STATUS, LAT, COUNT, RES0 = 0x00, 0x04, 0x08, 0x18, 0x19, 0x1A, 0x1B, 0x20


def pack_row(r):
    return sum((x & 0xFF) << (8 * i) for i, x in enumerate(r))


def s32(v):
    return v & 0xFFFFFFFF
