Problems / I. Machine learning inference

Tiny CNN shape classifier

c14_nexys_tiny_cnn Course tier course part 14 I Machine learning inference Nexys A7-100T

The problem

A very small convolutional neural network on the Nexys A7 that decides which of four simple shapes is in a small grey picture. The network's numbers come from files and it uses only whole-number arithmetic: two convolution layers with a pooling step between them, then a final layer that gives four scores. The board shows the winning class on a display digit and sends a letter over the serial port.

Where it is used. Small quantised networks like this run on cameras, sensors and microcontrollers for tasks such as gesture, symbol and defect recognition, and are a common way to learn how neural-network hardware works.

Adapted from a project in the owner's FPGA design course (the course itself is private).

The spec the agent is given

Tiny CNN shape classifier

I want the Nexys A7-100T to recognise which of four simple shapes is in a small grey picture, using a tiny neural network whose numbers I give you in files.

  • The pictures: eight of them, each 12 by 12 pixels, each pixel a signed 8-bit number from 0 to 127 (data/cnn_images.hex, one number per line, picture after picture, row by row). They show a horizontal bar, a vertical bar, a box outline or a cross; the four classes are numbered 0 (horizontal bar), 1 (vertical bar), 2 (box), 3 (cross).
  • The network, which must be followed exactly (all numbers are whole numbers): 1. Layer 1: four filters of 3 by 3, each sliding over the picture without going over the edge (so the result is 10 by 10 for each filter). For each place, multiply the nine pixels by the filter's nine weights, add them and add the filter's bias. Then scale the total by the fraction M1 / 2^S1, rounding to the nearest whole number with exact halves going up, and limit it to 0 to 127 (so negatives become 0). 2. Shrink each 10 by 10 result to 5 by 5 by keeping the largest of every 2 by 2 block. 3. Layer 2: eight filters of 3 by 3 over all four 5 by 5 results at once (each filter has 36 weights, one 3 by 3 per input result; add everything and a bias), giving 3 by 3 for each filter; then scale by M2 / 2^S2, round and limit to 0 to 127 in the same way. 4. Final layer: four sums, each of the 72 numbers from step 3 (taken filter by filter, row by row) times 72 weights, plus a bias. These four whole numbers ("scores") are not scaled or limited. The answer is the number of the biggest score (if two tie, the lower number).
  • The file data/cnn_params.hex holds all 612 weights, 16 biases (a 32-bit signed number each) and M1, S1, M2, S2 (one 32-bit hexadecimal word per line; each weight is a signed 8-bit number in two's complement stored in the low byte of its word with the upper 24 bits zero, so a word from 80 to FF is a negative weight and bit 7 is the sign; a bias is a full 32-bit signed number; M1, S1, M2, S2 are plain non-negative numbers; the order is: layer 1 weights, layer 2 weights, final layer weights, then the 16 biases, then M1, S1, M2, S2; the weights of a layer are ordered by filter, then input result, then row, then column).
  • Using the board: switches SW0 to SW2 choose the picture (0 to 7). Pressing the centre button (it needs debouncing) classifies that picture. When the answer is ready, show its number (0 to 3) on the right-hand seven-segment digit (blank before the first answer) and send one letter on the USB serial port at 115200 baud, 8 data bits, no parity, 1 stop bit, followed by a line feed: H for 0, V for 1, B for 2, X for 3.
  • I will check the letter and the digit for each of the eight pictures. The USB-UART carries the answer, so this design does not embed the test shell.

Test hooks: top module c14_nexys_tiny_cnn_top, ports named as in the board's master XDC, and the parameters DEBOUNCE_CYCLES (the button must be stable for this many clocks, 10 ms on the board) and CLKS_PER_BIT (868 on the board) as top-level parameters; the bench shrinks both. There are no other time constants.

Exactly spec.md. Anything it leaves open, the agent has to ask about.

Handed over with the spec (the agent may read them): cnn_images.hex, cnn_params.hex.

What the hidden tests check

The requirements in the hidden spec, and how each is shown to hold:

  • REQ-01 for each of the eight pictures the letter and the display digit equal the reference class (shown by simulation)
  • REQ-02 the display is blank before the first answer and shows only the right-hand digit (shown by simulation)
  • REQ-03 the four scores of each picture equal the reference exactly (checked by the designer's own simulation; the bench sees the class only) (shown by simulation)
  • REQ-04 The design closes timing at 100 MHz and fits the XC7A100T (shown by report analysis)
The full behaviour rules from hidden/spec.yaml

network

  • Exactly the course network: conv 3x3 1->4 with requantisation (acc*M1 + 2^(S1-1)) >>> S1 clamped to 0..127; 2x2 max-pool; conv 3x3 4->8 with requantisation by M2/S2 and clamp 0..127; dense 72->4 raw int32; class = argmax, lowest index on a tie.
  • Parameters and pictures: data/cnn_params.hex (612 weights, 16 biases, M1, S1, M2, S2) and data/cnn_images.hex (8 x 144 pixels).
  • Weight encoding: each of the 612 weights is a signed 8-bit two's complement number stored zero-extended in the low byte of its 32-bit word of cnn_params.hex (80..FF are negative, bit 7 is the sign); biases are 32-bit signed; M1, S1, M2, S2 are non-negative.

board

  • SW[2:0] choose the picture; a debounced rising edge of BTNC (stable for DEBOUNCE_CYCLES clocks) classifies it.
  • When the answer is ready: the class digit (0..3) on the right-hand digit (AN = 8'hFE; segments 0x40, 0x79, 0x24, 0x30 active low as {CG..CA}); all segments off before the first answer; one letter H, V, B or X then 0x0A on UART_RXD_OUT at 115200 8N1.
  • The reference loads its parameter memories after reset (about 650 clocks) before it accepts a press (LED15 is its ready flag).

leds

  • The reference shows ready on LED15 and the class on LED[1:0]; the bench does not check the LEDs.

// c14_nexys_tiny_cnn_top.sv: board top (Nexys A7-100T, master-XDC port names) around the course reference's tiny CNN system.
module c14_nexys_tiny_cnn_top #(
    parameter int DEBOUNCE_CYCLES = 1_000_000,
    parameter int CLKS_PER_BIT    = 868
) (
    input  logic        CLK100MHZ,
    input  logic        CPU_RESETN,
    input  logic        BTNC,
    input  logic [15:0] SW,
    output logic [7:0]  AN,
    output logic        CA, CB, CC, CD, CE, CF, CG, DP,
    output logic [15:0] LED,
    input  logic        UART_TXD_IN,
    output logic        UART_RXD_OUT
);
    logic [6:0] seg;
    cnn_nexys_top_ref #(.DEBOUNCE_CYCLES(DEBOUNCE_CYCLES), .CLKS_PER_BIT(CLKS_PER_BIT)) u_ref (
        .CLK100MHZ(CLK100MHZ), .CPU_RESETN(CPU_RESETN), .BTNC(BTNC), .SW(SW[2:0]), .AN(AN), .SEG(seg), .LED(LED),
        .UART_RXD_OUT(UART_RXD_OUT));
    assign {CG, CF, CE, CD, CC, CB, CA} = seg;
    assign DP = 1'b1;
endmodule

// Not run on a board; simulated in Icarus by projects/test_p14_projects.py with a shortened debounce and baud divider.
module cnn_nexys_top_ref #(
    parameter DEBOUNCE_CYCLES = 1000000,        // 10 ms at 100 MHz
    parameter CLKS_PER_BIT    = 868,            // 115200 baud at 100 MHz
    parameter PARAMS = "cnn_params.hex",
    parameter IMAGES = "cnn_images.hex"
) (
    input  logic        CLK100MHZ,
    input  logic        CPU_RESETN,
    input  logic        BTNC,
    input  logic [2:0]  SW,
    output logic [7:0]  AN,
    output logic [6:0]  SEG,
    output logic [15:0] LED,
    output logic        UART_RXD_OUT
);
    logic [2:0] rst_sr = '0;
    always_ff @(posedge CLK100MHZ) rst_sr <= {rst_sr[1:0], CPU_RESETN};
    wire rst_n = rst_sr[2];
    // debounce: the button value is accepted when it has been stable for DEBOUNCE_CYCLES clocks
    logic b_sync0 = 1'b0, b_sync1 = 1'b0, b_stable = 1'b0, b_prev = 1'b0;

        b_sync0 <= BTNC; b_sync1 <= b_sync0;
        if (b_sync1 == b_stable) cnt <= '0;
        else if (cnt == DEBOUNCE_CYCLES - 1) begin b_stable <= b_sync1; cnt <= '0; end
        else cnt <= cnt + 1;
        b_prev <= b_stable;
    end
    wire go = b_stable & ~b_prev;
    logic ready, result_valid;
    logic [1:0] cls, cls_q;
    logic have;
    logic [127:0] logits;
    cnn_system #(.CLKS_PER_BIT(CLKS_PER_BIT), .PARAMS(PARAMS), .IMAGES(IMAGES)) u_sys (
        .clk(CLK100MHZ), .rst_n, .go(go & ready), .img_sel(SW), .ready, .result_valid, .cls, .logits, .uart_tx(UART_RXD_OUT));

        if (!rst_n) have <= 1'b0;
        else if (result_valid) begin cls_q <= cls; have <= 1'b1; end

            endcase
    end

// Part 14 lab 1, the working core (checked in Icarus by test_lab_cnn.py): block-RAM parameters and eight test images, a loader that writes them into the course tiny CNN
// (solutions/p14l10_tiny_cnn/tiny_cnn.sv), a start on `go`, and a UART transmitter that sends the class letter (H, V, B or X for a horizontal bar, a vertical bar, a box
// or a cross) and a newline. After reset the 632 parameter words are loaded once (about 650 clocks); `ready` goes high when the system can take a `go`.
module cnn_system #(
    parameter CLKS_PER_BIT = 868,
    parameter PARAMS = "cnn_params.hex",
    parameter IMAGES = "cnn_images.hex"
) (
    input  logic        clk,
    input  logic        rst_n,
    input  logic        go,                 // one clock: classify image img_sel
    input  logic [2:0]  img_sel,
    output logic        ready,
    output logic        result_valid,       // one clock when cls is new
    output logic [1:0]  cls,
    output logic [127:0] logits,
    output logic        uart_tx
);
    logic [31:0] prom [0:631];
    logic [7:0]  irom [0:1151];
    initial begin
`include "cnn_init.svh"
    end
    logic        ld_we, start, busy, done;
    logic [1:0]  ld_sel;
    logic [9:0]  ld_addr;
    logic [31:0] ld_data;
    tiny_cnn u_cnn (.clk, .rst_n, .ld_we, .ld_sel, .ld_addr, .ld_data, .start, .busy, .done, .logits, .cls);

    typedef enum logic [2:0] {LOAD, IDLE, IMG, RUN, WAIT, SEND} st_t;
    st_t st;
    logic [9:0] n;
    logic [2:0] sel_q;
    always_comb begin
        ld_we = 1'b0; ld_sel = 2'd0; ld_addr = 10'd0; ld_data = 32'd0;
        if (st == LOAD) begin
            ld_we = 1'b1;
            ld_data = prom[n];
            if (n < 612) begin ld_sel = 2'd0; ld_addr = n; end
            else if (n < 628) begin ld_sel = 2'd1; ld_addr = n - 612; end
            else begin ld_sel = 2'd2; ld_addr = n - 628; end
        end else if (st == IMG) begin
            ld_we = 1'b1; ld_sel = 2'd3; ld_addr = n;
            ld_data = {24'd0, irom[11'({sel_q, 7'd0}) + 11'({sel_q, 4'd0}) + 11'(n)]};     // sel * 144 + n  (144 = 128 + 16)
        end
    end
    assign ready = (st == IDLE);
    logic tx_start, tx_busy;
    logic [7:0] tx_byte;
    logic send_nl;
    uart_tx #(.CLKS_PER_BIT(CLKS_PER_BIT)) u_tx (.clk, .rst_n, .start(tx_start), .data(tx_byte), .busy(tx_busy), .tx(uart_tx));
    always_ff @(posedge clk) begin
        start <= 1'b0; tx_start <= 1'b0; result_valid <= 1'b0;
        if (!rst_n) begin st <= LOAD; n <= '0; send_nl <= 1'b0; end
        else case (st)
            LOAD: if (n == 631) begin st <= IDLE; n <= '0; end else n <= n + 10'd1;
            IDLE: if (go) begin sel_q <= img_sel; n <= '0; st <= IMG; end
            IMG:  if (n == 143) begin st <= RUN; end else n <= n + 10'd1;
            RUN:  begin start <= 1'b1; st <= WAIT; end
            WAIT: if (done) begin result_valid <= 1'b1; st <= SEND; send_nl <= 1'b0; tx_start <= 1'b1; tx_byte <= "HVBX" >> ((3 - cls) * 8); end
            SEND: if (!tx_busy && !tx_start) begin
                      if (!send_nl) begin send_nl <= 1'b1; tx_start <= 1'b1; tx_byte <= 8'h0A; end
                      else st <= IDLE;
                  end
            default: st <= IDLE;
        endcase
    end
endmodule

// 8N1 UART transmitter, LSB first. start (one clock, only when busy is low) sends data.
module uart_tx #(
    parameter CLKS_PER_BIT = 868
) (
    input  logic       clk,
    input  logic       rst_n,
    input  logic       start,
    input  logic [7:0] data,
    output logic       busy,
    output logic       tx
);
    logic [9:0] sh;
    logic [3:0] bits;
    logic [$clog2(CLKS_PER_BIT+1):0] cnt;
    assign busy = (bits != 0);
    always_ff @(posedge clk) begin
        if (!rst_n) begin tx <= 1'b1; bits <= '0; cnt <= '0; end
        else if (start && !busy) begin sh <= {1'b1, data, 1'b0}; bits <= 4'd10; cnt <= '0; end
        else if (busy) begin
            tx <= sh[0];
            if (cnt == CLKS_PER_BIT - 1) begin cnt <= '0; sh <= {1'b1, sh[9:1]}; bits <= bits - 4'd1; end
            else cnt <= cnt + 1;
        end else tx <= 1'b1;
    end
endmodule

// Part 14 lesson 10 exercise: a whole tiny CNN in RTL, one multiply-accumulate unit, bit-exact against the numpy integer model (tools/ml_models.int_forward).
//
// The network (12 x 12 grey image, int8 values 0 .. 127) is   conv 3x3, 1 -> 4 channels, ReLU, requantise   (4 x 10 x 10)
//                                                             max-pool 2 x 2                                 (4 x 5 x 5)
//                                                             conv 3x3, 4 -> 8 channels, ReLU, requantise   (8 x 3 x 3)
//                                                             dense 72 -> 4, raw int32 logits (no requantisation); cls = index of the largest (the lowest index wins a tie).
// Layout, all row-major with the channel first: image[y*12 + x]; conv1 weights w[oc*9 + ky*3 + kx]; conv2 weights w[oc*36 + ic*9 + ky*3 + kx]; dense weights w[o*72 + i] where i is the
// flatten index c*9 + y*3 + x of the 8 x 3 x 3 map. A layer output y = clamp(requant(acc), 0, 127) with requant(acc) = (acc * M + 2^(S-1)) >>> S (M unsigned 16 bit, S 1 .. 31).
//
// Loading (any time while busy = 0): write ld_we = 1 with ld_sel and ld_addr, ld_data (the low bits are used, as signed numbers):
//   ld_sel 0: weight memory, addresses 0 .. 611 (conv1 0 .. 35, conv2 36 .. 323, dense 324 .. 611), 8-bit signed;
//   ld_sel 1: bias memory, addresses 0 .. 15 (conv1 0 .. 3, conv2 4 .. 11, dense 12 .. 15), 32-bit signed;
//   ld_sel 2: configuration, address 0 = M1, 1 = S1, 2 = M2, 3 = S2;
//   ld_sel 3: image, addresses 0 .. 143, 8-bit signed.
// Run: start = 1 for one clock (while busy = 0) begins an inference; busy is high until done pulses high for one clock; then logits[k*32 +: 32] (signed) and cls hold the result
// until the next start. The weights and the image stay loaded.
module tiny_cnn (
    input  logic          clk,
    input  logic          rst_n,
    input  logic          ld_we,
    input  logic [1:0]    ld_sel,
    input  logic [9:0]    ld_addr,
    input  logic [31:0]   ld_data,
    input  logic          start,
    output logic          busy,
    output logic          done,
    output logic [127:0]  logits,
    output logic [1:0]    cls
);
    logic signed [7:0]  wmem [0:611];
    logic signed [31:0] bmem [0:15];
    logic [15:0]        cfg_m1, cfg_m2;
    logic [4:0]         cfg_s1, cfg_s2;
    logic signed [7:0]  img [0:143];
    logic signed [7:0]  a1  [0:399];
    logic signed [7:0]  p1  [0:99];
    logic signed [7:0]  a2  [0:71];
    logic signed [31:0] lg  [0:3];

    always_ff @(posedge clk) begin
        if (ld_we) begin
            case (ld_sel)
                2'd0: wmem[ld_addr] <= ld_data[7:0];
                2'd1: bmem[ld_addr[3:0]] <= ld_data;
                2'd2: case (ld_addr[1:0])
                          2'd0: cfg_m1 <= ld_data[15:0];
                          2'd1: cfg_s1 <= ld_data[4:0];
                          2'd2: cfg_m2 <= ld_data[15:0];
                          default: cfg_s2 <= ld_data[4:0];
                      endcase
                default: img[ld_addr[7:0]] <= ld_data[7:0];
            endcase
        end
    end

    // ---- layer 1: conv, 1 -> 4, 12 x 12 -> 10 x 10
    logic l1_start, l1_done, l1_we;
    logic [15:0] l1_ia, l1_wa, l1_oa;
    logic [7:0]  l1_ba;
    logic signed [31:0] l1_od;
    mac_layer #(.CIN(1), .COUT(4), .IH(12), .IW(12), .K(3), .WB(0), .BB(0), .RAW(0)) u_l1 (
        .clk, .rst_n, .start(l1_start), .done(l1_done), .in_addr(l1_ia), .in_data(img[l1_ia[7:0]]), .w_addr(l1_wa), .w_data(wmem[l1_wa[9:0]]),
        .b_addr(l1_ba), .b_data(bmem[l1_ba[3:0]]), .mult(cfg_m1), .shift(cfg_s1), .out_we(l1_we), .out_addr(l1_oa), .out_data(l1_od));
    always_ff @(posedge clk) if (l1_we) a1[l1_oa[8:0]] <= l1_od[7:0];

    // ---- pool: 4 x 10 x 10 -> 4 x 5 x 5
    logic pl_start, pl_done, pl_we;
    logic [15:0] pl_ia, pl_oa;
    logic signed [7:0] pl_od;
    pool_layer #(.C(4), .IH(10), .IW(10)) u_pl (
        .clk, .rst_n, .start(pl_start), .done(pl_done), .in_addr(pl_ia), .in_data(a1[pl_ia[8:0]]), .out_we(pl_we), .out_addr(pl_oa), .out_data(pl_od));
    always_ff @(posedge clk) if (pl_we) p1[pl_oa[6:0]] <= pl_od;

    // ---- layer 2: conv, 4 -> 8, 5 x 5 -> 3 x 3
    logic l2_start, l2_done, l2_we;
    logic [15:0] l2_ia, l2_wa, l2_oa;
    logic [7:0]  l2_ba;
    logic signed [31:0] l2_od;
    mac_layer #(.CIN(4), .COUT(8), .IH(5), .IW(5), .K(3), .WB(36), .BB(4), .RAW(0)) u_l2 (
        .clk, .rst_n, .start(l2_start), .done(l2_done), .in_addr(l2_ia), .in_data(p1[l2_ia[6:0]]), .w_addr(l2_wa), .w_data(wmem[l2_wa[9:0]]),
        .b_addr(l2_ba), .b_data(bmem[l2_ba[3:0]]), .mult(cfg_m2), .shift(cfg_s2), .out_we(l2_we), .out_addr(l2_oa), .out_data(l2_od));
    always_ff @(posedge clk) if (l2_we) a2[l2_oa[6:0]] <= l2_od[7:0];

    // ---- layer 3: dense 72 -> 4 (a convolution with K = 1 over a 1 x 1 map), raw logits
    logic l3_start, l3_done, l3_we;
    logic [15:0] l3_ia, l3_wa, l3_oa;
    logic [7:0]  l3_ba;
    logic signed [31:0] l3_od;
    mac_layer #(.CIN(72), .COUT(4), .IH(1), .IW(1), .K(1), .WB(324), .BB(12), .RAW(1)) u_l3 (
        .clk, .rst_n, .start(l3_start), .done(l3_done), .in_addr(l3_ia), .in_data(a2[l3_ia[6:0]]), .w_addr(l3_wa), .w_data(wmem[l3_wa[9:0]]),
        .b_addr(l3_ba), .b_data(bmem[l3_ba[3:0]]), .mult(16'd0), .shift(5'd1), .out_we(l3_we), .out_addr(l3_oa), .out_data(l3_od));
    always_ff @(posedge clk) if (l3_we) lg[l3_oa[1:0]] <= l3_od;

    // ---- sequencer
    typedef enum logic [2:0] {IDLE, S1, SP, S2, S3, FIN} st_t;
    st_t st;
    assign busy = (st != IDLE);
    always_ff @(posedge clk) begin
        l1_start <= 1'b0; pl_start <= 1'b0; l2_start <= 1'b0; l3_start <= 1'b0; done <= 1'b0;
        if (!rst_n) st <= IDLE;
        else case (st)
            IDLE: if (start) begin st <= S1; l1_start <= 1'b1; end
            S1:   if (l1_done) begin st <= SP; pl_start <= 1'b1; end
            SP:   if (pl_done) begin st <= S2; l2_start <= 1'b1; end
            S2:   if (l2_done) begin st <= S3; l3_start <= 1'b1; end
            S3:   if (l3_done) begin st <= FIN; end
            FIN:  begin st <= IDLE; done <= 1'b1; end
            default: st <= IDLE;
        endcase
    end
    always_comb begin
        for (int k = 0; k < 4; k++) logits[k*32 +: 32] = lg[k];
        cls = 2'd0;
        for (int k = 1; k < 4; k++) if (lg[k] > lg[cls]) cls = 2'(k);
    end
endmodule

// A sequential convolution / dense layer: one MAC per clock. For every output (oc, oy, ox): load the bias, accumulate CIN*K*K products, then (unless RAW) requantise
// with mult and shift and clamp to 0 .. 127 (the ReLU), and write. Reads are combinational (in_addr -> in_data and w_addr -> w_data in the same clock).
module mac_layer #(
    parameter int CIN = 1, COUT = 1, IH = 4, IW = 4, K = 3, WB = 0, BB = 0, RAW = 0
) (
    input  logic                clk,
    input  logic                rst_n,
    input  logic                start,
    output logic                done,

"""Reference model for P14-1 (the Nexys tiny CNN). Standalone numpy: it rebuilds the integer network from cnn_params.hex and cnn_images.hex (the files the design loads) and
evaluates it. Layout: 612 weights (conv1 36: [oc][ky][kx]; conv2 288: [oc][ic][ky][kx]; dense 288: [o][i], i = c*9 + y*3 + x), 16 int32 biases, then M1, S1, M2, S2."""
from pathlib import Path

import numpy as np

HERE = Path(__file__).resolve().parent
LETTERS = "HVBX"


def _s8(v):
    return v - 256 if v >= 128 else v


def _s32(v):
    return v - (1 << 32) if v >= (1 << 31) else v


def load():
    p = [int(t, 16) for t in (HERE / "cnn_params.hex").read_text().split()]
    w = np.array([_s8(v & 0xFF) for v in p[:612]], dtype=np.int64)
    b = np.array([_s32(v) for v in p[612:628]], dtype=np.int64)
    m1, s1, m2, s2 = p[628:632]
    imgs = np.array([_s8(int(t, 16)) for t in (HERE / "cnn_images.hex").read_text().split()], dtype=np.int64).reshape(8, 12, 12)
    return w, b, (m1, s1, m2, s2), imgs


def requant_relu(acc, m, s):
    return np.clip((acc * m + (1 << (s - 1))) >> s, 0, 127)


def forward(img, w, b, cfg):
    m1, s1, m2, s2 = cfg
    w1, w2, w3 = w[:36].reshape(4, 3, 3), w[36:324].reshape(8, 4, 3, 3), w[324:].reshape(4, 72)
    a1 = np.zeros((4, 10, 10), dtype=np.int64)
    for oc in range(4):
        for ky in range(3):
            for kx in range(3):
                a1[oc] += w1[oc, ky, kx] * img[ky:ky + 10, kx:kx + 10]
        a1[oc] += b[oc]
    a1 = requant_relu(a1, m1, s1)
    p1 = a1.reshape(4, 5, 2, 5, 2).max(axis=(2, 4))
    a2 = np.zeros((8, 3, 3), dtype=np.int64)
    for oc in range(8):
        for ic in range(4):
            for ky in range(3):
                for kx in range(3):
                    a2[oc] += w2[oc, ic, ky, kx] * p1[ic, ky:ky + 3, kx:kx + 3]
        a2[oc] += b[4 + oc]
    a2 = requant_relu(a2, m2, s2)
    return w3 @ a2.reshape(72) + b[12:16]


def reference_output():
    w, b, cfg, imgs = load()
    out = []
    for k in range(8):
        lg = forward(imgs[k], w, b, cfg)
        cls = int(np.argmax(lg))                             # numpy picks the lowest index on a tie, as the design does
        out.append({"image": k, "logits": [int(v) for v in lg], "uart": LETTERS[cls] + "\n", "digit": cls})
    return {"images": out}
