Problems / A. Basic digital design drills

Electronic dice from an LFSR

t1_lfsr_dice Benchmark v1 T1 A Basic digital design drills Nexys A7-100T

The problem

An electronic dice. A linear-feedback shift register is a small circuit that steps through a long, repeatable scrambled sequence of numbers, and each button press steps it once and turns the new state into a roll from one to six. The roll shows on the right-hand digit of the display, and the design keeps the last four rolls and a count of rolls. The state can be loaded with a seed, and it is never allowed to stick at zero.

Where it is used. Shift-register generators of this kind are used for test patterns, data scrambling, error-check codes and cheap pseudo-random numbers in hardware. They are not suitable where unpredictability matters for security.

The spec the agent is given

Electronic dice from an LFSR

I want a dice on the Nexys A7-100T, driven by a 16-bit Galois LFSR.

  • Each press of BTNC (it bounces, so debounce it) steps the LFSR once and rolls a number from 1 to 6, taken from the LFSR state as (state mod 6) + 1. The roll shows on the rightmost 7-segment digit; the other digits stay dark.
  • The feedback taps are a register, starting at 0xB400. I can also load the state (a seed) and make the LFSR step any number of times without rolling. The state must never get stuck at zero.
  • Keep a history of the last four rolls and a count of rolls.
  • CPU_RESETN resets everything, the state to 0xACE1.
  • Over the test shell (USB-UART, 115200 baud) I can read the state, the last roll, the history and the roll count, set the seed and the taps, and ask for a number of steps. The design ID is "DICE".

Test hooks: top module t1_lfsr_dice_top, ports named as in the board's master XDC, the test shell's CLKS_PER_BIT, TIMEOUT_CYCLES and BUILD_STAMP parameters, plus DEBOUNCE_CYCLES (debounce time in clocks) and REFRESH_BITS (each display digit is lit for 2^REFRESH_BITS clocks) as top-level parameters.

Exactly spec.md. Anything it leaves open, the agent has to ask about.

Interface

Top module t1_lfsr_dice_top on the Nexys A7-100T (xc7a100tcsg324-1). Clock: CLK100MHZ at 100 MHz (board oscillator). What the hidden tests check

The requirements in the hidden spec, and how each is shown to hold:

  • REQ-01 Each press steps the Galois LFSR once and rolls (S mod 6) + 1 from the new state; HISTORY and ROLLS follow (shown by simulation)
  • REQ-02 S is never 0 - a step or SEED write that would give 0 gives 0x0001 (shown by simulation, formal)
  • REQ-03 TAPS, SEED and STEP bursts behave as listed; with the reset taps the period is 65535 (shown by simulation)
  • REQ-04 Digit 0 shows the roll (dark before the first); other digits are dark (shown by simulation)
  • REQ-05 Bounces shorter than the debounce time never roll (shown by simulation)
  • REQ-06 The design closes timing at 100 MHz with no unconstrained path (shown by report analysis)
  • REQ-07 On the board the register window answers as the model predicts (seeded sequence and burst) (shown by on the board)
The full behaviour rules from hidden/spec.yaml

lfsr

  • One step of the 16-bit state S (right-shifting Galois form): b = S[0]; S = S >> 1; if b = 1 then S = S xor TAPS.
  • If a step (or a SEED write) would make S = 0, S becomes 0x0001 instead, so S is never 0.
  • With TAPS = 0xB400 (x^16 + x^14 + x^13 + x^11 + 1) the sequence has the maximal period 65535.

roll

  • BTNC is synchronised (two flops), then debounced. The debounced level changes only after the synchronised input has differed from it for DEBOUNCE_CYCLES consecutive clocks; a shorter difference restarts the count. A press is a 0 -> 1 change of the debounced level; holding does not repeat.
  • A press steps S once, then rolls from the new state: ROLL = (S mod 6) + 1, S read as an unsigned 16-bit integer.
  • Each roll shifts HISTORY left by one nibble and puts the new roll in HISTORY[3:0] (the oldest of four drops out), and adds 1 to ROLLS (16 bits, wrapping).
  • A press during a step burst, or on the same clock as a SEED write, is lost (no step, no roll).

burst

  • A write of n to STEP starts a burst of n = wdata[15:0] steps, one a clock, from the next clock. No rolls. A STEP write during a burst replaces the steps left; a SEED write ends the burst.

display

  • Digits are numbered 0 (rightmost, AN[0]) to 7, lit one at a time in order 0..7, each for 2^REFRESH_BITS clocks; while digit k is lit AN[k] = 0 and the other AN = 1.
  • Digit 0 shows ROLL; it is dark (all AN high in its slot) while ROLL = 0 (no roll since reset). Digits 1..7 are always dark. DP is always 1 (off).
  • Glyphs (segments lit): 1 bc, 2 abdeg, 3 abcdg, 4 bcfg, 5 acdfg, 6 acdefg; CA..CG active low.

Settled assumptions

  • right-shifting Galois form, taps XORed in when the bit shifted out is 1. 0xB400 is the usual tap mask for that form.
  • the roll uses the state after the press's step. each press then shows a fresh state.
  • a burst steps once per clock, and a press during a burst is lost (no step, no roll). the bench needs a definite rate and a definite collision rule; a press cannot be queued behind a burst.

// bm_debounce.sv: two-flop synchroniser, then a counting debounce. The level
// changes only after the synchronised input has differed from it for CYCLES
// consecutive clocks; a shorter difference restarts the count. rise is a
// one-clock pulse on each 0 -> 1 change of the level.
module bm_debounce #(
    parameter int CYCLES = 1_000_000
) (
    input  logic clk,
    input  logic rst,
    input  logic d_async,
    output logic level,
    output logic rise
);
    localparam int CW = $clog2(CYCLES + 1);
    logic        d;
    logic [CW-1:0] run;

    sync2 u_sync (.clk(clk), .rst(rst), .d(d_async), .q(d));

    always_ff @(posedge clk) begin
        rise <= 1'b0;
        if (rst) begin
            level <= 1'b0;
            run   <= '0;
        end else if (d == level) begin
            run <= '0;
        end else if (run == CW'(CYCLES - 1)) begin
            level <= d;
            run   <= '0;
            rise  <= d;
        end else begin
            run <= run + 1'b1;
        end
    end
endmodule

// bm_scan8.sv: eight-digit multiplexed display. Digit k (0 = rightmost, AN[0])
// is lit for 2^REFRESH_BITS clocks, in order 0..7. While digit k is lit its
// anode is low unless blank[k] is set (then every anode stays high for that
// slot). seg is active-low {g,f,e,d,c,b,a}; dp_n is active low.
module bm_scan8 #(
    parameter int REFRESH_BITS = 17
) (
    input  logic        clk,
    input  logic        rst,
    input  logic        enable,
    input  logic [7:0][6:0] seg_lit,    // per digit k: seg_lit[k]: 1 = segment lit, bit 0 = a
    input  logic [7:0]  blank,
    input  logic [7:0]  dp_lit,
    output logic [7:0]  an,
    output logic [6:0]  seg_n,
    output logic        dp_n
);
    logic [REFRESH_BITS+2:0] t;
    logic [2:0] k;
    assign k = t[REFRESH_BITS+2:REFRESH_BITS];

    always_ff @(posedge clk) begin
        if (rst) begin
            t     <= '0;
            an    <= 8'hFF;
            seg_n <= 7'h7F;
            dp_n  <= 1'b1;
        end else begin
            t     <= t + 1'b1;
            an    <= (enable && !blank[k]) ? ~(8'b1 << k) : 8'hFF;
            seg_n <= ~seg_lit[k];
            dp_n  <= ~dp_lit[k];
        end
    end
endmodule

// lfsr_dice.sv: 16-bit Galois LFSR with settable taps and seed, step bursts,
// and debounced BTNC rolls of (state mod 6) + 1, for t1_lfsr_dice.
module lfsr_dice #(
    parameter int DEBOUNCE_CYCLES = 1_000_000
) (
    input  logic        clk,
    input  logic        rst,
    input  logic        btn,
    output logic [2:0]  roll,
    input  logic [6:0]  win_addr,
    input  logic        win_wr,
    input  logic        win_rd,
    input  logic [31:0] win_wdata,
    output logic [31:0] win_rdata
);
    localparam logic [6:0] R_STATE = 7'h00, R_SEED = 7'h01, R_TAPS = 7'h02, R_ROLL = 7'h03,
                           R_HIST = 7'h04, R_STEP = 7'h05, R_ROLLS = 7'h06;

    logic        lvl, press;
    logic [15:0] s, seed, taps, hist, left, rolls, ns;

    bm_debounce #(.CYCLES(DEBOUNCE_CYCLES)) u_db (.clk(clk), .rst(rst), .d_async(btn), .level(lvl), .rise(press));

    function automatic logic [15:0] lstep(input logic [15:0] v, input logic [15:0] t);
        logic [15:0] r;
        r = v >> 1;
        if (v[0]) r = r ^ t;
        if (r == 16'd0) r = 16'd1;
        return r;
    endfunction

    assign ns = lstep(s, taps);

    wire wr_seed = win_wr && win_addr == R_SEED;
    wire wr_step = win_wr && win_addr == R_STEP;
    wire busy    = left != 16'd0;

    always_ff @(posedge clk) begin
        if (rst) begin
            s <= 16'hACE1; seed <= 16'hACE1; taps <= 16'hB400; roll <= '0; hist <= '0; left <= '0; rolls <= '0;
        end else begin
            if (win_wr && win_addr == R_TAPS) taps <= win_wdata[15:0];
            if (wr_seed) begin
                seed <= win_wdata[15:0];
                s    <= (win_wdata[15:0] == 16'd0) ? 16'd1 : win_wdata[15:0];
                left <= '0;
            end else if (busy) begin
                s    <= ns;
                left <= wr_step ? win_wdata[15:0] : left - 16'd1;
            end else begin
                if (wr_step) left <= win_wdata[15:0];
                if (press) begin
                    s     <= ns;
                    roll  <= 3'(ns % 16'd6) + 3'd1;
                    hist  <= {hist[11:0], 1'b0, 3'(ns % 16'd6) + 3'd1};
                    rolls <= rolls + 1'b1;
                end
            end
        end
    end

`ifdef FORMAL
    always_comb assert (rst || s != 16'd0);
`endif

    always_ff @(posedge clk) begin
        if (rst) win_rdata <= '0;
        else if (win_rd) begin
            case (win_addr)
                R_STATE: win_rdata <= {16'd0, s};
                R_SEED:  win_rdata <= {16'd0, seed};
                R_TAPS:  win_rdata <= {16'd0, taps};
                R_ROLL:  win_rdata <= {29'd0, roll};
                R_HIST:  win_rdata <= {16'd0, hist};
                R_STEP:  win_rdata <= {16'd0, left};
                R_ROLLS: win_rdata <= {16'd0, rolls};
                default: win_rdata <= '0;
            endcase
        end
    end
endmodule

// t1_lfsr_dice_top.sv: board top (Nexys A7-100T, master-XDC port names).
// Reference design for benchmark task t1_lfsr_dice; DESIGN_ID "DICE".
module t1_lfsr_dice_top #(
    parameter int          CLKS_PER_BIT    = 868,
    parameter int          TIMEOUT_CYCLES  = 100_000,
    parameter int          DEBOUNCE_CYCLES = 1_000_000,
    parameter int          REFRESH_BITS    = 17,
    parameter logic [31:0] BUILD_STAMP     = 32'h0
) (
    input  logic        CLK100MHZ,
    input  logic        CPU_RESETN,
    input  logic        BTNC,
    output logic        CA, CB, CC, CD, CE, CF, CG, DP,
    output logic [7:0]  AN,
    input  logic        UART_TXD_IN,
    output logic        UART_RXD_OUT
);
    logic        clk, rst, win_wr, win_rd;
    logic [6:0]  win_addr, seg_n;
    logic [31:0] win_wdata, win_rdata;
    logic [2:0]  roll;
    logic [6:0]  glyph;
    logic [7:0][6:0] seg_lit;

    assign clk = CLK100MHZ;
    reset_sync u_rst (.clk(clk), .rst_n_async(CPU_RESETN), .rst(rst));

    fpga_shell #(.CLKS_PER_BIT(CLKS_PER_BIT), .TIMEOUT_CYCLES(TIMEOUT_CYCLES),
                 .DESIGN_ID(32'h4449_4345), .BUILD_STAMP(BUILD_STAMP)) u_shell (
        .clk(clk), .rst(rst), .uart_rx(UART_TXD_IN), .uart_tx(UART_RXD_OUT),
        .win_addr(win_addr), .win_wr(win_wr), .win_rd(win_rd), .win_wdata(win_wdata), .win_rdata(win_rdata));

    lfsr_dice #(.DEBOUNCE_CYCLES(DEBOUNCE_CYCLES)) u_dice (
        .clk(clk), .rst(rst), .btn(BTNC), .roll(roll),
        .win_addr(win_addr), .win_wr(win_wr), .win_rd(win_rd), .win_wdata(win_wdata), .win_rdata(win_rdata));

    always_comb begin
        case (roll)                    // bit 0 = a ... bit 6 = g, 1 = lit
            3'd1: glyph = 7'b0000110;
            3'd2: glyph = 7'b1011011;
            3'd3: glyph = 7'b1001111;
            3'd4: glyph = 7'b1100110;
            3'd5: glyph = 7'b1101101;
            3'd6: glyph = 7'b1111101;
            default: glyph = 7'b0000000;
        endcase
        seg_lit = '0;
        seg_lit[0] = glyph;
    end

    bm_scan8 #(.REFRESH_BITS(REFRESH_BITS)) u_scan (
        .clk(clk), .rst(rst), .enable(1'b1), .seg_lit(seg_lit), .blank({7'h7F, roll == 3'd0}), .dp_lit(8'h00),
        .an(AN), .seg_n(seg_n), .dp_n(DP));
    assign {CG, CF, CE, CD, CC, CB, CA} = seg_n;
endmodule

"""Acceptance tests of t1_lfsr_dice against model.py (hidden from the agent)."""

from __future__ import annotations

import random

import cocotb
from benchmark.lib.bench import Board, scan_display
from model import DESIGN_ID, HISTORY, ROLL, ROLLS, SEED, STATE, STEP, TAPS, Model

IDLE = {"BTNC": 0}
NAMES = ("STATE", "SEED", "TAPS", "ROLL", "HISTORY", "STEP", "ROLLS")


class Env:
    def __init__(self, dut) -> None:
        self.b = Board(dut, IDLE)
        self.dut, self.m = dut, Model()
        self.n = self.b.param("DEBOUNCE_CYCLES")
        self.slot = 1 << self.b.param("REFRESH_BITS")

    async def start(self) -> None:
        await self.b.start()

    async def wr(self, off: int, v: int) -> None:
        await self.b.write(off, v)
        self.m.write(off, v)

    async def press(self) -> None:
        self.dut.BTNC.value = 1
        await self.b.cycles(self.n + 6)
        self.dut.BTNC.value = 0
        await self.b.cycles(self.n + 6)
        self.m.press()

    async def check_regs(self) -> None:
        for off in range(7):
            await self.b.expect(off, self.m.read(off), NAMES[off])

    async def check_display(self) -> None:
        seen = await scan_display(self.dut, self.b.clk, self.slot)
        want = self.m.display()
        assert {k: v[0] for k, v in seen.items()} == want, f"display {seen} != model {want}"
        assert all(v[1] == 1 for v in seen.values()), "DP lit"


@cocotb.test()
async def test_identity_and_reset(dut):
    e = Env(dut)
    await e.start()
    assert await e.b.shell_id() == DESIGN_ID
    await e.check_regs()
    await e.check_display()

@cocotb.test()
async def test_step_burst_and_period(dut):
    e = Env(dut)
    await e.start()
    await e.wr(STEP, 1000)
    await e.b.cycles(1010)
    await e.check_regs()
    await e.wr(STEP, 0xFFFF)            # the reset taps are maximal: 65535 steps come back to the start
    left = await e.b.read(STEP)

    await e.check_regs()

    await e.wr(STEP, 0xFFFF)
    await e.b.cycles(66000)
    assert await e.b.read(STATE) == s0

    await e.check_regs()

"""Golden model of t1_lfsr_dice, written from spec.yaml alone (never from any RTL)."""

from __future__ import annotations

STATE, SEED, TAPS, ROLL, HISTORY, STEP, ROLLS = range(7)
DESIGN_ID = 0x44494345          # "DICE"
GLYPHS = {1: "bc", 2: "abdeg", 3: "abcdg", 4: "bcfg", 5: "acdfg", 6: "acdefg"}


def seg_pins(lit: str) -> int:
    """Active-low CA..CG, bit 0 = CA."""
    return sum(0 if s in lit else 1 << i for i, s in enumerate("abcdefg"))


def lstep(s: int, taps: int) -> int:
    b = s & 1
    s >>= 1
    if b:
        s ^= taps
    return s or 1


class Model:
    def __init__(self) -> None:
        self.s = self.seed = 0xACE1
        self.taps = 0xB400
        self.roll = self.hist = self.rolls = 0

    def step(self, n: int = 1) -> None:
        for _ in range(n):
            self.s = lstep(self.s, self.taps)

    def press(self) -> None:
        self.step()
        self.roll = self.s % 6 + 1
        self.hist = (self.hist << 4 | self.roll) & 0xFFFF
        self.rolls = (self.rolls + 1) & 0xFFFF

    def read(self, off: int) -> int:
        return {STATE: self.s, SEED: self.seed, TAPS: self.taps, ROLL: self.roll, HISTORY: self.hist,
                STEP: 0, ROLLS: self.rolls}.get(off, 0)

    def write(self, off: int, v: int) -> None:
        if off == SEED:
            self.seed = v & 0xFFFF
            self.s = self.seed or 1
        elif off == TAPS:
            self.taps = v & 0xFFFF
        elif off == STEP:
            self.step(v & 0xFFFF)          # the burst, once it has finished

    def display(self) -> dict[int, int]:
        return {0: seg_pins(GLYPHS[self.roll])} if self.roll else {}
