Problems / F. Interfaces and protocols

I2C bus scanner on the temperature-sensor bus

t2_i2c_scanner Benchmark v1 T2 F Interfaces and protocols Nexys A7-100T

The problem

A bus scanner in the style of the i2cdetect tool. When started, it tries every normal seven-bit I2C address in turn by sending the address with a write request, checking whether anything acknowledges, and then sending a stop. It never sends a data byte. The results are a map with one bit per address, a count of devices that answered, the lowest address that answered, and busy and done flags, and the LEDs show the count.

Where it is used. Scanning is the first step when bringing up a board with unknown or mis-wired I2C parts, and the same probe appears in operating-system tools and in firmware that detects which optional chips are fitted.

The spec the agent is given

I2C bus scanner on the temperature-sensor bus

I'd like a small I2C bus scanner on the Nexys A7-100T's sensor bus (TMP_SCL / TMP_SDA), like the "i2cdetect" tool, so I can see what answers.

  • When I tell it to start, it probes every normal 7-bit address from 0x08 to 0x77 in turn: a write-address probe, check for the ACK, then a STOP, and on to the next. The reserved addresses at both ends are left alone, and it must never send a data byte to anything.
  • Results: a 128-bit map with one bit per address, how many answered, the lowest address that answered, and busy / done flags. A new scan starts from a clean map.
  • The LEDs show how many devices answered.
  • Open-drain lines with the board's pull-ups (never drive them high); a slave may stretch the clock.
  • SCL speed from a parameter giving a quarter of the SCL period in clocks; 100 kHz on the board.
  • Through the test shell; design ID "SCAN".

Test hooks: top module t2_i2c_scanner_top, ports named as in the board's master XDC (TMP_SCL, TMP_SDA, LED, the USB-UART pins, CLK100MHZ, CPU_RESETN), the test shell's CLKS_PER_BIT, TIMEOUT_CYCLES and BUILD_STAMP parameters, plus QUARTER (a quarter of the SCL period, in clocks) as top-level parameters.

Exactly spec.md. Anything it leaves open, the agent has to ask about.

Interface

Top module t2_i2c_scanner_top on the Nexys A7-100T (xc7a100tcsg324-1). Clock: CLK100MHZ at 100 MHz (board oscillator). Reset: CPU_RESETN, active low: no scan running; MAP0-MAP3, COUNT, DONE = 0; LOWEST = 0xFF; both lines released. Resources expected: a couple of hundred LUTs and FFs (the 112-bit map in flops); no BRAM, no DSP.

Top-level parameters (board values): CLKS_PER_BIT = 868, QUARTER = 250, TIMEOUT_CYCLES = 100000. The hidden bench shrinks them to CLKS_PER_BIT = 8, QUARTER = 3, TIMEOUT_CYCLES = 400.

What the hidden tests check

The requirements in the hidden spec, and how each is shown to hold:

  • REQ-01 A scan probes exactly 0x08-0x77 in order, each with START, a write address, the ACK bit and STOP, and no data byte (shown by simulation)
  • REQ-02 MAP, COUNT, LOWEST and DONE report the addresses that ACKed; a new scan clears them first (shown by simulation)
  • REQ-03 Clock stretching is honoured and the lines are never driven high (shown by simulation)
  • REQ-04 LED shows COUNT (shown by simulation, on the board)
  • REQ-05 On the board the scan finds the ADT7420 at 0x4B (shown by on the board)
  • REQ-06 The design closes timing at 100 MHz with no unconstrained path (shown by report analysis)
The full behaviour rules from hidden/spec.yaml

scan

  • A write to CTRL with bit 0 = 1 while BUSY = 0 starts a scan - MAP0-MAP3 and COUNT are cleared, LOWEST is set to 0xFF, DONE is cleared and BUSY set. Writes while BUSY = 1 are ignored.
  • The scan probes addresses 0x08, 0x09, ... 0x77 in increasing order, one probe each - never 0x00-0x07 or 0x78-0x7F.
  • A probe - START, the byte {address, 0} (write), the ACK bit with SDA released (sampled at the end of its SCL high time), then STOP. No data byte is ever sent.
  • If the ACK bit was 0 the address answered - its MAP bit is set, COUNT increments, and LOWEST takes the address if it is the first to answer in this scan.
  • After the probe of 0x77 BUSY falls and DONE is set (DONE stays set until the next scan starts).
  • The results update during the scan, probe by probe.

waveforms

  • Q = QUARTER clocks. Releasing SCL is followed by waiting until SCL is seen high through the two-flop synchroniser (a stretching slave holds it low); high times count from that moment.
  • START - SDA low, wait 2Q, SCL low, wait Q. Each of the 9 bits - set SDA (pull low for 0, release for 1), wait Q, release SCL and wait high, wait 2Q, sample SDA, SCL low, wait Q. STOP - SDA low, wait Q, release SCL and wait high, wait 2Q, release SDA, wait 2Q (bus free) before the next START.
  • The lines are only ever pulled low or released (high-Z).

leds

  • LED[15:0] = COUNT (zero-extended), updated with COUNT.

Settled assumptions

  • LOWEST reads 0xFF when nothing has answered. 0xFF cannot be a 7-bit address, so it marks "none" without another flag.
  • the map has bits for all 128 addresses; reserved ones always read 0. four aligned 32-bit words keep the address arithmetic trivial for the host.

// scan_core.sv: I2C address scanner. Probes 0x08..0x77: START, {addr, W},
// ACK bit, STOP. Records answering addresses. Open drain; waits for SCL to be
// seen high after each release (clock stretching).
module scan_core #(
    parameter int QUARTER = 250
) (
    input  logic         clk,
    input  logic         rst,
    input  logic         go,
    input  logic         scl_in,
    input  logic         sda_in,
    output logic         scl_oe,
    output logic         sda_oe,
    output logic         busy,
    output logic         done,
    output logic [7:0]   count,
    output logic [7:0]   lowest,
    output logic [127:0] map
);
    localparam int CW = $clog2(2 * QUARTER + 1);
    localparam logic [CW-1:0] Q1 = CW'(QUARTER - 1), Q2 = CW'(2 * QUARTER - 1);

    typedef enum logic [3:0] {IDLE, S1, S2, B1, B2, B3, P1, P2, P3} st_t;
    st_t st;

    logic [CW-1:0] cnt;
    logic [3:0]    k;
    logic [6:0]    addr;
    logic          acked;
    logic [7:0]    byte_out;

    assign byte_out = {addr, 1'b0};

    always_ff @(posedge clk) begin
        if (rst) begin
            st <= IDLE; cnt <= '0; k <= '0; addr <= 7'h08; acked <= 1'b0;
            scl_oe <= 1'b0; sda_oe <= 1'b0; busy <= 1'b0; done <= 1'b0;
            count <= '0; lowest <= 8'hFF; map <= '0;
        end else begin
            case (st)
                IDLE: if (go) begin
                    busy <= 1'b1; done <= 1'b0; count <= '0; lowest <= 8'hFF; map <= '0;
                    addr <= 7'h08;
                    st <= S1; sda_oe <= 1'b1; cnt <= Q2;
                end
                S1: if (cnt == '0) begin st <= S2; scl_oe <= 1'b1; cnt <= Q1; end else cnt <= cnt - 1'b1;
                S2: if (cnt == '0) begin
                        st <= B1; k <= '0; cnt <= Q1; sda_oe <= !byte_out[7];
                    end else cnt <= cnt - 1'b1;
                B1: if (cnt == '0) begin st <= B2; scl_oe <= 1'b0; cnt <= Q2; end else cnt <= cnt - 1'b1;
                B2: if (!scl_in) cnt <= Q2;
                    else if (cnt == '0) begin
                        st <= B3; scl_oe <= 1'b1; cnt <= Q1;
                        if (k == 4'd8) acked <= !sda_in;
                    end else cnt <= cnt - 1'b1;
                B3: if (cnt == '0) begin
                        if (k == 4'd8) begin
                            st <= P1; sda_oe <= 1'b1; cnt <= Q1;
                            if (acked) begin
                                map[addr] <= 1'b1;
                                count <= count + 1'b1;
                                if (lowest == 8'hFF) lowest <= {1'b0, addr};
                            end
                        end else begin
                            st <= B1; k <= k + 1'b1; cnt <= Q1;
                            sda_oe <= (k == 4'd7) ? 1'b0 : !byte_out[3'd6 - k[2:0]];
                        end
                    end else cnt <= cnt - 1'b1;
                P1: if (cnt == '0) begin st <= P2; scl_oe <= 1'b0; cnt <= Q2; end else cnt <= cnt - 1'b1;
                P2: if (!scl_in) cnt <= Q2;
                    else if (cnt == '0) begin st <= P3; sda_oe <= 1'b0; cnt <= Q2; end
                    else cnt <= cnt - 1'b1;
                P3: if (cnt == '0) begin
                        if (addr == 7'h77) begin
                            st <= IDLE; busy <= 1'b0; done <= 1'b1;
                        end else begin
                            addr <= addr + 1'b1;
                            st <= S1; sda_oe <= 1'b1; cnt <= Q2;
                        end
                    end else cnt <= cnt - 1'b1;
                default: st <= IDLE;
            endcase
        end
    end
endmodule

// t2_i2c_scanner_top.sv: board top (Nexys A7-100T, master-XDC port names).
// Reference design for benchmark task t2_i2c_scanner; DESIGN_ID "SCAN".
// Scans I2C addresses 0x08..0x77 on the sensor bus; LED shows the count.
module t2_i2c_scanner_top #(
    parameter int          CLKS_PER_BIT   = 868,
    parameter int          TIMEOUT_CYCLES = 100_000,
    parameter int          QUARTER        = 250,
    parameter logic [31:0] BUILD_STAMP    = 32'h0
) (
    input  logic        CLK100MHZ,
    input  logic        CPU_RESETN,
    inout  wire         TMP_SCL,
    inout  wire         TMP_SDA,
    output logic [15:0] LED,
    input  logic        UART_TXD_IN,
    output logic        UART_RXD_OUT
);
    logic         clk, rst, win_wr, win_rd, scl_oe, sda_oe, busy, done;
    logic [1:0]   lines;
    logic [6:0]   win_addr;
    logic [31:0]  win_wdata, win_rdata;
    logic [7:0]   count, lowest;
    logic [127:0] map;

    assign clk = CLK100MHZ;
    reset_sync u_rst (.clk(clk), .rst_n_async(CPU_RESETN), .rst(rst));

    fpga_shell #(.CLKS_PER_BIT(CLKS_PER_BIT), .TIMEOUT_CYCLES(TIMEOUT_CYCLES),
                 .DESIGN_ID(32'h5343_414E), .BUILD_STAMP(BUILD_STAMP)) u_shell (
        .clk(clk), .rst(rst), .uart_rx(UART_TXD_IN), .uart_tx(UART_RXD_OUT),
        .win_addr(win_addr), .win_wr(win_wr), .win_rd(win_rd), .win_wdata(win_wdata), .win_rdata(win_rdata));

    assign TMP_SCL = scl_oe ? 1'b0 : 1'bz;
    assign TMP_SDA = sda_oe ? 1'b0 : 1'bz;
    sync2 #(.WIDTH(2), .RESET_VALUE(2'b11)) u_sync (.clk(clk), .rst(rst), .d({TMP_SCL, TMP_SDA}), .q(lines));

    scan_core #(.QUARTER(QUARTER)) u_scan (
        .clk(clk), .rst(rst), .go(win_wr && win_addr == 7'h00 && win_wdata[0]),
        .scl_in(lines[1]), .sda_in(lines[0]), .scl_oe(scl_oe), .sda_oe(sda_oe),
        .busy(busy), .done(done), .count(count), .lowest(lowest), .map(map));

    always_ff @(posedge clk) begin
        if (rst) LED <= '0;
        else     LED <= {8'd0, count};
    end

    always_ff @(posedge clk) begin
        if (rst) win_rdata <= '0;
        else if (win_rd) begin
            case (win_addr)
                7'h01:   win_rdata <= {30'd0, done, busy};
                7'h02:   win_rdata <= {24'd0, count};
                7'h03:   win_rdata <= {24'd0, lowest};
                7'h04:   win_rdata <= map[31:0];
                7'h05:   win_rdata <= map[63:32];
                7'h06:   win_rdata <= map[95:64];
                7'h07:   win_rdata <= map[127:96];
                default: win_rdata <= '0;
            endcase
        end
    end
endmodule

"""Acceptance tests of t2_i2c_scanner against model.py (hidden from the agent)."""

from __future__ import annotations

import random

import cocotb
from benchmark.lib.bench import Board, peek
from benchmark.lib.i2c_devices import Adt7420, FixedDevice, I2cBus
from model import BUSY, COUNT, CTRL, DESIGN_ID, LOWEST, MAP0, STATUS, Model

REGS = ((STATUS, "STATUS"), (COUNT, "COUNT"), (LOWEST, "LOWEST"), (MAP0, "MAP0"), (MAP0 + 1, "MAP1"),
        (MAP0 + 2, "MAP2"), (MAP0 + 3, "MAP3"))


# v1.2: SCL high time is 2Q to 2Q + SYNC_SLACK clocks. The spec says wait until SCL is seen high through a two-flop
# synchroniser, then 2Q: 2-3 clocks of synchroniser plus 1-3 of state and registered-output latency; 8 allows for that.
SYNC_SLACK = 8


class Env:
    def __init__(self, dut) -> None:
        self.b = Board(dut, {"dev_scl_pull": 0, "dev_sda_pull": 0})
        self.dut, self.m = dut, Model()
        self.q = self.b.param("QUARTER")

    async def start(self, addrs: set[int]) -> None:
        await self.b.start()
        self.bus = I2cBus(self.dut, self.devices(addrs))

    @staticmethod
    def devices(addrs: set[int]) -> list:
        return [Adt7420() if a == 0x4B else FixedDevice(a) for a in sorted(addrs)]

    async def regs(self) -> None:
        for off, name in REGS:
            await self.b.expect(off, self.m.read(off), name)
        led = await peek(self.b.clk, self.dut.LED)
        assert led == self.m.leds(), f"LED {led:#x} != model {self.m.leds():#x}"

    async def scan(self, addrs: set[int]) -> None:
        self.bus.clear()
        self.bus.addr_probes.clear()
        await self.b.write(CTRL, 1)
        want = self.m.scan({a for a in addrs if 0x08 <= a <= 0x77})
        for _ in range(200):
            await self.b.cycles(2000)
            if not (await self.b.read(STATUS)) & BUSY:
                break
        assert not self.bus.errors, self.bus.errors[:3]
        assert self.bus.addr_probes == list(range(0x08, 0x78)), f"probed {[hex(a) for a in self.bus.addr_probes][:12]}..."
        assert self.bus.log == want, "bus log differs from the model (first difference at entry " \
            f"{next((i for i, (x, y) in enumerate(zip(self.bus.log, want)) if x != y), min(len(self.bus.log), len(want)))})"
        await self.regs()

@cocotb.test(timeout_time=2333010, timeout_unit="ns")
async def test_rescan_clears_and_busy(dut):
    e = Env(dut)
    await e.start({0x20, 0x21, 0x5F})
    await e.scan({0x20, 0x21, 0x5F})
    e.bus.devices = Env.devices({0x4B, 0x60})
    e.bus.clear()
    e.bus.addr_probes.clear()
    await e.b.write(CTRL, 1)
    await e.b.cycles(3000)
    assert (await e.b.read(STATUS)) & BUSY, "not busy during a scan"
    await e.b.expect(COUNT, 0, "COUNT early in the new scan (cleared, nothing found yet)")
    await e.b.expect(MAP0 + 1, 0, "MAP1 cleared by the new scan")
    await e.b.write(CTRL, 1)                         # ignored while busy: the scan does not restart
    want = e.m.scan({0x4B, 0x60})
    for _ in range(200):
        await e.b.cycles(2000)
        if not (await e.b.read(STATUS)) & BUSY:
            break
    assert e.bus.addr_probes == list(range(0x08, 0x78)), "a write while busy restarted or disturbed the scan"
    assert e.bus.log == want
    await e.regs()
    await e.b.write(CTRL, 0)                         # bit 0 clear: no scan
    await e.b.cycles(500)
    await e.regs()

async def test_clock_stretching_and_timing(dut):
    e = Env(dut)
    await e.start({0x4B})
    e.bus.stretch_next = 400                         # the sensor stretches SCL after its ACK

"""Golden model of t2_i2c_scanner, written from spec.yaml alone (never from any RTL)."""

from __future__ import annotations

DESIGN_ID = 0x5343414E
CTRL, STATUS, COUNT, LOWEST, MAP0 = 0, 1, 2, 3, 4
BUSY, DONE = 1, 2
FIRST, LAST = 0x08, 0x77


class Model:
    def __init__(self) -> None:
        self.map = 0
        self.count = 0
        self.lowest = 0xFF
        self.done = False

    def scan(self, present: set[int]) -> list[tuple]:
        """A complete scan over a bus where ``present`` ACK; returns the bus log it must produce."""
        self.map, self.count, self.lowest = 0, 0, 0xFF
        log: list[tuple] = []
        for a in range(FIRST, LAST + 1):
            ack = a in present
            log += [("S",), ("A", a, 0, ack), ("P",)]
            if ack:
                self.map |= 1 << a
                self.count += 1
                if self.lowest == 0xFF:
                    self.lowest = a
        self.done = True
        return log

    def read(self, off: int) -> int:
        if off == STATUS:
            return DONE if self.done else 0
        if off == COUNT:
            return self.count
        if off == LOWEST:
            return self.lowest
        if MAP0 <= off <= MAP0 + 3:
            return (self.map >> (32 * (off - MAP0))) & 0xFFFF_FFFF
        return 0

    def leds(self) -> int:
        return self.count
