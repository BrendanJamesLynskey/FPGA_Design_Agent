Problems / O. Audio

Safe PWM audio output stage for the Nexys A7 speaker jack

c12_nexys_pwm_audio Course tier course part 12 O Audio Nexys A7-100T

The problem

An audio output stage for the board's speaker connector. It takes signed 16-bit audio samples, scales them by a volume register, and turns the result into a pulse-width-modulated signal whose pulse widths follow the sound. The volume register starts at a quiet default and is clamped, so no value written to it can make the output louder than a safe limit. The pin is only ever pulled low or released, never driven high.

Where it is used. Pulse-width modulation is a cheap way to make audio from a digital pin in microcontrollers, toys and small devices. Volume limits like this appear wherever a product could otherwise damage hearing.

Adapted from a project in the owner's FPGA design course (the course itself is private).

The spec the agent is given

Safe PWM audio output stage for the Nexys A7 speaker jack

The Nexys A7-100T has a mono audio output driven by a single pin (AUD_PWM) that feeds a low-pass filter and an amplifier (enabled by the pin AUD_SD). I want an output stage that takes signed 16-bit audio samples and turns them into a pulse-width-modulated waveform on that pin, with a volume control that cannot hurt anybody's ears.

  • The audio sample is a signed 16-bit number that may be changed at any time and is held between samples. There is a gain register and a way to write it. The sample after the volume, sample_out (signed 16 bits), is available combinationally from the sample and the gain register.
  • AUD_PWM is open-drain style: the design pulls the pin low or lets it go (high impedance), and the board's pull-up floats it high; the pin is never driven high. AUD_SD, the amplifier enable, is always high.
  • Volume: the gain register is unsigned Q15 (32768 = unity), sample_out = floor(sample * gain / 2^15). It resets to 2068 (about -24 dBFS). Writing a value sets it, but any value above 8192 (about -12 dBFS) is replaced by 8192, so the output can never be louder than -12 dBFS whatever is written.
  • PWM: a free-running 10-bit counter divides the clock by 1024 (97.7 kHz carrier). The pin is pulled low on the clocks where the counter is at or above the duty value, and released below it, so in each period the pin is pulled low for 1024 minus the duty clocks. The duty value is 512 + floor(sample_out / 128) (mid-scale 512 for silence), updated once per period.
  • CPU_RESETN resets the gain to its default and clears the sample.
  • The block must close timing at 100 MHz.
  • Over the shell I write the sample, write the gain, and read sample_out back. I will exercise it in simulation (reset, default gain, writes of 65535, 4000, 8192, 8193, a reset after a write; sample values of 0, +32767, -32768 and others; each held for several periods) and compare sample_out, the number of clocks the pin is pulled low per period (measured on the AUD_PWM pin), and AUD_SD.
  • The shell runs at 115200 baud on the USB-UART. The design ID is "PWMA".

Test hooks: top module c12_nexys_pwm_audio_top, ports named as in the board's master XDC (AUD_PWM, AUD_SD, the USB-UART pins, CLK100MHZ, CPU_RESETN, and the 16-bit LED output, which the block leaves off), and the test shell's CLKS_PER_BIT, TIMEOUT_CYCLES and BUILD_STAMP parameters as top-level parameters. There are no other time constants.

Exactly spec.md. Anything it leaves open, the agent has to ask about.

What the hidden tests check

The requirements in the hidden spec, and how each is shown to hold:

  • REQ-01 default gain 2068 after reset; writes clamp at 8192 (shown by simulation)
  • REQ-02 sample_out and the low-clock count per period equal the model for every step; AUD_SD always 1; the pin is never driven high (shown by simulation)
  • REQ-03 timing closes at 100 MHz (shown by report analysis)
The full behaviour rules from hidden/spec.yaml

gain

  • reset 2068, clamp 8192 on write; sample_out = (sample * gain) >>> 15 (arithmetic shift)

pwm

  • 10-bit counter; duty = 512 + (sample_out >>> 7) latched when the counter wraps (reset value 512); AUD_PWM pulled low while counter >= duty, otherwise high impedance (the board pull-up makes it high)

sd

  • AUD_SD = 1 always

data

  • the bench counts the clocks with AUD_PWM low over 4096 consecutive clocks (4 whole periods) after the sample has been held for 2048 clocks, and divides by 4

Settled assumptions

  • the LEDs stay off. nothing is asked of them.

// Part 12 lab 1: the PWM audio output stage for the Nexys A7's AUD_PWM pin, with the hearing-safety gain register.
//
// sample_in: signed 16-bit audio at the sample rate (hold it between samples). Output: a 10-bit PWM at clk / 1024 (97.7 kHz at 100 MHz), open-drain style:
// aud_pwm_drive_low = 1 drives the pin low, 0 releases it (the board's pull-up and its Sallen-Key low-pass do the rest; see the Nexys A7 reference manual,
// section 15). aud_sd is held high (the amplifier enabled).
// HEARING SAFETY: gain is a Q15 register. It RESETS to GAIN_DEFAULT (-24 dBFS = 2068) and a write can never raise it above GAIN_MAX (-12 dBFS = 8192).
// Start the first listening at the lowest volume of the speaker, through speakers before headphones.
module audio_pwm #(
    parameter logic [15:0] GAIN_DEFAULT = 16'd2068,
    parameter logic [15:0] GAIN_MAX     = 16'd8192
) (
    input  logic               clk,
    input  logic               rst_n,
    input  logic signed [15:0] sample_in,
    input  logic               gain_wr,
    input  logic [15:0]        gain_in,
    output logic signed [15:0] sample_out,        // after the gain (for the testbench and for a VU meter)
    output logic               aud_pwm_drive_low,
    output logic               aud_sd
);
    logic [15:0] gain;
    logic [9:0]  ctr;
    logic [9:0]  duty;
    logic signed [31:0] prod;
    always_comb begin
        prod = sample_in * $signed({1'b0, gain});
        sample_out = 16'(prod >>> 15);
    end
    always_ff @(posedge clk) begin
        if (!rst_n) begin
            gain <= GAIN_DEFAULT; ctr <= '0; duty <= 10'd512;
        end else begin
            if (gain_wr) gain <= (gain_in > GAIN_MAX) ? GAIN_MAX : gain_in;
            ctr <= ctr + 1'b1;
            if (ctr == 10'd1023) duty <= 10'(($signed({sample_out[15], sample_out}) >>> 7) + 17'sd512);   // 16-bit signed -> 10-bit offset binary
        end
    end
    assign aud_pwm_drive_low = (ctr >= duty);
    assign aud_sd = 1'b1;
endmodule

// c12_nexys_pwm_audio_regs.sv: the shell window of course task c12_nexys_pwm_audio (sample register, gain write port, sample_out read-back).
module c12_nexys_pwm_audio_regs (
    input  logic        clk,
    input  logic        rst,
    output logic [15:0] led,
    output logic        drive_low,
    output logic        aud_sd,
    input  logic [6:0]  win_addr,
    input  logic        win_wr,
    input  logic        win_rd,
    input  logic [31:0] win_wdata,
    output logic [31:0] win_rdata
);
    logic signed [15:0] sample_r, sample_out;
    logic               gain_wr;
    logic [15:0]        gain_in;

    assign led = 16'd0;

    audio_pwm u_core (.clk(clk), .rst_n(!rst), .sample_in(sample_r), .gain_wr(gain_wr), .gain_in(gain_in), .sample_out(sample_out),
                      .aud_pwm_drive_low(drive_low), .aud_sd(aud_sd));

    always_ff @(posedge clk) begin
        gain_wr <= 1'b0;
        if (win_wr) begin
            if (win_addr == 7'h00) sample_r <= win_wdata[15:0];
            if (win_addr == 7'h01) begin gain_in <= win_wdata[15:0]; gain_wr <= 1'b1; end
        end
        win_rdata <= 32'd0;
        if (win_rd) begin
            if (win_addr == 7'h00) win_rdata <= {16'd0, sample_r};
            if (win_addr == 7'h02) win_rdata <= {16'd0, sample_out};
        end
        if (rst) begin
            sample_r <= '0; gain_in <= '0; gain_wr <= 1'b0; win_rdata <= 32'd0;
        end
    end
endmodule

"""Acceptance tests of c12_nexys_pwm_audio against model.py (hidden from the agent)."""

from __future__ import annotations

import cocotb
from benchmark.lib.bench import Board
from cocotb.triggers import ReadOnly, RisingEdge
from model import DESIGN_ID, GAIN, SAMPLE, SOUT, expected, steps


def s16(v: int) -> int:
    return v - 65536 if v & 0x8000 else v


async def measure(b: Board, dut, clocks: int = 4096) -> tuple[int, bool]:
    """Clocks with the (resolved) pin low over `clocks` consecutive clocks, and whether AUD_SD stayed 1."""
    low, sd = 0, True
    for _ in range(clocks):
        await RisingEdge(b.clk)
        await ReadOnly()
        low += int(dut.pwm.value) == 0
        sd &= int(dut.AUD_SD.value) == 1
        assert int(dut.pwm_pd.value) == 0, "AUD_PWM was driven high (with a pull-down on the pin it read 1)"
    await RisingEdge(b.clk)
    return low, sd


@cocotb.test(timeout_time=400_000_000, timeout_unit="ns")
async def test_identity_and_reset(dut):
    b = Board(dut, {})
    await b.start()
    assert await b.shell_id() == DESIGN_ID
    await b.expect(SAMPLE, 0, "SAMPLE after reset")
    await b.expect(SOUT, 0, "SOUT after reset")


@cocotb.test(timeout_time=2_000_000_000, timeout_unit="ns")
async def test_gain_clamp_and_pwm_duty(dut):
    b = Board(dut, {})
    await b.start()
    st = steps()
    for k, (s, e) in enumerate(zip(st, expected(st))):
        what = f"step {k} (reset {s['reset']}, write {s['write']}, sample {s['sample']})"
        if s["reset"]:
            await b.reset()
        if s["write"] is not None:
            await b.write(GAIN, s["write"])
        await b.write(SAMPLE, s["sample"] & 0xFFFF)
        assert s16(await b.read(SOUT)) == e["sample_out"], f"{what}: sample_out {s16(await b.read(SOUT))}, expected {e['sample_out']}"
        await b.cycles(2048)
        low, sd = await measure(b, dut)
        assert sd, f"{what}: AUD_SD was not always high"
        assert low == 4 * e["low_per_period"], f"{what}: {low / 4} clocks pulled low per period, expected {e['low_per_period']}"

"""Reference model for P12-3 (PWM audio output stage with the hearing-safety gain register). Standalone: python only."""
GAIN_DEFAULT, GAIN_MAX = 2068, 8192


def steps():
    """Each step: reset first? / gain write (or None) / the sample held afterwards."""
    return [
        {"reset": True, "write": None, "sample": 0},
        {"reset": False, "write": None, "sample": 32767},
        {"reset": False, "write": None, "sample": -32768},
        {"reset": False, "write": 65535, "sample": 32767},
        {"reset": False, "write": None, "sample": -32768},
        {"reset": False, "write": 4000, "sample": 20000},
        {"reset": False, "write": 8192, "sample": 12345},
        {"reset": False, "write": 8193, "sample": 10000},
        {"reset": True, "write": None, "sample": 32767},
    ]


def expected(steps_):
    gain, out = GAIN_DEFAULT, []
    for s in steps_:
        if s["reset"]:
            gain = GAIN_DEFAULT
        if s["write"] is not None:
            gain = min(s["write"], GAIN_MAX)
        so = (s["sample"] * gain) >> 15
        out.append({"sample_out": so, "low_per_period": 1024 - (512 + (so >> 7))})
    return out
