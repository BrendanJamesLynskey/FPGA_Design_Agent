Problems / I. Machine learning inference

Compressed-database search behind the test shell

c15_pq_search Course tier course part 15 I Machine learning inference Nexys A7-100T

The problem

A nearest-neighbour search over a database stored in compressed form. Each entry is a few short codes, and for each query a table says how far each code is from the query. The block adds up the table values for every entry and keeps the eight closest, with ties settled by entry number, and raises a flag when the list is final.

Where it is used. Product quantisation shrinks large vector databases so they fit in memory, and is used in similarity search for images, text and recommendations. Hardware versions speed up the scan of the compressed entries.

Adapted from a project in the owner's FPGA design course (the course itself is private).

The spec the agent is given

Compressed-database search behind the test shell

I want a block for the Nexys A7-100T's FPGA that finds the database entries closest to a query when the database is stored in a compressed form, and I want to exercise it entirely from the test shell.

  • Each database entry is stored as eight small codes of 4 bits each (so a 32-bit word per entry, code j in bits 4j to 4j+3). There are up to 1000 entries, numbered 0 upwards in the order they arrive.
  • For each query I give the block a table of distances: 8 groups of 16 numbers, each a whole number below 2^20 (the table entry for group g and code c is the distance contribution of code c in group g). I write the table in over the shell: I set a table position (group and code) and then write the values one after another, each write storing the value and moving on to the next position (the next code, and after code 15 the next group).
  • The distance of a database entry to the query is the sum over its eight codes of the table entry that code picks in its group. Smaller is closer.
  • A "start" command, before the entries of a new query, forgets the previous result and restarts the entry numbering at 0. Then I park up to 16 entries over the shell and give a "burst" command with a count, which presents them on consecutive clocks, one per clock; several bursts follow each other, and the burst that carries the final entry is marked "last". The table is fully written before the first entry of a query and does not change during it.
  • When the last entry has been taken into account the block raises a "done" flag (it stays up until the next start) and I read the eight closest entries closest first: for each place a "filled" flag, the distance (up to 23 bits) and the entry number. If two entries have the same distance the one with the smaller number comes first. The result must be right at the moment done is high.
  • CPU_RESETN clears done and forgets the result. I will run several queries and check every place of the result exactly. LED0 shows done and LED1 shows that a burst is running. The shell runs at 115200 baud on the USB-UART. The design ID is "PQSR".

Test hooks: top module c15_pq_search_top, ports named as in the board's master XDC, and the test shell's CLKS_PER_BIT, TIMEOUT_CYCLES and BUILD_STAMP parameters as top-level parameters. There are no other time constants.

Exactly spec.md. Anything it leaves open, the agent has to ask about.

What the hidden tests check

The requirements in the hidden spec, and how each is shown to hold:

  • REQ-01 the eight places (distance and entry number) equal the model for each tested query (shown by simulation)
  • REQ-02 entries with equal distance are ordered by entry number, and START restarts the numbering and forgets the previous result (shown by simulation)
  • REQ-03 bursts of entries on consecutive clocks lose none and DONE is high only when the result is final (shown by simulation)
  • REQ-04 The design closes timing at 100 MHz with no unconstrained path (shown by report analysis)
The full behaviour rules from hidden/spec.yaml

distance

  • d(entry) = sum over j<8 of TABLE[j][code_j(entry)], code_j = entry[4j+3:4j]; table entries are below 2^20 so d < 2^23.

ranking

  • The eight entries with the smallest distance, closest first; equal distances: the smaller entry number first. Entry numbers count the entries taken since START, from 0.
  • An unfilled place reads 0 with FILLED = 0; with fewer than eight entries only that many places are filled.

protocol

  • START, then bursts of up to 16 entries on consecutive clocks, the last burst flagged LAST. DONE rises after the flagged entry has been taken into account and the list is final; it stays up until the next START or reset.
  • The table is written (TDATA) before the first burst of a query and unchanged during it; a second query may use a new table.

leds

  • LED[0] = DONE, LED[1] = BUSY, the other LEDs are 0.

// c15_pq_search_regs.sv: the shell window of course task c15_pq_search.
module c15_pq_search_regs (
    input  logic        clk,
    input  logic        rst,
    output logic [15:0] led,
    input  logic [6:0]  win_addr,
    input  logic        win_wr,
    input  logic        win_rd,
    input  logic [31:0] win_wdata,
    output logic [31:0] win_rdata
);
    logic [6:0]   ta_r;
    logic [19:0]  td_r;
    logic [31:0]  cd [0:15];
    logic [4:0]   n_tot, tx_i;
    logic         txing, last_f, we, st, done, in_v, last_c;
    logic [2:0]   t_m;
    logic [3:0]   t_k;
    logic [8*23-1:0] best_dist;
    logic [8*16-1:0] best_idx;
    logic [7:0]   best_valid;

    assign t_m  = ta_r[6:4];
    assign t_k  = ta_r[3:0];
    assign in_v = txing;
    assign last_c = txing && last_f && (tx_i + 5'd1 == n_tot);
    assign led  = {14'd0, txing, done};

    pq_search u_core (.clk(clk), .rst_n(!rst), .t_we(we), .t_m(t_m), .t_k(t_k), .t_data(td_r), .start(st), .in_valid(in_v),
                      .codes(cd[tx_i[3:0]]), .last(last_c), .done(done), .best_dist(best_dist), .best_idx(best_idx),
                      .best_valid(best_valid));

    always_ff @(posedge clk) begin
        we <= 1'b0; st <= 1'b0;
        if (win_wr) begin
            case (win_addr)
                7'h00: ta_r <= win_wdata[6:0];
                7'h01: begin td_r <= win_wdata[19:0]; we <= 1'b1; end
                7'h02: st <= 1'b1;
                7'h18: begin
                    n_tot <= (win_wdata[4:0] == 5'd0) ? 5'd1 : (win_wdata[4:0] > 5'd16 ? 5'd16 : win_wdata[4:0]);
                    last_f <= win_wdata[8]; tx_i <= 5'd0; txing <= 1'b1;
                end
                default: if (win_addr >= 7'h08 && win_addr <= 7'h17) cd[4'(win_addr - 7'h08)] <= win_wdata;
            endcase
        end
        if (we) ta_r <= ta_r + 7'd1;
        if (txing) begin
            tx_i <= tx_i + 5'd1;
            if (tx_i + 5'd1 == n_tot) txing <= 1'b0;
        end
        win_rdata <= 32'd0;
        if (win_rd) begin
            if (win_addr == 7'h00) win_rdata <= {25'd0, ta_r};
            else if (win_addr >= 7'h08 && win_addr <= 7'h17) win_rdata <= cd[4'(win_addr - 7'h08)];
            else if (win_addr == 7'h19) win_rdata <= {30'd0, txing, done};
            else if (win_addr >= 7'h40 && win_addr <= 7'h47)
                win_rdata <= best_valid[win_addr[2:0]] ? {7'd0, 1'b1, 1'b0, best_dist[win_addr[2:0]*23 +: 23]} : 32'd0;
            else if (win_addr >= 7'h48 && win_addr <= 7'h4F)
                win_rdata <= best_valid[win_addr[2:0]] ? {16'd0, best_idx[win_addr[2:0]*16 +: 16]} : 32'd0;
        end
        if (rst) begin
            ta_r <= '0; td_r <= '0; n_tot <= '0; tx_i <= '0; txing <= 1'b0; last_f <= 1'b0; we <= 1'b0; st <= 1'b0; win_rdata <= 32'd0;
            for (int i = 0; i < 16; i++) cd[i] <= '0;
        end
    end
endmodule

// P15-4 reference RTL: a copy of solutions/p15l04_pq_adc/pq_adc.sv (course exercise p15l04_pq_adc, M = 8, KB = 4).
// Part 15 lesson 4 exercise: a product-quantisation asymmetric-distance (ADC) unit.
//
// A database vector is stored as M codes of KB bits each (default M = 8 codes of 4 bits, so 16 centres per sub-space), packed codes[j*KB +: KB] = code of sub-space j.
// For one query the host computes a distance table: entry T[j][c] = squared distance between the query's j-th sub-vector and centre c of sub-space j, TW bits unsigned.
// The unit holds the table (M * 2^KB words) and, for each database vector, adds up the M entries its codes pick:
//   distance = sum over j of T[j][codes[j]]                        (DW = TW + $clog2(M) bits: no overflow)
// Table write: with t_we high, T[t_m][t_k] <= t_data at the next clock edge (do not present in_valid for a vector that needs that entry in the same clock).
// Lookups: with in_valid high, one clock later (out_valid high, one clock of latency; rst_n synchronous, active low, clears out_valid only) distance holds the sum.
// The table is memory read asynchronously by the lookups (distributed RAM on an FPGA); lesson 4 says what changes with a block RAM (a registered read).
module pq_adc #(
    parameter int M  = 8,
    parameter int KB = 4,
    parameter int TW = 20,
    parameter int DW = TW + $clog2(M)
) (
    input  logic                    clk,
    input  logic                    rst_n,
    input  logic                    t_we,
    input  logic [$clog2(M)-1:0]    t_m,
    input  logic [KB-1:0]           t_k,
    input  logic [TW-1:0]           t_data,
    input  logic                    in_valid,
    input  logic [M*KB-1:0]         codes,
    output logic                    out_valid,
    output logic [DW-1:0]           distance
);
    logic [TW-1:0] tab [0:M*(1<<KB)-1];
    logic [DW-1:0] sum;
    always_comb begin
        sum = '0;
        for (int j = 0; j < M; j++) sum = sum + tab[(j << KB) + int'(codes[j*KB +: KB])];
    end
    always_ff @(posedge clk) begin
        if (t_we) tab[(int'(t_m) << KB) + int'(t_k)] <= t_data;
        if (!rst_n) out_valid <= 1'b0;
        else out_valid <= in_valid;
        if (in_valid) distance <= sum;
    end
endmodule

// P15-4 reference top: the PQ distance unit (pq_adc.sv) feeding the top-8 list (topk.sv) with the negated distance, so the smallest distance is the best score.
// Timing: pq_adc answers one clock after in_valid; topk inserts at the edge after that; done rises at that same edge for the last entry.
module pq_search (
    input  logic            clk,
    input  logic            rst_n,
    input  logic            t_we,
    input  logic [2:0]      t_m,
    input  logic [3:0]      t_k,
    input  logic [19:0]     t_data,
    input  logic            start,
    input  logic            in_valid,
    input  logic [31:0]     codes,
    input  logic            last,
    output logic            done,
    output logic [8*23-1:0] best_dist,
    output logic [8*16-1:0] best_idx,
    output logic [7:0]      best_valid
);
    logic        d_valid, last_q;
    logic [22:0] d;
    logic [15:0] cnt, idx_q;
    logic [8*24-1:0] top_score;
    pq_adc #(.M(8), .KB(4), .TW(20)) u_adc (.clk, .rst_n, .t_we, .t_m, .t_k, .t_data, .in_valid, .codes, .out_valid(d_valid), .distance(d));
    topk #(.K(8), .SW(24), .IW(16)) u_top (.clk, .rst_n, .clear(start), .in_valid(d_valid), .score(-$signed({1'b0, d})), .idx(idx_q), .top_score, .top_idx(best_idx), .top_valid(best_valid));
    always_ff @(posedge clk) begin
        if (!rst_n || start) begin
            cnt <= 16'd0;
            last_q <= 1'b0;
            done <= 1'b0;
        end else begin
            if (in_valid) cnt <= cnt + 16'd1;
            last_q <= in_valid && last;
            done <= last_q || done;
        end
        if (in_valid) idx_q <= cnt;
    end
    always_comb for (int i = 0; i < 8; i++) best_dist[i*23 +: 23] = -top_score[i*24 +: 23];
endmodule

// P15-4 reference RTL: a copy of solutions/p15l03_topk/topk.sv (course exercise p15l03_topk).
// Part 15 lesson 3 exercise: a streaming top-K list (K = 8 by default), one candidate per clock, a deterministic tie rule.
//
// Candidates arrive as (score, idx): score signed SW bits, idx IW bits (unique per stream). The list holds the K best seen so far, best first:
//   "a is better than b"  <=>  a.score > b.score,  or  a.score == b.score and a.idx < b.idx.        (so equal scores: the smaller index wins)
// clear = 1 (one clock) empties the list (it wins over in_valid in the same clock). With in_valid high the candidate is inserted at the next clock edge: it takes the first slot
// whose content it beats (an empty slot is beaten by anything), the slots below shift down by one and the old last slot falls off. rst_n (synchronous, active low) empties the list.
// Outputs (registers, valid the clock after the edge that inserted): slot 0 is the best; top_valid[i] says slot i holds a candidate; slot i's score is
// top_score[i*SW +: SW] and its index top_idx[i*IW +: IW]. Slots with top_valid = 0 are don't-care.
module topk #(
    parameter int K  = 8,
    parameter int SW = 24,
    parameter int IW = 16
) (
    input  logic                  clk,
    input  logic                  rst_n,
    input  logic                  clear,
    input  logic                  in_valid,
    input  logic signed [SW-1:0]  score,
    input  logic [IW-1:0]         idx,
    output logic [K*SW-1:0]       top_score,
    output logic [K*IW-1:0]       top_idx,
    output logic [K-1:0]          top_valid
);
    logic [K-1:0] better;
    always_comb begin
        for (int i = 0; i < K; i++)
            better[i] = !top_valid[i] || (score > $signed(top_score[i*SW +: SW])) ||
                        (score == $signed(top_score[i*SW +: SW]) && idx < top_idx[i*IW +: IW]);
    end
    always_ff @(posedge clk) begin
        if (!rst_n || clear) top_valid <= '0;
        else if (in_valid) begin
            for (int i = 0; i < K; i++) begin
                if (better[i]) begin
                    if (i == 0 || !better[(i == 0) ? 0 : i - 1]) begin
                        top_valid[i] <= 1'b1;
                        top_score[i*SW +: SW] <= score;
                        top_idx[i*IW +: IW] <= idx;
                    end else begin
                        top_valid[i] <= top_valid[((i == 0) ? 0 : i - 1)];
                        top_score[i*SW +: SW] <= top_score[((i == 0) ? 0 : i - 1)*SW +: SW];
                        top_idx[i*IW +: IW] <= top_idx[((i == 0) ? 0 : i - 1)*IW +: IW];
                    end
                end
            end
        end
    end
endmodule

"""Acceptance tests of c15_pq_search against model.py (hidden from the agent)."""

from __future__ import annotations

import cocotb
from benchmark.lib.bench import Board, peek
from model import BURST, CODE, DESIGN_ID, RES_D, RES_I, START, STATUS, TADDR, TDATA, bench_queries


async def load_table(b: Board, table) -> None:
    await b.write(TADDR, 0)
    for g in range(8):
        for c in range(16):
            await b.write(TDATA, table[g][c])


async def run_query(b: Board, table, entries, want, what: str) -> None:
    await load_table(b, table)
    await b.expect(TADDR, 128 & 0x7F, "TADDR advanced past the table")
    await b.write(START, 1)
    for c in range(0, len(entries), 16):
        chunk = entries[c:c + 16]
        for k, e in enumerate(chunk):
            await b.write(CODE + k, e)
        last = c + 16 >= len(entries)
        await b.write(BURST, len(chunk) | (0x100 if last else 0))
        await b.cycles(len(chunk) + 12)
        if not last:
            await b.expect(STATUS, 0, f"{what}: DONE must stay low before the last entry")
    await b.expect(STATUS, 1, f"{what}: DONE")
    for k in range(8):
        if k < len(want):
            await b.expect(RES_D + k, 1 << 24 | want[k][0], f"{what}: place {k} distance")
            await b.expect(RES_I + k, want[k][1], f"{what}: place {k} entry")
        else:
            await b.expect(RES_D + k, 0, f"{what}: place {k} unfilled")

"""P15-4 model: the distance tables, the code stream and the reference result (standalone: python only; the data are in pq_data.json)."""
import json
from pathlib import Path

K = 8
M = 8
_DATA = json.loads((Path(__file__).with_name("pq_data.json")).read_text())


def tables():
    return _DATA["tables"]


def codes():
    return _DATA["codes"]


def distances(table):
    return [sum(table[j][(c >> (4 * j)) & 15] for j in range(M)) for c in codes()]


def reference_top(table):
    d = distances(table)
    return sorted(((d[i], i) for i in range(len(d))))[:K]            # smallest distance, then smaller index


def reference_output():
    return {"queries": [{"top": [list(p) for p in reference_top(t)]} for t in tables()]}


# ---- benchmark wrapper: the shell register map (from spec.yaml) ----
DESIGN_ID = 0x50515352          # "PQSR"
TADDR, TDATA, START, CODE, BURST, STATUS, RES_D, RES_I = 0x00, 0x01, 0x02, 0x08, 0x18, 0x19, 0x40, 0x48


def top_of(table, cs):
    d = [sum(table[j][(c >> (4 * j)) & 15] for j in range(M)) for c in cs]
    return sorted((d[i], i) for i in range(len(d)))[:K]


def bench_queries():
    """(table, entries, expected top-8): two course tables with 32 database entries each, and a constant table
    (every distance equal, so the order is decided by the entry number alone)."""
    ts, cs = tables(), codes()
    flat = [[5] * 16 for _ in range(M)]
    qs = [(ts[0], cs[:32]), (ts[3], cs[40:72]), (flat, cs[:20])]
