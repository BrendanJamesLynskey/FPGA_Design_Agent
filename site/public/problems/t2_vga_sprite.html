Problems / H. Video and image processing

A bouncing 16 x 16 sprite on VGA

t2_vga_sprite Benchmark v1 T2 H Video and image processing Nexys A7-100T

The problem

A small image drawn over a plain background on a VGA monitor. The image is a sixteen by sixteen block of pixels, loaded row by row over the shell, with a position and two colours that the user can set. A bounce mode moves it by one pixel in each direction every frame and turns it round at the screen edges, like an old screen saver. Parts of it that fall off the screen are simply not drawn, and the design counts frames.

Where it is used. Hardware sprites were how home computers and games consoles moved characters and cursors cheaply, and the same idea survives in mouse pointers, on-screen overlays and the simple video generators used in FPGA teaching boards.

The spec the agent is given

A bouncing 16 x 16 sprite on VGA

I want one small sprite on a VGA monitor from the Nexys A7-100T, at the ordinary 640 x 480, 60 Hz mode (25 MHz pixel rate made from the 100 MHz clock with an enable, no clocking wizard; standard timing and sync polarity for that mode).

  • The sprite is 16 x 16 pixels, one bit per pixel: 1 draws the sprite colour, 0 lets the background show through. I load its 16 rows from the test shell.
  • I can set its position (X, Y of its top-left corner), the sprite colour and the background colour (12-bit RGB), and switch it off.
  • Optional bounce mode: once per frame it moves one pixel horizontally and one vertically, and turns round when it reaches an edge of the screen, like the old screen savers.
  • It must behave sensibly if I put it partly or completely off the screen.
  • Outside the visible area the colour outputs are black. A frame counter would help me check it runs.
  • Design ID "SPRT".

Test hooks: top module t2_vga_sprite_top, ports named as in the board's master XDC (VGA_R, VGA_G, VGA_B, VGA_HS, VGA_VS, the USB-UART pins, CLK100MHZ, CPU_RESETN), the test shell's CLKS_PER_BIT, TIMEOUT_CYCLES and BUILD_STAMP parameters as top-level parameters. The video timing is fixed (no parameters).

Exactly spec.md. Anything it leaves open, the agent has to ask about.

Interface

Top module t2_vga_sprite_top on the Nexys A7-100T (xc7a100tcsg324-1). Clock: CLK100MHZ at 100 MHz (board oscillator). Reset: CPU_RESETN, active low: registers to reset values; the raster restarts at pixel (0, 0); colour outputs black, syncs inactive (high). What the hidden tests check

The requirements in the hidden spec, and how each is shown to hold:

  • REQ-01 640x480 timing with negative syncs at the listed positions (shown by simulation)
  • REQ-02 Sprite pixels, bit order, transparency, clipping and EN follow the listed rule (shown by simulation)
  • REQ-03 Bounce moves X and Y by one per frame and reverses at 0 and 624 / 464 exactly as listed (shown by simulation)
  • REQ-04 FRAME counts completed frames (shown by simulation, on the board)
  • REQ-05 On the board a monitor shows the sprite moving (shown by on the board)
  • REQ-06 The design closes timing at 100 MHz with no unconstrained path (shown by report analysis)
The full behaviour rules from hidden/spec.yaml

raster

  • A pixel lasts exactly 4 clocks. Columns x = 0..799, lines y = 0..524. Horizontal - visible 0-639, front porch 640-655, sync 656-751, back porch 752-799. Vertical - visible 0-479, front porch 480-489, sync 490-491, back porch 492-524.
  • VGA_HS = 0 exactly while x is 656..751, VGA_VS = 0 exactly for lines 490..491 (from x = 0 of line 490); both 1 otherwise (negative sync).
  • Colour and syncs change together on the same clock (one registered output stage). After reset the first pixel shown is (0, 0).

pixels

  • Outside the visible area (x >= 640 or y >= 480) the colour outputs are 0.
  • A visible pixel (x, y) is a sprite pixel when CTRL.EN = 1, X <= x <= X + 15, Y <= y <= Y + 15 and bit (15 - (x - X)) of ROW[y - Y] is 1 (bit 15 is the sprite's leftmost column, ROW0 its top row). Sprite pixels show SPRITE_COLOR, all other visible pixels BG_COLOR.
  • X and Y are 10-bit and are not wrapped - parts of the sprite at x >= 640 or y >= 480 are simply not shown (X = 1000 hides it).
  • Register writes act from the next pixel on.

bounce

  • At each frame wrap (from (799, 524) to (0, 0)), if CTRL.BOUNCE = 1, X and Y move - horizontally - if DX_NEG = 0 and X >= 624, DX_NEG becomes 1 and X decreases by 1; else if DX_NEG = 1 and X = 0, DX_NEG becomes 0 and X increases by 1; else X increases by 1 (DX_NEG = 0) or decreases by 1 (DX_NEG = 1). Vertically the same with Y, DY_NEG and the limit 464.
  • A shell write to X, Y or CTRL on the same clock as the frame update wins over the update.

frame counter

  • FRAME (32 bits) increments at every frame wrap; reset 0; read only.

Settled assumptions

  • bit 15 of a row register is the leftmost pixel. matches how a row of a bitmap is usually written as a hex number.
  • the sprite is clipped, not wrapped, at the right and bottom. wrapping would show a split sprite at the far side, which is never what a bounce wants.

// sprite_gen.sv: 640x480 at 60 Hz raster (800 x 525, negative syncs) on a
// pixel enable every 4th clock, one 16x16 1-bit sprite over a background.
module sprite_gen (
    input  logic            clk,
    input  logic            rst,
    input  logic [255:0]    rows,        // row r = rows[16*r +: 16], bit 15 of a row = leftmost pixel
    input  logic [9:0]      sx,
    input  logic [9:0]      sy,
    input  logic            en,
    input  logic [11:0]     sprite_color,
    input  logic [11:0]     bg_color,
    output logic            frame_tick,  // one clock at the wrap to (0, 0)
    output logic [11:0]     rgb,
    output logic            hs_n,
    output logic            vs_n
);
    localparam int HV = 640, HFP = 16, HSW = 96, HT = 800;
    localparam int VV = 480, VFP = 10, VSW = 2, VT = 525;

    logic [1:0]  ph;
    logic [9:0]  x, y;
    logic [10:0] dx, dy;           // x - X, y - Y (11 bits: negative = outside)
    logic        hit;
    logic [11:0] pix;
    logic [3:0]  c, r;
    logic [15:0] row;

    always_comb begin
        dx  = {1'b0, x} - {1'b0, sx};
        dy  = {1'b0, y} - {1'b0, sy};
        c   = dx[3:0];
        r   = dy[3:0];
        row = rows[16 * r +: 16];
        hit = en && dx < 11'd16 && dy < 11'd16 && row[4'd15 - c];
        if (x >= 10'(HV) || y >= 10'(VV)) pix = 12'h000;
        else if (hit)                     pix = sprite_color;
        else                              pix = bg_color;
    end

    always_ff @(posedge clk) begin
        frame_tick <= 1'b0;
        if (rst) begin
            ph <= '0; x <= '0; y <= '0; rgb <= '0; hs_n <= 1'b1; vs_n <= 1'b1;
        end else begin
            ph <= ph + 1'b1;
            if (ph == 2'd3) begin
                rgb  <= pix;
                hs_n <= !(x >= 10'(HV + HFP) && x < 10'(HV + HFP + HSW));
                vs_n <= !(y >= 10'(VV + VFP) && y < 10'(VV + VFP + VSW));
                if (x == 10'(HT - 1)) begin
                    x <= '0;
                    if (y == 10'(VT - 1)) begin
                        y <= '0;
                        frame_tick <= 1'b1;
                    end else begin
                        y <= y + 1'b1;
                    end
                end else begin
                    x <= x + 1'b1;
                end
            end
        end
    end
endmodule

// sprite_regs.sv: sprite rows, position, colours, CTRL (with the bounce
// update at each frame wrap) and FRAME, in the shell window.
module sprite_regs (
    input  logic              clk,
    input  logic              rst,
    input  logic              frame_tick,
    output logic [255:0]      rows,
    output logic [9:0]        sx,
    output logic [9:0]        sy,
    output logic [11:0]       sprite_color,
    output logic [11:0]       bg_color,
    output logic              en,
    input  logic [6:0]        win_addr,
    input  logic              win_wr,
    input  logic              win_rd,
    input  logic [31:0]       win_wdata,
    output logic [31:0]       win_rdata
);
    localparam logic [9:0] XMAX = 10'd624, YMAX = 10'd464;
    logic [3:0]  ctrl;
    logic [15:0] row_r [16];

    always_comb for (int i = 0; i < 16; i++) rows[16 * i +: 16] = row_r[i];
    logic [31:0] frame;

    assign en = ctrl[0];

    wire wr_x = win_wr && win_addr == 7'h10;
    wire wr_y = win_wr && win_addr == 7'h11;
    wire wr_c = win_wr && win_addr == 7'h14;
    wire move = frame_tick && ctrl[1];

    always_ff @(posedge clk) begin
        if (rst) begin
            for (int i = 0; i < 16; i++) row_r[i] <= '0;
            sx <= '0; sy <= '0; sprite_color <= 12'hFFF; bg_color <= 12'h000;
            ctrl <= 4'b0001; frame <= '0;
        end else begin
            if (frame_tick) frame <= frame + 1'b1;
            if (win_wr && win_addr < 7'h10) row_r[win_addr[3:0]] <= win_wdata[15:0];
            if (win_wr && win_addr == 7'h12) sprite_color <= win_wdata[11:0];
            if (win_wr && win_addr == 7'h13) bg_color <= win_wdata[11:0];
            // horizontal
            if (wr_x) sx <= win_wdata[9:0];
            else if (move) begin
                if (!ctrl[2] && sx >= XMAX)      sx <= sx - 1'b1;
                else if (ctrl[2] && sx == '0)    sx <= sx + 1'b1;
                else if (ctrl[2])                sx <= sx - 1'b1;
                else                             sx <= sx + 1'b1;
            end
            // vertical
            if (wr_y) sy <= win_wdata[9:0];
            else if (move) begin
                if (!ctrl[3] && sy >= YMAX)      sy <= sy - 1'b1;
                else if (ctrl[3] && sy == '0)    sy <= sy + 1'b1;
                else if (ctrl[3])                sy <= sy - 1'b1;
                else                             sy <= sy + 1'b1;
            end
            // CTRL: direction bits flip at the edges
            if (wr_c) ctrl <= win_wdata[3:0];
            else if (move) begin
                if (!ctrl[2] && sx >= XMAX) ctrl[2] <= 1'b1;
                else if (ctrl[2] && sx == '0) ctrl[2] <= 1'b0;
                if (!ctrl[3] && sy >= YMAX) ctrl[3] <= 1'b1;
                else if (ctrl[3] && sy == '0) ctrl[3] <= 1'b0;
            end
        end
    end

    always_ff @(posedge clk) begin
        if (rst) win_rdata <= '0;
        else if (win_rd) begin
            if (win_addr < 7'h10) win_rdata <= {16'd0, row_r[win_addr[3:0]]};
            else case (win_addr)
                7'h10:   win_rdata <= {22'd0, sx};
                7'h11:   win_rdata <= {22'd0, sy};
                7'h12:   win_rdata <= {20'd0, sprite_color};
                7'h13:   win_rdata <= {20'd0, bg_color};
                7'h14:   win_rdata <= {28'd0, ctrl};
                7'h15:   win_rdata <= frame;
                default: win_rdata <= '0;
            endcase
        end
    end
endmodule

    parameter int          CLKS_PER_BIT   = 868,
    parameter int          TIMEOUT_CYCLES = 100_000,

    input  logic       CLK100MHZ,

    output logic       VGA_VS,

    sprite_regs u_regs (
        .clk(clk), .rst(rst), .frame_tick(frame_tick), .rows(rows), .sx(sx), .sy(sy),
        .sprite_color(sprite_color), .bg_color(bg_color), .en(en),
        .win_addr(win_addr), .win_wr(win_wr), .win_rd(win_rd), .win_wdata(win_wdata), .win_rdata(win_rdata));

    sprite_gen u_gen (
        .clk(clk), .rst(rst), .rows(rows), .sx(sx), .sy(sy), .en(en), .sprite_color(sprite_color),
        .bg_color(bg_color), .frame_tick(frame_tick), .rgb(rgb), .hs_n(VGA_HS), .vs_n(VGA_VS));

    assign VGA_R = rgb[11:8];
    assign VGA_G = rgb[7:4];
    assign VGA_B = rgb[3:0];
endmodule

"""Acceptance tests of t2_vga_sprite against model.py (hidden from the agent)."""

from __future__ import annotations

import random

import cocotb
from benchmark.lib.bench import Board
from benchmark.lib.vga_sampler import edge_clock, now_clock, sample
from model import (BG_COLOR, BOUNCE, CPP, CTRL, DESIGN_ID, DX_NEG, DY_NEG, EN, FRAME, FRAME_CLOCKS, HS_START, HSW,
                   HT, LINE, SPRITE_COLOR, VS_START, VSW, VT, X, Y, Model)

ARROW = [0x8000, 0xC000, 0xE000, 0xF000, 0xF800, 0xFC00, 0xFE00, 0xFF00, 0xFF80, 0xFC00, 0xEC00, 0xC600, 0x8600,
         0x0300, 0x0300, 0x0181]


class Env:
    def __init__(self, dut) -> None:
        self.b = Board(dut)
        self.dut, self.m = dut, Model()

    async def start(self) -> None:
        await self.b.start()
        self.t_release = now_clock() - 8               # Board.start waits 8 clocks after releasing reset
        self.t0 = await edge_clock(self.dut.VGA_HS, rising=False)   # HS fall (sync start) of line 0
        self.line0 = self.t0 - CPP * HS_START

    def clock_of(self, x: int, y: int, frame: int = 0) -> int:
        return self.line0 + frame * FRAME_CLOCKS + y * LINE + CPP * x

    def next_line(self, margin: int = 50) -> tuple[int, int]:
        k = (now_clock() + margin - self.line0 + LINE - 1) // LINE
        return k // VT, k % VT

    def ahead(self, k: int) -> int:
        """A line of the current frame at least ``k`` lines ahead (the tests stay in the top of the frame)."""
        _, y = self.next_line()
        assert y + k + 20 < 470, f"test ran too far down the frame (line {y})"
        return y + k

    async def wr(self, off: int, v: int) -> None:
        await self.b.write(off, v)
        self.m.write(off, v)

    async def load(self, rows: list[int]) -> None:
        for i, r in enumerate(rows):
            await self.wr(i, r)

    async def regs(self, offs=(X, Y, CTRL, FRAME)) -> None:
        for off in offs:
            await self.b.expect(off, self.m.read(off), f"window 0x{off:02X}")

    async def check_line(self, frame: int, y: int, xs) -> None:
        xs = list(xs)
        got = await sample(self.dut, [self.clock_of(x, y, frame) + 2 for x in xs], ("rgb", "VGA_HS", "VGA_VS"))
        want = [(self.m.pixel(x, y), self.m.hs(x), self.m.vs(y)) for x in xs]
        bad = [(x, g, w) for x, g, w in zip(xs, got, want) if g != w]
        assert not bad, f"line {y}: {len(bad)} pixels differ, first (x, rtl (rgb, hs, vs), model) = {bad[:4]}"

    async def check_lines(self, ys, xs) -> None:
        """Lines ``ys`` of the next frame whose line min(ys) is still ahead."""
        f, y = self.next_line()
        frame = f if y <= min(ys) else f + 1
        for yy in ys:
            await self.check_line(frame, yy, xs)

    async def wait_frame_wrap(self) -> int:
        """Wait until just after the next frame wrap (the model's bounce update); returns the new frame index."""
        f = (now_clock() - self.line0) // FRAME_CLOCKS
        target = self.clock_of(0, 0, f + 1) + 8
        await self.b.cycles(target - now_clock())
        self.m.frame_wrap()
        return f + 1


@cocotb.test(timeout_time=1662700, timeout_unit="ns")

@cocotb.test(timeout_time=22000000, timeout_unit="ns")
async def test_bounce_and_vertical_timing(dut):
    """One frame wrap: the bounce turns at the right limit (X >= 624) and at the top (Y = 0); on the way, the bottom
    lines (background, then black) and VS timing. (A frame is 1.68 M clocks: one wrap keeps the test short.)"""
    e = Env(dut)
    await e.start()
    await e.load(ARROW)
    await e.wr(X, 624)
    await e.wr(Y, 0)
    await e.wr(CTRL, EN | BOUNCE | DY_NEG)
    await e.check_line(0, 479, range(600, 660, 3))
    await e.check_line(0, 480, range(0, HT, 9))
    t_vs = await edge_clock(dut.VGA_VS, rising=False)
    assert t_vs == e.clock_of(0, VS_START), f"VS fell at clock {t_vs - e.line0} of the frame, model {VS_START * LINE}"
    t_end = await edge_clock(dut.VGA_VS)
    assert t_end - t_vs == VSW * LINE, f"VS low for {t_end - t_vs} clocks, model {VSW * LINE}"
    await e.check_line(0, 500, range(0, HT, 9))
    for _ in range(1):                                  # both turn: (623, 1), moving left and down
        f = await e.wait_frame_wrap()
        await e.regs()

"""Golden model of t2_vga_sprite, written from spec.yaml alone (never from any RTL)."""

from __future__ import annotations

DESIGN_ID = 0x53505254
ROW0, X, Y, SPRITE_COLOR, BG_COLOR, CTRL, FRAME = 0x00, 0x10, 0x11, 0x12, 0x13, 0x14, 0x15
EN, BOUNCE, DX_NEG, DY_NEG = 1, 2, 4, 8
CPP = 4
HV, HFP, HSW, HT = 640, 16, 96, 800
VV, VFP, VSW, VT = 480, 10, 2, 525
HS_START, VS_START = HV + HFP, VV + VFP          # 656, 490
LINE = HT * CPP                                  # 3200 clocks
FRAME_CLOCKS = LINE * VT
XMAX, YMAX = 624, 464


class Model:
    def __init__(self) -> None:
        self.rows = [0] * 16
        self.x = self.y = 0
        self.sprite_color, self.bg_color = 0xFFF, 0x000
        self.ctrl = EN
        self.frame = 0

    def write(self, off: int, v: int) -> None:
        if off < 0x10:
            self.rows[off] = v & 0xFFFF
        elif off == X:
            self.x = v & 0x3FF
        elif off == Y:
            self.y = v & 0x3FF
        elif off == SPRITE_COLOR:
            self.sprite_color = v & 0xFFF
        elif off == BG_COLOR:
            self.bg_color = v & 0xFFF
        elif off == CTRL:
            self.ctrl = v & 0xF

    def read(self, off: int) -> int:
        if off < 0x10:
            return self.rows[off]
        return {X: self.x, Y: self.y, SPRITE_COLOR: self.sprite_color, BG_COLOR: self.bg_color,
                CTRL: self.ctrl, FRAME: self.frame}.get(off, 0)

    def frame_wrap(self) -> None:
        self.frame += 1
        if not self.ctrl & BOUNCE:
            return
        self.x, neg = self._axis(self.x, bool(self.ctrl & DX_NEG), XMAX)
        self.ctrl = (self.ctrl & ~DX_NEG) | (DX_NEG if neg else 0)
        self.y, neg = self._axis(self.y, bool(self.ctrl & DY_NEG), YMAX)
        self.ctrl = (self.ctrl & ~DY_NEG) | (DY_NEG if neg else 0)

    @staticmethod
    def _axis(p: int, neg: bool, lim: int) -> tuple[int, bool]:
        if not neg and p >= lim:
            return p - 1, True
        if neg and p == 0:
            return p + 1, False
        return (p - 1, True) if neg else (p + 1, False)

    def pixel(self, x: int, y: int) -> int:
        if x >= HV or y >= VV:
            return 0
        c, r = x - self.x, y - self.y
        if self.ctrl & EN and 0 <= c < 16 and 0 <= r < 16 and (self.rows[r] >> (15 - c)) & 1:
            return self.sprite_color
        return self.bg_color

    @staticmethod
    def hs(x: int) -> int:
        return int(not HS_START <= x < HS_START + HSW)

    @staticmethod
    def vs(y: int) -> int:
        return int(not VS_START <= y < VS_START + VSW)
