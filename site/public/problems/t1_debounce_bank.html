Problems / A. Basic digital design drills

Sixteen-switch debounce bank

t1_debounce_bank Benchmark v1 T1 A Basic digital design drills Nexys A7-100T

The problem

A bank that cleans up every slide switch on the board separately. A switch's clean level only changes after it has held its new position for the whole debounce time, so shorter glitches are ignored however they line up. For each switch the design counts how many times the clean level changed, and keeps a sticky flag for rising and falling edges that the user can choose per switch and clear by writing ones.

Where it is used. Switch and button inputs on nearly every embedded product need this kind of conditioning, from front-panel keypads to limit switches on machines. Per-input edge flags and event counters are the usual way a processor is told that something changed.

The spec the agent is given

Sixteen-switch debounce bank

I want all sixteen slide switches of the Nexys A7-100T cleaned up, each on its own.

  • Every switch is synchronised and debounced separately: a switch's clean level only changes once the switch has stayed at the new level for the whole debounce time; anything shorter is noise and is ignored completely, however it lines up with anything else.
  • LED[15:0] show the sixteen clean levels.
  • For each switch, count how many times its clean level has changed (a small counter per switch is enough).
  • Keep a register of sticky edge flags, one per switch, that I clear by writing ones to it. I want to choose, per switch, whether rising edges, falling edges or both set the flag.
  • CPU_RESETN resets everything.
  • Over the test shell (USB-UART, 115200 baud) I can read the clean levels, the counts and the edge flags, clear them, and set the edge selection. The design ID is "DBNK".

Test hooks: top module t1_debounce_bank_top, ports named as in the board's master XDC, the test shell's CLKS_PER_BIT, TIMEOUT_CYCLES and BUILD_STAMP parameters, plus DEBOUNCE_CYCLES (the debounce time in clocks) as top-level parameters.

Exactly spec.md. Anything it leaves open, the agent has to ask about.

Interface

Top module t1_debounce_bank_top on the Nexys A7-100T (xc7a100tcsg324-1). Clock: CLK100MHZ at 100 MHz (board oscillator). Reset: CPU_RESETN, active low: clean levels 0, EDGES = 0, every count 0, RISE_EN = 0xFFFF, FALL_EN = 0x0000. Resources expected: about 600 FFs (16 debounce counters of 21 bits, 16 8-bit counts) and 500 LUTs; no BRAM, no DSP.

Top-level parameters (board values): CLKS_PER_BIT = 868, DEBOUNCE_CYCLES = 2000000, TIMEOUT_CYCLES = 100000. The hidden bench shrinks them to CLKS_PER_BIT = 8, DEBOUNCE_CYCLES = 24, TIMEOUT_CYCLES = 400.

What the hidden tests check

The requirements in the hidden spec, and how each is shown to hold:

  • REQ-01 Each clean level follows its switch after DEBOUNCE_CYCLES of steady difference and never for a shorter glitch, at any phase (shown by simulation)
  • REQ-02 The switches are debounced independently (shown by simulation)
  • REQ-03 COUNT[k] counts every clean change, 8-bit wrapping, cleared four at a time by a write (shown by simulation)
  • REQ-04 EDGES are sticky, W1C, set by the selected edge kinds per switch (shown by simulation)
  • REQ-05 LED[15:0] show the clean levels; the register window has the listed map (shown by simulation)
  • REQ-06 The design closes timing at 100 MHz with no unconstrained path (shown by report analysis)
  • REQ-07 On the board LEVEL reads the switch positions and the register rules hold (shown by on the board)
The full behaviour rules from hidden/spec.yaml

debounce

  • Each SW[k] is synchronised (two flops), then debounced on its own. The clean level L[k] changes only after the synchronised input has differed from it for DEBOUNCE_CYCLES consecutive clocks; a shorter difference restarts the count. No slow sampling tick - a difference shorter than DEBOUNCE_CYCLES never changes L[k], wherever it falls in time.
  • Because the levels reset to 0, a switch already up at reset gives a rising edge DEBOUNCE_CYCLES clocks after reset.

counts

  • COUNT[k] (8 bits, wrapping at 256) adds 1 on every change of L[k], rising or falling, whatever the edge selection.

edges

  • EDGES[k] is set on a rise of L[k] when RISE_EN[k] = 1, and on a fall when FALL_EN[k] = 1. It stays set until a shell write to EDGES with bit k = 1 (write-1-to-clear); if an edge and the clear fall on the same clock, the edge wins.

leds

  • LED[15:0] = L[15:0]. No PWM.

Settled assumptions

  • one counter per switch rather than a shared sampling tick. the request says noise is ignored however it lines up.
  • rising edges only by default. a switch being turned on is the usual event of interest.

// bm_debounce.sv: two-flop synchroniser, then a counting debounce. The level
// changes only after the synchronised input has differed from it for CYCLES
// consecutive clocks; a shorter difference restarts the count. rise is a
// one-clock pulse on each 0 -> 1 change of the level.
module bm_debounce #(
    parameter int CYCLES = 1_000_000
) (
    input  logic clk,
    input  logic rst,
    input  logic d_async,
    output logic level,
    output logic rise
);
    localparam int CW = $clog2(CYCLES + 1);
    logic        d;
    logic [CW-1:0] run;

    sync2 u_sync (.clk(clk), .rst(rst), .d(d_async), .q(d));

    always_ff @(posedge clk) begin
        rise <= 1'b0;
        if (rst) begin
            level <= 1'b0;
            run   <= '0;
        end else if (d == level) begin
            run <= '0;
        end else if (run == CW'(CYCLES - 1)) begin
            level <= d;
            run   <= '0;
            rise  <= d;
        end else begin
            run <= run + 1'b1;
        end
    end
endmodule

// debounce_bank.sv: sixteen independent switch debouncers, per-switch change
// counts and selectable sticky edge flags, for t1_debounce_bank.
module debounce_bank #(
    parameter int DEBOUNCE_CYCLES = 2_000_000
) (
    input  logic        clk,
    input  logic        rst,
    input  logic [15:0] sw_async,
    output logic [15:0] led,
    input  logic [6:0]  win_addr,
    input  logic        win_wr,
    input  logic        win_rd,
    input  logic [31:0] win_wdata,
    output logic [31:0] win_rdata
);
    localparam logic [6:0] R_LEVEL = 7'h00, R_EDGES = 7'h01, R_RISE = 7'h02, R_FALL = 7'h03;

    logic [15:0]      lvl, lvl_d, rise, fall, edges, rise_en, fall_en, unused;
    logic [15:0][7:0] cnt;

    for (genvar k = 0; k < 16; k++) begin : g_db
        bm_debounce #(.CYCLES(DEBOUNCE_CYCLES)) u_db (.clk(clk), .rst(rst), .d_async(sw_async[k]),
                                                      .level(lvl[k]), .rise(unused[k]));
    end

    assign rise = lvl & ~lvl_d;
    assign fall = ~lvl & lvl_d;

    always_ff @(posedge clk) begin
        if (rst) begin
            lvl_d <= '0; edges <= '0; rise_en <= 16'hFFFF; fall_en <= '0; cnt <= '0;
        end else begin
            lvl_d <= lvl;
            edges <= (edges & ~((win_wr && win_addr == R_EDGES) ? win_wdata[15:0] : 16'h0000))
                   | (rise & rise_en) | (fall & fall_en);
            if (win_wr && win_addr == R_RISE) rise_en <= win_wdata[15:0];
            if (win_wr && win_addr == R_FALL) fall_en <= win_wdata[15:0];
            for (int k = 0; k < 16; k++) begin
                if (win_wr && win_addr == 7'(4 + k / 4)) cnt[k] <= '0;
                else if (lvl[k] != lvl_d[k])            cnt[k] <= cnt[k] + 8'd1;
            end
        end
    end

    assign led = lvl_d;

    always_ff @(posedge clk) begin
        if (rst) win_rdata <= '0;
        else if (win_rd) begin
            case (win_addr)
                R_LEVEL: win_rdata <= {16'd0, lvl_d};
                R_EDGES: win_rdata <= {16'd0, edges};
                R_RISE:  win_rdata <= {16'd0, rise_en};
                R_FALL:  win_rdata <= {16'd0, fall_en};
                7'h04:   win_rdata <= {cnt[3], cnt[2], cnt[1], cnt[0]};
                7'h05:   win_rdata <= {cnt[7], cnt[6], cnt[5], cnt[4]};
                7'h06:   win_rdata <= {cnt[11], cnt[10], cnt[9], cnt[8]};
                7'h07:   win_rdata <= {cnt[15], cnt[14], cnt[13], cnt[12]};
                default: win_rdata <= '0;
            endcase
        end
    end
endmodule

// Reference design for benchmark task t1_debounce_bank; DESIGN_ID "DBNK".
module t1_debounce_bank_top #(
    parameter int          CLKS_PER_BIT    = 868,
    parameter int          TIMEOUT_CYCLES  = 100_000,
    parameter int          DEBOUNCE_CYCLES = 2_000_000,
    parameter logic [31:0] BUILD_STAMP     = 32'h0
) (
    input  logic        CLK100MHZ,
    input  logic        CPU_RESETN,
    input  logic [15:0] SW,
    output logic [15:0] LED,
    input  logic        UART_TXD_IN,

    logic        clk, rst, win_wr, win_rd;
    logic [6:0]  win_addr;
    logic [31:0] win_wdata, win_rdata;

    assign clk = CLK100MHZ;
    reset_sync u_rst (.clk(clk), .rst_n_async(CPU_RESETN), .rst(rst));

    fpga_shell #(.CLKS_PER_BIT(CLKS_PER_BIT), .TIMEOUT_CYCLES(TIMEOUT_CYCLES),
                 .DESIGN_ID(32'h4442_4E4B), .BUILD_STAMP(BUILD_STAMP)) u_shell (
        .clk(clk), .rst(rst), .uart_rx(UART_TXD_IN), .uart_tx(UART_RXD_OUT),
        .win_addr(win_addr), .win_wr(win_wr), .win_rd(win_rd), .win_wdata(win_wdata), .win_rdata(win_rdata));

    debounce_bank #(.DEBOUNCE_CYCLES(DEBOUNCE_CYCLES)) u_bank (
        .clk(clk), .rst(rst), .sw_async(SW), .led(LED),
        .win_addr(win_addr), .win_wr(win_wr), .win_rd(win_rd), .win_wdata(win_wdata), .win_rdata(win_rdata));

"""Acceptance tests of t1_debounce_bank against model.py (hidden from the agent)."""

from __future__ import annotations

import random

import cocotb
from benchmark.lib.bench import Board, peek
from cocotb.triggers import ReadOnly, RisingEdge
from cocotb.utils import get_sim_time
from model import COUNT0, DESIGN_ID, EDGES, FALL_EN, LEVEL, RISE_EN, Model

NAMES = {LEVEL: "LEVEL", EDGES: "EDGES", RISE_EN: "RISE_EN", FALL_EN: "FALL_EN", 4: "COUNT0", 5: "COUNT1",
         6: "COUNT2", 7: "COUNT3"}


class Env:
    def __init__(self, dut) -> None:
        self.b = Board(dut, {"SW": 0})
        self.dut, self.m = dut, Model()
        self.n = self.b.param("DEBOUNCE_CYCLES")
        self.sw = 0

    async def start(self) -> None:
        await self.b.start()

    async def set_sw(self, v: int, settle: bool = True) -> None:
        self.sw = v & 0xFFFF
        self.dut.SW.value = self.sw
        if settle:
            await self.b.cycles(self.n + 8)
            self.m.settle(self.sw)

    async def wr(self, off: int, v: int) -> None:
        await self.b.write(off, v)
        self.m.write(off, v)

    async def check_regs(self) -> None:
        for off in range(8):
            await self.b.expect(off, self.m.read(off), NAMES[off])

    async def check_leds(self) -> None:
        led = await peek(self.b.clk, self.dut.LED)
        assert led == self.m.level, f"LED {led:04X} != model {self.m.level:04X}"


@cocotb.test()
async def test_identity_and_reset(dut):
    e = Env(dut)
    await e.start()
    assert await e.b.shell_id() == DESIGN_ID
    await e.check_regs()
    await e.check_leds()


@cocotb.test()
async def test_glitch_on_slow_tick(dut):
    """Trap: the textbook debouncer samples each switch on a slow tick, so a short glitch that happens to cover a
    sampling instant changes the level. Glitches of 3 clocks are swept across every phase of a DEBOUNCE_CYCLES
    period (and longer ones up to DEBOUNCE_CYCLES - 1): none may change any level."""
    e = Env(dut)
    await e.start()
    await e.set_sw(0x0F0F)
    await e.check_regs()
    base = e.sw
    for width, step in ((3, 3), (e.n - 1, 1), (e.n // 2, 5)):
        for _ in range(e.n // step + 2):
            dut.SW.value = base ^ 0xFFFF
            await e.b.cycles(width)
            dut.SW.value = base
            await e.b.cycles(e.n + step)
    await e.b.cycles(e.n + 8)
    await e.check_regs()                         # no level change, no count, no edge beyond the first settle
    await e.check_leds()


@cocotb.test()
async def test_levels_follow_switches(dut):
    e = Env(dut)
    await e.start()
    for v in (0x0001, 0x8000, 0xFFFF, 0x0000, 0xA5C3, 0x5A3C):
        await e.set_sw(v)
        await e.check_leds()
        await e.b.expect(LEVEL, e.m.read(LEVEL), "LEVEL")
    await e.check_regs()


@cocotb.test()
async def test_independent_timing(dut):
    """Each switch has its own debounce: a change on one never restarts or delays another."""
    e = Env(dut)
    await e.start()
    seen: dict[int, int] = {}

    async def watch():
        prev = 0
        while True:
            await RisingEdge(e.b.clk)
            await ReadOnly()
            v = int(dut.LED.value)
            for k in range(16):
                if (v ^ prev) >> k & 1 and k not in seen:
                    seen[k] = int(get_sim_time("ns")) // 10
            prev = v

    cocotb.start_soon(watch())
    t0 = int(get_sim_time("ns")) // 10
    dut.SW.value = 1 << 3                       # switch 3 up at t0
    await e.b.cycles(e.n // 2)
    dut.SW.value = 1 << 3 | 1 << 9              # switch 9 up half a debounce later
    for _ in range(3):                          # switch 12 chatters meanwhile
        await e.b.cycles(e.n // 6)
        dut.SW.value = int(dut.SW.value) | 1 << 12
        await e.b.cycles(2)
        dut.SW.value = int(dut.SW.value) & ~(1 << 12)
    await e.b.cycles(2 * e.n)
    assert set(seen) == {3, 9}, f"LEDs that changed: {sorted(seen)}"
    assert seen[9] - seen[3] == e.n // 2, f"switch 9 settled {seen[9] - seen[3]} clocks after 3, want {e.n // 2}"
    # v1.2: n + 1 .. n + 8 clocks (a two- to four-flop synchroniser plus one output register all pass)
    assert seen[3] - t0 - e.n in range(1, 9), f"switch 3 took {seen[3] - t0} clocks to settle"
    e.sw = 1 << 3 | 1 << 9
    e.m.settle(e.sw)
    await e.check_regs()


@cocotb.test()
async def test_counts_and_clear(dut):
    e = Env(dut)
    await e.start()
    for k, n in ((0, 3), (5, 2), (7, 5), (14, 1), (15, 4)):
        for _ in range(n):
            await e.set_sw(e.sw ^ 1 << k)
    await e.check_regs()
    await e.wr(5, 0x1234)                       # clears counts 4..7 only
    await e.check_regs()
    for _ in range(258):                        # count 0 wraps at 256
        await e.set_sw(e.sw ^ 1)
    await e.check_regs()


@cocotb.test()
async def test_edge_selection_and_w1c(dut):
    e = Env(dut)
    await e.start()
    await e.wr(RISE_EN, 0x00FF)
    await e.wr(FALL_EN, 0x0F0F)
    await e.set_sw(0xFFFF)                      # rises: EDGES 0x00FF
    await e.check_regs()
    await e.wr(EDGES, 0x000F)                   # W1C: clear four
    await e.check_regs()
    await e.wr(EDGES, 0)                        # zeros clear nothing
    await e.check_regs()
    await e.set_sw(0x0000)                      # falls: adds 0x0F0F
    await e.check_regs()
    await e.wr(EDGES, 0xFFFF)
    await e.wr(RISE_EN, 0)
    await e.wr(FALL_EN, 0)
    await e.set_sw(0xFFFF)                      # nothing selected: no flags, counts still move
    await e.set_sw(0x0000)
    await e.check_regs()

@cocotb.test()
async def test_random_activity(dut):
    e = Env(dut)
    await e.start()
    rng = random.Random(int(cocotb.RANDOM_SEED))
    await e.wr(RISE_EN, rng.getrandbits(16))
    await e.wr(FALL_EN, rng.getrandbits(16))
    for _ in range(25):
        r = rng.random()
        if r < 0.15:
            mask = rng.getrandbits(16)
            dut.SW.value = e.sw ^ mask          # a glitch: shorter than the debounce time
            await e.b.cycles(rng.randrange(1, e.n))
            dut.SW.value = e.sw
            await e.b.cycles(e.n + 4)
        elif r < 0.25:
            await e.wr(rng.choice((EDGES, 4, 5, 6, 7)), rng.getrandbits(32))
        else:
            await e.set_sw(e.sw ^ rng.getrandbits(16))
    await e.check_regs()
    await e.check_leds()

"""Golden model of t1_debounce_bank, written from spec.yaml alone (never from any RTL)."""

from __future__ import annotations

LEVEL, EDGES, RISE_EN, FALL_EN = 0, 1, 2, 3
COUNT0 = 4
DESIGN_ID = 0x44424E4B          # "DBNK"


class Model:
    def __init__(self) -> None:
        self.level = 0
        self.edges = 0
        self.rise_en, self.fall_en = 0xFFFF, 0
        self.cnt = [0] * 16

    def settle(self, sw: int) -> None:
        """The switches have been steady at ``sw`` for longer than the debounce time."""
        for k in range(16):
            old, new = self.level >> k & 1, sw >> k & 1
            if old != new:
                self.cnt[k] = (self.cnt[k] + 1) & 0xFF
                if (new and self.rise_en >> k & 1) or (not new and self.fall_en >> k & 1):
                    self.edges |= 1 << k
        self.level = sw & 0xFFFF

    def read(self, off: int) -> int:
        if off == LEVEL:
            return self.level
        if off == EDGES:
            return self.edges
        if off == RISE_EN:
            return self.rise_en
        if off == FALL_EN:
            return self.fall_en
        if COUNT0 <= off < COUNT0 + 4:
            g = off - COUNT0
            return sum(self.cnt[4 * g + i] << (8 * i) for i in range(4))
        return 0

    def write(self, off: int, v: int) -> None:
        if off == EDGES:
            self.edges &= ~v & 0xFFFF
        elif off == RISE_EN:
            self.rise_en = v & 0xFFFF
        elif off == FALL_EN:
            self.fall_en = v & 0xFFFF
        elif COUNT0 <= off < COUNT0 + 4:
            g = off - COUNT0
            for i in range(4):
                self.cnt[4 * g + i] = 0
