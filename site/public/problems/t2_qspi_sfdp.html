Problems / F. Interfaces and protocols

Read the configuration flash's ID and SFDP header

t2_qspi_sfdp Benchmark v1 T2 F Interfaces and protocols Nexys A7-100T

The problem

A small program in hardware that identifies the board's configuration flash chip. On a start command it reads the chip's three-byte JEDEC identifier and then the first sixteen bytes of its SFDP table, a standard self-description held in the flash. It reports the values and whether the table begins with the expected signature. Because the flash holds the board's bitstream, the design may send only those two read commands and never anything that writes.

Where it is used. SFDP lets software discover the size, commands and timing of a serial flash without a per-chip driver, which is how boot loaders and operating systems support many flash parts. Reading the ID is the usual safe first check that a flash connection works.

The spec the agent is given

Read the configuration flash's ID and SFDP header

I want to identify the Nexys A7-100T's configuration flash from the FPGA after it has booted: read its JEDEC ID and the start of its SFDP table (the standard self-description), and show them over the test shell.

  • Single-bit SPI only, mode 0. The flash clock goes out through the configuration clock pin, so it has to go through the STARTUPE2 primitive. Keep the write-protect line low and the hold line high.
  • On a start command: read the 3-byte JEDEC ID, then read 16 bytes of SFDP data from address 0 (the SFDP header and the first parameter header), with the dummy clocks the SFDP read needs.
  • Registers: the ID, the 16 SFDP bytes as four words, and status (busy, done, and whether the first four SFDP bytes are the "SFDP" signature).
  • This flash holds the board's bitstream: the design must never send anything but those two read commands.
  • The SPI clock half period is a parameter in clocks (5 MHz on the board is plenty).
  • Design ID "SFDP".

Test hooks: top module t2_qspi_sfdp_top, ports named as in the board's master XDC (QSPI_CSN, QSPI_DQ0.. QSPI_DQ3, the USB-UART pins, CLK100MHZ, CPU_RESETN), the test shell's CLKS_PER_BIT, TIMEOUT_CYCLES and BUILD_STAMP parameters, plus HALF (SPI clock half period in clocks) as top-level parameters.

Exactly spec.md. Anything it leaves open, the agent has to ask about.

Interface

Top module t2_qspi_sfdp_top on the Nexys A7-100T (xc7a100tcsg324-1). Clock: CLK100MHZ at 100 MHz (board oscillator). Reset: CPU_RESETN, active low: registers to reset values; QSPI_CSN high; SCK low; then the start-up SCK cycles (below). Resources expected: about a hundred and fifty LUTs and FFs; one STARTUPE2; no BRAM, no DSP.

Top-level parameters (board values): CLKS_PER_BIT = 868, HALF = 10, TIMEOUT_CYCLES = 100000. The hidden bench shrinks them to CLKS_PER_BIT = 8, HALF = 8, TIMEOUT_CYCLES = 400.

What the hidden tests check

The requirements in the hidden spec, and how each is shown to hold:

  • REQ-01 RDID and RSFDP (address 0, 8 dummy cycles, 16 bytes) are sent exactly as listed, in mode 0 (shown by simulation)
  • REQ-02 No opcode other than 0x9F and 0x5A ever reaches the flash (shown by simulation, report analysis)
  • REQ-03 ID, SFDP0-3 and SIG_OK hold what the flash returned (shown by simulation)
  • REQ-04 SCK leaves through STARTUPE2 USRCCLKO, with start-up cycles; WP# low, HOLD# high (shown by simulation, report analysis)
  • REQ-05 On the board the ID reads 01 20 18 (shown by on the board)
  • REQ-06 The design closes timing at 100 MHz with no unconstrained path (shown by report analysis)
The full behaviour rules from hidden/spec.yaml

sck

  • SCK reaches the flash only through STARTUPE2 - USRCCLKO = SCK, USRCCLKTS = 0; the other STARTUPE2 inputs inactive (GSR 0, GTS 0, KEYCLEARB 1, PACK 0, USRDONEO 1, USRDONETS 1). No QSPI_SCK port.
  • After reset, before any transaction, SCK makes at least 3 full cycles with QSPI_CSN high (STARTUPE2 drops the first 3 USRCCLKO edges after configuration).
  • SCK idles low (mode 0); each half period is HALF clocks.

transactions

  • Mode 0 - the flash samples DQ0 on SCK rising edges and changes DQ1 after falling edges; the master puts each bit on DQ0 before the rising edge and samples DQ1 (synchronised by two flops) at the rising edge. Bytes MSB first.
  • Each transaction - QSPI_CSN low, at least HALF clocks, the SCK cycles back to back, at least HALF clocks after the last falling edge QSPI_CSN high, and at least 4 * HALF clocks high before the next.
  • A write to CTRL with bit 0 = 1 while BUSY = 0 - BUSY set, DONE and SIG_OK cleared, then two transactions - RDID [0x9F, then 3 bytes read into ID] and RSFDP [0x5A, address 0x00 0x00 0x00, 8 dummy SCK cycles, then 16 bytes read into SFDP0-SFDP3]; then BUSY cleared, DONE set, SIG_OK = (SFDP0 == 0x50444653).
  • Writes to CTRL while BUSY are ignored. A later start reads both again.
  • No other opcode is ever sent (no write enable, program, erase, register write or reset); DQ0 is a don't-care during the dummy and read bytes.

pins

  • QSPI_DQ2 (WP#) = 0 and QSPI_DQ3 (HOLD#) = 1 at all times.

Settled assumptions

  • the start-up SCK cycles are sent once after reset, not before every start. STARTUPE2 drops edges only after configuration; once is enough.
  • SIG_OK compares only the four signature bytes. the request asks whether the signature matched.

// sf_spi.sv: single-bit SPI mode-0 transaction engine for the configuration
// flash. CS low, nhdr header bytes from hdr (MSB byte first), then nrd bytes
// with DQ0 = 0 whose received values come out on rx_valid / rx_byte, CS high,
// then a gap. Once after reset it first makes STARTUP SCK cycles with CS high.
module sf_spi #(
    parameter int HALF    = 10,
    parameter int STARTUP = 8
) (
    input  logic        clk,
    input  logic        rst,
    input  logic        go,
    input  logic [31:0] hdr,
    input  logic [2:0]  nhdr,
    input  logic [4:0]  nrd,
    input  logic        miso,          // synchronised
    output logic        sck,
    output logic        mosi,
    output logic        csn,
    output logic        busy,          // includes the start-up cycles
    output logic        rx_valid,
    output logic [7:0]  rx_byte
);
    localparam int CW = $clog2(4 * HALF + 1);
    typedef enum logic [2:0] {BOOT, IDLE, LEAD, LOW, HIGH, TAIL, GAP} st_t;
    st_t st;

    logic [CW-1:0] cnt;
    logic [2:0]    bitn;
    logic [5:0]    b, total;
    logic [31:0]   h;
    logic [2:0]    nh;
    logic [7:0]    sh_out, sh_in;
    logic [4:0]    boot_n;

    function automatic logic [7:0] tx_byte(input logic [5:0] idx, input logic [31:0] hh, input logic [2:0] n);
        if (idx >= {3'd0, n}) tx_byte = 8'h00;
        else                  tx_byte = hh[31 - 8 * idx[1:0] -: 8];
    endfunction
    function automatic logic msb(input logic [7:0] v);
        msb = v[7];
    endfunction

    always_ff @(posedge clk) begin
        rx_valid <= 1'b0;
        if (rst) begin
            st <= BOOT; cnt <= CW'(HALF - 1); bitn <= '0; b <= '0; total <= '0; h <= '0; nh <= '0;
            sh_out <= '0; sh_in <= '0; sck <= 1'b0; mosi <= 1'b0; csn <= 1'b1; busy <= 1'b1; rx_byte <= '0;
            boot_n <= '0;
        end else begin
            case (st)
                // start-up: STARTUP SCK cycles with CS high
                BOOT: if (cnt == '0) begin
                    cnt <= CW'(HALF - 1);
                    sck <= ~sck;
                    if (sck) begin
                        if (boot_n == 5'(STARTUP - 1)) begin st <= GAP; cnt <= CW'(4 * HALF - 1); end
                        boot_n <= boot_n + 1'b1;
                    end
                end else cnt <= cnt - 1'b1;
                IDLE: if (go) begin
                    busy <= 1'b1; csn <= 1'b0; h <= hdr; nh <= nhdr;
                    total <= {3'd0, nhdr} + {1'b0, nrd};
                    b <= '0; st <= LEAD; cnt <= CW'(HALF - 1);
                end
                LEAD: if (cnt == '0) begin
                    st <= LOW; cnt <= CW'(HALF - 1); bitn <= '0;
                    sh_out <= tx_byte(6'd0, h, nh); mosi <= msb(tx_byte(6'd0, h, nh));
                end else cnt <= cnt - 1'b1;
                LOW: if (cnt == '0) begin
                    st <= HIGH; cnt <= CW'(HALF - 1); sck <= 1'b1;
                    sh_in <= {sh_in[6:0], miso};
                end else cnt <= cnt - 1'b1;
                HIGH: if (cnt == '0) begin
                    sck <= 1'b0; cnt <= CW'(HALF - 1);
                    if (bitn == 3'd7) begin
                        if (b >= {3'd0, nh}) begin rx_valid <= 1'b1; rx_byte <= sh_in; end
                        if (b + 1'b1 == total) begin
                            st <= TAIL; mosi <= 1'b0;
                        end else begin
                            b <= b + 1'b1; bitn <= '0; st <= LOW;
                            sh_out <= tx_byte(b + 1'b1, h, nh); mosi <= msb(tx_byte(b + 1'b1, h, nh));
                        end
                    end else begin
                        bitn <= bitn + 1'b1; st <= LOW;
                        sh_out <= {sh_out[6:0], 1'b0}; mosi <= sh_out[6];
                    end
                end else cnt <= cnt - 1'b1;
                TAIL: if (cnt == '0) begin st <= GAP; csn <= 1'b1; cnt <= CW'(4 * HALF - 1); end
                      else cnt <= cnt - 1'b1;
                GAP: if (cnt == '0) begin st <= IDLE; busy <= 1'b0; end else cnt <= cnt - 1'b1;
                default: st <= IDLE;
            endcase
        end
    end
endmodule

// sfdp_ctl.sv: on a start command, RDID (9Fh, 3 bytes) then RSFDP (5Ah,
// address 0, 8 dummy cycles, 16 bytes). The only opcodes are these two
// constants; no write, erase, register-write or reset command exists here.
module sfdp_ctl #(
    parameter int HALF = 10
) (
    input  logic        clk,
    input  logic        rst,
    input  logic        miso,
    output logic        sck,
    output logic        mosi,
    output logic        csn,
    input  logic [6:0]  win_addr,
    input  logic        win_wr,
    input  logic        win_rd,
    input  logic [31:0] win_wdata,
    output logic [31:0] win_rdata
);
    localparam logic [7:0] OP_RDID = 8'h9F, OP_RSFDP = 8'h5A;

    typedef enum logic [2:0] {IDLE, ID, ID_W, SF, SF_W} st_t;
    st_t st;

    logic         go, sbusy, rx_valid, busy, done, sig_ok;
    logic [31:0]  hdr;
    logic [2:0]   nhdr;
    logic [4:0]   nrd, ridx;
    logic [7:0]   rx_byte;
    logic [23:0]  id;
    logic [127:0] sf;

    sf_spi #(.HALF(HALF)) u_spi (
        .clk(clk), .rst(rst), .go(go), .hdr(hdr), .nhdr(nhdr), .nrd(nrd), .miso(miso),
        .sck(sck), .mosi(mosi), .csn(csn), .busy(sbusy), .rx_valid(rx_valid), .rx_byte(rx_byte));

    wire start = win_wr && win_addr == 7'h00 && win_wdata[0] && !busy;

    always_ff @(posedge clk) begin
        go <= 1'b0;
        if (rst) begin
            st <= IDLE; hdr <= '0; nhdr <= '0; nrd <= '0; ridx <= '0; busy <= 1'b0; done <= 1'b0; sig_ok <= 1'b0;
            id <= '0; sf <= '0;
        end else begin
            case (st)
                IDLE: if (start) begin busy <= 1'b1; done <= 1'b0; sig_ok <= 1'b0; st <= ID; end
                ID: if (!sbusy) begin
                    hdr <= {OP_RDID, 24'h0}; nhdr <= 3'd1; nrd <= 5'd3; go <= 1'b1; ridx <= '0; st <= ID_W;
                end
                ID_W: begin
                    if (rx_valid) id <= {id[15:0], rx_byte};
                    if (!go && !sbusy) st <= SF;
                end
                SF: begin
                    hdr <= {OP_RSFDP, 24'h000000}; nhdr <= 3'd4; nrd <= 5'd17; go <= 1'b1; ridx <= '0; st <= SF_W;
                end
                SF_W: begin
                    if (rx_valid) begin
                        ridx <= ridx + 1'b1;
                        if (ridx != 5'd0) sf <= {rx_byte, sf[127:8]};      // byte 0 ends in [7:0]
                    end
                    if (!go && !sbusy) begin
                        st <= IDLE; busy <= 1'b0; done <= 1'b1;
                        sig_ok <= sf[31:0] == 32'h5044_4653;
                    end
                end
                default: st <= IDLE;
            endcase
        end
    end

    always_ff @(posedge clk) begin
        if (rst) win_rdata <= '0;
        else if (win_rd) begin
            case (win_addr)
                7'h01:   win_rdata <= {29'd0, sig_ok, done, busy};
                7'h02:   win_rdata <= {8'd0, id};
                7'h03:   win_rdata <= sf[31:0];
                7'h04:   win_rdata <= sf[63:32];
                7'h05:   win_rdata <= sf[95:64];
                7'h06:   win_rdata <= sf[127:96];
                default: win_rdata <= '0;
            endcase
        end
    end
endmodule

// t2_qspi_sfdp_top.sv: board top (Nexys A7-100T, master-XDC port names).
// Reference design for benchmark task t2_qspi_sfdp; DESIGN_ID "SFDP".
// Reads the configuration flash's JEDEC ID and SFDP header. SCK leaves through
// STARTUPE2 USRCCLKO; WP# (DQ2) low, HOLD# (DQ3) high; single-bit SPI mode 0.
module t2_qspi_sfdp_top #(
    parameter int          CLKS_PER_BIT   = 868,
    parameter int          TIMEOUT_CYCLES = 100_000,
    parameter int          HALF           = 10,
    parameter logic [31:0] BUILD_STAMP    = 32'h0
) (
    input  logic CLK100MHZ,
    input  logic CPU_RESETN,
    output logic QSPI_CSN,
    output logic QSPI_DQ0,
    input  logic QSPI_DQ1,
    output logic QSPI_DQ2,
    output logic QSPI_DQ3,
    input  logic UART_TXD_IN,
    output logic UART_RXD_OUT
);
    logic        clk, rst, win_wr, win_rd, miso, sck;
    logic [6:0]  win_addr;
    logic [31:0] win_wdata, win_rdata;

    assign clk = CLK100MHZ;
    reset_sync u_rst (.clk(clk), .rst_n_async(CPU_RESETN), .rst(rst));

    fpga_shell #(.CLKS_PER_BIT(CLKS_PER_BIT), .TIMEOUT_CYCLES(TIMEOUT_CYCLES),
                 .DESIGN_ID(32'h5346_4450), .BUILD_STAMP(BUILD_STAMP)) u_shell (
        .clk(clk), .rst(rst), .uart_rx(UART_TXD_IN), .uart_tx(UART_RXD_OUT),
        .win_addr(win_addr), .win_wr(win_wr), .win_rd(win_rd), .win_wdata(win_wdata), .win_rdata(win_rdata));

    sync2 u_sync (.clk(clk), .rst(rst), .d(QSPI_DQ1), .q(miso));

    assign QSPI_DQ2 = 1'b0;
    assign QSPI_DQ3 = 1'b1;

    sfdp_ctl #(.HALF(HALF)) u_ctl (
        .clk(clk), .rst(rst), .miso(miso), .sck(sck), .mosi(QSPI_DQ0), .csn(QSPI_CSN),
        .win_addr(win_addr), .win_wr(win_wr), .win_rd(win_rd), .win_wdata(win_wdata), .win_rdata(win_rdata));

    /* verilator lint_off UNUSEDSIGNAL */
    logic cfgclk_nc, cfgmclk_nc, eos_nc, preq_nc;
    /* verilator lint_on UNUSEDSIGNAL */
    STARTUPE2 #(.PROG_USR("FALSE"), .SIM_CCLK_FREQ(0.0)) u_startup (
        .CFGCLK(cfgclk_nc), .CFGMCLK(cfgmclk_nc), .EOS(eos_nc), .PREQ(preq_nc),
        .CLK(1'b0), .GSR(1'b0), .GTS(1'b0), .KEYCLEARB(1'b1), .PACK(1'b0),
        .USRCCLKO(sck), .USRCCLKTS(1'b0), .USRDONEO(1'b1), .USRDONETS(1'b1));
endmodule

"""Acceptance tests of t2_qspi_sfdp against model.py (hidden from the agent)."""

from __future__ import annotations

import random

import cocotb
from benchmark.lib.bench import Board
from flash_model import IDENT, SFDP_TABLE, Flash
from model import BUSY, CTRL, DESIGN_ID, ID, SFDP0, STATUS, Model


class Env:
    def __init__(self, dut) -> None:
        self.b = Board(dut, {"QSPI_DQ1": 0})
        self.dut, self.m = dut, Model()
        self.half = self.b.param("HALF")

    async def start(self, ident: bytes = IDENT, sfdp: bytes = SFDP_TABLE) -> None:
        await self.b.start()
        self.f = Flash(self.dut, ident, sfdp)
        self.ident, self.sfdp = ident, sfdp

    async def regs(self) -> None:
        for off, name in ((STATUS, "STATUS"), (ID, "ID"), (SFDP0, "SFDP0"), (SFDP0 + 1, "SFDP1"),
                          (SFDP0 + 2, "SFDP2"), (SFDP0 + 3, "SFDP3")):
            await self.b.expect(off, self.m.read(off), name)

    def check_tx(self, want: list[tuple[list[int], int]]) -> None:
        """Opcode and address bytes exactly, byte count exactly; DQ0 during dummy and read bytes is free."""
        got = self.f.transactions
        assert len(got) == len(want), f"{len(got)} transactions, model {len(want)}"
        for g, (fixed, n) in zip(got, want):
            assert len(g) == n, f"transaction of {len(g)} bytes {g}, model {n}"
            assert g[:len(fixed)] == fixed, f"opcode/address bytes {g[:len(fixed)]}, model {fixed}"

    async def run(self) -> list[tuple[list[int], int]]:
        await self.b.write(CTRL, 1)
        want = self.m.start(self.ident, self.sfdp)
        await self.b.cycles(30 * 16 * self.half + 400)
        return want

    def check_flash(self) -> None:
        f = self.f
        assert f.bad_opcodes == [], f"forbidden opcodes sent to the flash: {[hex(o) for o in f.bad_opcodes]}"
        assert not f.wp_hold_bad, "WP# (DQ2) left 0 or HOLD# (DQ3) left 1"
        assert not f.halves or min(f.halves) >= self.half, f"SCK half period {min(f.halves)} < HALF {self.half}"


@cocotb.test(timeout_time=1244260, timeout_unit="ns")
async def test_identity_and_reset(dut):
    e = Env(dut)
    await e.start()
    assert await e.b.shell_id() == DESIGN_ID
    await e.regs()
    for off in (CTRL, 0x07, 0x7F):
        await e.b.expect(off, 0, "unmapped / write-only")
    assert e.f.transactions == [], "flash traffic before the start command"
    assert e.f.idle_cycles >= 3, f"only {e.f.idle_cycles} SCK cycles with CS high after reset (STARTUPE2 drops 3)"
    e.check_flash()


@cocotb.test(timeout_time=1255880, timeout_unit="ns")
async def test_jedec_id_and_sfdp(dut):
    e = Env(dut)
    await e.start()
    want = await e.run()
    e.check_tx(want)
    await e.regs()
    assert e.m.sig
    e.check_flash()


@cocotb.test(timeout_time=1255880, timeout_unit="ns")
async def test_bad_signature(dut):
    e = Env(dut)
    await e.start(sfdp=bytes([0xFF] * 4) + SFDP_TABLE[4:])      # an erased or non-SFDP part
    await e.run()
    await e.regs()
    assert not e.m.sig
    e.check_flash()


@cocotb.test(timeout_time=1552200, timeout_unit="ns")
async def test_busy_and_repeat(dut):
    e = Env(dut)
    await e.start()
    await e.b.write(CTRL, 1)
    e.m.start(e.ident, e.sfdp)
    st = await e.b.read(STATUS)
    assert st == BUSY, f"STATUS 0x{st:X} during the reads, model BUSY only"
    await e.b.write(CTRL, 1)                                  # ignored while busy
    await e.b.cycles(30 * 16 * e.half)
    await e.regs()
    assert len(e.f.transactions) == 2, f"{len(e.f.transactions)} transactions; a start while busy was not ignored"
    e.f.ident = bytes([0x01, 0x02, 0x19]) + IDENT[3:]        # another part answers the second time
    e.ident = e.f.ident
    await e.run()
    await e.regs()
    assert len(e.f.transactions) == 4
    e.check_flash()

"""Golden model of t2_qspi_sfdp, written from spec.yaml alone (never from any RTL)."""

from __future__ import annotations

DESIGN_ID = 0x53464450
CTRL, STATUS, ID, SFDP0 = 0, 1, 2, 3
BUSY, DONE, SIG_OK = 1, 2, 4


class Model:
    def __init__(self) -> None:
        self.id = 0
        self.words = [0, 0, 0, 0]
        self.done = self.sig = False

    def start(self, ident: bytes, sfdp: bytes) -> list[tuple[list[int], int]]:
        """Returns, per transaction, the MOSI bytes the spec fixes (opcode, address) and the byte count. DQ0 during
        the dummy and read bytes is a don't-care (v1.2)."""
        self.id = ident[0] << 16 | ident[1] << 8 | ident[2]
        self.words = [int.from_bytes(sfdp[4 * i:4 * i + 4], "little") for i in range(4)]
        self.done = True
        self.sig = self.words[0] == 0x50444653
        return [([0x9F], 4), ([0x5A, 0, 0, 0], 21)]

    def read(self, off: int) -> int:
        if off == STATUS:
            return (DONE if self.done else 0) | (SIG_OK if self.sig else 0)
        if off == ID:
            return self.id
        if SFDP0 <= off < SFDP0 + 4:
            return self.words[off - SFDP0]
        return 0
