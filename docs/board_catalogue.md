# Board catalogue and trust labels

Generated by `python3 flow/board_catalogue.py table --write`; do not edit by hand. A test fails if this file is stale.

What each label means (computed from evidence on disk, never declared above it):

- **documented**: the board file exists in `boards/<board>/` and every fact in it cites a source or says it is unconfirmed and why. Nothing was built or run.
- **built**: a generated smoke design (clock, LEDs, a button or switch, the UART where the board has a PL UART) went through post-route and the bitstream on that part with the board's own constraints, with DRC and methodology clean. The record is `results/95_boards/<board>/smoke.json`. Nothing was run on a board.
- **hardware**: run on a real board that the owner has, with run records in the repository. The scope column says what those runs covered.

Licence tier: `free` means the installed Vivado licence (Basic tier, 2026.1) implements the part, as the probe or a build shows; `paid` means it does not, so the board is listed and documented but its flow stops at synthesis. Targetable: the agent can write the board's constraints from its resource names; `no` means the board has no PL clock or no usable pin list yet (see the board's known gaps).
