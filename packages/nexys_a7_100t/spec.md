# Nexys A7-100T package: a design for Digilent's Nexys A7-100T

The user's words (brief 174 pilot): a design that targets the Digilent Nexys A7-100T (`xc7a100tcsg324-1`). The board is finished and
cannot change. Its pins, I/O standards and clock come from Digilent's published master XDC in `board/`; the schematic and the reference
manual are not in the package yet (Digilent's server refuses automated downloads: see "Files for the owner to save" in
docs/design_package.md), so the PHY, oscillator and memory part numbers are not extracted and the interview must ask for them.
