Requirements in full

SQRT-F-MODEL: The model is the specification: it equals integer arithmetic

For the integer square root: the root and remainder equal math.isqrt for every radicand at W = 3 to 14 and for random values at W up to 200, the restoring and non-restoring recurrences equal the root step by step, and the non-restoring remainder stays in [-(2q+1), 2q].

  • simulation test: pass Model tests against Python integer arithmetic: 5 test(s) passed in the recorded run evidence

SQRT-F-RTL-EXH: Every variant is bit-exact against the model, exhaustively at small widths

Simulation (Icarus 14) of every variant against the model: every radicand at W = 3 to 16 (odd and even), every variant, with input gaps; root, remainder, order and latency checked.

  • simulation test: pass Exhaustive small widths, every variant: 1 test(s) passed in the recorded run evidence

SQRT-F-RTL-RAND: Every variant is bit-exact against the model at large widths

Simulation of every variant against the model: 3000 random and near-square values (remainders 0 and 2 * root) at W = 24, 31, 32, 48 and 64.

  • simulation test: pass Random and edge vectors at large widths: 1 test(s) passed in the recorded run evidence

SQRT-F-LAT: Latency and throughput are what the spec states

The measured latency equals the spec's formula (RW + 1 and ceil(RW / PIPE)) for PIPE = 1 to 6 at W = 11 (RW = 6), one result per clock for the pipelines.

  • simulation test: pass Latency measured per result: 1 test(s) passed in the recorded run evidence

SQRT-F-LINT: The RTL is Verilator -Wall clean

Verilator -Wall --lint-only reports nothing for any variant at W = 3, 4, 8, 13 and 32 with PIPE = 1, 3 and 40.

  • simulation test: pass Verilator -Wall lint: 1 test(s) passed in the recorded run evidence

SQRT-F-MUTANT: The bench catches seeded faults

Each of 16 seeded faults (one text change in the RTL, verif/mutants.yaml) makes the bench fail: killed/total = 16/16.

  • simulation test: pass The mutant check passes: 1 test(s) passed in the recorded run evidence
  • simulation measurement: pass Mutants killed / total: mutants_summary.killed = 16; mutants_summary.survived = 0 evidence

SQRT-F-FORMAL-REF: Every variant equals an independent reference (SymbiYosys)

SymbiYosys with the slang front end: each variant satisfies root^2 + rem = x and rem <= 2 * root (so root^2 <= x < (root+1)^2) for all input sequences from reset: 12 jobs at W = 6 to 10; unbounded (abc pdr). Six seeded faults are applied to the RTL and the same proof fails (bounded model checking finds the counterexample), which shows the harness is not vacuous.

  • simulation test: pass The formal reference and fault-catching tests pass: 2 test(s) passed in the recorded run evidence
  • formal: pass Reference proofs: jobs proved unbounded, none failed: summary.reference.proved_unbounded = 12; summary.reference.failed = 0 evidence
  • formal: bounded Six seeded faults each make the proof fail (bounded model checking): summary.mutant.faults_caught = 6; summary.mutant.failed = 0 evidence

SQRT-F-FORMAL-PAIR: Variants of the function agree with each other (SymbiYosys)

SymbiYosys with the slang front end, no reference involved: the restoring and non-restoring pipelines give the same output on the same inputs, W = 6, 8, 9; unbounded (abc pdr).

  • simulation test: pass The variant-pair tests pass: 1 test(s) passed in the recorded run evidence
  • formal: pass Variant pairs proved equal, none failed: summary.pair.proved_unbounded = 3; summary.pair.failed = 0 evidence

SQRT-F-LEAN-RESTORING: Restoring square root is correct for every width (Lean)

The restoring digit recurrence of isqrt_restoring_*.sv yields root and rem with root^2 + rem = x and rem <= 2 * root for every width, which determines the floor square root. Proved in Lean, statement not approved; the Lean text is a transcription of the RTL's step, cross-checked against the Python model for up to 10-bit radicands; register widths are not modelled. The non-restoring recurrence is not proved (spec.md).

  • Lean proof (all widths): statement not approved The restoring recurrence is a floor square root: root^2 + rem = x and rem <= 2 * root, every width: statement not approved; Arith.Isqrt.rsqrt_correct: kernel only; proof of the transcription, transcription tested; recorded build (not re-run) evidence

SQRT-F-BUILD: Out-of-context build descriptions are prepared for Artix-7 and K26 (prepared in brief 139b, run in brief 160)

For every variant of the integer square root there is a build.yaml and an out-of-context clock constraint for xc7a100t and xck26, current against arith/tools/gen_build.py, consistent with the RTL (top, parameters, sources), with the expected primitive use evaluated for each point; the out-of-context wrapper lints clean and is functionally exact for the always-ready variants; the packaged verification harness (harness/run.py, which a user reruns against their own instance) passes on the library instance with every coverage bin hit. This requirement is about preparation; the measured area, Fmax and power are in the brief 160 records.

  • simulation test: pass Build descriptions current and consistent; wrapper lint and simulation; packaged harness runs on the library instance: 3 test(s) passed in the recorded run evidence

Each point of the build files of isqrt (build/<variant>/build.yaml; 24 in all, both parts) goes through Vivado 2026.1 out-of-context synthesis, placement and routing and leaves a recorded result (utilisation, WNS, WHS, Fmax, logic levels, vectorless power) in verif/results/vivado_ooc_<variant>_<part>.json.
