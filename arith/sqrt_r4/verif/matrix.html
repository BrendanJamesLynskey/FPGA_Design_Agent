Requirements in full

SQRT4-F-MODEL: The model is the specification: it equals integer arithmetic

For the radix-4 integer square root: the root and remainder equal math.isqrt for every radicand at W = 5 to 14 and for random values at W up to 200, are the same pairs and packing as arith/isqrt, and the radix-4 recurrence equals the root step by step with the register widths of the RTL asserted at every step (sh below 2**(QW+3), the three trial values below it, rem <= 2q).

  • simulation test: pass Model tests against exact arithmetic: 6 test(s) passed in the recorded run evidence

SQRT4-F-RTL-EXH: Every variant is bit-exact against the model, exhaustively at small widths

Simulation (Icarus 14) of both variants against the model: every radicand at W = 5 to 16 (odd and even), with input gaps; root, remainder, order and latency checked.

  • simulation test: pass Every variant is bit-exact against the model, exhaustively at small widths: 1 test(s) passed in the recorded run evidence

SQRT4-F-RTL-RAND: Every variant is bit-exact against the model at large widths

Simulation of both variants against the model with 3000 random and near-square values (remainders 0 and 2 * root) at W = 24, 31, 32, 48 and 64.

  • simulation test: pass Every variant is bit-exact against the model at large widths: 1 test(s) passed in the recorded run evidence

SQRT4-F-LAT: Latency and throughput are what the spec states

The measured latency equals the spec formula (RP + 1 and ceil(RP / PIPE), RP = ceil(RW / 2)) for PIPE = 1 to 5 at W = 13 (RP = 4) and PIPE = 3 and 4 at W = 24, one result per clock for the pipeline.

  • simulation test: pass Latency measured per result: 1 test(s) passed in the recorded run evidence

SQRT4-F-LINT: The RTL is Verilator -Wall clean

Verilator -Wall --lint-only reports nothing for either variant at W = 5, 6, 8, 13, 32 and 64 with PIPE = 1, 2 and 40.

  • simulation test: pass Verilator -Wall lint: 1 test(s) passed in the recorded run evidence

SQRT4-F-FORMAL-REF: Every variant equals an independent reference (SymbiYosys)

SymbiYosys with the slang front end: each variant satisfies root^2 + rem = x and rem <= 2 * root (so root^2 <= x < (root+1)^2) for all input sequences from reset: 11 jobs at W = 6 to 14; unbounded (abc pdr). 6 seeded faults are applied to the RTL and the same proof fails (bounded model checking finds the counterexample), which shows the harness is not vacuous.

  • simulation test: pass The formal reference and fault-catching tests pass: 2 test(s) passed in the recorded run evidence
  • formal: pass Reference proofs: jobs proved unbounded, none failed: summary.reference.proved_unbounded = 11; summary.reference.failed = 0 evidence
  • formal: bounded 6 seeded faults each make the proof fail (bounded model checking): summary.mutant.faults_caught = 6; summary.mutant.failed = 0 evidence

SQRT4-F-FORMAL-ISQRT: The radix-4 pipeline agrees with the radix-2 pipeline of arith/isqrt (SymbiYosys)

SymbiYosys with the slang front end, no reference involved: sqrt_r4's pipeline and arith/isqrt's restoring pipeline (a different digit recurrence, written for the same specification, at its own latency, the shorter one delayed) give the same output on the same inputs, W = 8, 10, 12; unbounded (abc pdr): 3 jobs.

  • simulation test: pass The variant-pair tests pass: 1 test(s) passed in the recorded run evidence
  • formal: pass Pipelines proved equal across the two functions, none failed: summary.pair.proved_unbounded = 3; summary.pair.failed = 0 evidence

SQRT4-F-LEAN-RECURRENCE: The radix-4 recurrence is a floor square root for every width (Lean)

The radix-4 digit recurrence of sqrt_r4_iter.sv and sqrt_r4_pipe.sv yields root and rem with root^2 + rem = x and rem <= 2 * root for every number of steps, which determines the floor square root. Proved in Lean, statement not approved; the Lean text is a transcription of the RTL's step, cross-checked against the Python model for every 8-bit radicand and every 17th 12-bit radicand; register widths are not modelled.

  • Lean proof (all widths): statement not approved The radix-4 recurrence is a floor square root: root^2 + rem = x and rem <= 2 * root, every width: statement not approved; Arith.SqrtR4.r4sqrt_correct: kernel only; proof of the transcription, transcription tested; recorded build (not re-run) evidence
