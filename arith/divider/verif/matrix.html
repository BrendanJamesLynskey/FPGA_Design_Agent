DIV-F-MODEL: The model is the specification: it equals integer arithmetic

For the divider: the quotient and remainder equal Python integer division for every pair at W = 1 to 8 and for random pairs at W up to 128, division by zero gives all ones and n, and the restoring and non-restoring recurrences equal division step by step with the RTL's register widths.

  • simulation test: pass Model tests against Python integer arithmetic: 6 test(s) passed in the recorded run evidence

DIV-F-RTL-EXH: Every variant is bit-exact against the model, exhaustively at small widths

Simulation (Icarus 14) of every variant against the model: every operand pair at W = 2 to 8 (65536 pairs at W = 8), with input gaps; quotient, remainder, order and latency checked.

  • simulation test: pass Exhaustive small widths, every variant: 1 test(s) passed in the recorded run evidence

DIV-F-RTL-RAND: Every variant is bit-exact against the model at large widths

Simulation of every variant against the model: edge-value pairs plus 3000 random pairs (divisors of every magnitude) at W = 16, 24, 32 and 64.

  • simulation test: pass Random and edge vectors at large widths: 1 test(s) passed in the recorded run evidence

DIV-F-LAT: Latency and throughput are what the spec states

The measured latency of every result equals the spec's formula (W + 1, W + 2, ceil(W / PIPE)) for PIPE = 1 to 7 at W = 7, and a pipeline accepts an input on every clock.

  • simulation test: pass Latency measured per result: 2 test(s) passed in the recorded run evidence

DIV-F-LEAN-RESTORING: Restoring division is correct for every width (Lean)

The restoring recurrence of div_restoring_*.sv computes n / d and n % d for every width, and for d = 0 returns all ones and n. Proved for all widths in Lean, statement not approved; the Lean text is a transcription of the RTL's step, cross-checked against the Python model for W <= 5; register widths are not modelled.

  • Lean proof (all widths): statement not approved Restoring division equals Nat.div and Nat.mod, every width: statement not approved; Arith.Divide.restDiv_correct: kernel only; proof of the transcription, transcription tested; recorded build (not re-run) evidence
  • Lean proof (all widths): statement not approved Restoring division by zero returns all ones and the dividend, every width: statement not approved; Arith.Divide.restDiv_zero: kernel only; proof of the transcription, transcription tested; recorded build (not re-run) evidence

DIV-F-LEAN-NONRESTORING: Non-restoring division with correction is correct for every width (Lean)

The non-restoring recurrence of div_nonrestoring_*.sv, with its final correction, computes n / d and n % d for every width and d > 0 (invariant: a non-negative partial remainder is n - d*Q, a negative one n - d*(Q+1), always in [-d, d)). Proved in Lean, statement not approved; division by zero is not part of this theorem (covered by simulation and the formal reference).

  • Lean proof (all widths): statement not approved Non-restoring division with its final correction equals Nat.div and Nat.mod, every width: statement not approved; Arith.Divide.nr_correct: kernel only; proof of the transcription, transcription tested; recorded build (not re-run) evidence
