RECIP-F-LEAN-NEWTON: The exact Newton reciprocal step squares the residual and never overshoots (Lean)

For all integers S (the scale of 1.0), b and y: S*S - b*(y*(2S - b*y)) = (S - b*y)**2, hence b*y1 <= S*S: the exact Newton-Raphson reciprocal step squares the relative error and never exceeds the exact reciprocal. Proved in Lean, statements not approved; the truncations of the RTL (floor at every shift, two guard bits) and the seed table's accuracy are not in Lean (they are measured and proved at fixed widths by SymbiYosys).

  • Lean proof (all widths): not run The Newton reciprocal step squares the residual: S*S - b*y1 = (S - b*y)**2, every integer value: no recorded build for this theorem; run `python -m flow.trace_v1 lean-record`
  • Lean proof (all widths): not run The exact Newton reciprocal step never overshoots: b*y1 <= S*S: no recorded build for this theorem; run `python -m flow.trace_v1 lean-record`
