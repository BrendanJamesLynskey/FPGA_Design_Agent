Requirements in full

FAXIS-F-MODEL: The bit-exact model is right

arith/fft_axis/model.py gives, for every input, the result that spec.md defines. It agrees with an independent formulation (the wrapped variants' own models (arith/fft/model.py) and the packing of {imaginary, real} words), and the conventions that a user could guess wrong (spec.md, last section) are pinned by examples.

  • simulation test: pass The model against independent formulations and the pinned conventions: 2 test(s) passed in the recorded run evidence

FAXIS-F-EXACT: Every variant is bit-exact against the model

At every parameter point listed in spec.yaml (6 directed or exhaustive points, 4 random ones, across 2 variants), each variant's outputs equal the model's: the directed points send the FFT bench's frames as AXI4-Stream beats with no pauses (the first-beat latency equals the formula); the random points send random frames, the burst variant with random tvalid pauses inside and between frames and a sink that stalls 40 per cent of the clocks, the sdf variant with the legal gaps. Every output frame equals the model bit for bit, tlast is on the right beat, and the protocol checkers (valid stability, data stability, no unknowns, tlast position, no stall for sdf, no pause inside a frame for sdf) count no error.

  • simulation test: pass Every variant against the model at the small points (Icarus + cocotb): directed or exhaustive stimuli: 6 test(s) passed in the recorded run evidence
  • simulation test: pass Every variant against the model at the large points: random stimuli (Icarus + cocotb): 4 test(s) passed in the recorded run evidence

FAXIS-F-LAT: Latency is as specified and the bench would notice if it were not

Each variant's latency in clocks is the expression in spec.yaml (sdf: (1<<LOGN)-1+LOGN+((LOGN-1)//2)*(TWSTAGES+MULSTAGES+1)+(0 if ORDER else (1<<LOGN)+1); burst: (1<<LOGN)+LOGN*((1<<LOGN)//2+MULSTAGES+3)+1), and the bench, run with a latency two clocks off, fails for every variant, so the passing runs prove the latency rather than assume it.

  • simulation test: pass The bench passes at the stated latency and fails two clocks off, for every variant: 2 test(s) passed in the recorded run evidence

FAXIS-F-BENCH: The bench catches seeded faults

Every one of the mutants in verif/mutants.yaml (one exact text change each: an inverted condition, a wrong constant, a dropped connection, a wrong width) makes the cocotb bench fail, or is argued equivalent in the file's header; mutants that survive or do not build are reported, never hidden.

  • simulation test: pass The mutation run as a test: no mutant survives, none fails to build: 1 test(s) passed in the recorded run evidence
  • simulation measurement: stale Mutants killed of valid mutants (the record of the last full run): survived = []; invalid = []; valid = 13; score_pct = 100 evidence

FAXIS-F-PACKAGE: The RTL is lint-clean, and its files agree with the specification and with the Vivado build files

spec.yaml states an interface contract (protocol, throughput, latency, reset, clock, stalls) and integration guidance (port timing, constraints to carry). Every variant passes Verilator -Wall at every point of spec.yaml; its ports and default parameters are the ones spec.yaml states; its header states the intended primitive use before any Vivado run; spec.md is the rendering of spec.yaml; the out-of-context wrapper and the build.yaml for each variant (Artix-7 xc7a100t and K26 xck26, prepared and not run) are current and lint-clean at every point they list, so a Vivado run can start from the repository alone.

  • simulation test: stale spec.yaml against the RTL headers, spec.md against spec.yaml, Verilator -Wall at every point, wrappers and build.yaml current and lint-clean: 5 test(s) passed in the recorded run evidence

FAXIS-F-AXIS: The AXI4-Stream handshake rules hold, and the checkers can fail

On both streams of both variants the wrapper's SystemVerilog protocol checkers (fft_common/axis_checker.sv: valid stays high until accepted, tdata and tlast stable while stalled, no unknowns after reset, tlast on every N-th beat, no stall on the streaming variant, no pause inside a frame where the variant forbids it) count zero violations in every run of the directed and random benches, which stall the burst variant's sink and pause its source at random; tvalid is registered and independent of tready by construction (a mutant that makes it depend on tready is killed by the valid-stability rule). A deliberate-violation test shows each checker can fail. The back-pressure of each variant is stated in spec.yaml (sdf none, burst full).

  • simulation test: pass Every variant against the model at the large points: random stimuli (Icarus + cocotb): 4 test(s) passed in the recorded run evidence
  • simulation test: pass The protocol checkers can fail (a stalled sink on sdf, a withdrawn tvalid on burst): 2 test(s) passed in the recorded run evidence
