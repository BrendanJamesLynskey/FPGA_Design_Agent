SYNTHETIC. This capture comes from an offline model (flow/eyescan/fake.py), not from a board. It is not a measurement.
What this eye is. The GTH receiver compares a second, offset sampler with its data sampler after the equaliser (LPM or DFE). The plot is a statistical eye of the margin inside the receiver, built from the transceiver's own error counters. It is not the eye a scope would show at the pins. Each point examined a stated number of bits; a point with no errors only says its BER is below 3/bits, so a depth deeper than a point's bits can vouch for is shown hatched, not open.

How to read the numbers

Bits per point = samples x 2^(1+prescale) x 32; BER = errors / bits. Width is the span of open points along the row nearest 0 mV; height is the span along the column nearest 0 UI, converted with UG576's nominal mV per code. Both carry one grid step of uncertainty. The scan runs deeper only where a point shows no errors, so the number of bits differs from point to point.
