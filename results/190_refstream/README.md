# 190_refstream: order-table refusals on a realistic reference stream

This folder holds the measurements made by brief 190 (item 18) on how many order-table slots a live order count needs, and on whether giving each
reference two candidate slots is worth it. They come from Python models of the placement rule only, run on the synthetic reference stream of
`designs/b110_itch_ouch/model/refstream.py` (seeded; the gap between our references, the lifetime tail and the share of orders that never end are
parameters). The idea of sizing against the birthday bound and of bounded two-slot lookups is from Edwards 2026, ch 7; the derivation and the code are ours.

## Records

- `results.md`: generated by `designs/b110_itch_ouch/scripts/refstream_measure.py`. Refused adds, percent, for one candidate slot and for two, at four
  table sizes, for three reference modes (sequential with sparse gaps, sequential dense, random), over seeds 1 to 5; the closed-form birthday bound
  against a random-trial simulation; the slots needed for a chance of any collision.

## Reproduce

```bash
python3 -m designs.b110_itch_ouch.scripts.refstream_measure      # about 5 s, no heavy slot, no hardware
python3 -m pytest -q designs/b110_itch_ouch/tests/test_b190_refstream.py
```

The knowledge-bank skill `table-sizing-and-bounded-lookup` (private repository) states the rules and quotes these numbers.

## Known gaps and limits

- Models of the rule only: no RTL, no synthesis, no board. The RTL's own refusal counter (`oovf` in b110) is the real measurement, and b110's order
  table is still direct mapped; this brief did not change it.
- The stream is synthetic. Its shape (a heavy-tailed lifetime, a small share of orders that never end, sparse references) follows the argument that
  tidy test streams hide collisions; no real exchange data was used, and its parameters were chosen, not fitted to any venue.
- Two candidate slots here never move a resident item (no cuckoo-style relocation); relocation would lower the figures and is not measured.
- A second bank costs LUTs, RAM and possibly clock rate; none of that is measured here.
- A first draft scattered references by multiplying by an odd constant and measured the same refusals as the plain counter: an odd multiplier does
  not change which low-bit indices collide. The random mode replaced it; a test records the reason.
