# results/19_ipgen: worked examples of external design tools driving AMD IP (brief 19)

Each directory is one run of `python3 -m flow.ipgen.run <adapter> <dir>/spec.yaml <dir>` (Vivado 2025.2, xc7a100tcsg324-1). The Vivado work
directory (`work/`) and the Tcl configuration are regenerated by the runner and are not committed. Every number in
[docs/ipgen.md](../../docs/ipgen.md) and in the report comes from a file here.

| File | What it is |
|---|---|
| `spec.yaml` | the plain-number specification |
| `design.json` | the Python design tool's result (method, taps, floating-point and quantised response, attenuation lost to quantisation) |
| `fir.coe`, `table.coe`, `response.csv`, `table.csv` | the data the IP reads, and the plot data of the designed response |
| `readback.json` | what the IP reported after `create_ip` and `generate_target`: `CONFIG.*` values, generated model parameters (latency, multiply-accumulates, widths), and the Python tool's prediction |
| `sim.json` | the xsim comparison: match or mismatch per schedule, decimation phase, latency, widths |
| `stimulus.txt`, `xsim_output.txt` / `xsim_output.hex` | the input and the IP's output of the random-gap run; `flow/ipgen/tests/test_19_results.py` recomputes the golden from them |
| `ooc.json` | out-of-context synthesis: LUTs, registers, DSP, BRAM tiles, post-synthesis WNS and the Fmax estimate (an upper bound: no routing) |

| Directory | Adapter | Example |
|---|---|---|
| `fir/` | FIR Compiler 7.2 | decimate-by-4 low-pass for a 20 MS/s stream: 1.0 MHz pass band, 1.5 MHz stop band, 0.1 dB ripple, 80 dB |
| `cic/` | CIC Compiler 4.0 | the PDM microphone decimator, 2.4 MS/s to 96 kS/s |
| `chain_fir/` | FIR Compiler 7.2 | the compensating FIR behind the CIC, 96 kS/s to 48 kS/s |
| `bmg_sine/` | Block Memory Generator 8.4 | a 1024 x 16 sine ROM |
| `dds/`, `dds_no_margin/`, `dds_coherent/` | DDS Compiler 6.0 | a 34-bit-phase NCO: with a 3 dB design margin, without, and with a coherent tone |
| `chain/` | (the chain model) | `chain.yaml`, `chain.svg` (the block diagram), `chain_results.json`, `output_spectrum.csv` |
