# A pulse stretcher (a deliberately vague request)

*Written as a user would write it, for a Nexys A7-100T on my desk.*

I want a small block that stretches a button press. When I press the centre button, LED 0 should light for a while and then go out.
If I press again while it is lit, it should stay lit a bit longer. "A while" is about half a second. The button is noisy.
I would like to be able to read from the host whether the LED is lit.
