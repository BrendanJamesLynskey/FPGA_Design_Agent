Use the 74.25 MHz pixel clock to generate CEA-861 720p60 raster timing and a stream containing RGB, positive
horizontal and vertical sync, active-picture indication, and pixel-clock-stable indication. Generate eight
160-pixel vertical bars in the specified order by default. Provide the one-pixel checkerboard as the other
selectable pattern. The STATUS register is read-only, has reset value zero, and is exposed through the shell window.
